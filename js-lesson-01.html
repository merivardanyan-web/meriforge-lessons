JavaScript-ի առաջին քայլերը

Այսօր բրաուզերին սովորեցնում ենք մտածել։ Կսովորենք գրել առաջին կոդը, պահել տվյալները փոփոխականների մեջ և հասկանալ, թե ինչ տիպի տվյալների հետ ենք գործ ունենում։

Նախապայման՝ HTML + CSS Բլոկ 1 · Լեզվի հիմքերը Տնային՝ 8 առաջադրանք

00Ի՞նչ ենք սովորելու այսօր

  • Ի՞նչ է JavaScript-ը և ինչո՞ւ է այն պետք
  • Ինչպե՞ս բացել բրաուզերի Console-ը և գրել առաջին տողը
  • Ինչպե՞ս JS ֆայլը միացնել HTML-ին
  • Փոփոխականներ՝ let, const, var
  • Տվյալների տիպերը՝ տեքստ, թիվ, ճշմարիտ/կեղծ
  • Ինչպես տեքստերը միացնել իրար և ինչ է `${}`-ը
  • Ինչո՞ւ "5" + 3-ը հավասար չէ 8-ի 🙂

01Ի՞նչ է JavaScript-ը

Պատկերացրու մարդուն։

  • HTML-ը կմախքն է՝ ոսկորները։ Այն ասում է՝ այստեղ գլուխ կա, այստեղ՝ ձեռք։
  • CSS-ը հագուստն ու արտաքինն է՝ գույնը, հասակը, ձևը։
  • JavaScript-ը շարժումն ու ուղեղն է։ Ձեռքը բարձրացնելը, աչքով անելը, մտածելը՝ «եթե անձրև է, հովանոց վերցնեմ»։

HTML-ով և CSS-ով դու սարքեցիր գեղեցիկ, բայց անշարժ կայք։ Կոճակը կա, բայց սեղմելիս ոչինչ չի լինում։ JavaScript-ը հենց այն լեզուն է, որով կոճակին ասում ենք՝ «քեզ սեղմեցին — բացիր մենյուն»։

Կարևոր

JavaScript-ը և Java-ն տարբեր լեզուներ են։ Ինչպես «կատու» և «կատվաձուկ»։ Անունը պատմական մարքեթինգային հնարք է եղել 1995 թվականին։

Ի՞նչ կարող ենք անել JS-ով

  • Բացել/փակել մենյուն, մոդալ պատուհանը, ակորդեոնը
  • Ստուգել ֆորմը՝ «էլ. հասցեն սխալ է»
  • Սերվերից տվյալներ բերել և ցույց տալ էջում (Instagram-ի ժապավենը)
  • Խաղեր, զամբյուղ, ֆիլտրեր, անիմացիաներ
  • Իսկ Node.js-ով՝ նույնիսկ սերվեր գրել

02Որտե՞ղ է աշխատում JS-ը

Ամեն բրաուզերի ներսում կա մի փոքրիկ «շարժիչ», որը կարդում է JS կոդը և կատարում այն։ Chrome-ում այդ շարժիչի անունը V8 է։ Այսինքն՝ քեզ ոչինչ տեղադրել պետք չէ։ Բրաուզերն արդեն պատրաստ է։

Բացենք Console-ը

Console-ը JS-ի «խոհանոցն» է՝ այնտեղ կարող ես կոդ գրել ու անմիջապես տեսնել արդյունքը։

  • Windows / Linux՝ F12 կամ Ctrl + Shift + I
  • macOS՝ Cmd + Option + I
  • Կամ՝ աջ սեղմում էջի վրա → Inspect → ներդիր Console
Խորհուրդ

Console-ը դատարկելու համար սեղմիր Ctrl + L։ Նոր տող սկսելու համար՝ Shift + Enter։

03Առաջին կոդը՝ console.log()

console.log()-ը ամենակարևոր գործիքն է, որ կսովորես այսօր։ Այն նշանակում է՝ «բրաուզե՛ր, տպիր սա Console-ում, որ ես տեսնեմ»։

script.js
console.log("Բարև, աշխարհ։");
console.log(2026);
console.log(10 + 5);
Console
Բարև, աշխարհ։
2026
15

Նկատեցի՞ր՝ երրորդ տողում մենք գրեցինք 10 + 5, իսկ Console-ը տպեց 15։ Ուրեմն JS-ը նախ հաշվում է, հետո տպում արդյունքը։

Երկու կարևոր մանրուք

  • Չակերտները։ Տեքստը միշտ դրվում է չակերտների մեջ՝ "Բարև"։ Թիվը՝ ոչ՝ 2026։
  • Կետ-ստորակետը (;)։ Այն ասում է՝ «այս հրամանն ավարտվեց»։ Ինչպես կետը նախադասության վերջում։
Ուշադրություն

JS-ը մեծատառ/փոքրատառ զգայուն է։ console.log() ✅ · Console.Log() ❌ — երկրորդը սխալ կտա։

ինչ է լինում սխալի դեպքում
Console.Log("Բարև");
Console
Uncaught ReferenceError: Console is not defined
    at script.js:1:1

Կարմիր տեքստից մի՛ վախեցիր։ Սա բրաուզերի օգնությունն է․ նա ասում է՝ «տող 1-ում ես Console անունով բան չեմ ճանաչում»։ Սխալները քո ընկերներն են։

04Ինչպե՞ս JS-ը միացնել HTML-ին

Console-ը լավ է փորձարկելու համար, բայց իրական նախագծում կոդը գրում ենք ֆայլում։ Երեք եղանակ կա, բայց իրականում օգտագործում ենք միայն երրորդը։

1. Ներսում՝ <script> թեգով

index.html
<body>
  <h1>Իմ կայքը</h1>

  <script>
    console.log("Ես HTML-ի ներսում եմ");
  </script>
</body>

2. Առանձին ֆայլով ✅ (այսպես ենք աշխատելու)

index.html
<!DOCTYPE html>
<html lang="hy">
<head>
  <meta charset="UTF-8">
  <title>Դաս 1</title>
  <link rel="stylesheet" href="css/style.css">
  <script src="js/main.js" defer></script>
</head>
<body>
  <main>
    <section>
      <div class="row">
        <div class="col">
          <div class="wrapper">Բովանդակություն</div>
        </div>
      </div>
    </section>
  </main>
</body>
</html>
Ի՞նչ է defer-ը

Բրաուզերը HTML-ը կարդում է վերևից ներքև։ Եթե <head>-ում գրես սովորական <script>, նա կկանգնի, կկարդա JS-ը, և միայն հետո կշարունակի HTML-ը։

defer բառը նշանակում է՝ «ֆայլը ներբեռնիր հիմա, բայց կատարիր այն ժամանակ, երբ ամբողջ HTML-ը պատրաստ լինի»։ Այդպես JS-ը միշտ գտնում է իրեն պետք էլեմենտները։

05Մեկնաբանություններ

Մեկնաբանությունը գրառում է մարդկանց համար։ JS-ը այն կարդում է ու անտեսում։ Օգտագործում ենք բացատրելու համար՝ ինչո՞ւ ենք այս կոդը գրել։

main.js

06Փոփոխականներ

Փոփոխականը տուփ է անունով։ Ներսում դնում ես արժեք և հետո կանչում ես տուփի անունը, որ արժեքը ստանաս։

main.js
let name = "Անի";
let age = 12;

console.log(name);
console.log(age);
Console
Անի
12

Կարդում ենք այսպես․ «ստեղծի՛ր name անունով տուփ և ներսը դիր "Անի" տեքստը»։ = նշանը այստեղ «հավասար է» չի նշանակում — այն նշանակում է «դի՛ր ներսը»։

var — հին եղանակ

var-ը հին JS-ի փոփոխականն է։ Այն ունի տարօրինակ վարքագիծ, որի պատճառով ծրագրավորողները շատ սխալներ էին թույլ տալիս։ 2015-ից հետո var չենք օգտագործում։ Պետք է իմանաս միայն նրա համար, որ հին կոդում կհանդիպես։

07Տվյալների տիպերը

Ամեն արժեք ունի իր «տեսակը»։ Ինչպես խանութում՝ կաթը հեղուկ է, հացը՝ պինդ։ JS-ը դրանք տարբեր ձևով է վերաբերվում։

ՏիպԻ՞նչ էՕրինակ
stringՏեքստ, միշտ չակերտների մեջ"Անի", 'բարև'

typeof null-ը վերադարձնում է "object"։ Սա JS-ի սխալ է, որը թույլ են տվել 1995-ին։ Երբեք չեն ուղղել, որովհետև աշխարհի միլիոնավոր կայքեր կփչանային։ Պարզապես հիշիր այն։

undefined ընդդեմ null

  • undefined — «տուփը դատարկ է, ես դեռ ոչինչ չեմ դրել»։ JS-ը ինքն է դնում։
  • null — «տուփը դատարկ է, և ես դիտմամբ եմ դատարկ թողել»։ Ծրագրավորողն է դնում։

08Տեքստերի միացում

Հին եղանակը՝ + նշանով։ Այն կոչվում է կոնկատենացիա։

հին եղանակ
const firstName = "Անի";
const lastName  = "Սարգսյան";
const age       = 14;

console.log("Բարև, " + firstName + " " + lastName + "։ Դու " + age + " տարեկան ես։");
Console
Բարև, Անի Սարգսյան։ Դու 14 տարեկան ես։

Տեսնո՞ւմ ես՝ որքան չակերտ ու + կա։ Հեշտ է սխալվել՝ մոռանալ բացատը կամ մի չակերտը։ Հենց դրա համար ստեղծվեց նոր եղանակը։

Template literals — ժամանակակից եղանակ ✅

Օգտագործում ենք հետադարձ չակերտներ (backtick՝ `) — ստեղնաշարի ձախ վերևի անկյունում, Tab-ից վերև։ Փոփոխականը դնում ենք ${...}-ի մեջ։

նոր եղանակ
const firstName = "Անի";
