Սելեկտորներ և կասկադ

Կմախքը պատրաստ է — ժամանակն է հագցնելու։ Այսօր սովորում ենք ընտրել էլեմենտները, հասկանում ենք ինչու է երբեմն ոճը «չաշխատում», և ստեղծում ենք global.css-ը, որը կուղեկցի քեզ բոլոր նախագծերում։

Նախապայման՝ Դաս 01–05 Բլոկ 1 · CSS հիմունքներ Ծնվում է global.css-ը

01CSS կանոն

սելեկտոր │ ▼ h1 { color: red; ← հատկություն: արժեք; font-size: 32px; ← հայտարարություն } │ │ └──── բլոկ ────────┘
շարահյուսություն
/* Մեկնաբանություն CSS-ում */

h1 {
    color: red;
    font-size: 32px;
    text-align: center;
}
Երեք սովորական սխալ

1. Մոռացած կետ-ստորակետ։ Առանց ;-ի հաջորդ հայտարարությունը կանտեսվի։
2. Չփակված ձևավոր փակագիծ։ Հետո ամբողջ ֆայլը դադարում է աշխատել։
3. Երկու կետի փոխարեն հավասարման նշան։ CSS-ում color: red, ոչ color = red։

CSS-ը սխալի մասին չի ասում

Ի տարբերություն JavaScript-ի, CSS-ը սխալ չի գցում։ Այն պարզապես լուռ անտեսում է այն, ինչ չի հասկանում։ Ուստի եթե ոճը չի կիրառվում — առաջին բանը, որ պիտի ստուգես, շարահյուսությունն է վերևի տողերում։

02Միացման երեք ձև

1. inline — ուղիղ թեգում
<h1 style="color: red; font-size: 32px;">Վերնագիր</h1>
2. internal — head-ում
<head>
    <style>
        h1 { color: red; }
    </style>
</head>
3. external — առանձին ֆայլ ✅
<head>
    <link rel="stylesheet" href="css/global.css">
    <link rel="stylesheet" href="css/main.css">
</head>
ՁևԱռավելությունԹերություն
inlineԱրագ փորձարկումՉի վերաօգտագործվում, դժվար է փոխել, ամենաուժեղն է կասկադում
internalՄեկ ֆայլում ամեն ինչԱշխատում է միայն այս էջում
externalՄեկ ֆայլ՝ բոլոր էջերի համար, քեշավորվում է—
Մենք միշտ օգտագործում ենք external

Երկու ֆայլ՝ global.css և main.css։ Հերթականությունը կարևոր է․ global.css-ը միշտ առաջինն է, որովհետև main.css-ը կարող է վերագրել նրա կանոնները։ Ինչու՝ կհասկանանք 06-րդ բաժնում։

03Հիմնական սելեկտորներ

երեք տեսակ
/* Ըստ թեգի — բոլոր h1-երը */
h1 { color: navy; }

/* Ըստ դասի — կետով */
.title { color: navy; }

/* Ըստ id-ի — վանդակագծով */
#hero { background: gray; }

/* Բոլորը */
* { margin: 0; }
HTML-ում
<h1 class="title">Վերնագիր</h1>

<!-- Մի քանի դաս՝ բացատով -->
<div class="col w-25 text-center">...</div>

<section id="hero">...</section>
classid
Քանի՞ էլեմենտի վրաՔանի ուզեսՈւղիղ մեկ էջում
Մեկ էլեմենտին քանի՞սըՔանի ուզեսՄեկը
CSS-ում.name#name
Ե՞րբ օգտագործելԳրեթե միշտԲաժիններ, խարիսխներ
Ոճավորման համար օգտագործիր դասեր

id-ն ունի շատ բարձր սպեցիֆիկություն, և հետո դժվար է վերագրել այն։ Բացի այդ, id-ն մեկն է — չես կարող կրկնել ոճը։

Բացառություն՝ բաժինների id-երը, որոնք արդեն կան նավիգացիայի համար։ Դրանք հարմար է օգտագործել բաժնային ոճերի համար՝ #products .wrapper { ... }։

Դասերի անվանում

❌ vs ✅
/* ❌ Անունը՝ ըստ տեսքի */
.red-text { color: red; }
.big { font-size: 40px; }

/* ✅ Անունը՝ ըստ դերի */
.error { color: red; }
.title-2 { font-size: 40px; }
Ինչո՞ւ

Վաղը դիզայներն ասի՝ «սխալները թող կապույտ լինեն»։ .red-text { color: blue } — կոդն այլևս ստում է։ Իսկ .error { color: blue }-ը շարունակում է իմաստ ունենալ։

04Համակցված սելեկտորներ

հինգ կարևոր համակցություն
/* 1. Ներսում — բոլոր p-երը article-ի ներսում, ցանկացած խորության */
article p { color: gray; }

/* 2. Ուղիղ երեխա — միայն առաջին մակարդակը */
.row > .col { padding: 10px; }

/* 3. Երկու դաս միաժամանակ — առանց բացատի */
.btn.btn-light { background: lightblue; }

/* 4. Խմբավորում — ստորակետով */
h1, h2, h3 { font-weight: 700; }

/* 5. Թեգ + դաս */
a.btn { text-decoration: none; }
Բացատը ամեն ինչ փոխում է

.btn.btn-light — էլեմենտ, որն ունի երկու դասն էլ։
.btn .btn-light — .btn-light, որը գտնվում է .btn-ի ներսում։

Մեկ բացատ, բոլորովին այլ իմաստ։ Սա հաճախ հանդիպող սխալ է։

Ատրիբուտով սելեկտորներ

հատկապես օգտակար ֆորմաներում
input[type="text"] { border: 1px solid gray; }
input[required] { border-color: navy; }
a[target="_blank"] { color: green; }

Կեղծ-դասեր

վիճակներ
.btn:hover         { background: navy; }
input:focus       { border-color: navy; }
a:visited         { color: purple; }
button:disabled   { opacity: .5; }

li:first-child    { font-weight: 700; }
li:last-child     { border: none; }
tr:nth-child(even) { background: #f5f5f5; }
:focus-visible

:focus-ն աշխատում է և՛ մկնիկով, և՛ ստեղնաշարով։ :focus-visible-ը՝ միայն ստեղնաշարով։ Դա թույլ է տալիս ցույց տալ ֆոկուսի շրջանակը այնտեղ, որտեղ այն իսկապես պետք է։ Կօգտագործենք global.css-ում։

05Կասկադ

CSS = Cascading Style Sheets։ «Կասկադ» նշանակում է՝ կանոնները հոսում են վերևից ներքև, և երբ մի քանիսը վերաբերում են նույն էլեմենտին, պիտի որոշվի՝ որն է հաղթում։

Երեք հարց՝ հերթականությամբ 1. Կա՞ !important → հաղթում է ↓ ոչ 2. Ո՞ր սելեկտորն է ավելի սպեցիֆիկ → հաղթում է ↓ հավասար են 3. Ո՞րն է գրված ավելի ուշ → հաղթում է
հերթականությունը՝ երբ սպեցիֆիկությունը հավասար է
.title { color: red; }
.title { color: blue; }   /* ← սա հաղթում է */
Ահա թե ինչու է հերթականությունը կարևոր

global.css-ը միացնում ենք առաջինը, main.css-ը՝ երկրորդը։ Դրա շնորհիվ նախագծի ոճերը կարող են վերագրել գլոբալները՝ առանց սպեցիֆիկության հետ պայքարելու։

06Սպեցիֆիկություն

Ամեն սելեկտոր ունի «կշիռ»։ Հաշվում ենք երեք թվով։

ԻնչԿշիռ
id (#hero)1-0-0
դաս (.btn), ատրիբուտ ([type]), կեղծ-դաս (:hover)0-1-0
թեգ (div), կեղծ-էլեմենտ (::before)0-0-1
*0-0-0
օրինակներ
p                      /* 0-0-1 */
.text                  /* 0-1-0 */
p.text                 /* 0-1-1 */
.card .text            /* 0-2-0 */
#hero p               /* 1-0-1 */
#hero .card p.text    /* 1-2-1 */

Համեմատում ենք ձախից աջ․ նախ առաջին թիվը, հետո երկրորդը, հետո երրորդը։ Մեկ id-ն ուժեղ է հազար դասից։

դասական շփոթություն
/* main.css-ում գրեցի սա, բայց չաշխատեց */
.card { background: white; }

/* որովհետև ինչ-որ տեղ կա սա */
#products .card { background: gray; }
/*    1-1-0    ուժեղ է քան   0-1-0   */
!important — վերջին միջոց

color: red !important; հաղթում է ամեն ինչին։ Բայց երբ դու օգտագործես այն, հաջորդ անգամ վերագրելու համար պետք կլինի ևս մեկ !important։ Եվ այդպես՝ մինչև ամբողջ ֆայլը լցվի դրանցով։

Կանոն՝ եթե ուզում ես գրել !important, նախ ստուգիր՝ արդյո՞ք սելեկտորը կարող ես ավելի սպեցիֆիկ դարձնել։ 99% դեպքերում կարող ես։

DevTools-ը ամեն ինչ ցույց է տալիս

Աջ սեղմում էլեմենտի վրա → Inspect → աջ վահանակում Styles։ Այնտեղ երևում են բոլոր կանոնները, որոնք վերաբերում են էլեմենտին, և վրայից գծված են այն ոճերը, որոնք պարտվել են։ Սա CSS-ի հիմնական դեբագի գործիքն է։

07Ժառանգում

Որոշ հատկություններ ինքնաբերաբար փոխանցվում են ծնողից երեխաներին։

ժառանգվում է
body {
    font-family: "Noto Sans Armenian", sans-serif;
    color: #1a1a1a;
    line-height: 1.5;
}

/* Ամբողջ էջը ստանում է այս ոճերը */
Ժառանգվում էՉի ժառանգվում
colormargin, padding
font-family, font-sizeborder
font-weight, font-stylebackground
line-heightwidth, height
text-aligndisplay
letter-spacingposition
Տրամաբանությունը պարզ է

Ժառանգվում է այն, ինչ տեքստի մասին է։ Չի ժառանգվում այն, ինչ տուփի մասին է։ Պատկերացրու՝ եթե border-ը ժառանգվեր, մեկ շրջանակ դնելով բոլոր ներսի էլեմենտները շրջանակված կլինեին։

inherit — ստիպել ժառանգել
/* Հղումները լռելյայն ունեն իրենց կապույտ գույնը */
a {
    color: inherit;   /* վերցնում է ծնողի գույնը */
}
Հենց սա կլինի global.css-ում

a { color: inherit } — շատ հարմար է։ Հղումն ընդունում է իր շրջապատի գույնը, և դու ինքդ ես որոշում, թե որտեղ ինչ գույն լինի։

08global.css-ի ծնունդը

Ամեն բրաուզեր ունի իր լռելյայն ոճերը՝ h1-ի չափը, պարբերությունների բացակները, ցուցակների կետերը։ Եվ դրանք փոքր-ինչ տարբեր են ամեն բրաուզերում։

Ուստի առաջին բանը, որ անում ենք — զրոյացնում ենք դրանք։

css/global.css — առաջին տարբերակը
/* ---------- Reset ---------- */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

/* ---------- Հղումներ ---------- */
a {
    display: inline-block;
    color: inherit;
    text-decoration: none;
    white-space: nowrap;
}

/* ---------- Ցուցակներ ---------- */
ul, ol {
    list-style: none;
}

/* ---------- Տեքստ ---------- */
.text-center { text-align: center; }
.text-left   { text-align: left; }
.text-right  { text-align: right; }

/* ---------- Հասանելիություն ---------- */
.skip-link {
    position: absolute;
    left: -9999px;
}

.skip-link:focus {
    left: 10px;
    top: 10px;
    background: white;
    padding: 10px;
    z-index: 100;
}

.visually-hidden {
    position: absolute;
    width: 1px;
    height: 1px;
    overflow: hidden;
    clip-path: inset(50%);
    white-space: nowrap;
}
ԿանոնԻնչու
margin: 0; padding: 0Հանում է բրաուզերի լռելյայն բացակները — մենք ինքներս ենք որոշում
box-sizing: border-boxՓոխում է չափերի հաշվարկը։ Մանրամասն՝ 8-րդ դասին
a { color: inherit }Հղումը վերցնում է շրջապատի գույնը
text-decoration: noneՀանում է ընդգծումը
display: inline-blockԹույլ է տալիս հղումին տալ padding և չափեր
list-style: noneՀանում է կետերը — մենյուների համար պետք չեն
Ուշադրություն՝ ցուցակների կետերը

list-style: none-ը հանում է կետերը բոլոր ցուցակներից։ Դա հարմար է մենյուների համար, բայց հոդվածի ներսում ցուցակը կմնա առանց նշանների։

Այդ դեպքում պարզապես վերադարձնում ես դրանք main.css-ում՝ article ul { list-style: disc; padding-left: 20px; }։

Այս ֆայլը կաճի

Ամեն դասին global.css-ը կստանա նոր տողեր՝ Flexbox-ի օգնականներ, լայնությունների դասեր, ֆորմայի տարրերի ոճեր։ Դասընթացի վերջում այն կլինի քո սեփական մինի-ֆրեյմվորքը, որը կվերցնես ամեն նոր նախագծի մեջ։

09Խաղահրապարակ

Փորձարկիր սելեկտորները և սպեցիֆիկությունը։ Փոխիր CSS-ը և տես, թե որն է հաղթում։

CSS-ը բացված է առաջինը
Փորձիր

1. Փոխիր տեղերով .title-ի երկու կանոնները։
2. Ջնջիր #box-ը երրորդ կանոնից — ի՞նչ գույն կդառնա։
3. Ավելացրու բացատ .btn.primary-ի մեջ։
4. Ավելացրու ul { list-style: none } և տես տարբերությունը։

10Դասարանական

Ստեղծում ենք նախագծի CSS կառուցվածքը՝ մեկընդմիշտ։

my-project/ ├── index.html ├── css/ │ ├── global.css ← այսօր լրացնում ենք │ └── main.css ← այսօր սկսում ենք └── images/
  1. Ստեղծիր երկու CSS ֆայլը
  2. Միացրու դրանք head-ում՝ ճիշտ հերթականությամբ
  3. global.css-ում գրիր 08-րդ բաժնի ամբողջ կոդը
  4. Բացիր Դաս 5-ի էջը և տես, թե ինչ փոխվեց
  5. main.css-ում ավելացրու ներքևի կոդը
  6. Փորձարկիր DevTools-ով՝ գտիր, թե որ կանոններն են պարտվում
css/main.css — առաջին տողերը
body {
    font-family: "Segoe UI", system-ui, sans-serif;
    color: #1a1a1a;
    background-color: #f5f5f5;
    line-height: 1.5;
}

/* Վերնագրերի սանդղակ — կլրացնենք 13-րդ դասին */
h1, .title-1 { font-size: 60px; font-weight: 700; }
h2, .title-2 { font-size: 40px; font-weight: 700; }
h3, .title-3 { font-size: 30px; font-weight: 700; }
h4, .title-4 { font-size: 20px; font-weight: 700; }

/* Հոդվածի ներսում ցուցակները վերադարձնում ենք */
article ul {
    list-style: disc;
    padding-left: 20px;
}
Ինչո՞ւ h1 և .title-1 միասին

Երբեմն տեքստը պիտի ունենա h1-ի տեսքը, բայց h1 չլինի իմաստով (հիշիր Դաս 2-ի կանոնը՝ էջում մեկ h1)։ Այդ դեպքում գրում ես <div class="title-1">։

Այսպես իմաստը և տեսքը բաժանվում են — HTML-ը պատասխանում է իմաստի համար, CSS-ը՝ տեսքի։

11Տնային աշխատանք

Մինի-նախագիծ

Այս տնայինի գլխավոր մասը՝ «Առաջին ոճերը», քայլ առ քայլ, starter ֆայլերով և պատրաստի օրինակով։ Ներքևի ցուցակի մնացած կետերը առանձին վարժություններ են։

  1. Ստեղծիր global.css և main.css։ Միացրու ճիշտ հերթականությամբ։
  2. Փորձիր փոխել հերթականությունը՝ main.css-ը առաջինը։ Նկարագրիր՝ ինչ կոտրվեց։ Վերականգնիր։
  3. Գրիր հինգ կանոն թեգային սելեկտորով, հինգը՝ դասով, երկուսը՝ id-ով։
  4. Օգտագործիր բոլոր հինգ համակցությունները 04-րդ բաժնից։
  5. Ստեղծիր երկու կանոն, որոնք հակասում են իրար։ Կանխագուշակիր՝ որը կհաղթի, հետո ստուգիր DevTools-ով։
  6. Հաշվիր սպեցիֆիկությունը՝ .card p, #hero .btn, ul li a.link, input[type="text"]:focus։ Ստուգիր DevTools-ով։
  7. Ցուցադրիր ժառանգումը․ body-ին տուր color և font-family, և ցույց տուր, որ դրանք հասնում են ներսի էլեմենտներին։ Հետո ցույց տուր, որ border-ը չի ժառանգվում։
  8. Ավելացրու :hover և :focus-visible վիճակներ կոճակներին ու հղումներին։ Ստուգիր Tab-ով։
  9. Օգտագործիր :nth-child(even) աղյուսակի տողերի համար (Դաս 3-ի աղյուսակը)։
  10. Վերցրու Դաս 5-ի սեմանտիկ էջը և ոճավորիր այն՝ գույներ, տառաչափեր, hover վիճակներ։ Ոչ մի !important։

12Հիշելու թերթիկ

ՍելեկտորԻնչ է ընտրում
h1Բոլոր h1-երը
.btnԲոլորը btn դասով
#heroid="hero"-ով էլեմենտը
*Ամեն ինչ
.card pp-երը .card-ի ներսում
.row > .colՈւղիղ երեխաներ ⭐
.btn.activeԵրկու դասն էլ ունեցողը
h1, h2Խմբավորում
input[type="text"]Ըստ ատրիբուտի
:hover, :focus-visibleՎիճակներ
:first-child, :nth-child(even)Ըստ դիրքի

Կասկադի կանոնները

  1. !important — խուսափիր
  2. Սպեցիֆիկություն՝ id > դաս > թեգ
  3. Հերթականություն՝ վերջինը հաղթում է

Ի՞նչ ավելացավ global.css-ում այսօր

✓ Reset՝ * { margin, padding, box-sizing } ✓ a { display, color: inherit, text-decoration, white-space } ✓ ul, ol { list-style: none } ✓ .text-center / .text-left / .text-right ✓ .skip-link ✓ .visually-hidden

Ստուգաթերթ

  • CSS-ը միացված է link-ով, ոչ style ատրիբուտով
  • global.css-ը միացված է main.css-ից առաջ
  • Դասերի անունները ըստ դերի են, ոչ տեսքի
  • Ոչ մի !important
  • Ոճավորումը դասերով է, ոչ id-երով
  • Հղումներն ու կոճակներն ունեն :hover և :focus-visible

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչու ոճը երբեմն «չի աշխատում»
  • Գիտե՞մ տարբերությունը .a.b-ի և .a .b-ի միջև
  • Կարո՞ղ եմ հաշվել սպեցիֆիկությունը
  • Գիտե՞մ, ինչու ենք global.css-ը միացնում առաջինը
  • Հասկանո՞ւմ եմ, ինչ է ժառանգվում և ինչ՝ ոչ
Հաջորդ դասին

Գույն, տեքստ, տառատեսակներ։ Գունային ձևաչափեր, Google Fonts, միավորներ (px, rem, %), և կոնտրաստի հարաբերակցությունը — ինչպես ստուգել, որ տեքստն ընթեռնելի է։
