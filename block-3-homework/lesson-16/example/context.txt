ՆԱԽԱԳԻԾ
«Անիի գրքերը»՝ ընթերցանության օրագիր Անի Սարգսյանի անձնական կայքում։
Ցույց է տալիս գրքերի դարակը, կարգավիճակները (կարդալու եմ / կարդում եմ / կարդացել եմ),
առաջընթացը էջերով և վիճակագրությունը։ Ուսումնական նախագիծ, PHP բլոկ, Դաս 04։

ՍՏԵԿ
- PHP 8.3, առանց ֆրեյմվորքի, առանց Composer-ի
- declare(strict_types=1) ամեն .php ֆայլում, որտեղ կան ֆունկցիաներ
- Տվյալները՝ data.php-ի $books զանգվածում (բազան՝ Դաս 08-ից)
- HTML/CSS՝ Բլոկ 1–2-ի իմ կայքից, ոչ մի CSS ֆրեյմվորք

ԿԱՆՈՆՆԵՐ
- Ֆունկցիաները ստանում են ամեն ինչ պարամետրով, global չկա
- Տիպեր ամեն պարամետրի և վերադարձի համար (int, string, array, ?array)
- Շաբլոններում՝ այլընտրանքային շարահյուսություն (foreach: ... endforeach;)
- Ամեն գիրք՝ ['id', 'title', 'author', 'year'?, 'pages', 'read', 'genre', 'rating', 'color']

CSS ԴԱՍԵՐ (գոյություն ունեցող, նորերը մի հորինիր)
.book, .book__cover, .book__body, .book__title, .meta, .progress, .progress__bar,
.pill, .is-done, .is-reading, .is-planned, .grid-auto, .gap-20, .section-title, .empty

ԱՐԳԵԼՔՆԵՐ
- Մի առաջարկիր Laravel, Composer փաթեթներ կամ JavaScript
- Մի վերաշարադրիր ամբողջ ֆայլը․ ցույց տուր խնդիրը և տողը
- Մի օգտագործիր ֆունկցիաներ, որ PHP 8.3-ում չկան կամ հնացած են
- Պատասխանիր հայերեն, կոդի մեկնաբանությունները՝ նույնպես
