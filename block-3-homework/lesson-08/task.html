02Քայլեր

Քայլ 1 · Բազա և աղյուսակ

  • sql/schema.sql՝ SET NAMES utf8mb4, DROP DATABASE IF EXISTS, CREATE DATABASE … utf8mb4_unicode_ci
  • Սյունակները՝ ստորև։ year-ը NULL է, ոչ 0․ «Հոբիտի» տարին անհայտ է
sql/schema.sql — books
CREATE TABLE books (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    title       VARCHAR(200) NOT NULL,
    slug        VARCHAR(200) NOT NULL UNIQUE,          -- հասցեի համար՝ book/samvel (Դաս 15)
    author      VARCHAR(100) NOT NULL,
    year        SMALLINT     NULL,                      -- հայտնի չէ՝ NULL, ոչ 0
    pages       SMALLINT UNSIGNED NOT NULL,
    read_pages  SMALLINT UNSIGNED NOT NULL DEFAULT 0,
    genre       VARCHAR(40)  NOT NULL,                  -- Դաս 09-ում՝ առանձին աղյուսակ
    rating      TINYINT UNSIGNED NOT NULL DEFAULT 0,    -- 0 = դեռ չեմ գնահատել
    color       CHAR(7)      NOT NULL DEFAULT '#003459',
    link        VARCHAR(255) NULL,
    cover       VARCHAR(255) NULL,                      -- Դաս 07-ի վերբեռնումը՝ Դաս 11-ից
    is_active   TINYINT(1)   NOT NULL DEFAULT 1,        -- թաքցնել, ոչ ջնջել
    created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP
);

  • Առաջընթացը տոկոսով, միայն 50%-ից քիչ․ բանաձևը կրկնվում է WHERE-ում (տնային 6)
sql/queries.sql — տնային 6
SELECT title, read_pages, pages,
       ROUND(read_pages * 100 / pages) AS percent
FROM books
WHERE read_pages > 0 AND ROUND(read_pages * 100 / pages) < 50
ORDER BY percent;

04Դասի տնային աշխատանքը

Սրանք Դաս 08-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Ավարտիր դասարանականի 10 հարցումը։ Ուղարկիր SQL-ը և արդյունքների սքրինշոթները։ մինի-նախագծում
  2. Ավելացրու ևս 5 ապրանք քո ընտրությամբ, որոնցից մեկը՝ էմոջիով անվան մեջ։ Ստուգիր, որ այն ճիշտ է ցուցադրվում։ մինի-նախագծում
  3. Ցույց տուր WHERE specs = NULL-ի և WHERE specs IS NULL-ի տարբերությունը։ մինի-նախագծում
  4. Գրիր հարցում, որը գտնում է 50 000 – 150 000 դրամ արժեցող ակտիվ ապրանքները՝ թանկից էժան։ մինի-նախագծում
  5. Թաքցրու (is_active = 0) բոլոր ապրանքները, որոնք պահեստում չկան։ Նախ՝ SELECT։ մինի-նախագծում
  6. Հաշվարկիր զեղչված գինը և ցույց տուր միայն այն ապրանքները, որոնց զեղչված գինը 100 000-ից փոքր է։ Հուշում․ WHERE-ում final_price-ը դեռ չկա, կրկնիր բանաձևը։ մինի-նախագծում
  7. Խնդրիր AI-ին գրել 5 հարցում քո աղյուսակի համար, ապա կատարիր դրանք։ Բոլորը աշխատեցի՞ն։ Եթե ոչ՝ ինչու։
