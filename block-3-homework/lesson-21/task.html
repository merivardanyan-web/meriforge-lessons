02Քայլեր

Քայլ 1 · Հայերեն

  • php artisan lang:publish, lang/hy/validation.php՝ AI-ի օգնությամբ, :attribute-ը և :max-ը անփոփոխ (տնային 3)

Քայլ 2 · BookRequest

  • authorize()՝ can('manage-books')
  • genre_id՝ Rule::exists, read_pages՝ lte:pages, link՝ url:http,https
  • cover՝ image, mimes:jpg,jpeg,png,webp, max:2048 (տնային 5)
app/Http/Requests/BookRequest.php — rules()
public function rules(): array
{
    return [
        'title'      => ['required', 'string', 'max:200'],
        'author'     => ['required', 'string', 'max:100'],
        'genre_id'   => ['nullable', 'integer', Rule::exists('genres', 'id')],      // curl-ով genre_id=99999 → սխալ
        'year'       => ['nullable', 'integer', 'min:1', 'max:' . date('Y')],
        'pages'      => ['required', 'integer', 'min:1', 'max:5000'],
        'read_pages' => ['required', 'integer', 'min:0', 'lte:pages'],             // Դաս 04-ի «120%»-ը
        'rating'     => ['required', 'integer', 'between:0,5'],
        'color'      => ['required', 'regex:/^#[0-9a-fA-F]{6}$/'],
        'link'       => ['nullable', 'url:http,https', 'max:255'],                 // javascript:-ը՝ ոչ
        'format'     => ['required', Rule::in(['paper', 'audio', 'ebook'])],
        'minutes'    => ['nullable', 'required_if:format,audio', 'integer', 'min:1', 'max:6000'],
        'narrator'   => ['nullable', 'string', 'max:100'],
        'lent_to'    => ['nullable', 'string', 'max:60'],
        'cover'      => ['nullable', 'image', 'mimes:jpg,jpeg,png,webp', 'max:2048'],   // տնային 5
        'is_active'  => ['boolean'],
    ];
}

routes/web.php — ադմին
Route::middleware(['auth', 'can:manage-books'])
    ->prefix('admin')
    ->name('admin.')
    ->group(function () {
        Route::get('/', fn () => redirect()->route('admin.books.index'));

        Route::get('books/trashed', [AdminBookController::class, 'trashed'])->name('books.trashed');

        // Դաս 16-ի /admin/book/{slug}/read-ը
        Route::post('books/{book}/read', [ReadingController::class, 'store'])->name('books.read');

  • Դատարկ վերնագիր և rating=9՝ երկու հայերեն սխալ, մյուս դաշտերը լրացված են

04Դասի տնային աշխատանքը

Սրանք Դաս 21-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Ավարտիր դասարանականի 5 քայլը և վեց փորձարկումը։ Ուղարկիր սքրինշոթներ։ մինի-նախագծում
  2. Վերաշարադրիր Դաս 6-ի կոնտակտների ֆորման Laravel-ում՝ Form Request-ով, old()-ով և @error-ով։ Համեմատիր տողերի քանակը։ մինի-նախագծում
  3. Թարգմանիր lang/hy/validation.php-ը AI-ի օգնությամբ և ստուգիր, որ բոլոր տեղապահները (:attribute, :max…) անփոփոխ են։ մինի-նախագծում
  4. Թարգմանիր lang/hy/auth.php-ը։ Ստուգիր, որ սխալ գաղտնաբառի և անգոյ հասցեի հաղորդագրությունները նույնն են (Դաս 16)։ մինի-նախագծում
  5. Ավելացրու նկարի վերբեռնում ադմին ֆորմայում․ 'image' => ['nullable', 'image', 'mimes:jpg,png,webp', 'max:2048'], $request->file('image')->store('products', 'public'), php artisan storage:link։ Համեմատիր Դաս 7-ի վեց քայլի հետ։ մինի-նախագծում
  6. Փոխարինիր CartController-ի abort_if(..., 422)-ը $request->validate()-ով և տպիր payload.errors-ը cart.js-ում։ մինի-նախագծում
  7. Խորացված․ ստեղծիր ProductPolicy (php artisan make:policy ProductPolicy --model=Product) և տեղափոխիր երկու Gate-երը նրա մեջ։ Ի՞նչ փոխվեց կոնտրոլերում։ մինի-նախագծում

05Համեմատիր օրինակի հետ
