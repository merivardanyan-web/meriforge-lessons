Քայլ 2 · What I added

  • ratings աղյուսակ՝ UNIQUE(user_id, book_id) (տնային 2)
  • RatingController՝ կա՞ գնահատական՝ թարմացնել, չկա՞՝ ստեղծել, միայն auth
  • user_id-ն fillable չէ․ updateOrCreate(['user_id' => …])-ը shouldBeStrict-ով կտա MassAssignmentException
  • Գրքի էջում՝ loadAvg('ratings', 'stars') և loadCount
app/Http/Controllers/RatingController.php
public function store(Request $request, Book $book)
{
    abort_unless($book->is_active, 404);

    $data = $request->validate(['stars' => ['required', 'integer', 'between:1,5']], [], ['stars' => 'գնահատականը']);

    // Կա՞ արդեն՝ թարմացնում ենք, չկա՝ ստեղծում։ UNIQUE(user_id, book_id)-ը երաշխավորում է նույնը բազայում
    // ⚠️ updateOrCreate(['user_id' => ...])-ը կփորձեր user_id-ն լցնել fill()-ով, իսկ այն fillable չէ (դիտավորյալ)․
    //    shouldBeStrict()-ով դա MassAssignmentException է։ Ուստի user_id-ն՝ ուղիղ վերագրմամբ, ինչպես role-ը (Դաս 20)
    $rating = $book->ratings()->where('user_id', $request->user()->id)->first() ?? $book->ratings()->make();
    $rating->user_id = $request->user()->id;
    $rating->stars = $data['stars'];
    $rating->save();

    return redirect()->route('book.show', $book)->with('success', 'Շնորհակալություն, գնահատականը պահպանվեց');
}

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Production-ում սպիտակ էջAPP_KEY չկա․ php artisan key:generate --force
CSS-ը չի բեռնվում hosting-ումAPP_URL-ը սխալ է կամ document root-ը արմատն է, ոչ public/
/.env-ը բացվում էDocument root-ը սխալ է․ սա ամենավտանգավոր սխալն է (Դաս 22, բաժին 04)
Գնահատականը կրկնվում էunique(['user_id', 'book_id']) միգրացիայում, իսկ կոնտրոլերում նախ փնտրիր անդամի գնահատականը, ոչ միշտ create
Add fillable property [user_id]updateOrCreate-ի առաջին զանգվածը նույնպես լցվում է fill()-ով․ user_id-ն վերագրիր ուղիղ

04Դասի տնային աշխատանքը

Սրանք Դաս 22-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Ավարտիր դասարանականի 5 քայլը։ Ուղարկիր demo հղումը, GitHub պրոֆիլը և LinkedIn-ը։ մինի-նախագծում
  2. Ավելացրու մեկ ֆունկցիա, որ դասընթացում չկար, և նկարագրիր այն README-ի «What I added» բաժնում։ Տարբերակներ․ ապրանքների գնահատականներ · ցանկությունների ցուցակ (wishlist) մուտք գործած օգտատերերի համար · պատվերի ձևակերպում և email Mail-ով (լոկալ՝ MAIL_MAILER=log) · ֆիլտրեր գնի և կատեգորիայի համար՝ query string-ով · API փաստաթուղթ Դաս 17-ի endpoint-ների համար։ մինի-նախագծում
  3. Հրապարակիր HTML և JS բլոկի նախագծերը GitHub Pages-ում (եթե դեռ չես արել) և ավելացրու հղումները README-ներում։ Ստուգիր HTML Դաս 2-ի ուղիների սխալը։ մինի-նախագծում
  4. Ստեղծիր պրոֆիլի README։ Չորս տողից ոչ ավելի։ մինի-նախագծում
  5. Գործարկիր Lighthouse-ը demo-ում։ Գրիր չորս թվերը և ուղղիր Accessibility-ի առնվազն մեկ սխալ։ մինի-նախագծում
  6. Գրիր LinkedIn-ի About-ը ինքդ, ապա ուղղիր AI-ով «grammar only» հրահանգով։ Համեմատիր երկու տարբերակը։
  7. Պատրաստիր Դաս 23-ի համար․ գտիր երեք իրական աշխատանքային հայտարարություն (մեկը Հայաստանից, մեկը remote, մեկը freelance) Laravel կամ PHP դերի համար և պահիր դրանց տեքստը։
