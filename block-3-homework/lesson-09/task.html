02Քայլեր

Քայլ 1 · Ամբողջ սխեման մեկ ֆայլում

  • sql/schema.sql՝ genres, books (genre_id), reading_sessions (տնային 7)
  • books.genre_id՝ ON DELETE SET NULL, reading_sessions.book_id՝ ON DELETE RESTRICT
sql/schema.sql — reading_sessions
CREATE TABLE reading_sessions (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    book_id     INT UNSIGNED NOT NULL,
    pages       SMALLINT UNSIGNED NOT NULL,
    read_on     DATE         NOT NULL,
    note        VARCHAR(255) NULL,
    created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT fk_sessions_book
        FOREIGN KEY (book_id) REFERENCES books(id)
        ON DELETE RESTRICT,                             -- պատմությամբ գիրքը չի ջնջվում, միայն թաքցվում է

    INDEX idx_sessions_date (read_on)
) ENGINE=InnoDB;

Քայլ 2 · Տվյալներ

  • starter/sql/seed.sql՝ 7 ժանր (մեկը՝ առանց գրքի), 12 գիրք, 22 ընթերցանության օր
  • Ամեն գրքի սեսիաների գումարը = read_pages․ հարցում 8-ը ստուգում է դա

Քայլ 3 · Ութ հարցում

  • Գրքեր՝ ժանրի անունով (JOIN), բոլոր ժանրերը քանակով (LEFT JOIN), էջերը ժանրերով (SUM), HAVING COUNT(*) > 2
  • Վերջին 5 օրը, ամեն գիրքը՝ օրեր և էջեր, հոկտեմբերը, ստուգում
sql/queries.sql — LEFT JOIN
SELECT g.name, COUNT(b.id) AS books
FROM genres g
LEFT JOIN books b ON b.genre_id = g.id
GROUP BY g.id, g.name
ORDER BY books DESC, g.name;

Քայլ 4 · Նոր օր՝ երեք գրքով

  • Երեք INSERT նույն օրով և երեք UPDATE … read_pages (տնային 2)
  • Հարցում՝ ամեն օրը քանի գիրք և քանի էջ

Քայլ 5 · Արտաքին բանալիների փորձեր

  • DELETE FROM books WHERE id = 2 → սխալ 1451 (տնային 3)
  • Ջնջիր «պատմվածք»-ը, տես genre_id = NULL, վերադարձրու (տնային 4)
  • ON … AND և WHERE․ «դետեկտիվ»-ը անհետանում է (տնային 5)
  • Ամենաշատ կարդացած 3-ը (տնային 6)

03Ստուգաթերթ

  • schema.sql + seed.sql-ը զրոյից վերստեղծում են բազան
  • Հարցում 2-ում «դետեկտիվ»-ը կա՝ 0-ով
  • Հարցում 8-ը տալիս է 0 տող
  • Գիրքը սեսիաներով չի ջնջվում
  • Կարող ես բացատրել ON … AND-ի և WHERE-ի տարբերությունը մեկ նախադասությամբ

04Դասի տնային աշխատանքը

Սրանք Դաս 09-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Ավարտիր 8 հարցումը։ Ուղարկիր SQL-ը և արդյունքների սքրինշոթները։ մինի-նախագծում
  2. Ավելացրու երկրորդ պատվեր երեք ապրանքով և գրիր հարցում, որը ցույց է տալիս բոլոր պատվերները՝ ամեն մեկի տողերի քանակով և գումարով։ մինի-նախագծում
  3. Փորձիր ջնջել ապրանք, որը կա պատվերում։ Ի՞նչ սխալ ստացար։ Ինչու է դա լավ։ մինի-նախագծում
  4. Ջնջիր կատեգորիա և ստուգիր, թե ինչ եղավ նրա ապրանքների հետ։ Վերադարձրու կատեգորիան։ մինի-նախագծում
  5. Համեմատիր ON ... AND p.is_active = 1 և WHERE p.is_active = 1 տարբերակները բաժին 05-ի խորացված նշումից։ Բացատրիր տարբերությունը քո բառերով։ մինի-նախագծում
  6. Գրիր հարցում․ «ամենավաճառված 3 ապրանքը»՝ SUM(oi.quantity)-ով։ մինի-նախագծում
  7. Պահիր բոլոր CREATE TABLE հրամանները մեկ schema.sql ֆայլում։ Ջնջիր բազան, կատարիր ֆայլը և ստուգիր, որ ամեն ինչ վերականգնվեց։ Այս ֆայլը պետք կլինի հաջորդ դասին։ մինի-նախագծում
  8. Տուր AI-ին քո schema.sql-ը և խնդրիր վերանայել այն։ Ի՞նչ առաջարկեց։ Համաձա՞յն ես։ Ինչու։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
