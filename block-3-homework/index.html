Անիի գրքերի ակումբը

Ամեն դասի տնային աշխատանքը ունի մեկ մինի-նախագիծ՝ քայլերով, starter ֆայլերով, պատրաստի օրինակով և սքրինշոթներով։ Բոլորը մեկ նախագիծ են․ Անիի «Գրքեր» էջը դառնում է գրքերի ակումբ՝ MySQL-ով, սեփական MVC-ով, մուտքով և API-ով, իսկ վերջում՝ Laravel-ով և հրապարակված պորտֆոլիոյում։

task.html → starter/ → example/ Դաս 01–17՝ մաքուր PHP, 18–22՝ Laravel Դաս 23–24՝ ՏեխնոՄարկետի պաշտպանություն

00Ինչպես աշխատել

lesson-NN/ ├── task.html ← առաջադրանքը․ սկսիր այստեղից ├── starter/ ← տվյալներ, SQL և CSS, որ չգրես ձեռքով ├── example/ ← պատրաստի օրինակ․ բացիր միայն ավարտելուց հետո └── screenshots/ ← ինչ պետք է ստացվի
Կանոն

Նախ կատարիր առաջադրանքը և անցիր ստուգաթերթով, հետո բացիր օրինակը։ Ամեն դասի օրինակը նախորդի շարունակությունն է, ուստի եթե բաց ես թողել դասը, հաջորդը կարող ես սկսել նախորդի օրինակից։

Օրինակները սերվեր են ուզում

PHP-ի օրինակները չեն բացվում կրկնակի սեղմումով։ Դաս 01–09՝ php -S localhost:8000 թղթապանակում, Դաս 10–13՝ նաև բազա (sql/) և config.php, Դաս 14–17՝ composer install և .env, Դաս 15-ից՝ -t public public/index.php։ Ամեն task.html-ի բաժին 01-ում՝ ճշգրիտ հրամանը։

01Մեկ նախագիծ, որը աճում է

Ինչու Անիի ակումբը

Անին նույն ուսանողն է, որի կայքը աճեց Բլոկ 1 և 2-ի տնայիններում։ Այստեղ նրա «Գրքեր» էջը դառնում է իսկական ծրագիր՝ բազայով, անդամներով և ադմինով։ Ամեն քայլ նույնն է, ինչ դասում ՏեխնոՄարկետի հետ, բայց այլ տվյալներով, ուստի պատճենելը չի աշխատի․ պետք է հասկանալ։ Յուրաքանչյուր առաջադրանք օգտագործում է միայն այն, ինչ անցել ենք մինչև այդ դասը։

03Ինչպես է ստուգված

Դաս 01–17-ի օրինակները ստուգված են ավտոմատ թեստերով իրական MariaDB-ի վրա (185 ստուգում՝ ֆիլտրեր, էջավորում, injection, CRUD, տրանզակցիա, վերբեռնում, դերեր, CSRF, API, առանց JS-ի աշխատանք)։ Laravel-ի ֆայլերը (Դաս 18–22) գործարկված են իրական Laravel 12-ի վրա․ ամեն դասի վիճակը հավաքվել է մաքուր նախագծի վրա, և Դաս 19, 21, 22-ը ստուգվել են բրաուզերում (8 + 48 + 50 ստուգում)։
