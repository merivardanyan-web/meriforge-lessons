# functions.php-ի վերանայում (PHP Դաս 04, վարժանք 3)

Պրոմպտը՝ prompts.md, №3։ Ստորև՝ ինչ գտավ AI-ն, ինչ ստուգեցի ինքս և ինչ ուղղեցի **ինքս**։

| Ֆունկցիա | Մուտք | Ինչ եղավ | Ստուգեցի | Ուղղում |
|---|---|---|---|---|
| `progress()` | `pages = 0` | `DivisionByZeroError`, էջը սպիտակ է | Այո, data.php-ում դրեցի 0 | `pages <= 0` → 0 |
| `progress()` | `read = 120`, `pages = 96` | 125%, գիծը դուրս է գալիս քարտից | Այո | `min(100, ...)` |
| `progress()` | `read = -10` | −10% | Այո | `max(0, ...)` |
| `bookStatus()` | `read = -10` | «Կարդում եմ» | Այո | `read <= 0` → planned |
| `shortestBook()` | `[]` | `$sorted[-1]` | Այո, բայց `?? null`-ը արդեն փրկում է | Չփոխեցի |
| `sortBooks()` | `'rating'` | Զանգվածը չի փոխվում, սխալ չկա | Այո | Չփոխեցի․ `default => null` ճիշտ է, բայց հիշեցի, որ Դաս 10-ում սա սպիտակ ցուցակ կլինի |

## Ինչ AI-ն սխալ ասաց

Առաջարկեց `str_contains`-ի փոխարեն `strpos($a, $b) !== false`՝ «PHP 8-ում str_contains-ը չկա»։
php.net-ում՝ str_contains-ը կա PHP 8.0-ից։ Սա հալյուցինացիա էր (Դաս 04, բաժին 04)։

## Ինչ սովորեցի

Ամեն ֆունկցիա, որ բաժանում է, պետք է իմանա, թե ինչ անել 0-ի դեպքում։
Եզրային դեպքերը ստուգում եմ data.php-ում «վատ» գիրք ավելացնելով, ոչ թե վստահելով պատասխանին։
