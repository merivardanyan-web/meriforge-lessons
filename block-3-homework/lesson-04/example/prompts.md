# Երեք պրոմպտ՝ հինգ բաղադրիչով (PHP Դաս 04)

Ամեն պրոմպտ սկսվում է context.txt-ով։ Ստորև՝ միայն առաջադրանքի մասը։

## 1. Նոր ֆունկցիա

**Դեր․** Դու PHP 8.3 ուսուցիչ ես, որ գրում է պարզ, տիպավորված կոդ սկսնակների համար։
**Առաջադրանք․** Գրիր `booksByAuthor(array $books, string $author): array` ֆունկցիան։
**Համատեքստ․** Գրքի կառուցվածքը՝ context.txt-ում։ Հեղինակի անունը կարող է գրված լինել մեծատառով կամ փոքրատառով։
**Սահմանափակումներ․** Միայն array_filter և array_values, mb_ ֆունկցիաներ հայերենի համար, ոչ մի global։
**Ձևաչափ․** Միայն ֆունկցիան և երկու օրինակ կանչ մեկնաբանություններով։

## 2. Բացատրություն

**Դեր․** Դու համբերատար մենթոր ես։
**Առաջադրանք․** Բացատրիր, թե ինչու է `array_filter`-ից հետո պետք `array_values`, և ինչ կլինի `json_encode`-ի հետ առանց դրա։
**Համատեքստ․** Ես գիտեմ JavaScript-ի filter-ը, PHP-ում՝ երկրորդ շաբաթն եմ։
**Սահմանափակումներ․** Մինչև 150 բառ, մեկ կոդի օրինակ իմ $books-ով։
**Ձևաչափ․** Նախ՝ մեկ նախադասությամբ պատասխանը, հետո՝ օրինակը։

## 3. Վերանայում (Դաս 04-ի երրորդ ռեժիմը)

**Դեր․** Դու code reviewer ես, որ փնտրում է եզրային դեպքեր։
**Առաջադրանք․** Վերանայիր functions.php-ը (կցված է)։ Գտիր դեպքեր, որ հաշվի չեմ առել։
**Համատեքստ․** Տվյալները դեռ ձեռքով են, բայց Դաս 08-ից կգան բազայից, իսկ ադմինը կարող է սխալվել։
**Սահմանափակումներ․** Մի՛ վերաշարադրիր։ Ամեն խնդրի համար՝ ֆունկցիան, մուտքը, որ կոտրում է այն, և ինչ է լինում։
**Ձևաչափ․** Աղյուսակ՝ ֆունկցիա | մուտք | արդյունք | ինչու է վատ։
