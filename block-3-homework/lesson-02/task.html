Քայլ 3 · Կարգավիճակ և պիտակ

  • if/elseif՝ planned, reading, done
  • match՝ պիտակը հայերեն (տնային 7․ համեմատիր switch-ի հետ)
  • ?? 'տարին անհայտ'՝ «Հոբիտի» համար
index.php — կարգավիճակը
if ($book['read'] === 0) {
    $status = 'planned';
} elseif ($book['read'] >= $book['pages']) {
    $status = 'done';
} else {
    $status = 'reading';
}

// match՝ կարճ, վերադարձնում է արժեք, համեմատում է === -ով
$label = match ($status) {
    'done'    => 'Կարդացել եմ',
    'reading' => 'Կարդում եմ',
    'planned' => 'Կարդալու եմ',
};

04Դասի տնային աշխատանքը

Սրանք Դաս 02-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Կատարիր դասարանականի բոլոր 8 քայլը։
  2. Փորձարկիր 6 համեմատություն ==-ով և ===-ով։ Կազմիր աղյուսակ արդյունքներով։ մինի-նախագծում
  3. Ցուցադրիր, թե ինչու "0e123" == "0e456"-ը վտանգավոր է։ Բացատրիր սեփական բառերով։ մինի-նախագծում
  4. Փորձարկիր strlen-ը և mb_strlen-ը հայերեն բառի վրա։ Բացատրիր տարբերությունը։ մինի-նախագծում
  5. Կազմիր աղյուսակ՝ isset, empty, is_null 6 տարբեր արժեքի վրա։ մինի-նախագծում
  6. Գտիր empty-ի թակարդի իրական օրինակ քո ֆորմայում և ուղղիր։
  7. Վերաշարադրիր որևէ switch match-ով։ Հաշվիր՝ քանի՞ տող կրճատվեց։ մինի-նախագծում
  8. Ցուցադրիր foreach-ի հղումային թակարդը կոդով և բացատրիր, ինչու է վերջին տարրը փչանում։ մինի-նախագծում
  9. Վերաշարադրիր մեկ բաժին echo-ով, ապա այլընտրանքային շարահյուսությամբ։ Ո՞րն է ընթեռնելի։ մինի-նախագծում
  10. Օգտագործիր ??-ը առնվազն երեք տեղում։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
