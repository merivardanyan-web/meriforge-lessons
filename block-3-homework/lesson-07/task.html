/** Միայն ներքին հասցե՝ բաց վերահղման դեմ (Դաս 07-ի տնային, կետ 10) */
function safeBack(?string $back): string
{
    $back = (string) $back;

    if ($back === '' || str_starts_with($back, '//') || str_contains($back, ':')) {
        return 'index.php';
    }

04Դասի տնային աշխատանքը

Սրանք Դաս 07-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Կատարիր դասարանականի 10 քայլը։ մինի-նախագծում
  2. Բացիր DevTools → Application → Cookies և գտիր PHPSESSID-ը։ Ուղարկիր սքրինշոթ։
  3. Փորձիր կարդալ document.cookie-ն Console-ում httponly-ով և առանց դրա։ Նկարագրիր տարբերությունը։
  4. Գտիր սեսիայի ֆայլը սերվերում (Laragon → tmp) և բացիր այն։ Ի՞նչ ես տեսնում։
  5. Ավելացրու քանակի փոփոխում զամբյուղում (+/−)։ մինի-նախագծում
  6. Ցուցադրիր, ինչ կլինի, եթե սեսիայում պահես գինը և հետո փոխես այն data.php-ում։ մինի-նախագծում
  7. Ավելացրու թեմայի պահպանում cookie-ով (Դաս 19-ի HTML բլոկից)։ մինի-նախագծում
  8. Կառուցիր ֆայլի վերբեռնման ֆորմա uploadImage()-ով։ մինի-նախագծում
  9. Փորձիր վերբեռնել .php ֆայլ՝ վերանվանելով .jpg։ Բռնվե՞ց finfo-ով։ մինի-նախագծում
  10. Ցուցադրիր բաց վերահղման խնդիրը՝ ուղարկելով back=https://example.com ստուգումով և առանց դրա։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
