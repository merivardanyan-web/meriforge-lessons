02Քայլեր

Քայլ 1 · Նախագծի թղթապանակ

  • Laragon-ի www/-ում ստեղծիր ani-club/ և պատճենիր starter/-ի ֆայլերը
  • Բաց արա http://ani-club.test, ապա նույնը php -S localhost:8000-ով (տնային 2)

Քայլ 2 · index.html → index.php

  • Փոխանվանիր ֆայլը և թարմացրու էջը։ Ոչինչ չպիտի փոխվի․ PHP-ն HTML-ը թողնում է ինչպես կա
  • Ctrl+U․ PHP կոդ էջում չկա, սերվերն այն արդեն կատարել է (տնային 10)

Քայլ 3 · Փոփոխականներ

  • Ֆայլի սկզբում՝ $siteName, $email, $city, $year
  • Օգտագործիր դրանք առնվազն երեք տեղում՝ <title>, logo, footer
index.php — սկիզբը
<?php
// Անիի գրքերը · PHP Դաս 01
// Բլոկ 2-ի pages/books.html-ը՝ վերանվանված index.php․ HTML-ը նույնն է, PHP-ն՝ միայն մի քանի տեղում

// Սխալների ցուցադրում — միայն զարգացման ժամանակ
ini_set('display_errors', 1);
ini_set('display_startup_errors', 1);
error_reporting(E_ALL);

$siteName = "Անի Սարգսյան";
$email    = "ani@example.com";
$city     = "Սևան";
$year     = date("Y");
?>

Քայլ 4 · Սխալներ

  • display_errors-ը միացված է
  • Դիտմամբ ջնջիր մի ; և կարդա հաղորդագրությունը․ ո՞ր տողն է նշում և ինչու հաջորդը (տնային 7)

Քայլ 5 · dd() և var_dump

  • Ստեղծիր debug.php՝ չորս տիպի փոփոխական և dd() ֆունկցիա
  • Համեմատիր var_dump-ը և print_r-ը զանգվածի վրա։ Ինչու՞ է "Սամվել"-ը string(12)
debug.php — dd()
function dd($data): void
{
    echo "<pre style='background:#1e252a;color:#e8eced;padding:14px;border-radius:8px'>";
    var_dump($data);
    echo "</pre>";
    die();
}

03Ստուգաթերթ

  • index.php-ը բացվում է Laragon-ով և php -S-ով
  • Footer-ի տարեթիվը՝ date("Y"), ոչ ձեռքով գրված
  • Կայքի անունը գրված է ՄԵԿ տեղում
  • Ctrl+U-ում PHP կոդ չկա
  • debug.php-ը ցույց է տալիս 4 տիպ

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Բրաուզերը ցույց է տալիս <?php տեքստըՖայլը բացել ես կրկնակի սեղմումով (file://)։ PHP-ին սերվեր է պետք
Ներբեռնվում է index.php ֆայլըLaragon-ը միացված չէ կամ թղթապանակը www/-ում չէ
Undefined variable $siteNameՓոփոխականը սահմանված է ավելի ներքև, քան օգտագործվում է, կամ տառասխալ կա
Հայերենը «Õ...» էՖայլը պահպանիր UTF-8 կոդավորմամբ, <meta charset="UTF-8">-ը տեղում է

04Դասի տնային աշխատանքը

Սրանք Դաս 01-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Տեղադրիր Laragon։ Ուղարկիր սքրինշոթ երկու կանաչ ցուցիչով։
  2. Գործարկիր php -S և Laragon։ Գրիր, ի՞նչ տարբերություն նկատեցիր։
  3. Տեղափոխիր ՏեխնոՄարկետը www-ի մեջ և բաց արա .test հասցեով։
  4. Փոխանվանիր index.html → index.php։ Համոզվիր, որ ամեն ինչ աշխատում է։ մինի-նախագծում
  5. Դարձրու footer-ի տարեթիվը դինամիկ։ մինի-նախագծում
  6. Ստեղծիր փոփոխականներ կայքի անվան, հեռախոսի և հասցեի համար։ Օգտագործիր դրանք էջում առնվազն 3 տեղում։ մինի-նախագծում
  7. Ավելացրու սխալների ցուցադրումը։ Դիտմամբ արա սխալ (մոռացիր ;) և նկարագրիր հաղորդագրությունը։ մինի-նախագծում
  8. Գրիր dd() ֆունկցիան և փորձարկիր այն 4 տարբեր տիպի վրա։ մինի-նախագծում
  9. Համեմատիր var_dump-ը և print_r-ը զանգվածի վրա։ Ո՞րն է ավելի հարմար և ե՞րբ։ մինի-նախագծում
  10. Բացիր էջը և սեղմիր Ctrl+U։ Գտի՞ր PHP կոդը։ Բացատրիր, ինչու։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
