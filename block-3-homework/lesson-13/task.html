classes/Book.php — ֆաբրիկա
public static function fromRow(array $row): static
{
    return match ($row['format'] ?? 'paper') {
        'audio' => AudioBook::fromRow($row),
        'ebook' => EBook::fromRow($row),
        default => PaperBook::fromRow($row),
    };
}

04Դասի տնային աշխատանքը

Սրանք Դաս 13-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում՝ Անիի ակումբում։ Մնացածը կատարիր ՏեխնոՄարկետում, ինչպես գրված է դասում։

  1. Կատարիր դասարանականի 10 քայլը։ մինի-նախագծում
  2. Ավելացրու երրորդ տեսակ՝ ServiceProduct (վերանորոգում, տեղադրում)։ Ի՞նչ մեթոդներ պիտի իրագործի։ մինի-նախագծում
  3. Ցուցադրիր մոռացված parent::__construct()-ի սխալը։ մինի-նախագծում
  4. Ստեղծիր Discountable ինտերֆեյսը և իրագործիր այն։
  5. Գրիր ֆունկցիա, որը ընդունում է Shippable և հաշվում ընդհանուր քաշը։ մինի-նախագծում
  6. Ցուցադրիր պոլիմորֆիզմը՝ մեկ foreach-ով երեք տարբեր տեսակի ապրանք։ մինի-նախագծում
  7. Գրիր նույն կոդը առանց պոլիմորֆիզմի՝ if/elseif-ով։ Համեմատիր տողերի քանակը և ընթեռնելիությունը։ մինի-նախագծում
  8. Գտիր քո կոդում տեղ, որտեղ ժառանգումը սխալ որոշում կլիներ։ Բացատրիր, ինչու։
  9. Վերաշարադրիր formattedPrice()-ը կոմպոզիցիայով՝ MoneyFormatter դասով։ մինի-նախագծում
  10. Խնդրիր AI-ին քննադատել քո հիերարխիան։ Առաջարկե՞ց կոմպոզիցիա որևէ տեղում։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը։ Օրինակում lab-… ֆայլերը փորձնական են․ դրանք հաջորդ դասի օրինակում այլևս չկան։ Գործարկելուց առաջ ստեղծիր բազան example/sql/-ի ֆայլերով և config.php-ը։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
