Կառուցվածքի համակարգը

Այսօր նոր CSS հատկություններ չենք սովորի։ Փոխարենը կկառուցենք համակարգ, որով կաշխատես մնացած 62 դասը՝ main > section > .row > .col > .wrapper։ Սա դասընթացի ամենակարևոր դասերից է։

Նախապայման՝ Դաս 01–09 Բլոկ 1 · Կառուցվածք Կրկնվում է Դաս 11–12-ին

00Ի՞նչ ենք սովորելու այսօր

  • Ինչո՞ւ է պետք համակարգ
  • Հինգ շերտը և ամեն մեկի պատասխանատվությունը
  • .row — պատերը
  • .col — բացակները
  • .wrapper — տեսքը
  • Լայնությունների համակարգը
  • Տիպիկ սխալները

01Խնդիրը

Պատկերացրու պարզ առաջադրանք․ երեք քարտ կողք կողքի, դրանց միջև 20px բացակ, էջի եզրերից՝ 60px։

առաջին միտքը
.card {
    width: 33.33%;
    margin: 10px;
    background: white;
    border-radius: 12px;
    padding: 16px;
}
Ի՞նչ կոտրվեց

1. 33.33% + margin-եր > 100% — երրորդ քարտն ընկնում է ներքև։
2. margin: 10px-ը կա նաև ձախ եզրին և աջ եզրին — բայց այնտեղ բացակ պետք չէր։
3. Վաղը քարտի ֆոնը պիտի փոխես — ուղղում ես նույն դասը, որտեղ նաև լայնությունն է։
4. Երկրորդ բաժնում նույն քարտերը պիտի լինեն 25%-ով — պիտի ստեղծես .card-small։

Խնդիրը մեկն է․ մեկ դասը փորձում է անել չորս գործ — դասավորել, բացակ ստեղծել, չափ սահմանել և տեսք տալ։

Լուծման գաղափարը

Բաժանել այդ չորս պատասխանատվությունը չորս տարբեր շերտի։ Ամեն շերտը պատասխանում է ուղիղ մեկ հարցի։

Այս սկզբունքը կոչվում է պատասխանատվությունների բաժանում, և այն աշխատում է ոչ միայն CSS-ում — երկրորդ և երրորդ բլոկներում կտեսնես նույնը JavaScript-ում և PHP-ում։

02Հինգ շերտ

<main> │ └── <section id="products"> ← ի՞նչ բաժին է սա │ └── <div class="row"> ← որտե՞ղ են պատերը │ ├── <div class="col w-33"> ← որքա՞ն լայն, որքա՞ն բացակ │ └── <div class="wrapper"> ← ինչպիսի՞ն է տեսքը │ ├── <div class="col w-33"> │ └── <div class="wrapper"> │ └── <div class="col w-33"> └── <div class="wrapper">
ՇերտՊատասխանում է հարցինԻ՞նչ CSS ունի
mainՀիմնական բովանդակությունն էԳրեթե ոչինչ
sectionԻ՞նչ բաժին է սաՖոն, ուղղահայաց padding
.rowՈրտե՞ղ են կողային պատերըdisplay: flex, padding: 0 60px
.colՈրքա՞ն լայն և որքա՞ն բացակwidth, padding: 10px
.wrapperԻնչպիսի՞ն է տեսքըՖոն, եզրագիծ, ստվեր, կլորացում
Գլխավոր կանոնը

Երբեք մի՛ խառնիր շերտերի պատասխանատվությունները։

Ֆոն .col-ի վրա — ❌
Լայնություն .wrapper-ի վրա — ❌
Բացակ .wrapper-ի margin-ով — ❌

Երբ սա պահպանվում է, ամեն ինչ աշխատում է կանխատեսելի։ Երբ խախտվում է — սկսվում է քաոսը։

03section — շերտը էջում

Դաս 5-ից գիտենք․ էջը բաժանվում է հորիզոնական շերտերի։ Ամեն section մեկ շերտ է։

css/main.css
/* Ընդհանուր բոլոր բաժինների համար */
section {
    padding: 60px 0;      /* ուղղահայաց բացակ — վեր և վար */
}

/* Կոնկրետ բաժնի ոճեր */
#hero {
    background-color: var(--dark);
    color: var(--on-dark);
}

#products {
    background-color: var(--bg);
}
Ուշադրություն ուղղություններին

section → ուղղահայաց բացակ (padding: 60px 0)
.row → հորիզոնական բացակ (padding: 0 60px)

Երկուսը միասին տալիս են ամբողջական «շրջանակը»։ Բայց դրանք առանձին են, որովհետև ուղղահայաց բացակը կարող է տարբեր լինել բաժնից բաժին, իսկ պատերը՝ միշտ նույնը։

Ինչո՞ւ ֆոնը section-ի վրա, ոչ .row-ի

section-ը ձգվում է ամբողջ էկրանի լայնությամբ։ Եթե ֆոնը դնես .row-ի վրա, այն կավարտվի 60px պատերի հետ միասին — կստացվի, որ գունավոր շերտն ամբողջ էկրանով չէ։

04.row — պատերը

երկու ֆայլ, երկու պատասխանատվություն
/* css/global.css — ՎԱՐՔԱԳԻԾԸ (նույնն է ամեն նախագծում) */
.row {
    display: flex;
}

/* css/main.css — ՉԱՓԸ (փոխվում է նախագծից նախագիծ) */
.row {
    padding: 0 60px;
}
┌─────────────────────────────────────────────┐ │ section (ամբողջ էկրանով, ֆոնով) │ │ │ │ ←60px→ ┌───────────────────────┐ ←60px→ │ │ │ .row │ │ │ │ երեխաները՝ կողք կողքի │ │ │ └───────────────────────┘ │ │ │ └─────────────────────────────────────────────┘ ↑ ↑ ձախ պատ աջ պատ
display: flex — առայժմ ընդունիր որպես տրված

Այս մեկ տողը երեխաներին դասավորում է կողք կողքի՝ առանց Դաս 9-ի 4px բացակների խնդրի։

Ինչպես է այն աշխատում — մանրամասն 11-րդ դասին։ Այսօր կենտրոնանում ենք կառուցվածքի վրա, ոչ մեխանիզմի։

Ինչո՞ւ պատերը .row-ի վրա, ոչ section-ի

Որովհետև մեկ section-ը կարող է ունենալ մի քանի .row՝ վերնագրի տողը, քարտերի տողը, կոճակի տողը։ Բոլորն էլ պիտի ունենան նույն պատերը։

Եթե պատերը լինեին section-ի վրա, հետո չէիր կարողանա ինչ-որ տող դարձնել ամբողջ լայնությամբ (օրինակ՝ նկարների շերտ առանց եզրերի)։

մի քանի row մեկ section-ում
<section id="products">

    <!-- Տող 1՝ վերնագիր -->
    <div class="row">
        <div class="col w-100">
            <h2>Մեր ապրանքները</h2>
        </div>
    </div>

    <!-- Տող 2՝ քարտեր -->
    <div class="row">
        <div class="col w-33">...</div>
        <div class="col w-33">...</div>
        <div class="col w-33">...</div>
    </div>

</section>

05.col — բացակները

Ահա այն շերտը, որը լուծում է 01-րդ բաժնի գլխավոր խնդիրը։

css/main.css
.col {
    padding: 10px;
}
Երկու քարտի միջև՝ 10 + 10 = 20px ┌──── .col ────┐┌──── .col ────┐ │ ←10px→ ││ ←10px→ │ │ ┌────────┐ ││ ┌────────┐ │ │ │.wrapper│ ││ │.wrapper│ │ │ └────────┘ ││ └────────┘ │ │ ││ │ └──────────────┘└──────────────┘ ↑ ↑ այս 10px-ը ընկնում է .row-ի պատի վրա
Խորամանկ և պարզ

Ամեն .col ունի 10px ներսի բացակ բոլոր կողմերից։ Երկու հարևան սյուների միջև ստացվում է 20px։

Իսկ ամենաձախ և ամենաաջ սյուների արտաքին 10px-ը գումարվում է .row-ի 60px-ին։ Եթե ուզում ես ուղիղ 60px՝ գրիր .row { padding: 0 50px }։

Ինչո՞ւ padding, ոչ margin

1. padding-ը ներսում է, ուստի width: 33.33%-ը մնում է ուղիղ 33.33% (շնորհիվ box-sizing: border-box-ի, Դաս 8)։ margin-ի դեպքում լայնությունը կգերազանցեր 100%-ը։
2. margin-ները կարող են «կպչել» իրար (margin collapse, Դաս 8)։ padding-ի հետ այդ խնդիրը չկա։
3. Դատարկ .col-ը չի ստեղծում տեսանելի բացակ, որովհետև ֆոն չունի։

.col-ը միշտ դատարկ է

.col-ը ոչ մի տեսողական ոճ չունի — ոչ ֆոն, ոչ եզրագիծ, ոչ ստվեր։ Այն միայն տարածություն է հատկացնում։

Եթե երբևէ ուզես ֆոն դնել .col-ի վրա, կտեսնես, որ բացակները անհետանում են — գունավոր ուղղանկյունները կկպչեն իրար։ Հենց դրա համար ֆոնը գնում է .wrapper-ի վրա։

06.wrapper — տեսքը

global.css + main.css
/* global.css — վարքագիծը */
.wrapper {
    height: 100%;    /* լցնում է ամբողջ .col-ը */
}

/* main.css — կոնկրետ բաժնի տեսքը */
#products .wrapper {
    background: white;
    border-radius: 12px;
    overflow: hidden;
    box-shadow: 0 2px 8px rgba(0,0,0,.08);
}
height: 100% — ինչու է կարևոր

Երեք քարտ տարբեր երկարության տեքստերով։ display: flex-ի շնորհիվ սյուները հավասար բարձրության են։ Բայց ներսի .wrapper-ները՝ ոչ, եթե չնշես։

height: 100%-ը ստիպում է սպիտակ քարտին լցնել ամբողջ սյունը։ Արդյունքում բոլոր քարտերը հավասար են՝ անկախ բովանդակությունից։

Հիշո՞ւմ ես Դաս 9-ի երրորդ խնդիրը՝ «հավասար բարձրություն հնարավոր չէ»։ Ահա լուծումը։

Ինչո՞ւ բաժնային սելեկտոր՝ #products .wrapper

.wrapper-ը օգտագործվում է ամենուր — և hero-ում, և ապրանքներում, և footer-ում։ Եթե գրես պարզապես .wrapper { background: white }, սպիտակ ֆոնը կհայտնվի բոլոր բաժիններում։

Ուստի կոնկրետ տեսքը միշտ կապում ենք բաժնին՝ #products .wrapper, #team .wrapper։

07Լայնությունների համակարգը

css/global.css
.w-10  { width: 10%; }
.w-20  { width: 20%; }
.w-25  { width: 25%; }
.w-30  { width: 30%; }
.w-33  { width: 33.3333%; }
.w-40  { width: 40%; }
.w-50  { width: 50%; }
.w-60  { width: 60%; }
.w-70  { width: 70%; }
.w-75  { width: 75%; }
.w-80  { width: 80%; }
.w-100 { width: 100%; }
HTML-ում
<!-- Չորս սյուն -->
<div class="row">
    <div class="col w-25">...</div>
    <div class="col w-25">...</div>
    <div class="col w-25">...</div>
    <div class="col w-25">...</div>
</div>

<!-- Անհամաչափ՝ 70 / 30 -->
<div class="row">
    <div class="col w-70">Հոդված</div>
    <div class="col w-30">Կողքի բլոկ</div>
</div>
Ինչո՞ւ 33.3333%, ոչ 33%

33% × 3 = 99%։ Կմնա 1% դատարկ տեղ աջ կողմում — փոքր, բայց նկատելի։
33.3333% × 3 = 99.9999% — գործնականում ուղիղ 100%։

Այս մոտեցումը կոչվում է utility-դասեր

Դասը մեկ գործ է անում, և անունը ուղիղ ասում է՝ ինչ։ .w-25 = «լայնությունը 25%»։

Կա նաև այլ մոտեցում՝ ամեն կոմպոնենտի համար սեփական դաս (.product-card, .product-card__image)։ Երկուսի առավելություններն ու թերությունները կհամեմատենք 13-րդ դասին։

08Տիպիկ սխալներ

❌ 1. Բաց թողնված շերտ
<!-- .wrapper-ը բացակայում է -->
<div class="row">
    <div class="col w-33">
        <h3>Վերնագիր</h3>
    </div>
</div>

<!-- ✅ Ճիշտ -->
<div class="row">
    <div class="col w-33">
        <div class="wrapper">
            <h3>Վերնագիր</h3>
        </div>
    </div>
</div>

Հիշիր Դաս 3-ի աղյուսակը՝ table > tr > td։ Այնտեղ շերտ բաց թողնելը սխալ էր։ Այստեղ նույնպես։

❌ 2. Ֆոն .col-ի վրա
/* ❌ Բացակները անհետանում են */
.col { background: white; }

/* ✅ */
#products .wrapper { background: white; }
❌ 3. Բացակ margin-ով
/* ❌ Կոտրում է 33.33%-ը */
.wrapper { margin: 10px; }

/* ✅ Բացակը միշտ .col-ի padding-ն է */
❌ 4. .row առանց .col-ի
<!-- ❌ Տեքստը ուղիղ .row-ի մեջ -->

Հետևողականությունը կարևոր է

Թվում է՝ մեկ վերնագրի համար .col-ը ավելորդ է։ Բայց երբ կառուցվածքը միշտ նույնն է, դու մտածում ես ավելի քիչ։ Չես հիշում՝ որտեղ շերտ կա, որտեղ՝ ոչ։

Բացի այդ՝ վաղը այդ վերնագրի կողքին կհայտնվի կոճակ, և կառուցվածքն արդեն պատրաստ կլինի։

09Խաղահրապարակ

Ամբողջ համակարգը՝ աշխատող վիճակում։ Փոխիր .w-* դասերը, ավելացրու սյուներ։

CSS ներդիրում կա փորձարկման բլոկ
Փորձիր

1. Բացիր CSS ներդիրը և հանիր մեկնաբանությունը վերջին բլոկից — կտեսնես բոլոր շերտերի սահմանները։
2. Փոխիր w-33-ը w-50-ի։
3. Ջնջիր .wrapper { height: 100% }-ը։
4. Փորձիր տեղափոխել background: white-ը .col-ի վրա։

10Դասարանական

Կառուցում ենք բաժին զրոյից՝ շերտ առ շերտ։ Ամեն քայլից հետո՝ պահպանիր և նայիր։

  1. Ստեղծիր <section id="team">
  2. Ներսում՝ առաջին .row վերնագրի համար, ներսում .col w-100
  3. Երկրորդ .row՝ չորս .col w-25
  4. Ամեն սյան ներսում՝ .wrapper
  5. .wrapper-ի ներսում՝ նկար, անուն, պաշտոն
  6. Ավելացրու global.css-ի կանոնները
  7. Ավելացրու main.css-ի պատերն ու բացակները
  8. Ոճավորիր #team .wrapper-ը
վերջնական HTML

Ստուգիր DevTools-ով

Ընտրիր ցանկացած .col և նայիր box model դիագրամը։ Կտեսնես 10px padding և զրո margin։

Ապա ընտրիր .wrapper-ը — այնտեղ ֆոն կա, բայց margin չկա։ Ամեն շերտ իր գործն է անում։

11Տնային աշխատանք

  1. Ավելացրու global.css-ում .row, .wrapper և բոլոր .w-* դասերը։
  2. Ավելացրու main.css-ում section-ի, .row-ի և .col-ի չափերը։
  3. Կառուցիր բաժին չորս սյունով (w-25)։ Ստուգիր, որ բացակները հավասար են։
  4. Կառուցիր բաժին երկու անհամաչափ սյունով՝ w-70 և w-30։
  5. Կառուցիր section, որի ներսում կան երեք տարբեր .row՝ վերնագիր, բովանդակություն, կոճակ։
  6. Ցուցադրիր height: 100%-ի ազդեցությունը՝ երեք քարտ շատ տարբեր երկարության տեքստերով, առաջ և հետո։
  7. Դիտավորյալ դիր ֆոն .col-ի վրա։ Նկարագրիր՝ ինչ կոտրվեց և ինչու։
  8. Դիտավորյալ բաց թող .wrapper-ը մեկ սյան մեջ։ Համեմատիր հարևանների հետ։
  9. Ժամանակավորապես ավելացրու outline-ներ բոլոր երեք շերտին տարբեր գույներով։ Ուղարկիր սքրինշոթ։
  10. Վերցրու Դաս 5-ի սեմանտիկ էջը և վերակառուցիր այն ամբողջովին այս համակարգով։ Ամեն բաժին պիտի ունենա id, ամեն սյուն՝ .wrapper։

12Հիշելու թերթիկ

main > section > .row > .col > .wrapper
ՇերտՊատասխանատվությունՉԻ անում
sectionՖոն, ուղղահայաց բացակԿողային պատեր
.rowdisplay: flex, կողային պատերՖոն, չափեր
.colԼայնություն, բացակ (padding)Ֆոն, եզրագիծ, ստվեր
.wrapperԱմբողջ տեսքըԼայնություն, margin

Ի՞նչ ավելացավ global.css-ում այսօր

✓ .row { display: flex; } ✓ .wrapper { height: 100%; } ✓ .h-100 { height: 100%; } ✓ .w-10 … .w-100 (12 դաս)

Ի՞նչ ավելացավ main.css-ում

✓ section { padding: 60px 0; } ✓ .row { padding: 0 50px; } ✓ .col { padding: 10px; }

Ստուգաթերթ

  • Ամեն section ունի id
  • Ամեն .row-ի ուղիղ երեխան .col է
  • Ամեն .col-ի ներսում կա .wrapper
  • Ամեն .col ունի .w-* դաս
  • Ֆոնը .wrapper-ի վրա է, ոչ .col-ի
  • Բացակները .col-ի padding-ն են, ոչ margin
  • Կոնկրետ ոճերը կապված են բաժնին՝ #section .wrapper
  • Մեկ սյան դեպքում էլ կառուցվածքը ամբողջական է

Ինքնաստուգում

  • Կարո՞ղ եմ անվանել հինգ շերտը հերթականությամբ
  • Գիտե՞մ, ինչու ֆոնը .wrapper-ի վրա է
  • Հասկանո՞ւմ եմ, ինչու padding, ոչ margin
  • Գիտե՞մ, ինչու պատերը .row-ի վրա են, ոչ section-ի
  • Կարո՞ղ եմ բացատրել height: 100%-ի իմաստը
Հաջորդ երկու դասը

Այս համակարգը կկրկնվի 11-րդ և 12-րդ դասերին։ Ամեն անգամ կկառուցենք նոր բաժին, բայց զուգահեռ կսովորենք Flexbox-ը՝ նախ առանցքներն ու հավասարեցումը, ապա flex-grow-ը և gap-ը։

Այդ ժամանակ վերջապես կհասկանաս, թե ինչ է անում display: flex-ը, որը այսօր ընդունեցիր որպես տրված։
