CSS փոփոխականներ և թեմաներ

Փոփոխականներն օգտագործում ենք Դաս 7-ից՝ առանց խորանալու։ Այսօր հասկանում ենք, ինչպես են դրանք իսկապես աշխատում, և կառուցում ենք մուգ թեմա՝ առանց մեկ տող JavaScript-ի։

Նախապայման՝ Դաս 06, 13, 17 Բլոկ 1 · Ճարտարապետություն Դիզայն-տոկեններ

00Ի՞նչ ենք սովորելու այսօր

  • Ինչպես են աշխատում փոփոխականները
  • Ժառանգում և վերասահմանում
  • Պահեստային արժեքներ
  • Դիզայն-տոկենների երկու շերտ
  • Մուգ թեմա՝ առանց JS-ի
  • prefers-color-scheme
  • Փոփոխականներ կոմպոնենտներում

01Հիմունքներ

սահմանում և օգտագործում
:root {
    --secondary: #003459;    /* սահմանում — երկու գծիկ */
}

.btn {
    background: var(--secondary);   /* օգտագործում */
}
ԱռանձնահատկությունԲացատրություն
Անունը սկսվում է ---ովՊարտադիր
Ռեգիստրը կարևոր է--Main ≠ --main
Ժառանգվում էԻ տարբերություն Sass-ի փոփոխականների ⭐
Աշխատում է runtime-ումԿարելի է փոխել media query-ով, JS-ով
Երևում է DevTools-ումԿարելի է խմբագրել ուղիղ բրաուզերում
Ի՞նչ է :root-ը

Դա <html> էլեմենտն է, բայց ավելի բարձր սպեցիֆիկությամբ (0-1-0 ընդդեմ 0-0-1)։

Փոփոխականները դնում ենք այնտեղ, որովհետև html-ը բոլորի նախնին է — և ժառանգման շնորհիվ դրանք հասանելի են ամենուր։

02Ժառանգում — գլխավոր գաղափարը

Սա այն է, ինչ տարբերում է CSS փոփոխականները սովորական «հաստատուններից»։

վերասահմանում ցանկացած մակարդակում
:root {
    --card-bg: #ffffff;
    --card-text: #1a1a1a;
}

.card {
    background: var(--card-bg);
    color: var(--card-text);
}

/* Մուգ բաժնում քարտերը դառնում են այլ —
   ԱՌԱՆՑ .card-ի կանոնը փոխելու            */
#hero {
    --card-bg: rgba(255,255,255,.1);
    --card-text: #ffffff;
}
:root --card-bg: #fff │ ├── section#products │ └── .card → #fff │ └── section#hero --card-bg: rgba(255,255,255,.1) └── .card → rgba(255,255,255,.1) Նույն .card դասը, տարբեր արդյունք։ Փոփոխականը վերցվում է մոտակա ծնողից։
Ինչո՞ւ է սա հզոր

Առանց փոփոխականների պիտի գրեիր՝
#hero .card { background: ...; color: ...; }

Իսկ եթե քարտն ունի 8 գունային հատկություն՝ 8 վերագրում։ Եվ ամեն նոր բաժնի համար՝ նորից 8։

Փոփոխականներով բաժինը պարզապես հայտարարում է իր պայմանները, և կոմպոնենտն ինքն է հարմարվում։

Պահեստային արժեք

var()-ի երկրորդ արգումենտը
.badge {
    background: var(--badge-bg, #c62828);
    /*                    ↑            ↑         */
    /*                փոփոխական    պահեստային    */
}

/* Եթե --badge-bg-ն սահմանված չէ, կօգտագործվի #c62828 */

/* Կարելի է շղթայել */
.el { color: var(--custom, var(--text, #000)); }
Անվավեր արժեքի թակարդ

Եթե փոփոխականը պարունակում է անվավեր արժեք, հատկությունը դառնում է «անվավեր ժառանգման ժամանակ» — և վերցնում է ժառանգված արժեքը, ոչ լռելյայնը։

--gap: 10rem; հետո margin: var(--gap) — լավ։
--gap: կապույտ; հետո margin: var(--gap) — margin-ը կդառնա ժառանգված արժեք, ոչ 0։

Սա շփոթեցնող է, և դրա համար DevTools-ում միշտ ստուգիր Computed ներդիրը։

03Դիզայն-տոկեններ

Հասուն համակարգում փոփոխականները երկու շերտի են։

շերտ 1 — պարզունակ արժեքներ
:root {
    /* Գունապնակ — ի՞նչ գույներ ունենք */
    --navy-900: #00253f;
    --navy-700: #003459;
    --navy-300: #9db4c0;
    --slate-900: #1a1a1a;
    --slate-500: #6b6b6b;
    --slate-100: #f5f5f5;
    --white: #ffffff;
    --red-600: #c62828;
    --green-600: #0f7b4f;
}
շերտ 2 — իմաստային անուններ
:root {
    /* Ի՞նչ դեր է կատարում ամեն գույնը */
    --bg:          var(--slate-100);
    --surface:     var(--white);
    --text:        var(--slate-900);
    --text-muted:  var(--slate-500);
    --accent:      var(--navy-700);
    --accent-hover:var(--navy-900);
    --on-accent:   var(--white);
    --border:      #e2e6e9;
    --danger:      var(--red-600);
    --success:     var(--green-600);
}

/* Կոմպոնենտները օգտագործում են ՄԻԱՅՆ երկրորդ շերտը */
.card { background: var(--surface); color: var(--text); }
.btn--primary { background: var(--accent); color: var(--on-accent); }
Ինչո՞ւ երկու շերտ — կրիտիկական պահ

Պատկերացրու՝ կոմպոնենտները գրված են var(--white)-ով։ Հիմա ուզում ես մուգ թեմա։ Պիտի գրես --white: #1e1e1e — և ստացվում է սպիտակը սև է։ Անհեթեթություն։

Իսկ --surface-ը իմաստային է․ «մակերես, որի վրա նստում է բովանդակությունը»։ Բաց թեմայում այն սպիտակ է, մուգում՝ մուգ մոխրագույն։ Անունը ճիշտ է մնում։

Կանոն՝ կոմպոնենտները երբեք ուղիղ չեն դիմում գունապնակին։

Այլ տոկեններ

ոչ միայն գույներ
:root {
    /* Հեռավորություններ */
    --space-1: 4px;
    --space-2: 8px;
    --space-3: 16px;
    --space-4: 24px;
    --space-5: 40px;

    /* Կմախք */
    --wall: 60px;
    --gap:  10px;

    /* Կլորացումներ */
    --radius-sm: 6px;
    --radius-md: 12px;
    --radius-full: 999px;

    /* Ստվերներ — Դաս 17 */
    --shadow-sm: 0 1px 3px rgba(0,0,0,.08);
    --shadow-md: 0 4px 12px rgba(0,0,0,.12);

    /* Անցումներ — Դաս 21 */
    --transition: .15s ease;
}

04Մուգ թեմա

Ահա ամբողջ երկու շերտի պարգևը․ թեման փոխվում է մեկ բլոկով։

css/main.css
/* ---------- Բաց թեմա (լռելյայն) ---------- */
:root, [data-theme="light"] {
    --bg:         #f5f5f5;
    --surface:    #ffffff;
    --text:       #1a1a1a;
    --text-muted: #6b6b6b;
    --border:     #e2e6e9;
    --accent:     #003459;
    --on-accent:  #ffffff;
    --shadow-md:  0 4px 12px rgba(0,0,0,.12);
}

/* ---------- Մուգ թեմա ---------- */
[data-theme="dark"] {
    --bg:         #151a1d;
    --surface:    #1e252a;
    --text:       #e8eced;
    --text-muted: #9aa5ab;
    --border:     #2c353b;
    --accent:     #5b9dd9;   /* ավելի բաց — կոնտրաստի համար ⭐ */
    --on-accent:  #0a1520;
    --shadow-md:  0 4px 14px rgba(0,0,0,.5);
}
Չորս սխալ, որ բոլորն են անում մուգ թեմա սարքելիս

1. Մաքուր սև ֆոն — #000-ը սպիտակ տեքստի հետ ստեղծում է չափազանց մեծ կոնտրաստ, տառերը «թրթռում են»։ Օգտագործիր #151a1d տիպի մուգ մոխրագույն։

2. Նույն ակցենտային գույնը — #003459-ը մուգ ֆոնի վրա գրեթե անտեսանելի է։ Մուգ թեմայում ակցենտները պիտի լինեն ավելի բաց։

3. Ստվերները մոռացված — մուգ ֆոնի վրա rgba(0,0,0,.1) ստվերը չի երևում։ Ուժեղացրու անթափանցիկությունը կամ օգտագործիր բաց եզրագիծ։

4. Նկարները չափազանց պայծառ — լուծում՝ img { filter: brightness(.9) } մուգ թեմայում։

անջատիչը — checkbox-ի հնարքով
<!-- body-ի սկզբում -->
<input type="checkbox" id="theme" class="theme-toggle">
<label for="theme" class="theme-btn">
    <span aria-hidden="true">☾</span>
    <span class="visually-hidden">Մուգ թեմա</span>
</label>
.theme-toggle { position: absolute; opacity: 0; }

/* Երբ նշված է — վերասահմանում ենք փոփոխականները */
.theme-toggle:checked ~ * {
    --bg:      #151a1d;
    --surface: #1e252a;
    --text:    #e8eced;
}
Այս մոտեցման սահմանափակումը

~ *-ը հասնում է միայն հետագա եղբայրներին։ Եթե ինչ-որ բան checkbox-ից առաջ է, այն չի փոխվի։ Նաև body-ի ֆոնը չի փոխվի, քանի որ body-ն եղբայր չէ։

Իրական լուծումը <html data-theme="dark">-ն է, որը պահանջում է մեկ տող JavaScript․
document.documentElement.dataset.theme = "dark"

Դա կանենք JS բլոկի Դաս 14-ում, երբ սովորենք localStorage-ը՝ որ ընտրությունը հիշվի։ Այս դասի էջն ինքը հենց այդպես է աշխատում — նայիր վերևի կոճակին։

05prefers-color-scheme

Համակարգն արդեն գիտի՝ օգտագործողը մուգ թեմա՞ է նախընտրում։ Կարելի է հարգել այդ ընտրությունը՝ ամբողջովին առանց JS-ի։

ավտոմատ թեմա
@media (prefers-color-scheme: dark) {
    :root {
        --bg:      #151a1d;
        --surface: #1e252a;
        --text:    #e8eced;
        --accent:  #5b9dd9;
    }
}
Լավագույն համադրությունը

1. Լռելյայն՝ հարգիր համակարգի ընտրությունը (prefers-color-scheme)։
2. Տուր օգտագործողին անջատիչ՝ ձեռքով փոխելու համար (data-theme)։
3. Հիշիր նրա ընտրությունը (localStorage — JS բլոկ)։

Ձեռքով ընտրությունը միշտ պիտի հաղթի համակարգայինին։

Ինչպես ստուգել DevTools-ով

Ctrl+Shift+P → գրիր «rendering» → Show Rendering

Այնտեղ կա Emulate CSS media feature prefers-color-scheme։ Ընտրիր dark և տես արդյունքը՝ առանց համակարգի կարգավորումները փոխելու։

Նույն վահանակում կա նաև prefers-reduced-motion-ը՝ Դաս 21-ի համար։

06Փոփոխականներ կոմպոնենտներում

Հզոր օրինաչափություն․ կոմպոնենտը հայտարարում է իր «պարամետրերը», որոնք դրսից կարելի է փոխել։

կոմպոնենտ՝ պարամետրերով
.btn {
    /* Պարամետրերը՝ լռելյայն արժեքներով */
    --btn-bg:     var(--accent);
    --btn-color:  var(--on-accent);
    --btn-border: transparent;

    background: var(--btn-bg);
    color: var(--btn-color);
    border: 1px solid var(--btn-border);
    padding: 12px 24px;
    border-radius: var(--radius-sm);
}

/* Մոդիֆիկատորները փոխում են ՄԻԱՅՆ պարամետրերը */
.btn--outline {
    --btn-bg: transparent;
    --btn-color: var(--accent);
    --btn-border: var(--accent);
}

.btn--danger {
    --btn-bg: var(--danger);
    --btn-color: #ffffff;
}

.btn--ghost {
    --btn-bg: transparent;
    --btn-color: var(--accent);
}
Համեմատիր Դաս 17-ի հետ

Այնտեղ ամեն մոդիֆիկատոր վերագրում էր background, color, border-color — երեք հատկություն։

Այստեղ մոդիֆիկատորը փոխում է միայն երեք փոփոխական, իսկ իրական հատկությունները գրված են մեկ տեղում՝ .btn-ում։

Երբ ուզես ավելացնել, օրինակ, box-shadow-ը՝ ավելացնում ես մեկ տեղում, և բոլոր տարբերակները ստանում են այն։

մեկ անգամ օգտագործվող ուղղում
<!-- Inline style-ը այստեղ արդարացված է -->
<button class="btn" style="--btn-bg: #7b1fa2">Հատուկ</button>
Ե՞րբ է inline style-ը ընդունելի

Սովորաբար՝ երբեք։ Բայց փոփոխականի փոխանցումը բացառություն է․ դու չես գրում ոճ, դու փոխանցում ես պարամետր։

Հատկապես օգտակար է, երբ արժեքը գալիս է սերվերից՝ ապրանքի գույնը, առաջընթացի տոկոսը, դիագրամի բարձրությունը։ PHP բլոկում սա շատ կհանդիպի։

07Խաղահրապարակ

Աշխատող թեմայի փոխարկիչ։ Սեղմիր անջատիչին կամ փոխիր փոփոխականները CSS ներդիրում։

Սեղմիր «Փոխել թեման»
Փորձիր

1. Սեղմիր անջատիչին — քանի՞ կանոն փոխվեց։ (Ոչ մեկը, միայն 9 փոփոխական։)
2. Ջնջիր .hero-ի ներսի փոփոխականները։
3. Փոխիր --accent-ը մուգ թեմայում var(--navy-700)-ի — ընթեռնե՞լի է։
4. Փոխիր inline կոճակի --btn-bg-ը։

08Դասարանական

  1. Վերակառուցիր main.css-ի :root-ը երկու շերտով
  2. Գունապնակին տուր տեխնիկական անուններ (--navy-700)
  3. Ստեղծիր իմաստային շերտ (--surface, --text, --accent)
  4. Անցիր բոլոր կոմպոնենտներով և փոխարինիր ուղիղ գույները իմաստային փոփոխականներով
  5. Ավելացրու հեռավորությունների և կլորացումների տոկեններ
  6. Ստեղծիր մուգ թեմայի բլոկ
  7. Ստուգիր բոլոր կոնտրաստները մուգ թեմայում
  8. Ավելացրու prefers-color-scheme
  9. Վերաշարադրիր .btn-ը պարամետրերով
Ամենակարևոր քայլը՝ չորրորդը

Բացիր main.css-ը և որոնիր # նշանը։ Ամեն HEX գույն, որը գտնում ես :root-ից դուրս, խնդիր է։

Այն պիտի կամ դառնա տոկեն, կամ փոխարինվի գոյություն ունեցող տոկենով։ Երբ ավարտես, մուգ թեման կաշխատի ինքնաբերաբար։

Եթե ինչ-որ գույն մուգ թեմայում սխալ է երևում — ուրեմն մի տեղ HEX է մնացել։

09Տնային աշխատանք

Մինի-նախագիծ

Այս տնայինի գլխավոր մասը՝ «Տոկեններ և մուգ թեմա», քայլ առ քայլ, starter ֆայլերով և պատրաստի օրինակով։ Ներքևի ցուցակի մնացած կետերը առանձին վարժություններ են։

  1. Ստեղծիր երկու շերտի տոկենների համակարգ՝ 8+ գունապնակ, 10+ իմաստային։
  2. Ցուցադրիր ժառանգումը՝ նույն .card դասը երկու բաժնում, տարբեր տեսքով, առանց վերագրումների։
  3. Օգտագործիր var()-ի պահեստային արժեքը։ Ցույց տուր, ինչ է լինում, երբ փոփոխականը սահմանված չէ։
  4. Ստեղծիր անվավեր արժեք (--gap: կապույտ) և նկարագրիր, ինչ եղավ։ Ստուգիր DevTools-ի Computed ներդիրում։
  5. Կառուցիր մուգ թեմա։ Ստուգիր բոլոր կոնտրաստները և գրիր արժեքները։
  6. Ցուցադրիր չորս սխալը մուգ թեմայում՝ մաքուր սև, նույն ակցենտ, անտեսանելի ստվեր, պայծառ նկար։ Ապա ուղղիր բոլորը։
  7. Ավելացրու prefers-color-scheme և ստուգիր DevTools-ի Rendering վահանակով։
  8. Վերաշարադրիր .btn-ը պարամետրերով։ Համեմատիր Դաս 17-ի տարբերակի հետ՝ քանի՞ տող կրճատվեց։
  9. Ստեղծիր առաջընթացի գիծ, որի տոկոսը փոխանցվում է inline փոփոխականով՝ style="--progress: 65%"։
  10. Անցիր ամբողջ նախագծով և հեռացրու բոլոր HEX գույները :root-ից դուրս։ Հաշվիր՝ քանիսը գտար։

10Հիշելու թերթիկ

ԳրառումԻնչ է անում
--name: valueՍահմանում
var(--name)Օգտագործում
var(--name, fallback)Պահեստային արժեք
:rootԳլոբալ սահմանում
Վերասահմանում սելեկտորումԱզդում է միայն այնտեղ և ներսում ⭐
[data-theme="dark"]Թեմայի փոխարկում
@media (prefers-color-scheme: dark)Համակարգի ընտրություն
style="--x: value"Պարամետրի փոխանցում ✅

Երկու շերտ

Շերտ 1՝ ի՞նչ գույներ ունենք --navy-700: #003459 --white: #ffffff Շերտ 2՝ ի՞նչ դեր են կատարում --accent: var(--navy-700) --surface: var(--white) Կոմպոնենտները դիմում են ՄԻԱՅՆ շերտ 2-ին

Ի՞նչ ավելացավ main.css-ում այսօր

✓ Գունապնակի շերտ (--navy-*, --slate-*) ✓ Իմաստային շերտ (--bg, --surface, --text, --accent...) ✓ --space-*, --radius-*, --shadow-* ✓ [data-theme="dark"] բլոկ ✓ @media (prefers-color-scheme: dark) ✓ .btn-ը՝ պարամետրերով

Ստուգաթերթ

  • :root-ից դուրս HEX գույն չկա
  • Կոմպոնենտները դիմում են իմաստային շերտին
  • Մուգ թեմայի ֆոնը մաքուր սև չէ
  • Մուգ թեմայի ակցենտն ավելի բաց է
  • Ստվերները հարմարեցված են մուգ թեմային
  • Բոլոր կոնտրաստները ≥ 4.5:1 երկու թեմայում
  • Անջատիչն ունի տեքստային անուն
  • Կա prefers-color-scheme աջակցություն

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչու երկու շերտ
  • Գիտե՞մ, ինչ է լինում, երբ փոփոխականը վերասահմանվում է սելեկտորում
  • Հասկանո՞ւմ եմ, ինչու մուգ թեմայում ակցենտը պիտի փոխվի
  • Կարո՞ղ եմ բացատրել, ե՞րբ է inline style-ը ընդունելի
  • Գիտե՞մ, ինչու CSS փոփոխականներն ավելի հզոր են, քան Sass-ինը
