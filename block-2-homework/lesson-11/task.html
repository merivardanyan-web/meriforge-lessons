00Ինչ պետք է ստացվի

01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/css/books-11.css — CSS-ը, որ ավելանում է այս դասին
  • starter/pages/books.html — «Գրքեր» էջի markup-ը (JS չկա, միայն <script>-ները)

02Քայլեր

Քայլ 1 · Նոր HTML

  • Ֆիլտրի կոճակներ data-filter-ով և որոնման դաշտ (starter/pages/books.html)
  • Մոդալի markup-ը՝ main-ի վերջում
  • Header-ում՝ թեմայի կոճակ բոլոր էջերում, և js/site.js՝ բոլոր էջերում

Քայլ 2 · Ֆիլտր և որոնում

  • Երկու փոփոխական՝ currentFilter և query
  • getVisibleBooks()՝ երկու filter
  • Կոճակի սեղմում → փոխել փոփոխականը → «հանել բոլորից, ավելացնել ընտրվածին» → render()
js/books.js — ֆիլտրի կոճակներ
filterButtons.forEach(button => {
    button.addEventListener("click", () => {
        currentFilter = button.dataset.filter;
        filterButtons.forEach(b => b.classList.remove("is-active"));
        button.classList.add("is-active");
        render();
    });
});

Քայլ 3 · Մոդալ

  • «Մանրամասն»-ը բացում է մոդալը գրքի տվյալներով
  • Փակվում է խաչիկով, ֆոնին սեղմելով (e.target === modal) և Escape-ով
  • Բաց մոդալի տակ էջը չի սքրոլվում՝ no-scroll

Քայլ 4 · Խնդիրը

  • Ֆիլտրից հետո «Մանրամասն»-ը չի աշխատում։ Ինչու՞․ innerHTML-ը ստեղծել է նոր կոճակներ՝ առանց մշակիչների
  • Այսօրվա լուծում՝ render()-ի վերջում կանչիր bindDetailsButtons()։ Դաս 12-ում կգտնենք ավելի լավը

Քայլ 5 · Թեմա և բուրգեր

  • document.body.classList.toggle("dark"), իսկ մուգ տոկենները՝ CSS-ում (body.dark)
  • Կոճակի նշանը՝ ☾ / ☀
  • Բուրգեր՝ ամեն հղման սեղմելիս և Escape-ով navToggle.checked = false

03Ստուգաթերթ

  • «Կարդացել եմ»-ը թողնում է 3 գիրք, ակտիվ կոճակը մեկն է
  • Որոնումը աշխատում է վերնագրով և հեղինակով, մեծատառ-փոքրատառ չի զգում
  • Մոդալը աշխատում է նաև ֆիլտրից հետո
  • Մուգ թեման աշխատում է բոլոր էջերում (բայց թարմացնելիս կորչում է․ Դաս 14)
  • Հեռախոսում մենյուն փակվում է հղման սեղմելիս

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Մոդալը փակվում է ներսում սեղմելիսՍտուգիր e.target === modal, ոչ պարզապես սեղմումը
«Մանրամասն»-ը աշխատում է միայն մինչև առաջին ֆիլտրըՄշակիչները կորել են innerHTML-ից։ Կախիր նորից render-ից հետո
Մի քանի կոճակ ակտիվ էՆախ հանիր is-active-ը բոլորից
site.js-ը սխալ է տալիս էջում, որտեղ մոդալ չկաsite.js-ում միայն այն, ինչ կա բոլոր էջերում

04Դասի մյուս վարժությունները

Սրանք Դաս 11-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Կոճակ, որը սեղմելիս փոխում է h1-ի տեքստը։ Երկրորդ սեղմումին՝ վերադարձնում է հինը։
  2. Հաշվիչ․ երկու կոճակ (+ և −) և թիվ էկրանին։ Թիվը 0-ից ցածր չպիտի իջնի։
  3. Մուգ/բաց թեմայի փոխարկիչ՝ document.body.classList.toggle("dark")։ մինի-նախագծում
  4. Բուրգեր մենյու։ Ավելացրու՝ մենյուն փակվի նաև ցանկացած հղումի սեղմելիս։ մինի-նախագծում
  5. Մոդալ պատուհան՝ բացում, փակում խաչիկով, ֆոնին սեղմելով և Escape-ով։ մինի-նախագծում
  6. Ակորդեոն առնվազն 4 հարցով։ Միաժամանակ միայն մեկը պիտի բաց լինի։
  7. Թաբեր՝ 3 ներդիրով և 3 պանելով, data-* ատրիբուտներով։
  8. Դաշտ և պարբերություն։ input իրադարձությամբ պարբերությունը պիտի ցույց տա մուտքագրվածը իրական ժամանակում։ մինի-նախագծում
  9. Նույն դաշտի տակ ցույց տուր՝ քանի՞ նիշ է մնացել 100-ից։ 90-ից հետո տեքստը դառնա կարմիր (classList-ով)։
  10. Վերցրու Դաս 10-ի կատալոգը։ Ավելացրու 3 ֆիլտրի կոճակ՝ «Բոլորը», «Առկա», «Էժան»։ Ամեն սեղմումին կանչիր render()-ը ֆիլտրված զանգվածով և ակտիվ կոճակին տուր is-active դասը։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
