02Քայլեր

Քայլ 1 · Պլան օրերով

  • «Վերք Հայաստանի», 320 էջ, օրական 45
  • for, որի քայլը 45 է․ from += perDay
  • Վերջին օրը՝ միայն մնացած էջերը
main.js — պլան
for (let from = 1; from <= pages; from += perDay) {
    let to = from + perDay - 1;
    if (to > pages) {
        to = pages;
    }
    console.log(`Օր ${day}՝ էջ ${from}–${to}`);
    day++;
}

04Դասի մյուս վարժությունները

Սրանք Դաս 03-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Տպիր 1-ից 20 թվերը for-ով, ապա նույնը՝ while-ով։
  2. Տպիր 100-ից 1 թվերը՝ 5-ական քայլով (100, 95, 90…)։
  3. Հաշվիր 1-ից 50 զույգ թվերի գումարը։
  4. Օգտագործողից վերցրու թիվ և տպիր դրա բազմապատկման աղյուսակը 1-ից 10։
  5. Հաշվիր տրված թվի ֆակտորիալը (5! = 1×2×3×4×5 = 120)։

  8. Տրված է թիվ։ Հաշվիր՝ քանի՞ թվանշան ունի (օրինակ՝ 4729 → 4)։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
