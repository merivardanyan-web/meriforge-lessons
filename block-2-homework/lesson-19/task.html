Ինչ կարդալ հետո՝ ասինխրոն

00Ինչ պետք է ստացվի

01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/css/books-19.css — CSS-ը, որ ավելանում է այս դասին
  • starter/js/fake-api.js — առաջարկների և խորհուրդների տվյալները
  • starter/pages/books.html — «Գրքեր» էջի markup-ը (JS չկա, միայն <script>-ները)

02Քայլեր

Քայլ 1 · «Սերվեր»

  • fake-api.js՝ delay(ms), getRecommended() (20% դեպքերում՝ սխալ), getTip()
  • Ֆունկցիաները վերադարձնում են Promise, տվյալները՝ starter/-ից
js/fake-api.js
export const delay = ms => new Promise(resolve => setTimeout(resolve, ms));

export function getRecommended() {
    return delay(DELAY).then(() => {
        if (Math.random() < FAIL_RATE) {
            return Promise.reject(new Error("Սերվերը չպատասխանեց"));
        }
        return RECOMMENDED;
    });
}

03Ստուգաթերթ

  • Էջը բացվում է կմախքներով, մոտ 1 վրկ հետո՝ առաջարկներ
  • «Թարմացնել»-ը մի քանի անգամ․ երբեմն երևում է սխալը, իսկ խորհուրդը մնում է
  • Բեռնման ընթացքում կոճակը անջատված է
  • Նույն գիրքը դարակում երկու անգամ չի հայտնվում

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Էջում [object Promise]Promise-ը արժեք չէ․ արդյունքը՝ .then-ում
Սխալը չի բռնվում.then շղթայի վերջում չկա .catch (կամ allSettled-ի status-ը չես ստուգում)
Կոճակը մնում է անջատվածՄիացրու finally-ում, ոչ միայն հաջողության դեպքում
Մեկ .then-ում մոռացված returnՀաջորդ .then-ը ստանում է undefined (Դաս 19 տնային)

04Դասի մյուս վարժությունները

Սրանք Դաս 19-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Կանխագուշակիր հերթականությունը, հետո ստուգիր․ console.log("A"), setTimeout(...,0) «B»-ով, Promise.resolve().then() «C»-ով, console.log("D")։ Բացատրիր արդյունքը մեկնաբանության մեջ։
  2. Գրիր delay(ms) ֆունկցիան։ Օգտագործիր այն 3 վայրկյանանոց հետհաշվարկի համար՝ 3, 2, 1, «Մեկնարկ»։
  3. Գրիր getRandomNumber(), որը 1 վայրկյան հետո resolve է անում պատահական թիվ։ 50% դեպքերում՝ reject։ Մշակիր երկու դեպքն էլ։ մինի-նախագծում
  4. Գրիր getUser(id), որը վերադարձնում է Promise։ Անվավեր id-ի դեպքում՝ reject(new Error(...))։
  5. Ավելացրու getOrders(userId) և կապիր շղթայով՝ նախ օգտագործող, հետո նրա պատվերները։
  6. Կրկնիր նույն շղթան, բայց մոռացիր return-ը մեկ .then-ում։ Գրիր՝ ինչ ստացվեց և ինչու։
  7. Օգտագործիր Promise.all՝ երեք «հարցում» զուգահեռ։ Չափիր ժամանակը console.time-ով և համեմատիր հերթականի հետ։
  8. Կրկնիր նույնը Promise.allSettled-ով, որտեղ մեկը ձախողվում է։ Ցուցադրիր՝ որոնք հաջողվեցին և որը՝ ոչ։ մինի-նախագծում
  9. Կառուցիր էջ՝ կոճակով, բեռնման ցուցիչով և արդյունքի բլոկով։ Սեղմելիս ցուցիչը հայտնվում է, 2 վրկ հետո՝ արդյունքը։ Օգտագործիր .finally()։ մինի-նախագծում
  10. Նույն էջում 30% հավանականությամբ նմանակիր սխալ և ցույց տուր հաղորդագրություն՝ «Կրկին փորձել» կոճակով։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Դաս 18-ից օրինակը բացիր Live Server-ով։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
