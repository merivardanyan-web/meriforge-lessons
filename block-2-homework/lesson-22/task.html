js/models/Book.js — setter
set read(value) {
    if (value < 0 || value > this.pages) {
        throw new Error(`Էջը պիտի լինի 0-ից ${this.pages}`);
    }
    this.#read = value;
}

04Դասի մյուս վարժությունները

Սրանք Դաս 22-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Ստեղծիր User դաս՝ name, email, age և greet() մեթոդով։ Ստեղծիր 3 օրինակ։
  2. Ավելացրու get isAdult(), որը վերադարձնում է true, եթե տարիքը 18-ից մեծ է։
  3. Ավելացրու set email(value)՝ վալիդացիայով (Դաս 13-ի regex-ով)։ Սխալի դեպքում՝ throw։
  4. Ցուցադրիր this-ի կորուստը․ պոկիր մեթոդը օբյեկտից և կանչիր։ Ուղղիր bind-ով։
  5. Ստեղծիր Rectangle դաս՝ area և perimeter getter-ներով։ Ապա Square extends Rectangle։
  6. Ստեղծիր BankAccount դաս #balance-ով, deposit, withdraw և get balance մեթոդներով։ Ստուգիր բոլոր սխալ դեպքերը։
  7. Ավելացրու static հաշվիչ՝ քանի՞ հաշիվ է ստեղծվել։
  8. Ստեղծիր Timer դաս՝ start(), stop(), reset() մեթոդներով։ Օգտագործիր arrow ֆունկցիա setInterval-ի ներսում և բացատրիր ինչու։ մինի-նախագծում
  9. Վերածիր Դաս 16-ի զամբյուղը Cart դասի՝ դասարանական օրինակի պես։ Ստուգիր, որ ամեն ինչ աշխատում է։
  10. Ստեղծիր երկրորդ օրինակ՝ wishlist, նույն Cart դասով, բայց տարբեր բանալիով։ Համոզվիր, որ դրանք իրար չեն խանգարում։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Դաս 18-ից օրինակը բացիր Live Server-ով։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
