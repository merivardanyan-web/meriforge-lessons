01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/.gitignore — պատրաստի կանոններ
  • starter/README.md — README-ի ձևանմուշ

02Քայլեր

Քայլ 1 · Պահոց

  • Կայքի թղթապանակում՝ git init, .gitignore (starter/-ից)
  • Առաջին commit-ը՝ HTML/CSS բլոկի վիճակը, երկրորդը՝ JS-ը
  • Եթե արդեն ունես հին պատմություն՝ շարունակիր դրանից

git add .
git commit -m "Անիի կայքը՝ HTML/CSS բլոկ"
git log --oneline

04Դասի մյուս վարժությունները

Սրանք Դաս 17-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Կարգավորիր Git-ը՝ user.name և user.email։ Ուղարկիր git config --global --list-ի արդյունքի սքրինշոթը։
  2. Հրապարակիր քո կատալոգը GitHub Pages-ով։ Ուղարկիր աշխատող հասցեն։ մինի-նախագծում
  3. Գրիր README.md՝ նկարագրությամբ, հնարավորությունների ցուցակով և հասցեով։ մինի-նախագծում
  4. Կատարիր առնվազն 5 իմաստալից commit՝ առանձին փոփոխություններով։ Ուղարկիր git log --oneline-ի արդյունքը։ մինի-նախագծում
  5. Ստեղծիր feature/ ճյուղ, ավելացրու նոր հնարավորություն, միացրու main-ին և ջնջիր ճյուղը։ մինի-նախագծում
  6. Դիտավորյալ ստեղծիր կոնֆլիկտ․ երկու ճյուղում փոխիր նույն տողը և միացրու։ Լուծիր և նկարագրիր՝ ինչ արեցիր։
  7. Ավելացրու .gitignore առնվազն 5 կանոնով։ մինի-նախագծում
  8. Հրապարակիր նաև քո HTML/CSS բլոկի նախագծերից մեկը՝ առանձին պահոցում։ մինի-նախագծում
  9. Փորձիր git clone-ը՝ ներբեռնիր քո սեփական պահոցը ուրիշ թղթապանակում և համոզվիր, որ ամեն ինչ տեղում է։
  10. Գտիր GitHub-ում որևէ հետաքրքիր բաց նախագիծ, նայիր դրա README-ն և commit-երի պատմությունը։ Գրիր՝ ի՞նչ նկատեցիր։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
