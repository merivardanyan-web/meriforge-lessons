# Անի Սարգսյան · անձնական կայք

Անիի կայքը, որը կառուցվել է HTML/CSS բլոկում, և դրա «Գրքեր» էջը՝ ընթերցանության օրագիր JavaScript-ով։

## Դիտել
https://ՕԳՏԱՆՈՒՆ.github.io/ՊԱՀՈՑ/

## Հնարավորություններ
- Դարակ՝ ֆիլտրեր, որոնում, գնահատական աստղերով, առաջընթացի գիծ
- Նոր գիրք ֆորմայով՝ սխալների ստուգմամբ
- Ամեն ինչ պահվում է localStorage-ում
- «Կարդում եմ հիմա» ժամաչափ
- Մուգ/բաց թեմա՝ ընտրության պահպանմամբ

## Տեխնոլոգիաներ
HTML, CSS (Flexbox, Grid, տոկեններ), JavaScript (ES6+)

## Կառուցվածք
- `pages/books.html` — ընթերցանության օրագիր
- `js/` — `storage.js`, `site.js` (բոլոր էջերում), `data.js`, `books.js`, `form.js`, `timer.js`

## Հեղինակ
