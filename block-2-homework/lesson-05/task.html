02Քայլեր

Քայլ 1 · Երկու զանգված՝ նույն ինդեքսներով

  • shelf՝ վերնագրեր, pagesList՝ էջեր։ Նույն ինդեքսը՝ նույն գիրքը
  • showShelf()՝ համարակալված ցուցակ, դատարկի դեպքում՝ հաղորդագրություն

Քայլ 2 · Ավելացնել և հանել

  • addBook(title, pages)՝ կրկնություն չի թույլատրում (includes)
  • removeBook(title)՝ indexOf + splice, երկու զանգվածից
  • Չգտնվելու դեպքում՝ «Չգտնվեց»
main.js — removeBook
function removeBook(title) {
    const index = shelf.indexOf(title);
    if (index === -1) {
        return "Չգտնվեց";
    }
    shelf.splice(index, 1);
    pagesList.splice(index, 1);
    return `Հանվեց՝ «${title}»`;
}

03Ստուգաթերթ

  • Նույն գիրքը երկրորդ անգամ չի ավելանում
  • Հանելուց հետո երկու զանգվածը նույն երկարությունն ունեն
  • Բնօրինակը չի փոխվում reverse-ից
  • Ֆունկցիաները վերադարձնում են տեքստ, տպում է կանչող կոդը

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Հանելուց հետո էջերը «տեղաշարժվել» ենՀանել ես միայն մեկ զանգվածից
splice(index)-ը հանեց ամեն ինչԵրկրորդ արգումենտը՝ քանակը․ splice(index, 1)
reverse()-ը փոխեց դարակըreverse-ը փոխում է բնօրինակը։ Նախ պատճեն՝ [...shelf]
indexOf-ը միշտ -1 էՎերնագրում բացատ կամ տառասխալ կա․ համեմատումը ճշգրիտ է

04Դասի մյուս վարժությունները

Սրանք Դաս 05-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Ստեղծիր 7 թվից բաղկացած զանգված։ Տպիր առաջինը, վերջինը, երկարությունը և միջինը։
  2. Գրիր getSum(arr) ֆունկցիա, որը վերադարձնում է զանգվածի բոլոր թվերի գումարը։ մինի-նախագծում
  3. Գրիր getMax(arr) և getMin(arr)՝ առանց Math.max-ի, ցիկլով։
  4. Ունես 10 գնահատական։ Հաշվիր՝ քանիսն են 14-ից բարձր, և ստեղծիր դրանցից նոր զանգված։
  5. Գրիր countEvens(arr)՝ քանի՞ զույգ թիվ կա զանգվածում։
  6. Ունես անունների զանգված։ Տպիր դրանք համարակալված ցուցակով՝ 1. Անի, 2. Դավիթ… մինի-նախագծում
  7. Գրիր reverseArray(arr)՝ վերադարձնում է շրջված նոր զանգված։ Բնօրինակը չպիտի փոխվի (օգտագործիր [...arr])։
  8. Տրված է "կարմիր,կանաչ,կապույտ,դեղին" տողը։ Վերածիր զանգվածի, ավելացրու «սև», ապա հետ վերածիր տողի՝ " | " բաժանարարով։ մինի-նախագծում
  9. Գրիր removeItem(arr, item)՝ գտնում է էլեմենտը indexOf-ով և հեռացնում splice-ով։ Եթե չկա — վերադարձնում է «Չգտնվեց»։ մինի-նախագծում
  10. Ունես երկու զանգված։ Ստեղծիր երրորդը, որտեղ կլինեն միայն այն էլեմենտները, որոնք կան երկուսում էլ (օգտագործիր includes)։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը
