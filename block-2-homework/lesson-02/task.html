02Քայլեր

Քայլ 1 · Մուտքի ստուգում

  • prompt-ով հարցրու՝ քանի էջ ես կարդացել «Սամվել»-ից (560 էջ)
  • Եթե թիվը բացասական է կամ էջերից մեծ՝ «Սխալ թիվ»։ Մնացած ամեն ինչ՝ else-ի ներսում

Քայլ 2 · Կարգավիճակ

  • 0 → «Կարդալու եմ», էջերից քիչ → «Կարդում եմ», հավասար → «Կարդացել եմ ✓»
  • Ternary-ով՝ «Մեծ գիրք է», եթե 300 էջից ավելի է
main.js — կարգավիճակ
let status;
if (pagesRead === 0) {
    status = "Կարդալու եմ";
} else if (pagesRead < pages) {
    status = "Կարդում եմ";
} else {
    status = "Կարդացել եմ ✓";
}

Քայլ 3 · Օրվա նպատակ

  • Նպատակը՝ 20 էջ, հանգստյան օրերին (6 և 7)՝ կրկնակի
  • day === 6 || day === 7 և ternary
  • Կատարե՞լ ես՝ թե՞ քանի էջ է մնացել

Քայլ 4 · Գնահատական switch-ով

  • 5 → «★★★★★ Գերազանց», 4 → «★★★★☆ Լավ», 3 → «Միջին», 2 և 1 → «Չհավանեցի» (երկու case՝ մեկ գործողություն), մնացածը → «Դեռ չեմ գնահատել»

Քայլ 5 · ?? և ||

  • note ?? "չկա"
  • Տես, թե ինչ է տալիս 0 || "ոչինչ"-ը և 0 ?? "անհայտ"-ը։ Ինչու՞ են տարբեր (Դաս 2, truthy/falsy)

Քայլ 6 · Գրախանութ

  • Գիրքը 6 500 դրամ է, գնում ես 4 հատ
  • 20 000-ից բարձր՝ 10%, 50 000-ից բարձր՝ 20% զեղչ
  • Տպիր գումարը, զեղչը և վճարելիքը

03Ստուգաթերթ

  • Բոլոր ճյուղերը փորձարկված են․ prompt-ում գրիր 0, 140, 560 և 700
  • ===, ոչ ==
  • switch-ի ամեն case ավարտվում է break-ով
  • Կախարդական թվեր չկան․ 20, 300 և զեղչի սահմանները՝ փոփոխականներում

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Ամեն ինչ «Կարդում եմ» էՊայմանների հերթականությունը․ նախ 0, հետո «քիչ», վերջում մնացածը
switch-ը տպում է մի քանի տողՄոռացել ես break-ը
"140" === 140-ը false էprompt-ի արժեքը՝ Number()-ով
Զեղչը 20% է 30 000-ի դեպքումՆախ ստուգիր մեծ սահմանը (50 000), հետո փոքրը

04Դասի մյուս վարժությունները

Սրանք Դաս 02-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. prompt-ով վերցրու թիվ և տպիր՝ դրական է, բացասական, թե զրո։
  2. Վերցրու թիվ և տպիր՝ զույգ է թե կենտ։ Օգտագործիր %։
  3. Երեք թիվ՝ a, b, c։ Գտիր և տպիր ամենամեծը (միայն if-երով, առանց Math.max)։
  4. Ջրի ջերմաստիճանը՝ փոփոխական։ 0-ից ցածր՝ «սառույց», 0–99՝ «հեղուկ», 100 և ավելի՝ «գոլորշի»։
  5. Խանութում գնումը 20 000 դրամից բարձր է — 10% զեղչ։ 50 000-ից բարձր — 20%։ Հաշվիր և տպիր վերջնական գումարը։ մինի-նախագծում
  6. Օգտագործողից վերցրու օրվա համարը (1–7) և switch-ով տպիր օրվա անունը։ Սխալ թվի դեպքում՝ «Սխալ մուտք»։
  7. Մուտքի ստուգում․ login === "admin" ԵՎ password === "1234" → «Բարի գալուստ», այլապես՝ «Սխալ տվյալներ»։
  8. Գրիր ternary-ով․ եթե տարիքը 18-ից մեծ է — «մուտքն ազատ է», այլապես — «մուտքն արգելված է»։ մինի-նախագծում
  9. Բացատրիր մեկնաբանության մեջ՝ ինչո՞ւ է 0 || "պահեստային"-ը տալիս «պահեստային», իսկ 0 ?? "պահեստային"-ը՝ 0։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
