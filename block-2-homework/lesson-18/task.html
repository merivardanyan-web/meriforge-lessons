01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

Starter չկա․ այս դասին փոխվում է միայն JS-ի կառուցվածքը։

04Դասի մյուս վարժությունները

Սրանք Դաս 18-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Տեղադրիր Live Server-ը VS Code-ում և բացիր քո կատալոգը դրանով։ Համոզվիր, որ հասցեն սկսվում է http://-ով։ մինի-նախագծում
  2. Ստեղծիր երկու ֆայլ՝ math.js (արտահանում է add, multiply) և main.js։ Ստուգիր, որ import-ը աշխատում է։
  3. Ավելացրու math.js-ում ներքին ֆունկցիա, որը չես արտահանում։ Փորձիր դիմել դրան main.js-ից և գրիր՝ ինչ սխալ ստացար։
  4. Դիտավորյալ գրիր import { add } from "math.js" (առանց ./)։ Գրիր՝ ինչ սխալ ստացար։ Հետո ուղղիր։
  5. Փորձիր export default։ Ներմուծիր այն երկու տարբեր անուններով երկու ֆայլում։
  6. Վերակառուցիր քո կատալոգը մոդուլներով՝ data.js, storage.js, utils.js, catalog.js, cart.js, main.js։ մինի-նախագծում
  7. Համոզվիր, որ ամեն մոդուլ արտահանում է միայն այն, ինչ իսկապես պետք է դրսում։ Ներքին օգնականները թողիր առանց export-ի։ մինի-նախագծում
  8. Նկարիր (թղթի վրա կամ ֆայլում) քո նախագծի կախվածությունների գրաֆը։ Համոզվիր, որ օղակ չկա։ մինի-նախագծում
  9. Ավելացրու նոր մոդուլ՝ wishlist.js, հավանածների ցուցակի համար՝ իր localStorage բանալիով։
  10. Commit արա և push արա GitHub։ Ստուգիր, որ GitHub Pages-ի վրա էլ ամեն ինչ աշխատում է (Pages-ը սերվեր է, ուստի մոդուլները պիտի աշխատեն)։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Դաս 18-ից օրինակը բացիր Live Server-ով։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
