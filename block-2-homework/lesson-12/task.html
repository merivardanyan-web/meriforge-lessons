Քայլ 3 · Մեկ listener

  • e.target.closest("[data-action]") → քարտը՝ closest(".book") → Number(dataset.id)
  • switch՝ ըստ data-action-ի
js/books.js — դելեգացիա
container.addEventListener("click", (e) => {
    const button = e.target.closest("[data-action]");
    if (!button) return;
    const id = Number(button.closest(".book").dataset.id);

    switch (button.dataset.action) {
        case "read":   readPages(id); break;
        case "done":   markDone(id); break;
        case "delete": deleteBook(id); break;
        // ...
    }
});

04Դասի մյուս վարժությունները

Սրանք Դաս 12-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Կառուցիր ներդրված երեք բլոկ և ամեն մեկին կախիր մշակիչ։ Սեղմիր ամենաներքինին և գրիր մեկնաբանության մեջ՝ ինչ հերթականությամբ աշխատեցին։
  2. Նույն կոդում ավելացրու stopPropagation միջինին։ Նկարագրիր՝ ինչ փոխվեց։
  3. Ցուցակ 5 էլեմենտով։ Մեկ դելեգացված listener-ով՝ սեղմած էլեմենտին ավելացրու is-selected դաս, մյուսներից հանիր։
  4. Նույն ցուցակին ավելացրու «Ավելացնել» կոճակ։ Համոզվիր, որ նոր էլեմենտների վրա էլ ընտրությունն աշխատում է։
  5. Ամբողջական to-do ցուցակ դասարանական օրինակի հիման վրա։ Գրիր զրոյից՝ առանց նայելու, հետո համեմատիր։
  6. To-do-ին ավելացրու ֆիլտրի կոճակներ՝ «Բոլորը», «Ակտիվ», «Կատարված»։ Ֆիլտրը պահիր փոփոխականում և հաշվի առ render()-ում։ մինի-նախագծում
  7. To-do-ին ավելացրու «Ջնջել կատարվածները» կոճակ։ մինի-նախագծում
  8. Ավելացրու հաստատում ջնջելուց առաջ՝ confirm("Վստա՞հ եք")։ մինի-նախագծում
  9. Վերցրու Դաս 11-ի 10-րդ տնայինը (կատալոգի ֆիլտրերը) և վերաշարադրիր դելեգացիայով։ Համոզվիր, որ «Գնել» կոճակներն այժմ աշխատում են ֆիլտրից հետո։ մինի-նախագծում
  10. Կատալոգին ավելացրու զամբյուղ․ առանձին զանգված, «Գնել» սեղմելիս ապրանքն ավելանում է, էկրանին ցուցադրվում է քանակը և ընդհանուր գումարը։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
