00Ինչ պետք է ստացվի

01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/css/books-13.css — CSS-ը, որ ավելանում է այս դասին
  • starter/pages/books.html — «Գրքեր» էջի markup-ը (JS չկա, միայն <script>-ները)

02Քայլեր

Քայլ 1 · Երեք ֆայլ

  • data.js՝ զանգվածը և հաստատունները, books.js՝ դարակը, form.js՝ ֆորման
  • Հերթականությունը՝ data → books → form․ defer-ով սկրիպտները կատարվում են գրված հերթականությամբ
  • Ֆորման կանչում է addBook(...)-ը, որը ապրում է books.js-ում

Քայլ 2 · Կանոններ

  • Վերնագիր՝ պարտադիր, 2+ նիշ, հեղինակ՝ պարտադիր, էջեր՝ ամբողջ թիվ 1–3000
  • «Կարդացած էջեր»՝ միայն «Կարդում եմ»-ի դեպքում, 1-ից մինչև էջերից քիչ
  • Ամեն կանոն վերադարձնում է սխալի տեքստ կամ ""
js/form.js — կանոն, որ կախված է ուրիշ դաշտից
read(value) {
    const status = form.querySelector('input[name="status"]:checked').value;
    if (status !== "reading") return "";
    const n = Number(value);
    const pages = Number(form.pages.value);
    if (!Number.isInteger(n) || n < 1) return "Քանի՞ էջ ես արդեն կարդացել";
    if (pages && n >= pages) return `Պիտի լինի ${pages}-ից քիչ`;
    return "";
}

Քայլ 3 · Երբ ցույց տալ

  • blur՝ դաշտից դուրս գալիս (երրորդ արգումենտը՝ true)
  • input՝ սխալը վերանում է ուղղելիս
  • Կարգավիճակը փոխելիս՝ «Կարդացած էջեր»-ը ստուգիր նորից (change)

Քայլ 4 · Ուղարկում

  • preventDefault, բոլոր դաշտերը՝ map(validateField).every(...), ֆոկուս առաջին սխալի վրա
  • Ճիշտ դեպքում՝ FormData → օբյեկտ → կարդացած էջերը ըստ կարգավիճակի → addBook → form.reset()

04Դասի մյուս վարժությունները

Սրանք Դաս 13-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Ֆորմա մեկ դաշտով և կոճակով։ Սեղմելիս տպիր դաշտի արժեքը։ Համոզվիր, որ էջը չի վերաբեռնվում։
  2. Դաշտ և պարբերություն։ input-ով ցույց տուր մուտքագրվածը իրական ժամանակում և նիշերի քանակը։
  3. Checkbox՝ «Ցույց տալ գաղտնաբառը»։ Նշելիս type-ը դառնա text, հանելիս՝ նորից password։
  4. Radio կոճակներ՝ վճարման եղանակի ընտրություն։ Ընտրվածը ցույց տուր էկրանին։ մինի-նախագծում
  5. Select երկրների ցուցակով։ Ընտրվածի փոփոխման ժամանակ ցույց տուր համապատասխան հեռախոսի կոդը։
  6. Գրիր validators.js ֆայլ՝ isEmpty, minLength, isEmail, isPhone, isNumber, inRange ֆունկցիաներով։ Ամեն մեկը ստուգիր 3 արժեքով։
  7. Կապի ֆորմա՝ անուն, էլ. հասցե, հաղորդագրություն (textarea, առնվազն 10 նիշ)։ Սխալները ցույց տուր դաշտի տակ։
  8. Ամբողջական գրանցման ֆորմա դասարանական օրինակի հիման վրա։ Ավելացրու «Կրկնել գաղտնաբառը» դաշտ և ստուգիր համընկնումը։
  9. Ավելացրու գաղտնաբառի ուժի ցուցիչ՝ թույլ / միջին / ուժեղ, գունավոր գծով (classList-ով)։
  10. Ֆորմա, որը հաջող ուղարկումից հետո ավելացնում է նոր տող աղյուսակում կամ քարտ ցուցակում (միացրու Դաս 10-ի render-ը և Դաս 12-ի դելեգացիան՝ ջնջելու համար)։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
