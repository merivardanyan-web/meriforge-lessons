  • markAsRead()
  • Տպիր վիճակը նախքան և հետո
main.js — մեթոդ
read(count) {
    this.pagesRead = Math.min(this.pagesRead + count, this.pages);
    if (this.pagesRead === this.pages) {
        this.markAsRead();
    }
    return this.pagesRead;
}

03Ստուգաթերթ

  • Մեթոդները օգտագործում են this, ոչ book
  • Կարդացած էջերը երբեք չեն անցնում pages-ից
  • ?.-ը չի գցում սխալ չեղած օբյեկտի դեպքում
  • Բնօրինակը չի փոխվում updateBook-ից

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
this.title-ը undefined էՄեթոդը գրել ես arrow ֆունկցիայով։ Օբյեկտի մեթոդների համար՝ getInfo() { }
for...in-ը տպում է [object Object]Ներդրված օբյեկտը տող չէ․ բաց թող typeof ... === "object" դաշտերը
updateBook-ից հետո բնօրինակն էլ փոխվեցԳրել ես original.isRead = true․ վերադարձրու նոր օբյեկտ spread-ով

04Դասի մյուս վարժությունները

Սրանք Դաս 07-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Ստեղծիր book օբյեկտ՝ վերնագիր, հեղինակ, տարեթիվ, էջերի քանակ, isRead։ Տպիր բոլորը template literal-ով։ մինի-նախագծում
  2. Ավելացրու genres զանգված և publisher ներդրված օբյեկտ (անուն, քաղաք)։ Տպիր հրատարակչի քաղաքը։ մինի-նախագծում
  3. Ավելացրու getInfo() մեթոդ, որը this-ով վերադարձնում է «[վերնագիր] — [հեղինակ], [տարեթիվ]»։ մինի-նախագծում
  4. Ավելացրու markAsRead() մեթոդ, որը isRead-ը դարձնում է true։ Ստուգիր՝ տպելով նախքան և հետո։ մինի-նախագծում
  5. Ստեղծիր օբյեկտ առանց price հատկության։ Տպիր book.price ?? "Գինը նշված չէ"։ Ապա փորձիր book.publisher?.country։ մինի-նախագծում
  6. Destructuring-ով հանիր վերնագիրը և հեղինակին առանձին փոփոխականների։ Հեղինակին վերանվանիր writer։ մինի-նախագծում
  7. Ստեղծիր գնահատականների օբյեկտ (5 առարկա)։ Տպիր՝ բանալիները, արժեքները, միջինը և ամենաբարձր առարկան։ մինի-նախագծում
  8. Ստեղծիր 5 ապրանքի զանգված (անուն, գին, կատեգորիա, inStock)։ Գրիր ֆունկցիաներ՝ բոլոր առկա ապրանքները, ընդհանուր արժեքը, ամենաթանկը։
  9. Նույն զանգվածով՝ մեկ շղթայով գտիր որոշակի կատեգորիայի առկա ապրանքները, դասավորիր գնով և վերադարձրու «անուն — գին֏» տողերի զանգված։
  10. Գրիր updateProduct(product, changes) ֆունկցիա, որը վերադարձնում է նոր օբյեկտ՝ { ...product, ...changes }։ Ապացուցիր, որ բնօրինակը չի փոխվել։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
