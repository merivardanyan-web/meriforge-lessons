00Ինչ պետք է ստացվի

01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/css/books-14.css — CSS-ը, որ ավելանում է այս դասին
  • starter/pages/books.html — «Գրքեր» էջի markup-ը (JS չկա, միայն <script>-ները)

02Քայլեր

Քայլ 1 · storage.js

  • save(key, value) և load(key, fallback)՝ try/catch-ով
  • Այն պետք է բոլոր էջերում (թեմայի համար), ուստի առաջին սկրիպտն է

Քայլ 2 · Դարակը

  • let books = load(BOOKS_KEY, INITIAL_BOOKS)
  • Պահպանումը՝ մեկ տող render()-ի վերջում։ Ինչու՞ այնտեղ
js/books.js — render
function render() {
    // ... քարտեր և վիճակագրություն
    save(BOOKS_KEY, books);     // ← ամբողջ պահպանումը
}

  • Էջը թարմացնելուց հետո դարակը, նոր գրքերը և թեման տեղում են

  • Երկու անգամ «Սկսել»՝ ժամաչափը չի արագանում
  • Կախարդական թվեր չկան՝ 400, 3000, 300, 1000

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Թարմացնելուց հետո [object Object]Պահել ես առանց JSON.stringify-ի
Ժամաչափը արագանում էԵրկրորդ setInterval․ ստուգիր intervalId !== null
load is not defined այլ էջերումstorage.js-ը միացված չէ կամ site.js-ից հետո է
Գաղտնի ռեժիմում սխալԱռանց try/catch-ի localStorage-ը կարող է սխալ գցել

04Դասի մյուս վարժությունները

Սրանք Դաս 14-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Դաշտ և կոճակ։ Սեղմելիս անունը պահպանիր localStorage-ում։ Էջը թարմացնելիս ցույց տուր «Բարև, [անուն]»։
  2. Ավելացրու «Մոռանալ» կոճակ, որը ջնջում է պահված անունը։
  3. Հաշվիչ, որի արժեքը պահպանվում է էջը թարմացնելուց հետո։
  4. Մուգ/բաց թեմայի փոխարկիչ՝ ընտրության պահպանմամբ։ մինի-նախագծում
  5. Գրիր save(key, value) և load(key, fallback) ֆունկցիաները try/catch-ով։ Ստուգիր օբյեկտով, զանգվածով և չգոյություն ունեցող բանալիով։ մինի-նախագծում
  6. Կենդանի ժամացույց էջում՝ ժժ:րր:վվ ձևաչափով, padStart-ով։
  7. Հետհաշվարկ մինչև քո ընտրած ամսաթիվը՝ օր, ժամ, րոպե, վայրկյան։ Հասնելիս՝ կանգնեցրու clearInterval-ով։
  8. Ծանուցում (toast), որը հայտնվում է կոճակի սեղմումից և ինքնաբերաբար անհետանում 3 վայրկյան հետո։ մինի-նախագծում
  9. «Վեր» կոճակ, որը հայտնվում է 400px սքրոլից հետո և սահուն վերադարձնում վեր։ մինի-նախագծում
  10. Վերցրու Դաս 12–13-ի to-do-ն։ Ավելացրու՝ (ա) պահպանում localStorage-ում, (բ) որոնման դաշտ debounce-ով, (գ) «Ջնջել բոլորը» կոճակ confirm-ով։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
