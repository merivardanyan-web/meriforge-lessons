02Քայլեր

Քայլ 1 · Ժանրեր տվյալներից

  • get genres()՝ [...new Set(books.map(b => b.genre))]
  • get genreCounts()՝ Map․ ժանր → քանակ
  • renderGenres՝ «պատմավեպ (2)» կոճակներ, Shelf.setGenre
js/models/Shelf.js
get genreCounts() {
    const counts = new Map();
    this.#books.forEach(b => counts.set(b.genre, (counts.get(b.genre) ?? 0) + 1));
    return counts;
}

js/form.js — validateField
try {
    rule(input.value);
    setError(input, "");
    return true;
} catch (error) {
    if (!(error instanceof ValidationError)) throw error;
    setError(form.querySelector(`[name="${error.field}"]`), error.message);
    return false;
}

04Դասի մյուս վարժությունները

Սրանք Դաս 23-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Գրիր createCounter(start), որը վերադարձնում է increment, decrement, reset և get value։ Ստեղծիր երկու անկախ հաշվիչ։
  2. Գրիր once(fn) և ստուգիր, որ երկրորդ կանչը չի կատարում ֆունկցիան։ մինի-նախագծում
  3. Գրիր memoize(fn) և կիրառիր դանդաղ ֆունկցիայի վրա։ Ցույց տուր տարբերությունը console.time-ով։
  4. Բացատրիր մեկնաբանության մեջ, ինչու var-ով ցիկլը տալիս է 4, 4, 4։ Ուղղիր երկու տարբեր ձևով։
  5. Գրիր ValidationError և NetworkError դասեր։ Ֆունկցիա, որը պատահականորեն նետում է մեկը, և catch, որը տարբերում է դրանք։
  6. Վերցրու Դաս 13-ի ֆորմայի վալիդացիան և վերաշարադրիր ValidationError-ով։ մինի-նախագծում
  7. Զանգվածից հանիր կրկնվող արժեքները Set-ով։ Համեմատիր filter + indexOf տարբերակի հետ։ մինի-նախագծում
  8. Դաս 15-ի կատալոգում ֆիլտրի կոճակները գեներացրու ինքնաբերաբար՝ Set-ով, ապրանքների կատեգորիաներից։ մինի-նախագծում
  9. Ավելացրու Map-ով քեշ Դաս 21-ի էջավորմանը։ Ցույց տուր Console-ում՝ «քեշից» թե «սերվերից»։ մինի-նախագծում
  10. Վերցրու Դաս 12-ի to-do-ն և վերաշարադրիր անփոփոխ ձևով․ ոչ մի push, splice կամ ուղիղ վերագրում — միայն map, filter և spread։
