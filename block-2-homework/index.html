Մինի-նախագծեր ամեն դասից հետո

Ամեն դասի տնային աշխատանքը ունի մեկ մինի-նախագիծ՝ քայլերով, starter ֆայլերով և պատրաստի օրինակով։ Բոլորը մեկ նախագիծ են՝ Անիի ընթերցանության օրագիրը, որը Console-ից տեղափոխվում է կայք, իսկ վերջում որոնում է գրքեր աշխարհի բաց գրադարանում։ Յուրաքանչյուր առաջադրանք օգտագործում է միայն այն, ինչ անցել ենք մինչև այդ դասը։

task.html → starter/ → example/ Դաս 01–08՝ Console, 09–23՝ Անիի կայքը Դաս 15–16 և 24՝ ՏեխնոՄարկետ

00Ինչպես աշխատել

lesson-NN/ ├── task.html ← առաջադրանքը․ սկսիր այստեղից ├── starter/ ← տվյալներ, markup և CSS, որ չգրես ձեռքով ├── example/ ← պատրաստի օրինակ․ բացիր միայն ավարտելուց հետո └── screenshots/ ← ինչ պետք է ստացվի (Դաս 09-ից)
Կանոն

Նախ կատարիր առաջադրանքը և անցիր ստուգաթերթով, հետո բացիր օրինակը։ Եթե բաց ես թողել դասը կամ տնայինը, հաջորդ դասի առաջադրանքը կարող ես սկսել նախորդի օրինակից։

01Մեկ նախագիծ, որը աճում է

ԴասերՈրտեղԻնչ է աճում
01–08ConsoleՄեկ գիրք → պայմաններ → պլան ցիկլերով → ֆունկցիաներ → դարակ զանգվածով → վիճակագրություն → օբյեկտներ → ամսաթվեր

17–18GitHub, մոդուլներՊահոց և Pages → ES մոդուլներ, դինամիկ import
19–23API և դասերPromise → fetch և POST → Open Library որոնում → դասեր → Set, Map, սխալներ
Ինչու Անիի կայքը

Դաս 9-ի տնայինը ասում է՝ «օգտագործիր քո HTML/CSS նախագիծը»։ Անին նույն ուսանողն է, որի կայքը աճեց Բլոկ 1-ի տնայիններում։ Հիմա այն ստանում է «Գրքեր» էջ, որը աշխատում է JavaScript-ով։ Նախագծային դասերը (15–16, 24)՝ ՏեխնոՄարկետում։
