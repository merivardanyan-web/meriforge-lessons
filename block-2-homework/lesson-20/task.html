00Ինչ պետք է ստացվի

01Ինչ ես ստանում

Աշխատիր քո կայքում (կամ նախորդ դասի օրինակում)։ CSS-ը տրված է, որ կենտրոնանաս JS-ի վրա․ HTML/CSS-ը արդեն գիտես։

  • starter/data/recommended.json — առաջարկների JSON-ը
  • starter/pages/books.html — «Գրքեր» էջի markup-ը (JS չկա, միայն <script>-ները)

  • Արտաքինից նույնն է, ինչ fake-api-ն․ մնացած կոդը գրեթե չի փոխվում
js/api.js — request
async function request(url, options) {
    const response = await fetch(url, options);
    if (!response.ok) {
        throw new Error(`Սերվերը վերադարձրեց ${response.status}`);
    }
    return response.json();
}

04Դասի մյուս վարժությունները

Սրանք Դաս 20-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում։

  1. Բեռնիր /users-ը և տպիր բոլոր անունները Console-ում։ Օգտագործիր .then ձևը։
  2. Կրկնիր նույնը async/await-ով։ Համեմատիր՝ որն է ավելի ընթեռնելի։
  3. Փորձիր բեռնել /users/9999։ Ավելացրու response.ok-ի ստուգում և ցույց տուր ճիշտ սխալ։ մինի-նախագծում
  4. Ցուցադրիր օգտագործողներին քարտերով՝ քո .row / .col / .wrapper կառուցվածքով։ Ամեն քարտում՝ անուն, էլ. հասցե, քաղաք, ընկերություն։
  5. Ավելացրու երեք վիճակ՝ բեռնում, հաջողություն, սխալ։ Կոճակը բեռնման ընթացքում պիտի լինի disabled։ մինի-նախագծում
  6. Ստուգիր սխալի վիճակը՝ DevTools → Network → Offline։ Համոզվիր, որ «Կրկին փորձել» կոճակն աշխատում է։ մինի-նախագծում
  7. Բեռնիր /posts-ը և ցուցադրիր միայն առաջին 10-ը։ Ավելացրու որոնում վերնագրով (Դաս 14-ի debounce-ով)։
  8. Ամեն օգտագործողի քարտին ավելացրու «Գրառումները» կոճակ, որը բեռնում է /posts?userId=X և ցուցադրում մոդալում (Դաս 11)։
  9. Օգտագործիր Promise.all՝ միաժամանակ բեռնելու /users և /posts։ Ցուցադրիր՝ ամեն օգտագործողի կողքին քանի՞ գրառում ունի։
  10. Ֆորմա նոր գրառման համար (վերնագիր + տեքստ)։ Ուղարկիր POST-ով, ցուցադրիր պատասխանը և ավելացրու ցուցակի սկզբում։ Օգտագործիր Դաս 13-ի վալիդացիան։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և դրա կոդը example/js/-ում։ Դաս 18-ից օրինակը բացիր Live Server-ով։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
