Ադապտիվություն

Այցելուների կեսից ավելին գալիս է հեռախոսով։ Այսօր սովորում ենք media queries, ընտրում ենք breakpoint-ները և մեր .w-* համակարգը դարձնում ենք ճկուն։

Նախապայման՝ Դաս 10–13 Բլոկ 1 · Ադապտիվություն global.css-ը էապես աճում է

Հեռախոսի բրաուզերը ձևացնում է, թե էկրանը 980px է, հետո ամբողջ էջը փոքրացնում է։ Ամեն ինչ դառնում է մանրիկ, և media queries-ը երբեք չի գործարկվում — բրաուզերը կարծում է, թե 980px է։

Առանց այս մեկ տողի ամբողջ այսօրվա դասը անիմաստ է։

02Media query

շարահյուսություն
@media (max-width: 768px) {
    /* Կիրառվում է, երբ էկրանը 768px ԿԱՄ ՊԱԿԱՍ է */
    .row { padding: 0 10px; }
}

@media (min-width: 769px) {
    /* Կիրառվում է, երբ էկրանը 769px ԿԱՄ ԱՎԵԼԻ է */
}

@media (min-width: 768px) and (max-width: 1024px) {
    /* Միջակայք */
}
ԳրառումՆշանակություն
max-width: 768pxՄինչև 768px ներառյալ — ներքև
min-width: 768px768px-ից սկսած — վեր
orientation: landscapeՀորիզոնական դիրք
prefers-color-scheme: darkՀամակարգի մուգ թեմա
prefers-reduced-motionԱնիմացիաների նվազեցում
Media query-ները միշտ ՎԵՐՋՈՒՄ

Դրանք ունեն նույն սպեցիֆիկությունը, ինչ սովորական կանոնները (Դաս 6)։ Հաղթում է վերջինը գրվածը։

Եթե գրես media query-ն վերևում, իսկ .row { padding: 0 50px }-ը՝ ներքևում, media query-ն երբեք չի աշխատի։

03Breakpoint-ներ

Կետեր, որտեղ դասավորությունը փոխվում է։ Չկա «ճիշտ» ցուցակ, բայց կան տարածված արժեքներ։

ԱնունԼայնությունԻ՞նչ սարք
sm576pxՀեռախոս
md768pxՊլանշետ ուղղահայաց
lg992pxՊլանշետ հորիզոնական, փոքր նոութբուք
xl1200pxՀամակարգիչ
Ինչպես ընտրել իրականում

Մի՛ ընտրիր ըստ սարքերի — դրանք հազարավոր են։

Փոխարենը՝ նեղացրու պատուհանը դանդաղ և նայիր, թե որտեղ է դասավորությունը սկսում վատ երևալ։ Հենց այնտեղ դիր breakpoint։

Երեք breakpoint սովորաբար բավական է։ Յոթ breakpoint նշանակում է, որ ինչ-որ բան սխալ է կառուցված։

04Mobile-first vs desktop-first

Desktop-first — max-width
/* Բազան՝ մեծ էկրան */
.col { width: 25%; }

@media (max-width: 992px) { .col { width: 50%; } }
@media (max-width: 576px) { .col { width: 100%; } }
Mobile-first — min-width
/* Բազան՝ հեռախոս */
.col { width: 100%; }

@media (min-width: 576px) { .col { width: 50%; } }
@media (min-width: 992px) { .col { width: 25%; } }
Desktop-firstMobile-first
ԲազանՄեծ էկրանՀեռախոս
Հեռախոսը բեռնում էԲազա + վերագրումներ✅ Միայն բազան
Համապատասխանում է մակետին✅ Դիզայնը սովորաբար desktop էՊիտի պատկերացնես
Ստիպում է մտածել բովանդակության մասինՈչ✅ Այո
Ընդունված մոտեցումՀին✅ Ժամանակակից
Մեր ընտրությունը

Օգտագործում ենք desktop-first (max-width), որովհետև մեր մակետերը desktop են, և այդպես ուղիղ համապատասխանում է Դաս 13-ի աշխատանքային հոսքին։

Բայց իմացիր՝ իրական թիմերում mobile-first-ը ավելի տարածված է։ Երբ հանդիպես դրան, տարբերությունը միայն min-width vs max-width է և հերթականությունը։

05Ադապտիվ .w-* դասեր

Ահա ինչպես մեր համակարգը դառնում է ճկուն։

css/global.css
/* ---------- Ադապտիվ լայնություններ ----------
   Օրինաչափությունը՝ .w-md-50 = «մինչև 992px դառնում է 50%»
   HTML-ում գրվում է ՄԵԾ էկրանի դասից հետո՝
   <div class="col w-25 w-md-50 w-sm-100">               */

@media (max-width: 992px) {
    .w-md-25  { width: 25%; }
    .w-md-33  { width: 33.3333%; }
    .w-md-50  { width: 50%; }
    .w-md-100 { width: 100%; }
}

@media (max-width: 576px) {
    .w-sm-50  { width: 50%; }
    .w-sm-100 { width: 100%; }
}

</div>

flex-wrap-ը պարտադիր է

Առանց flex-wrap: wrap-ի սյուները չեն տողադարձվի — դրանք պարզապես կսեղմվեն։ 50%-ը կլինի 50%, բայց չորսն էլ մեկ տողում։

Ուստի ամեն .row, որի սյուները փոխվում են, պիտի ունենա flex-wrap։

Այս մոտեցման սահմանը

Հիշո՞ւմ ես Դաս 13-ի քննարկումը utility-ի մասին։ Ահա հենց այն տեղը, որտեղ դասերը սկսում են բազմապատկվել՝ w-25 w-md-50 w-sm-100։

Այս պատճառով ավելացնում ենք միայն 4 միջին և 2 փոքր տարբերակ — նրանք, որ իսկապես պետք են։ Եթե ամեն լայնության համար ստեղծեինք երեք տարբերակ, կստանայինք 36 դաս։

06Ի՞նչ ևս պիտի փոխվի

Սյուները միայն սկիզբն են։ Ահա ամբողջ ցուցակը։

css/main.css — ադապտիվ բլոկը
/* ============ ՊԼԱՆՇԵՏ ============ */
@media (max-width: 992px) {

    /* Վերնագրերը փոքրանում են */
    h1, .title-1 { font-size: 1.75rem; }
    h2, .title-2 { font-size: 1.375rem; }
}

/* ============ ՀԵՌԱԽՈՍ ============ */
@media (max-width: 768px) {

    /* 1. Պատերը — 60px-ը շատ է */
    :root { --wall: 20px; }

    /* 2. Բաժինների ուղղահայաց բացակը */
    section { padding: 30px 0; }

    /* 3. Վերնագրերը */
    h1, .title-1 { font-size: 1.5rem; }

    /* 4. Header-ը՝ ուղղահայաց */
    header .row { flex-wrap: wrap; }
    .menu { flex-wrap: wrap; justify-content: center; }

    /* 5. Կոճակները՝ ամբողջ լայնությամբ */
    .btn-block-sm { width: 100%; text-align: center; }

    /* 6. Աղյուսակները՝ սքրոլով */
    .table-wrap { overflow-x: auto; }
}
Ի՞նչԻնչու
Պատերը60px × 2 = 120px 375px էկրանից → մնում է 255px
Վերնագրերը34px վերնագիրը կոտրվում է 3 տողի
Ուղղահայաց բացակներըՀեռախոսում ոլորելը թանկ է
ՄենյունՀորիզոնականը չի տեղավորվում
ԿոճակներըԱմբողջ լայնությամբ՝ ավելի հեշտ սեղմելի
ԱղյուսակներըՉեն սեղմվում — պետք է սքրոլ
Մեկ փոփոխական, մեծ ազդեցություն

Նկատեցի՞ր՝ :root { --wall: 20px } մեկ տողը փոխում է բոլոր .row-երի պատերը։

Դա Դաս 13-ի calc(var(--wall) - var(--gap))-ի պտուղն է։ Առանց փոփոխականների պիտի փնտրեիր բոլոր տեղերը, որտեղ 50px է գրված։

07clamp() — առանց media query

Երբեմն media query-ի փոխարեն կարելի է գրել մեկ տող, որը սահուն փոխվում է։

երեք արժեք
h1 {
    font-size: clamp(1.5rem, 4vw, 2.125rem);
    /*              ↑        ↑       ↑          */
    /*          նվազագույն ցանկալի առավելագույն */
}
Էկրանի լայնություն font-size 375px 1.5rem (նվազագույնը) 600px 1.5rem 800px 2rem (4vw = 32px) 1200px 2.125rem (առավելագույնը) 1920px 2.125rem
օգտակար կիրառություններ
/* Վերնագրեր */
h1 { font-size: clamp(1.5rem, 4vw, 2.125rem); }
h2 { font-size: clamp(1.25rem, 3vw, 1.5rem); }

/* Պատերը */
:root { --wall: clamp(20px, 5vw, 60px); }

/* Բաժինների բացակը */
section { padding: clamp(30px, 6vw, 60px) 0; }
Ե՞րբ clamp, ե՞րբ media query

clamp() — երբ արժեքը պիտի փոխվի սահուն․ տառաչափեր, բացակներ, պատեր։

Media query — երբ պիտի փոխվի կառուցվածքը․ 4 սյուն դառնում է 1, մենյուն դառնում է բուրգեր, բլոկը թաքնվում է։

clamp()-ը չի կարող փոխել flex-direction-ը կամ թաքցնել էլեմենտ։

08Փորձարկում

2. Վերևում ընտրիր սարքը կամ քաշիր եզրերը՝ ձեռքով
3. Ուշադրություն դարձրու լայնության թվին — այնտեղ ես տեսնում breakpoint-ները
4. Responsive ռեժիմում քաշիր դանդաղ և նայիր, որտեղ է կոտրվում

Իրական սարքի փորձարկում

DevTools-ը լավն է, բայց չի ցույց տալիս ամեն ինչ՝ իրական մատի չափը, արևի տակ կոնտրաստը, դանդաղ ինտերնետը։

Եթե Live Server-ը գործարկես, տերմինալում կերևա երկրորդ հասցե՝ http://192.168.x.x:5500։ Բացիր այն հեռախոսում՝ նույն Wi-Fi-ում։

09Խաղահրապարակ

Նեղացրու պատուհանը կամ քաշիր նախադիտման եզրը՝ տեսնելու համար breakpoint-ները։

Քաշիր նախադիտման ներքևի եզրը կամ նեղացրու պատուհանը
Փորձիր

1. Ջնջիր flex-wrap-ը .row-ից — սյուները կտողադարձվե՞ն։
2. Փոխիր clamp(1.25rem, 5vw, 2rem)-ը 2rem-ի և նեղացրու։
3. Փոխիր breakpoint-ը 992-ից 700-ի։
4. Ջնջիր :root { --wall: 16px }-ը 768-ի բլոկից։

10Դասարանական

Վերցնում ենք Դաս 13-ի էջը և դարձնում ենք ադապտիվ։

  1. Ստուգիր, որ viewport meta-ն կա
  2. Ավելացրու global.css-ում ադապտիվ .w-* դասերը
  3. Ավելացրու flex-wrap բոլոր .row-երին, որտեղ սյուներ կան
  4. HTML-ում ավելացրու w-md-* և w-sm-*
  5. main.css-ի վերջում ավելացրու ադապտիվ բլոկը
  6. Փոխիր --wall-ը 768px-ից ներքև
  7. Փոքրացրու վերնագրերը կամ օգտագործիր clamp()
  8. Ստուգիր 375, 768, 1440 լայնություններով
  9. Ստուգիր հորիզոնական սքրոլի բացակայությունը
main.css — ամբողջական ադապտիվ բլոկը
/* ============ 9. ԱԴԱՊՏԻՎՈՒԹՅՈՒՆ ============
   Միշտ ֆայլի ՎԵՐՋՈՒՄ                            */

@media (max-width: 992px) {
    h1, .title-1 { font-size: 1.75rem; }
    h2, .title-2 { font-size: 1.375rem; }
}

@media (max-width: 768px) {
    :root { --wall: 20px; }

    section { padding: 30px 0; }

    h1, .title-1 { font-size: 1.5rem; }

    header .row { flex-wrap: wrap; justify-content: center; }
    .menu       { flex-wrap: wrap; justify-content: center; }

    #hero { padding: 30px 0; text-align: center; }
    #hero .btn { width: 100%; text-align: center; }
}

@media (max-width: 576px) {
    .btn { padding: 12px 16px; }
}
Ամենահաճախ սխալը դասարանում

Media query-ն գրված է ֆայլի մեջտեղում, և ներքևի կանոնները վերագրում են այն։

Կանոն՝ ադապտիվ բլոկը միշտ main.css-ի վերջին բաժինն է։ Դա նաև հարմար է — բոլոր ադապտիվ ոճերը մեկ տեղում են։

11Տնային աշխատանք

  1. Ջնջիր viewport meta-ն և բացիր հեռախոսում (կամ DevTools-ի սարքի ռեժիմում)։ Ուղարկիր սքրինշոթ։ Վերականգնիր։
  2. Ավելացրու global.css-ում ադապտիվ .w-* դասերը։
  3. Կառուցիր 4-սյունանոց ցանց, որը դառնում է 2, ապա 1։ Ստուգիր երեք լայնությամբ։
  4. Ջնջիր flex-wrap-ը և նկարագրիր, ինչ եղավ։
  5. Դարձրու պատերը ադապտիվ երկու ձևով՝ media query-ով և clamp()-ով։ Համեմատիր։
  6. Կիրառիր clamp() բոլոր վերնագրերին։ Նեղացրու պատուհանը դանդաղ և նկարագրիր վարքագիծը։
  7. Դիտավորյալ ստեղծիր հորիզոնական սքրոլ (օրինակ՝ width: 120% ինչ-որ բլոկի վրա)։ Գտիր այն Console-ի կոդով։
  8. Բացիր քո էջը իրական հեռախոսում Live Server-ի ցանցային հասցեով։ Նկարագրիր, ինչ նկատեցիր, որ DevTools-ում չէիր տեսնում։
  9. Դարձրու Դաս 12-ի footer-ը ադապտիվ՝ 40/20/40-ից 100/50/50, ապա 100/100/100։
  10. Վերցրու Դաս 13-ի ամբողջ էջը և դարձրու ամբողջովին ադապտիվ։ Ստուգիր՝ 375, 576, 768, 992, 1440։ Ուղարկիր հինգ սքրինշոթ։

Ստուգաթերթ

  • Կա viewport meta
  • Media query-ները ֆայլի վերջում են
  • Բոլոր .row-երն ունեն flex-wrap, որտեղ պետք է
  • Պատերը փոքրանում են հեռախոսում
  • Վերնագրերը չեն կոտրվում 375px-ում
  • Չկա հորիզոնական սքրոլ
  • Կոճակների սեղմելի տարածքը ≥ 44px
  • Աղյուսակներն ունեն overflow-x: auto
  • Ստուգված է 375, 768, 1440 լայնություններով

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչու viewport-ն է առաջինը
  • Գիտե՞մ տարբերությունը max-width-ի և min-width-ի միջև
  • Հասկանո՞ւմ եմ, ինչու media query-ները վերջում են
  • Գիտե՞մ, ե՞րբ clamp(), ե՞րբ media query
  • Կարո՞ղ եմ գտնել հորիզոնական սքրոլի պատճառը
Հաջորդ դասին

position և z-index։ Կսովորենք հանել էլեմենտը նորմալ հոսքից՝ կպչուն header, մոդալ պատուհան, պիտակ նկարի անկյունում։ Եվ կհասկանանք, ինչու է z-index-ը երբեմն «չաշխատում»։
