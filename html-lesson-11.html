Կառուցվածք և Flexbox I

Կրկնում ենք կմախքը գործնականում և վերջապես բացում ենք այն display: flex տողը, որն անցյալ դասին ընդունեցինք որպես տրված։ Այսօր՝ առանցքներ և հավասարեցում։

Նախապայման՝ Դաս 10 Բլոկ 1 · Կառուցվածք Դասարանում՝ header

00Ի՞նչ ենք սովորելու այսօր

  • Կմախքի կրկնում գործնականում
  • Ի՞նչ է անում display: flex
  • Երկու առանցք
  • justify-content — բաշխում գլխավոր առանցքով
  • align-items — հավասարեցում խաչաձև առանցքով
  • flex-direction — առանցքների փոխարկում
  • Կիրառում՝ header և քարտի ներսի կառուցվածք

01Կրկնում

Նախքան նոր բան սովորելը՝ վերականգնենք անցյալ դասը։ Փորձիր պատասխանել առանց նայելու։

main > section > .row > .col > .wrapper
ՀարցՊատասխան
Որտե՞ղ է ֆոնըsection (շերտի) և .wrapper (քարտի)
Որտե՞ղ են պատերը.row { padding: 0 50px }
Որտե՞ղ են բացակները.col { padding: 10px }
Որտե՞ղ է լայնությունը.col՝ .w-* դասով
Ի՞նչ չի կարելի .col-ի վրաՖոն, եզրագիծ, ստվեր
Ի՞նչ չի կարելի .wrapper-ի վրաԼայնություն, margin
Արագ վարժություն

Բացիր դատարկ ֆայլ և գրիր կմախքը՝ section երկու .row-ով, առաջինում մեկ w-100, երկրորդում՝ երեք w-33։ Ամեն սյան ներսում .wrapper։

Երբ սա դառնա ավտոմատ շարժում, հետագա դասերը շատ ավելի հեշտ կլինեն։

02Ի՞նչ է անում display: flex

մեկ տող, մեծ ազդեցություն
.row {
    display: flex;
}
ԱՌԱՆՑ flex-ի flex-ով ┌──────────────┐ ┌────┐┌────┐┌────┐ │ .col 1 │ │col1││col2││col3│ └──────────────┘ └────┘└────┘└────┘ ┌──────────────┐ կողք կողքի │ .col 2 │ հավասար բարձրության └──────────────┘ առանց 4px բացակների ┌──────────────┐ │ .col 3 │ └──────────────┘
Ինչ է փոխվումԲացատրություն
Երեխաները դառնում են կողք կողքիԱնկախ նրանից՝ div են, թե span
Բացակներ չկանHTML-ի տողադարձերն անտեսվում են ⭐
Երեխաները հավասար բարձրության ենԼռելյայն ձգվում են ամենաբարձրի չափ
Margin collapse չկաԴաս 8-ի խնդիրն անհետանում է
display-ը երեխաներում անտեսվում էԲոլորը դառնում են flex տարրեր
Կարևոր տերմիններ

Flex-կոնտեյներ — էլեմենտը, որի վրա գրված է display: flex։ Մեր դեպքում՝ .row-ը։
Flex-տարրեր — նրա ուղիղ երեխաները։ Մեր դեպքում՝ .col-երը։

Միայն ուղիղ երեխաները։ .wrapper-ը արդեն flex-տարր չէ — այն թոռ է։

Դաս 9-ի բոլոր երեք խնդիրը լուծվեց

1. 4px բացակները — չկան։
2. vertical-align: top — պետք չէ։
3. Հավասար բարձրություն — լռելյայն է։

Երեք սյուն 33.3333%-ով հիմա տեղավորվում են ուղիղ։

03Երկու առանցք

Flexbox-ի ամբողջ տրամաբանությունը կառուցված է երկու առանցքի վրա։ Հասկանալով դրանք՝ հասկանում ես ամեն ինչ։

flex-direction: row (լռելյայն) ────────────── գլխավոր առանցք ──────────────► ┌──────┐ ┌──────┐ ┌──────┐ │ │ │ │ │ │ │ │ խաչաձև │ 1 │ │ 2 │ │ 3 │ │ առանցք │ │ │ │ │ │ │ └──────┘ └──────┘ └──────┘ ▼ justify-content → գլխավոր առանցքով (հորիզոնական) align-items → խաչաձև առանցքով (ուղղահայաց)
Ամենակարևոր բանը հիշելու

justify-content և align-items — սրանք «հորիզոնական» և «ուղղահայաց» չեն։

Դրանք են՝ «գլխավոր առանցքով» և «խաչաձև առանցքով»։ Իսկ առանցքները փոխվում են տեղերով, երբ փոխես flex-direction-ը։

Սա այն տեղն է, որտեղ շատերը շփոթվում են։ Հիշիր առանցքներով, ոչ ուղղություններով։

04justify-content

Բաշխում է տարրերը գլխավոր առանցքով։ Աշխատում է միայն այն դեպքում, երբ ազատ տեղ կա։

հինգ արժեք
.row { justify-content: flex-start; }    /* լռելյայն */
.row { justify-content: center; }
.row { justify-content: flex-end; }
.row { justify-content: space-between; }
.row { justify-content: space-around; }
flex-start [1][2][3] center [1][2][3] flex-end [1][2][3] space-between [1] [2] [3] space-around [1] [2] [3]
ԱրժեքԵ՞րբ օգտագործել
flex-startԼռելյայն — ձախից
centerԿենտրոնացված կոճակ, պատկերակներ
flex-endԿոճակներ մոդալի ներքևում
space-betweenԼոգո ձախում, մենյու աջում ⭐
space-aroundՀազվադեպ
space-between — ամենաօգտագործվողը

Առաջին տարրը կպչում է ձախին, վերջինը՝ աջին, մնացածը բաշխվում է հավասար։

Header, քարտի ներքևի տողը (գին և կոճակ), աղյուսակի վերնագիր — ամենուր space-between։

Ինչո՞ւ մեր .row-ի վրա այն սովորաբար չկա

Երբ սյուները ունեն .w-* դասեր և միասին կազմում են 100%, ազատ տեղ չի մնում — justify-content-ը ոչինչ չի փոխի։

Այն օգտագործում ենք այնտեղ, որտեղ լայնությունները ֆիքսված չեն՝ header-ում, քարտի ներսում, կոճակների խմբում։

05align-items

Հավասարեցնում է տարրերը խաչաձև առանցքով։

չորս արժեք
.row { align-items: stretch; }      /* լռելյայն */
.row { align-items: flex-start; }
.row { align-items: center; }
.row { align-items: flex-end; }
stretch (լռելյայն) flex-start center ┌────┐┌────┐┌────┐ ┌────┐┌────┐┌────┐ ┌────┐┌────┐┌────┐ │ ││ ││ │ │ 1 ││ 2 ││ 3 │ │ ││ 2 ││ │ │ 1 ││ 2 ││ 3 │ └────┘└────┘└────┘ │ 1 │└────┘│ 3 │ │ ││ ││ │ տարբեր բարձրություն │ │ │ │ └────┘└────┘└────┘ վերևից հավասարեցված └────┘ └────┘
stretch-ը մեր բարեկամն է

Լռելյայն stretch-ի շնորհիվ են բոլոր .col-երը հավասար բարձրության։ Իսկ .wrapper { height: 100% }-ը (Դաս 10) այդ բարձրությունը փոխանցում է սպիտակ քարտին։

Երկուսը միասին տալիս են հավասար քարտեր՝ անկախ տեքստի երկարությունից։

ամենահաճախ պետք եկող համադրություն
/* Ուղղահայաց կենտրոնացում — երբեմնի ամենադժվար խնդիրը */
.center-box {
    display: flex;
    justify-content: center;   /* հորիզոնական */
    align-items: center;       /* ուղղահայաց */
    min-height: 400px;
}
Պատմական մանրուք

Մինչև Flexbox-ը ուղղահայաց կենտրոնացումը CSS-ի ամենահայտնի գլխացավն էր։ Կային տասնյակ հնարքներ՝ բացասական margin-ներով, table-cell-ով, transform-ով։

Հիմա՝ երկու տող։

06flex-direction

առանցքները փոխվում են տեղերով
.box { flex-direction: row; }             /* լռելյայն */
.box { flex-direction: column; }
.box { flex-direction: row-reverse; }
.box { flex-direction: column-reverse; }
row column գլխավոր ────► գլխավոր ┌───┐┌───┐┌───┐ │ │ 1 ││ 2 ││ 3 │ ▼ └───┘└───┘└───┘ ┌──────┐ │ │ 1 │ ▼ խաչաձև └──────┘ ┌──────┐ ────► խաչաձև │ 2 │ └──────┘
Ահա թե ինչու չենք ասում «հորիզոնական»

column-ի դեպքում․
justify-content → դառնում է ուղղահայաց
align-items → դառնում է հորիզոնական

Հատկությունների անունները նույնն են, ազդեցությունը՝ շրջված։ Դրա համար է կարևոր մտածել առանցքներով։

գործնական օրինակ՝ քարտի ներսը
.wrapper {
    display: flex;
    flex-direction: column;
    height: 100%;
}

.card__bottom {
    margin-top: auto;    /* հրում է ներքև ⭐ */
}
margin-top: auto — շատ օգտակար հնարք

Երեք քարտ տարբեր երկարության տեքստերով։ Ուզում ես, որ կոճակները լինեն նույն մակարդակին՝ քարտի ամենաներքևում։

flex-direction: column + margin-top: auto ներքևի բլոկի վրա — և այն «կպչում» է ներքևին՝ անկախ վերևի տեքստի երկարությունից։

Առանց դրա կոճակները կլինեն տարբեր բարձրություններում և քարտերը կթվան անփույթ։

07global.css-ի ավելացումը

Ամեն անգամ display: flex գրելու փոխարեն՝ ստեղծում ենք օգնական դասեր։

css/global.css
/* ---------- Flex օգնականներ ---------- */
.flex        { display: flex; }
.flex-column { flex-direction: column; }

.justify-start   { justify-content: start; }
.justify-center  { justify-content: center; }
.justify-end     { justify-content: end; }
.justify-between { justify-content: space-between; }
.justify-around  { justify-content: space-around; }

.align-start  { align-items: start; }
.align-center { align-items: center; }
.align-end    { align-items: end; }
օգտագործում HTML-ում
<div class="row align-center">
    <div class="col w-50">...</div>
    <div class="col w-50">...</div>
</div>

<!-- .wrapper-ի ներսում -->
<div class="wrapper">
    <div class="flex justify-between align-center">
        <span>450 000 ֏</span>
        <a href="#" class="btn">Գնել</a>
    </div>
</div>
Երկու մակարդակի flex

Նկատեցի՞ր — .row-ը flex է, և .wrapper-ի ներսի բլոկը նույնպես։ Դա նորմալ է և շատ տարածված։

Flex-կոնտեյները կարող է լինել ուրիշ flex-կոնտեյների տարրը։ Ամեն մեկն ունի իր առանցքները և իր կանոնները։

08Խաղահրապարակ

Փոխիր արժեքները և տես արդյունքը
Փորձիր

1. .d3-ը փոխիր space-around-ի։
2. Ջնջիր .card .bottom { margin-top: auto }-ը — կոճակները կցրվե՞ն։
3. Ջնջիր .card { height: 100% }-ը։
4. Ավելացրու .cards { flex-direction: column }։

09Դասարանական · header

Կառուցում ենք էջի վերնամասը՝ լոգո ձախում, մենյու աջում։ Դասական space-between-ի կիրառություն։

HTML

        <!-- Լոգո -->
        <div class="col">

Ուշադրություն՝ .col-ը առանց .w-*

Այստեղ սյուներին լայնություն չենք տվել։ Դա դիտավորյալ է․ space-between-ը աշխատում է միայն այն դեպքում, երբ ազատ տեղ կա։

Եթե երկուսին տայիր w-50, դրանք կլրացնեին ամբողջ լայնությունը, և բաշխելու բան չէր մնա։ Լոգոն կմնար ձախում, մենյուն՝ իր սյան ձախ եզրին — կենտրոնում։

Ստուգիր ստեղնաշարով

Tab-ով անցիր մենյուով։ Ամեն հղում պիտի ստանա տեսանելի ֆոն։ Հերթականությունը՝ ձախից աջ, ինչպես տեսողականորեն։

Ուշադրություն դարձրու․ եթե երբևէ օգտագործես row-reverse, տեսողական հերթականությունը կփոխվի, բայց Tab-ի հերթականությունը կմնա HTML-ի պես։ Դա շփոթեցնում է օգտագործողին — խուսափիր reverse-ից նավիգացիայում։

10Տնային աշխատանք

  1. Ավելացրու global.css-ում բոլոր flex օգնական դասերը։
  2. Ցուցադրիր justify-content-ի հինգ արժեքը՝ հինգ առանձին բլոկով։
  3. Ցուցադրիր align-items-ի չորս արժեքը՝ տարբեր բարձրության երեխաներով։
  4. Կենտրոնացրու բլոկը երկու առանցքով էլ (min-height: 400px)։
  5. Ցուցադրիր flex-direction: column-ի ազդեցությունը՝ նույն justify-content: center-ով։ Բացատրիր, ինչու արդյունքը փոխվեց։
  6. Կառուցիր header՝ դասարանական օրինակի պես։ Ավելացրու :hover և :focus-visible։
  7. Կառուցիր երեք քարտ, որտեղ կոճակները նույն մակարդակին են՝ flex-direction: column + margin-top: auto։ Տեքստերը պիտի լինեն շատ տարբեր երկարության։
  8. Ջնջիր margin-top: auto-ն և ուղարկիր երկու սքրինշոթ՝ առաջ և հետո։
  9. Կառուցիր footer՝ երեք սյուն, ներսում ուղղահայաց ցուցակներ (flex-column)։
  10. Վերցրու Դաս 10-ի «Մեր թիմը» բաժինը և ավելացրու երկրորդ .row՝ վերնագրով ձախում և «Բոլորը» հղումով աջում (justify-between)։

11Հիշելու թերթիկ

ՀատկությունԻնչ է անում
display: flexԵրեխաները՝ կողք կողքի
flex-direction: rowԼռելյայն — հորիզոնական
flex-direction: columnՈւղղահայաց, առանցքները փոխվում են ⭐
justify-contentԲաշխում գլխավոր առանցքով
align-itemsՀավասարեցում խաչաձև առանցքով
space-betweenԱռաջինը ձախ, վերջինը աջ ⭐
align-items: stretchԼռելյայն — հավասար բարձրություն
margin-top: autoՀրում է ներքև (column-ում) ⭐

Կատարյալ կենտրոն

display: flex; justify-content: center; align-items: center;

Ի՞նչ ավելացավ global.css-ում այսօր

✓ .flex, .flex-column ✓ .justify-start / center / end / between / around ✓ .align-start / center / end

Ստուգաթերթ

  • Կմախքը պահպանված է՝ .row > .col > .wrapper
  • space-between-ի դեպքում սյուներն ունեն ազատ տեղ
  • Քարտերի կոճակները նույն մակարդակին են
  • Ֆոկուսը տեսանելի է Tab-ով անցնելիս
  • Չկա row-reverse նավիգացիայում

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել գլխավոր և խաչաձև առանցքները
  • Գիտե՞մ, ինչու justify-content-ը երբեմն ոչինչ չի փոխում
  • Հասկանո՞ւմ եմ, ինչ է լինում column-ի դեպքում
  • Կարո՞ղ եմ բացատրել margin-top: auto հնարքը
Հաջորդ դասին

Flexbox II՝ flex-grow, flex-shrink, flex-basis և gap։ Կհասկանանք, ինչպես են սյուները բաշխում ազատ տեղը, և ինչու է gap-ը երբեմն ավելի լավ, քան .col-ի padding-ը։ Կրկին կկառուցենք նոր բաժին։
