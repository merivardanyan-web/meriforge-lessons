Անցումներ և անիմացիաներ

Շարժումը ուժեղ գործիք է՝ և՛ լավի, և՛ վատի համար։ Այսօր սովորում ենք անիմացնել այնպես, որ էջը չդանդաղի, և հարգել այն մարդկանց, ում համար շարժումը ֆիզիկապես անհարմար է։

Նախապայման՝ Դաս 15, 17, 19 Բլոկ 1 · Առաջադեմ Արտադրողականություն և հասանելիություն

00Ի՞նչ ենք սովորելու այսօր

  • transition — չորս պարամետր
  • Ի՞նչ կարելի է անիմացնել և ի՞նչ՝ ոչ
  • transform՝ translate, scale, rotate
  • Ինչո՞ւ միայն երկու հատկություն է «էժան»
  • @keyframes
  • Ֆիլտրեր
  • prefers-reduced-motion — պարտադիր

01transition

չորս պարամետր
.btn {
    transition: background-color .2s ease 0s;
    /*           ↑              ↑    ↑     ↑        */
    /*        հատկություն   տևող. ֆունկց. ուշաց.    */
}

/* Մի քանի հատկություն */
.card {
    transition: transform .2s ease, box-shadow .2s ease;
}
Կարևոր՝ transition-ը գրվում է ԲԱԶԱՅԻՆ վիճակում

.btn { transition: ... } ✅ — անցումն աշխատում է և ներս, և դուրս։
.btn:hover { transition: ... } ❌ — մուտքը սահուն է, ելքը՝ կտրուկ։

Սա ամենահաճախ հանդիպող սխալն է։ Հեշտ է նկատել՝ սավառնիր և հեռացիր։

ՖունկցիաԶգացողությունԵ՞րբ
linearՄեխանիկականԱռաջընթացի գծեր, ոլորում
easeԲնական (լռելյայն)Ունիվերսալ
ease-outԱրագ սկիզբ, փափուկ վերջՀայտնվող տարրեր ⭐
ease-inԴանդաղ սկիզբԱնհետացող տարրեր
cubic-bezier(...)ՍեփականՀատուկ դեպքեր
Տևողության կանոն

100–200ms — փոքր բաներ՝ գույն, ֆոն, եզրագիծ
200–300ms — տեղաշարժ, չափի փոփոխություն
300–500ms — մեծ պանելներ, մոդալներ

500ms-ից ավելին սովորական ինտերֆեյսում սկսում է թվալ դանդաղ։ Օգտագործողն արդեն որոշել է, թե ինչ է ուզում, և սպասում է։

transition: all — խուսափիր
/* ❌ Անիմացնում է ամեն ինչ, ներառյալ այն, ինչ պետք չէ */
.card { transition: all .3s; }

/* ✅ Հստակ ցուցակ */
.card { transition: transform .2s ease, box-shadow .2s ease; }
Ինչո՞ւ ոչ all

Բրաուզերը ստիպված է հետևել բոլոր հատկություններին։ Եթե ինչ-որ բան փոխվի (օրինակ՝ height-ը բովանդակության պատճառով), կստացվի անսպասելի անիմացիա։

Բացի այդ՝ Դաս 19-ի թեմայի փոխարկման ժամանակ all-ը կանիմացնի ամեն գույն միանգամից՝ ստեղծելով «ալիք» ամբողջ էջով։

02Ի՞նչ է «էժան» անիմացնելը

Սա այն գիտելիքն է, որը տարբերում է սահուն կայքը դանդաղից։

Բրաուզերի աշխատանքի փուլերը 1. Layout → հաշվում է չափերն ու դիրքերը ԹԱՆԿ 2. Paint → նկարում է պիքսելները ՄԻՋԻՆ 3. Composite→ հավաքում է շերտերը ԷԺԱՆ width, height, margin, padding, top, left → ամբողջ 1-2-3 շղթան, ամեն կադրում background-color, box-shadow, color → 2-3 transform, opacity → ՄԻԱՅՆ 3 ⭐
նույն արդյունքը, տարբեր գին
/* ❌ Թանկ — layout ամեն կադրում */
.card:hover { top: -4px; }
.box:hover  { width: 320px; }

/* ✅ Էժան — միայն composite */
.card:hover { transform: translateY(-4px); }
.box:hover  { transform: scaleX(1.1); }
Ոսկե կանոն

Անիմացնում ենք միայն transform և opacity։

Ամեն ինչ, ինչ շարժում, մեծացնում, պտտում կամ թափանցիկ է դարձնում, կարելի է անել այս երկուսով։

Բացառություն՝ գույների անցումները (background-color, color) ընդունելի են, եթե դրանք hover-ի վրա են և ոչ շարունակական։

Ինչպես ստուգել

DevTools → Ctrl+Shift+P → «Show frames per second» կամ Rendering → Frame Rendering Stats։

Սահուն անիմացիան 60 FPS է։ Եթե ընկնում է 30-ից ցածր — ինչ-որ բան թանկ ես անիմացնում։

03transform

հիմնական ֆունկցիաները
/* Տեղաշարժ */
transform: translateX(20px);
transform: translateY(-4px);
transform: translate(10px, 20px);
transform: translate(-50%, -50%);   /* Դաս 15՝ կենտրոնացում */

/* Չափ */
transform: scale(1.05);
transform: scaleX(0);            /* սեղմված զրոյի */

/* Պտույտ */
transform: rotate(45deg);      /* Դաս 18՝ բուրգեր */

/* Համադրում — հերթականությունը ԿԱՐԵՎՈՐ Է */
transform: translateY(-4px) scale(1.03);
Երկու թակարդ

1. Հերթականությունը կարևոր է
rotate(45deg) translateX(20px) — նախ պտտվում է, հետո շարժվում պտտված առանցքով։
translateX(20px) rotate(45deg) — նախ շարժվում է, հետո պտտվում տեղում։

2. Երկրորդ transform-ը ջնջում է առաջինը
transform: translateY(-4px); հետո transform: scale(1.05); → մնում է միայն scale-ը։ Պիտի գրես երկուսը մեկ տողում։

transform-origin

որտեղի՞ց է սկսվում
.el { transform-origin: center; }        /* լռելյայն */
.el { transform-origin: left center; }   /* ձախ եզրից */
.el { transform-origin: top left; }

/* Օրինակ՝ ընդգծում, որ աճում է ձախից */
.link::after {
    content: "";
    position: absolute;
    left: 0; bottom: 0;
    width: 100%;
    height: 2px;
    background: currentColor;
    transform: scaleX(0);
    transform-origin: left;
    transition: transform .2s ease;
}

.link:hover::after { transform: scaleX(1); }
Ինչո՞ւ scaleX, ոչ width

width: 0 → 100% — layout ամեն կադրում, և ամբողջ էջը վերահաշվարկվում է։
scaleX(0) → scaleX(1) — միայն composite։ Նույն արդյունքը, տասնապատիկ էժան։

Սա այն օրինակն է, որտեղ «էժան անիմացիա»-ի կանոնը գործնական տարբերություն է տալիս։

04@keyframes

transition-ը պետք է սկիզբ (hover, focus)։ Անիմացիան կարող է աշխատել ինքնուրույն։

սահմանում և կիրառում
@keyframes fade-up {
    from { opacity: 0; transform: translateY(16px); }
    to   { opacity: 1; transform: translateY(0); }
}

.hero__title {
    animation: fade-up .5s ease-out;
}
animation-ի պարամետրերը
.el {
    animation-name: fade-up;
    animation-duration: .5s;
    animation-timing-function: ease-out;
    animation-delay: .1s;
    animation-iteration-count: infinite;   /* կամ թիվ */
    animation-direction: alternate;
    animation-fill-mode: both;              /* ⭐ */
}

/* Կարճ գրառում */
.el { animation: fade-up .5s ease-out .1s both; }
animation-fill-mode: both — գրեթե միշտ պետք է

Առանց դրա՝ animation-delay: .5s-ի ընթացքում էլեմենտը երևում է իր վերջնական վիճակում, հետո ցատկում է սկզբնականին և սկսում անիմացիան։

both-ը ասում է․ «մինչև սկսելը՝ պահիր from-ի վիճակը, ավարտից հետո՝ to-ի»։

երեք գործնական անիմացիա
/* 1. Բեռնման ցուցիչ */
@keyframes spin { to { transform: rotate(360deg); } }

.spinner {
    width: 28px; height: 28px;
    border: 3px solid var(--border);
    border-top-color: var(--accent);
    border-radius: 50%;
    animation: spin .8s linear infinite;
}

/* 2. Բովանդակության «կմախք» բեռնման ժամանակ */
@keyframes shimmer {
    to { background-position: 200% 0; }
}

.skeleton {
    background: linear-gradient(90deg, #e8ecee 25%, #f4f6f7 50%, #e8ecee 75%);
    background-size: 200% 100%;
    animation: shimmer 1.4s linear infinite;
}

/* 3. Ուշադրության գրավում */
@keyframes pulse {
    0%, 100% { transform: scale(1); }
    50%      { transform: scale(1.06); }
}

.badge--new { animation: pulse 2s ease-in-out 3; }  /* 3 անգամ, ոչ անվերջ */
Անվերջ անիմացիաների կանոն

infinite օգտագործիր միայն այն ժամանակ, երբ անիմացիան տեղեկություն է փոխանցում — բեռնման ցուցիչ, ընթացիկ գործընթաց։

Դեկորատիվ անվերջ շարժումը հոգնեցնում է և շեղում ուշադրությունը բովանդակությունից։ Ուշադրություն գրավելու համար բավական է 2–3 կրկնություն։

05prefers-reduced-motion

Սա ոչ թե նախընտրություն է, այլ բժշկական կարիք

Վեստիբուլյար խանգարումներ ունեցող մարդկանց մոտ էկրանի շարժումը կարող է առաջացնել գլխապտույտ, սրտխառնոց և միգրեն։ Դա նույն մեխանիզմն է, ինչ ծովային հիվանդությունը։

Նրանք համակարգի կարգավորումներում միացնում են «Reduce motion»։ Քո գործն է հարգել դա։

global.css — ավելացրու մեկ անգամ
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: .01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: .01ms !important;
        scroll-behavior: auto !important;
    }
}
Ինչո՞ւ .01ms, ոչ 0

Զրոյի դեպքում որոշ բրաուզերներում animationend իրադարձությունը չի գործարկվում, և JS-ով գրված տրամաբանությունը կոտրվում է։

.01ms-ը գործնականում ակնթարթային է, բայց տեխնիկապես անիմացիան «տեղի է ունենում»։

Իսկ !important-ը այստեղ արդարացված է — սա այն հազվագյուտ դեպքն է, երբ պիտի հաղթի ամեն ինչին։

Ավելի նուրբ մոտեցում

Ամեն ինչ անջատելու փոխարեն կարելի է թողնել opacity-ի անցումները և հանել միայն շարժումը՝

@media (prefers-reduced-motion: reduce) {
  .card:hover { transform: none; }
  .fade-up { animation: fade-in .3s; }
}

Թափանցիկության փոփոխությունը սովորաբար խնդիր չի ստեղծում — խնդիրը շարժումն է։

Ստուգում

DevTools → Ctrl+Shift+P → Show Rendering → Emulate prefers-reduced-motion։

Նույն վահանակում, որտեղ Դաս 19-ի prefers-color-scheme-ն էր։

06Ֆիլտրեր

հիմնականները
filter: blur(4px);
filter: brightness(1.1);
filter: contrast(1.2);
filter: grayscale(1);
filter: saturate(1.4);
filter: drop-shadow(0 4px 6px rgba(0,0,0,.3));

/* Համադրում */
filter: grayscale(1) brightness(1.1);
գործնական օրինակներ
/* 1. Գործընկերների լոգոներ — գունավորվում են hover-ին */
.partner img {
    filter: grayscale(1);
    opacity: .7;
    transition: filter .25s, opacity .25s;
}
.partner:hover img { filter: none; opacity: 1; }

/* 2. Մուգ թեմայում նկարները մեղմել — Դաս 19 */
[data-theme="dark"] img { filter: brightness(.88); }

/* 3. drop-shadow — հետևում է ձևին, ոչ ուղղանկյունին ⭐ */
.icon { filter: drop-shadow(0 2px 3px rgba(0,0,0,.3)); }
drop-shadow vs box-shadow

box-shadow — միշտ ուղղանկյուն (կամ border-radius-ի ձևով)։
drop-shadow — հետևում է իրական ձևին՝ ներառյալ թափանցիկ PNG-ի և SVG-ի ուրվագիծը։

Եռանկյուն SVG պատկերակի համար box-shadow-ը կտա քառակուսի ստվեր։ drop-shadow-ը՝ եռանկյուն։

Երկու զգուշացում

1. filter-ը թանկ է — հատկապես blur-ը։ Չանիմացնես այն շարունակաբար։

2. filter-ը ստեղծում է stacking context (Դաս 15)։ Եթե z-index-ը հանկարծ դադարեց աշխատել, ստուգիր՝ ծնողի վրա filter չկա՞։

Համեմատիր առաջին երկու քարտը
Փորձիր

1. Սավառնիր երկու քարտի վրայով և հեռացիր — տարբերությունը հենց այնտեղ է։
2. Փոխիր .card:hover-ի transform: translateY(-4px)-ը margin-top: -4px-ի։
3. Ջնջիր transform-origin: left-ը ընդգծումից։
4. Ջնջիր .fade-ի both-ը և թարմացրու։

08Դասարանական

  1. Ավելացրու global.css-ում prefers-reduced-motion բլոկը
  2. Ավելացրու --transition տոկեն :root-ում (Դաս 19)
  3. Ավելացրու անցումներ բոլոր կոճակներին
  4. Ավելացրու քարտի hover՝ translateY + box-shadow
  5. Կառուցիր ընդգծում scaleX-ով մենյուի հղումների համար
  6. Ավելացրու fade-up hero-ի տարրերին՝ հերթականությամբ
  7. Կառուցիր spinner
  8. Ստուգիր DevTools-ի FPS ցուցիչով
  9. Միացրու Emulate prefers-reduced-motion և ստուգիր, որ ամեն ինչ դեռ աշխատում է
Ամենակարևոր ստուգումը

Միացրու reduced motion և անցիր ամբողջ էջով։

Ամեն ինչ պիտի աշխատի՝ մենյուն բացվի, մոդալը հայտնվի, քարտերը երևան։ Պարզապես ակնթարթորեն, առանց շարժման։

Եթե ինչ-որ բան անհետացավ կամ կոտրվեց — ուրեմն անիմացիան կրում էր ֆունկցիոնալ բեռ, և դա սխալ է։ Անիմացիան պիտի լինի զարդարանք, ոչ մեխանիզմ։

09Տնային աշխատանք

  1. Կառուցիր երկու նույնական քարտ՝ մեկում transition-ը բազայում, մյուսում՝ :hover-ում։ Նկարագրիր տարբերությունը։
  2. Համեմատիր margin-top: -4px-ը և transform: translateY(-4px)-ը։ Չափիր FPS-ը DevTools-ով։
  3. Ցուցադրիր, որ երկրորդ transform-ը ջնջում է առաջինը։ Ուղղիր։
  4. Ցուցադրիր հերթականության կարևորությունը՝ rotate + translateX երկու կարգով։
  5. Կառուցիր ընդգծում, որը աճում է ձախից, կենտրոնից և աջից (transform-origin)։
  6. Կառուցիր fade-up անիմացիա 5 քարտի համար՝ animation-delay-ի հերթականությամբ։
  7. Ջնջիր animation-fill-mode: both-ը և նկարագրիր, ինչ եղավ delay-ի ընթացքում։
  8. Կառուցիր skeleton-ցուցիչ բեռնման համար։
  9. Համեմատիր box-shadow-ը և drop-shadow-ը ոչ ուղղանկյուն SVG-ի վրա։
  10. Ավելացրու prefers-reduced-motion, միացրու այն DevTools-ում և անցիր ամբողջ նախագծով։ Գրիր ցուցակ՝ ի՞նչ կոտրվեց և ինչպես ուղղեցիր։

  • transition-ը գրված է բազայում, ոչ :hover-ում
  • Անիմացվում են միայն transform և opacity
  • Չկա transition: all
