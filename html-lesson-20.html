Grid

Flexbox-ը մեկ չափի համար է՝ տող կամ սյուն։ Grid-ը երկու չափի՝ տողեր և սյուներ միաժամանակ։ Այսօր սովորում ենք, ե՞րբ որն ընտրել։

01Flexbox vs Grid

FLEXBOX — մեկ չափ GRID — երկու չափ ┌────┐┌────┐┌────┐ ┌────┬────┬────┐ │ ││ ││ │ │ │ │ │ └────┘└────┘└────┘ ├────┼────┼────┤ │ │ │ │ բովանդակությունն է ├────┼────┼────┤ որոշում չափերը │ │ │ │ └────┴────┴────┘ ցանցն է որոշում չափերը
ԻրավիճակԸնտրություն
Header՝ լոգո և մենյուFlex
Կոճակների շարքFlex
Քարտի ներսի տարրերFlex
Ապրանքների ցանցGrid
Ամբողջ էջի կմախքGrid
Գալերեա տարբեր չափի բլոկներովGrid
Ֆորմա՝ պիտակ + դաշտGrid
Պարզ թեստ

Հարցրու ինքդ քեզ․ «Ես ուզում եմ, որ տարրերը շարվեն, թե՞ ուզում եմ, որ դրանք հավասարեցվեն ցանցի վրա»։

«Շարվեն» → Flex։ Բովանդակությունը թելադրում է չափերը։
«Հավասարեցվեն» → Grid։ Ցանցը թելադրում է չափերը։

Դրանք մրցակիցներ չեն — իրական էջում օգտագործվում են երկուսն էլ, հաճախ իրար ներսում։

Մեր համակարգում

.row > .col-ը Flexbox է, և դա տրամաբանական է՝ սյուների լայնությունը գալիս է .w-* դասերից, ոչ ցանցից։

Բայց միատեսակ քարտերի ցանցի համար Grid-ը հաճախ ավելի պարզ է։ Այս դասի վերջում կտեսնենք, ինչպես համատեղել երկուսը։

02Հիմունքներ

երեք սյուն
.grid {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    gap: 20px;
}

fr — ազատ տեղի բաժին

Grid-ի սեփական միավորը
/* Երեք հավասար սյուն */
.grid { grid-template-columns: 1fr 1fr 1fr; }

/* Անհամաչափ՝ 2:1 */
.grid { grid-template-columns: 2fr 1fr; }

/* Խառը՝ ֆիքսված կողքի բլոկ + ճկուն բովանդակություն */
.grid { grid-template-columns: 250px 1fr; }
fr vs % — կարևոր տարբերություն

1fr 1fr 1fr + gap: 20px — սյուները զբաղեցնում են մնացած տեղը բացակներից հետո։ Ամեն ինչ տեղավորվում է։

33.33% 33.33% 33.33% + gap: 20px — 100% + 40px > 100%։ Դուրս է գալիս։

Հիշո՞ւմ ես Դաս 12-ի gap-ի և տոկոսների կոնֆլիկտը։ fr-ը հենց դրա լուծումն է — այն ի սկզբանե հաշվի է առնում gap-ը։

repeat()

կրճատում
/* Այս երկուսը նույնն են */
.grid { grid-template-columns: 1fr 1fr 1fr 1fr; }
.grid { grid-template-columns: repeat(4, 1fr); }

/* Կարելի է համադրել */
.grid { grid-template-columns: 250px repeat(3, 1fr); }

Տողեր և բացակներ

մնացած հիմնական հատկությունները
.grid {
    grid-template-rows: auto 1fr auto;   /* header / body / footer */

    gap: 20px;              /* և տողերի, և սյուների */
    row-gap: 30px;
    column-gap: 10px;
}
Տողերը սովորաբար պետք չեն

Grid-ը ինքնաբերաբար ստեղծում է այնքան տող, որքան պետք է։ 9 տարր և 3 սյուն → 3 տող։

grid-template-rows-ը գրում ես միայն այն ժամանակ, երբ տողերի բարձրությունը կարևոր է — օրինակ՝ էջի կմախքի համար։

03auto-fit և minmax

Ահա Grid-ի ամենաօգտակար հնարքը՝ ադապտիվ ցանց առանց ոչ մի media query-ի։

մեկ տող, ամբողջ ադապտիվությունը
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
    gap: 20px;
}
Կարդում ենք աջից ձախ․ minmax(260px, 1fr) → ամեն սյուն նվազագույնը 260px, առավելագույնը՝ ազատ տեղի բաժին auto-fit → տեղավորիր այնքան սյուն, որքան հնարավոր է repeat(...) → կրկնիր 1200px էկրան → 4 սյուն 800px էկրան → 3 սյուն 560px էկրան → 2 սյուն 375px էկրան → 1 սյուն
auto-fit vs auto-fill

auto-fit — երբ տարրերը քիչ են, ավելորդ սյուները փլվում են, և առկա տարրերը ձգվում են։

auto-fill — ավելորդ սյուները մնում են դատարկ, տարրերը չեն ձգվում։

Օրինակ՝ 4 սյան տեղ կա, բայց 2 քարտ ունես։ auto-fit-ով երկուսը լցնում են ամբողջ լայնությունը։ auto-fill-ով դրանք մնում են ձախում, աջում՝ դատարկ տեղ։

Սովորաբար պետք է auto-fit։

Համեմատիր Դաս 14-ի հետ

Այնտեղ ադապտիվության համար պետք էր՝
· flex-wrap: wrap
· .w-25 w-md-50 w-sm-100 HTML-ում
· երկու media query global.css-ում

Այստեղ՝ մեկ տող CSS, և HTML-ում ոչ մի դաս։

Դա Grid-ի ամենաուժեղ փաստարկն է միատեսակ ցանցերի համար։

թակարդ՝ նեղ էկրանում
/* ❌ 320px էկրանին սյունը դուրս է գալիս */
.grid { grid-template-columns: repeat(auto-fit, minmax(350px, 1fr)); }

/* ✅ Լուծում */
.grid {
    grid-template-columns: repeat(auto-fit, minmax(min(350px, 100%), 1fr));
}
Ի՞նչ է կատարվում

minmax(350px, 1fr)-ը ասում է «երբեք 350px-ից նեղ»։ 320px էկրանին դա անհնար է — և սյունը դուրս է գալիս՝ ստեղծելով հորիզոնական սքրոլ (Դաս 14)։

min(350px, 100%)-ը նշանակում է «350px, բայց ոչ ավելի, քան ծնողի ամբողջ լայնությունը»։

04Տեղադրում ցանցի վրա

span — ամենապարզ ձևը
.featured {
    grid-column: span 2;    /* զբաղեցնում է 2 սյուն */
    grid-row:    span 2;    /* և 2 տող */
}
┌─────────┬────┬────┐ │ │ 2 │ 3 │ │ 1 ├────┼────┤ │ span 2 │ 4 │ 5 │ ├────┬────┼────┼────┤ │ 6 │ 7 │ 8 │ 9 │ └────┴────┴────┴────┘ .featured { grid-column: span 2; grid-row: span 2 }
ճշգրիտ գծերով
/* Գծերը համարվում են 1-ից, ոչ 0-ից */
.el { grid-column: 1 / 3; }      /* 1-ին գծից մինչև 3-րդը */
.el { grid-column: 2 / -1; }     /* 2-րդից մինչև վերջ ⭐ */
.el { grid-column: 1 / -1; }     /* ամբողջ լայնությամբ */
Գծերի համարակալում՝ 3 սյուն = 4 գիծ 1 2 3 4 │ │ │ │ ├──────┼──────┼──────┤ │ սյուն│ սյուն│ սյուն│ ├──────┼──────┼──────┤ │ │ │ │ -4 -3 -2 -1 ← բացասական՝ վերջից
grid-column: 1 / -1

Ամենաօգտակար գրառումներից․ «ամբողջ լայնությամբ, անկախ սյուների քանակից»։

Օգտագործվում է բաժնի վերնագրի, բաժանարարի, «Բոլորը դիտել» կոճակի համար — երբ տարրը պիտի ձգվի ամբողջ ցանցով։

Հավասարեցում

ծանոթ անուններ Flexbox-ից
/* Բոլոր վանդակների ներսում */
.grid {
    justify-items: center;   /* հորիզոնական */
    align-items:   center;   /* ուղղահայաց */
}

/* Մեկ տարրի բացառություն */
.special { justify-self: end; align-self: start; }

/* Ամբողջ ցանցը կոնտեյների ներսում */
.grid { justify-content: center; }
Grid-ում անունները շփոթեցնող են

justify-items / align-items → վանդակների ներսի բովանդակությունը
justify-content / align-content → ամբողջ ցանցը կոնտեյների ներսում

Flexbox-ում justify-content-ը բաշխում էր տարրերը։ Grid-ում այն շարժում է ամբողջ ցանցը։ Հեշտ է շփոթել։

05grid-template-areas

Դասավորությունը՝ նկարված ուղիղ CSS-ում։

էջի կմախք
.layout {
    display: grid;
    grid-template-columns: 240px 1fr;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
    gap: 16px;

    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
}

.layout > header  { grid-area: header; }
.layout > aside   { grid-area: sidebar; }
.layout > main    { grid-area: main; }
.layout > footer  { grid-area: footer; }
հեռախոսում՝ վերադասավորում
@media (max-width: 768px) {
    .layout {
        grid-template-columns: 1fr;
        grid-template-areas:
            "header"
            "main"
            "sidebar"
            "footer";
    }
}
Առավելությունը

Հեռախոսում կողքի բլոկը տեղափոխվեց բովանդակությունից հետո՝ առանց HTML-ը փոխելու։

Կոդը կարդալիս անմիջապես տեսնում ես դասավորությունը — դա գրեթե ASCII նկար է։ Համեմատիր grid-column: 1 / 3 գրառման հետ, որտեղ պիտի պատկերացնես գծերի համարները։

Զգուշացում — նույնը, ինչ Դաս 12-ի order-ի դեպքում

grid-template-areas-ը փոխում է տեսողական հերթականությունը։ Tab-ի հերթականությունը և էկրանընթերցիչի ընթերցումը մնում են ըստ HTML-ի։

Header → main → sidebar → footer վերադասավորումը անվտանգ է, որովհետև HTML-ում էլ մոտավորապես նույն տրամաբանությունն է։ Բայց խուսափիր կտրուկ վերադասավորումներից։

դատարկ վանդակ
.layout {
    grid-template-areas:
        "header header"
        "sidebar main"
        ".       footer";   /* կետը = դատարկ */
}

06Grid մեր համակարգում

Չենք հրաժարվում .row > .col-ից։ Ավելացնում ենք Grid-ը այնտեղ, որտեղ այն ավելի պարզ է։

css/global.css — այսօրվա ավելացումը
/* ---------- Grid օգնականներ ---------- */
.grid { display: grid; }

/* Ինքնահարմարվող ցանց — ամենաօգտագործվողը */
.grid-auto {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(min(260px, 100%), 1fr));
}

/* Ֆիքսված սյուներ */
.grid-2 { display: grid; grid-template-columns: repeat(2, 1fr); }
.grid-3 { display: grid; grid-template-columns: repeat(3, 1fr); }
.grid-4 { display: grid; grid-template-columns: repeat(4, 1fr); }

/* Ամբողջ լայնությամբ */
.col-full { grid-column: 1 / -1; }

@media (max-width: 768px) {
    .grid-2, .grid-3, .grid-4 { grid-template-columns: 1fr; }
}
օգտագործում՝ .row-ի ներսում
<section id="products">
    <div class="row">
        <div class="col w-100">

            <!-- Grid-ը՝ .wrapper-ի փոխարեն -->
            <div class="grid-auto gap-20">
                <article class="card">...</article>
                <article class="card">...</article>
                <article class="card">...</article>
                <article class="card">...</article>
            </div>

        </div>
    </div>
</section>
.row > .col.w-*.grid-auto
Անհամաչափ սյուներ (70/30)✅Պետք է span
Միատեսակ քարտերԱշխատում է✅ Ավելի պարզ
Ադապտիվություն3 դաս + media query✅ Ավտոմատ
Հավասար բարձրություն✅ .wrapper height:100%✅ Լռելյայն
Ծանոթ է աշակերտին✅ 10 դասՆոր
Առաջարկվող կանոն

Էջի կմախք և անհամաչափ բաժանումներ → .row > .col.w-*
Միատեսակ տարրերի ցանկ (ապրանքներ, թիմ, բլոգ) → .grid-auto

Երկուսն էլ ապրում են նույն նախագծում։ Դա նորմալ է — իրական կոդում միշտ այդպես է։

DevTools-ի Grid օգնականը

Ընտրիր grid-կոնտեյները Elements-ում — կողքին կհայտնվի փոքր grid պիտակ։ Սեղմիր դրան։

Էջի վրա կհայտնվեն գծերի համարները և բացակների ուրվագծերը։ Առանց դրա grid-column: 2 / 4-ը գուշակություն է։

Layout ներդիրում կարող ես նաև միացնել գծերի անունները և չափերը։

Փորձիր

1. Փոխիր auto-fit-ը auto-fill-ի և ջնջիր 3 քարտ։
2. Փոխիր minmax(min(180px, 100%), 1fr)-ը minmax(400px, 1fr)-ի և նեղացրու։
3. Ջնջիր .full { grid-column: 1 / -1 }-ը։
4. .layout-ի areas-ում փոխիր sidebar-ը և main-ը տեղերով։

08Դասարանական

  1. Ավելացրու global.css-ում Grid օգնականները
  2. Վերցրու ապրանքների բաժինը և փոխարինիր .col w-33 w-md-50 w-sm-100-ը .grid-auto-ով
  3. Համեմատիր՝ քանի՞ դաս կրճատվեց HTML-ից
  4. Ավելացրու մեկ «առանձնահատուկ» քարտ՝ grid-column: span 2
  5. Ավելացրու բաժնի վերնագիր ցանցի ներսում՝ col-full-ով
  6. Կառուցիր էջի կմախք grid-template-areas-ով
  7. Ավելացրու հեռախոսի տարբերակը՝ վերադասավորմամբ
  8. Ստուգիր DevTools-ի Grid overlay-ով
  9. Ստուգիր 320px լայնությամբ՝ չկա՞ հորիզոնական սքրոլ
Ուշադրություն՝ քարտի հավասար բարձրություն

Grid-ում վանդակները լռելյայն ձգվում են ամբողջ բարձրությամբ (align-items: stretch)։ Բայց քարտն ինքը պիտի ունենա height: 100%, եթե այն .wrapper-ի պես ներդրված է։

Եթե .card-ը ուղիղ grid-ի երեխա է, ոչինչ պետք չէ — ամեն ինչ արդեն աշխատում է։ Դա Grid-ի ևս մեկ պարզեցում է։

09Տնային աշխատանք

  1. Կառուցիր ցանց 1fr-ով և ցանց տոկոսներով՝ երկուսն էլ gap: 20px-ով։ Ցույց տուր, ինչու տոկոսներով տարբերակը դուրս է գալիս։
  2. Ցուցադրիր auto-fit-ի և auto-fill-ի տարբերությունը՝ 2 տարրով լայն էկրանին։
  3. Կառուցիր ապրանքների ցանց auto-fit-ով։ Համեմատիր Դաս 14-ի flex տարբերակի հետ՝ քանի՞ տող կոդ և քանի՞ դաս կրճատվեց։
  4. Ցուցադրիր minmax(400px, 1fr)-ի խնդիրը 320px էկրանին։ Ուղղիր min()-ով։
  5. Կառուցիր գալերեա, որտեղ առաջին նկարը զբաղեցնում է 2×2 վանդակ։
  6. Օգտագործիր grid-column: 1 / -1 բաժնի վերնագրի համար ցանցի ներսում։
  7. Կառուցիր էջի կմախք grid-template-areas-ով՝ header, sidebar, main, footer։
  8. Ավելացրու հեռախոսի տարբերակը, որտեղ sidebar-ը գնում է main-ից հետո։ Ստուգիր Tab-ի հերթականությունը։
  9. Կառուցիր ֆորմա Grid-ով՝ պիտակները ձախում, դաշտերը աջում (grid-template-columns: 140px 1fr)։
  10. Գրիր ցուցակ՝ քո նախագծի որ բաժիններում կօգտագործեիր Grid, որտեղ՝ Flex, և ինչու։

Ոսկե տողը

grid-template-columns: repeat(auto-fit, minmax(min(260px, 100%), 1fr)); Ադապտիվ ցանց՝ առանց ոչ մի media query

Ի՞նչ ավելացավ global.css-ում այսօր

✓ .grid, .grid-auto ✓ .grid-2 / .grid-3 / .grid-4 ✓ .col-full (grid-column: 1 / -1) ✓ @media 768px — բոլորը դառնում են 1 սյուն

Ստուգաթերթ

  • Ցանցերն օգտագործում են fr, ոչ տոկոսներ
  • minmax-ը փաթեթավորված է min()-ով
  • Չկա հորիզոնական սքրոլ 320px-ում
  • Grid-ը օգտագործվում է միատեսակ ցանցերի համար
  • Flex-ը մնում է կոմպոնենտների ներսում
  • grid-template-areas-ը չի կոտրում Tab-ի հերթականությունը

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ե՞րբ Grid, ե՞րբ Flex
  • Գիտե՞մ, ինչու fr-ը ավելի լավն է, քան %-ը gap-ի հետ
  • Հասկանո՞ւմ եմ auto-fit-ի և auto-fill-ի տարբերությունը
  • Կարո՞ղ եմ բացատրել 1 / -1-ը
  • Գիտե՞մ, ինչու Grid-ում justify-content-ը այլ բան է անում
Հաջորդ դասին

transition, transform, @keyframes, ֆիլտրեր։ Կսովորենք շարժում ավելացնել՝ առանց էջը դանդաղեցնելու, և կհարգենք prefers-reduced-motion-ը։ Դա HTML/CSS բլոկի վերջին տեսական դասն է — հետո նախագիծն է։
