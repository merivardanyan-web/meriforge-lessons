Նավիգացիա

Header-ը էջի ամենակարևոր կոմպոնենտն է — այն կա ամեն էջում և դրանով են սկսում ամեն այցելուները։ Այսօր կառուցում ենք ամբողջական համակարգ՝ dropdown, բուրգեր-մենյու, footer։

01Ճիշտ կառուցվածքը

հիմքը
<nav aria-label="Գլխավոր մենյու">
    <ul class="menu">
        <li><a href="index.html" aria-current="page">Գլխավոր</a></li>
        <li><a href="products.html">Ապրանքներ</a></li>
        <li><a href="about.html">Մեր մասին</a></li>
    </ul>
</nav>
ՏարրԻնչու
<nav>Landmark — էկրանընթերցիչը կարող է ցատկել այստեղ
aria-labelԵրբ էջում մի քանի nav կա — Դաս 5
<ul> / <li>Հայտարարվում է «ցուցակ՝ 3 կետից»
aria-current="page"«Դու հիմա այստեղ ես» ⭐
aria-current — երկու օգուտ մեկ ատրիբուտից

1. Էկրանընթերցիչը հայտարարում է «ընթացիկ էջ»։
2. CSS-ում ոճավորելու համար լրացուցիչ դաս պետք չէ՝

.menu a[aria-current="page"] { color: var(--secondary); }

Սա class="is-active"-ից լավն է, որովհետև մեկ ատրիբուտը միաժամանակ իմաստ և ոճ է տալիս։

Skip link — վերադառնանք Դաս 5-ին

Ստեղնաշարով նավարկողը ամեն էջում պիտի անցնի մենյուի բոլոր հղումներով, նախքան բովանդակությանը հասնելը։ 8 հղում × 20 էջ = տառապանք։

Ուստի <body>-ի հենց սկզբում՝
<a href="#main" class="skip-link">Անցնել բովանդակությանը</a>

.skip-link-ը արդեն կա global.css-ում Դաս 6-ից։ Հիմա գիտես՝ ինչու։

03Dropdown

HTML
<li class="has-sub">
    <a href="catalog.html">Կատեգորիաներ ▾</a>

    <ul class="submenu">
        <li><a href="#">Նոութբուքեր</a></li>
        <li><a href="#">Մոնիտորներ</a></li>
        <li><a href="#">Աքսեսուարներ</a></li>
    </ul>
</li>
CSS
.has-sub { position: relative; }

.submenu {
    position: absolute;
    top: calc(100% + 4px);
    left: 0;
    z-index: 10;

    min-width: 200px;
    background: #ffffff;
    border-radius: 8px;
    box-shadow: var(--shadow-lg);
    padding: 6px;

    opacity: 0;
    visibility: hidden;
    transform: translateY(-6px);
    transition: opacity .15s, transform .15s, visibility .15s;
}

.has-sub:hover .submenu,
.has-sub:focus-within .submenu {
    opacity: 1;
    visibility: visible;
    transform: translateY(0);
}

.submenu a { display: block; padding: 10px 12px; border-radius: 6px; }
.submenu a:hover { background: var(--bg); }
Ինչո՞ւ visibility, ոչ display: none

display: none-ը չի անիմացվում — մենյուն ուղղակի ցատկում է։

visibility: hidden + opacity: 0 — անիմացվում է, և միևնույն ժամանակ էլեմենտն անհասանելի է Tab-ի համար (ի տարբերություն միայն opacity: 0-ի, Դաս 9)։

Երկու պարտադիր բան

1. :focus-within — առանց դրա ստեղնաշարով մենյուն չի բացվի։

2. Ծնող հղումը պիտի աշխատող լինի — href="catalog.html", ոչ href="#"։ Հեռախոսում :hover չկա, և եթե ծնողը ոչ մի տեղ չի տանում, օգտագործողը փակուղում է։

04Բուրգեր-մենյու

Հեռախոսում 5 հղում հորիզոնական չեն տեղավորվում։ Լուծումը՝ թաքցնել դրանք կոճակի հետևում։

Բուրգերի պատկերակը

երեք գիծ → ✕
<!-- HTML -->
<button class="burger" aria-label="Բացել մենյուն" aria-expanded="false">
    <span></span>
    <span></span>
    <span></span>
</button>
.burger {
    display: none;              /* միայն հեռախոսում */
    width: 44px;
    height: 44px;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    gap: 5px;
    background: transparent;
    border: 0;
    cursor: pointer;
}

.burger span {
    display: block;
    width: 24px;
    height: 2px;
    background: var(--text);
    transition: transform .25s, opacity .25s;
}

/* Բացված վիճակ՝ ✕ */
.is-open .burger span:nth-child(1) { transform: translateY(7px) rotate(45deg); }
.is-open .burger span:nth-child(2) { opacity: 0; }
.is-open .burger span:nth-child(3) { transform: translateY(-7px) rotate(-45deg); }

Ինչո՞ւ ենթամենյուն միշտ բաց

Հեռախոսում :hover չկա։ Առանց JS-ի ենթամենյուն բացելու ձև չկա։

Ուստի ամենապարզ և ամենաազնիվ լուծումն է՝ ցույց տալ այն միանգամից՝ ներսի հատվածով։ Օգտագործողը տեսնում է ամբողջ կառուցվածքը մեկ հայացքով։

05CSS-ով բացել-փակելը

Մինչև JS սովորելը կա հնարք՝ թաքնված checkbox։

checkbox-ի հնարքը
<!-- Checkbox-ը գալիս է ԱՌԱՋ մենյուից -->
<input type="checkbox" id="nav-toggle" class="nav-toggle">

<label for="nav-toggle" class="burger">
    <span></span><span></span><span></span>
    <span class="visually-hidden">Մենյու</span>
</label>

<nav><ul class="menu">...</ul></nav>
.nav-toggle { position: absolute; opacity: 0; pointer-events: none; }

/* ~ = հետագա եղբայր */
.nav-toggle:checked ~ nav .menu { transform: translateX(0); }

.nav-toggle:checked ~ .burger span:nth-child(1) { transform: translateY(7px) rotate(45deg); }
.nav-toggle:checked ~ .burger span:nth-child(2) { opacity: 0; }
.nav-toggle:checked ~ .burger span:nth-child(3) { transform: translateY(-7px) rotate(-45deg); }

/* Ֆոկուս label-ի վրա, երբ checkbox-ը ֆոկուսում է */
.nav-toggle:focus-visible ~ .burger {
    outline: 2px solid var(--secondary);
}
Ազնիվ գնահատական — սա ժամանակավոր լուծում է

Աշխատում է՝ բացվում և փակվում է, անիմացվում է, ստեղնաշարով հասանելի է։

Բայց՝
· checkbox-ը իմաստային առումով սխալ է — դա ֆորմայի տարր է, ոչ կոճակ
· Չի փակվում Esc-ով
· Չի փակվում հղումին սեղմելուց հետո
· Չի փակվում դրսում սեղմելիս
· aria-expanded-ը չի թարմացվում — էկրանընթերցիչը չգիտի վիճակը

JS բլոկի Դաս 11-ում այս նույն մենյուն կվերաշարադրենք ճիշտ՝ <button>-ով, aria-expanded-ի թարմացմամբ և բոլոր փակելու ձևերով։ Այսօրվա CSS տարբերակը լավ է հասկանալու համար, բայց իրական նախագծում օգտագործիր JS-ը։

Ի՞նչ է ~

Հետագա եղբոր սելեկտոր — ընտրում է բոլոր հետո եկող եղբայրներին։

A ~ B — բոլոր B-երը, որոնք A-ից հետո են, նույն ծնողի ներսում։
A + B — միայն անմիջապես հաջորդը (Դաս 17-ի bread crumbs-ը)։

Ուստի checkbox-ը պիտի լինի HTML-ում ավելի վաղ, քան այն, ինչ ուզում ես կառավարել։ CSS-ը չի կարող «հետ նայել»։

Footer-ի հասանելիության մանրուքներ

1. Footer-ի nav-ը նույնպես պիտի ունենա aria-label — այլապես էկրանընթերցիչը կասի «նավիգացիա» երկու անգամ։
2. <address>-ը կոնտակտների համար է (Դաս 5)։
3. Մուգ ֆոնի վրա հղումների կոնտրաստը ստուգիր առանձին — մոխրագույն տեքստը մուգի վրա հաճախ ձախողվում է։

07Խաղահրապարակ

Ամբողջական աշխատող նավիգացիա։ Նեղացրու նախադիտումը 768px-ից ներքև՝ բուրգերը տեսնելու համար։

Նեղացրու պատուհանը · սեղմիր Tab
Փորձիր

1. Նեղացրու պատուհանը և սեղմիր բուրգերին։
2. Սեղմիր Tab առաջին անգամ — կհայտնվի skip link-ը։
3. Ջնջիր :focus-within-ը և փորձիր Tab-ով բացել ենթամենյուն։
4. Բացիր մենյուն և սեղմիր հղումին — կփակվի՞։ (Ահա CSS-ի սահմանափակումը։)

08Դասարանական

  1. Կառուցիր header՝ լոգոյով և 5 կետանոց մենյուով
  2. Ավելացրու aria-current="page" և ոճավորիր այն
  3. Ավելացրու skip link ամենասկզբում
  4. Ավելացրու dropdown մեկ կետի համար՝ :hover և :focus-within
  5. Կառուցիր բուրգերի պատկերակը երեք span-ով
  6. Ավելացրու checkbox-ի հնարքը
  7. 768px-ից ներքև՝ մենյուն դարձրու fullscreen պանել
  8. Կառուցիր footer՝ երեք սյունով և ներքևի տողով
  9. Ստուգիր ամեն ինչը Tab-ով՝ առանց մկնիկի
Ստուգման կարգը՝ մկնիկը մի կողմ

Ձեռքդ վերցրու մկնիկից և փորձիր անցնել ամբողջ էջով միայն Tab-ով և Enter-ով։

Պիտի կարողանաս՝ ցատկել բովանդակությանը, բացել մենյուն, մտնել ենթամենյու, հասնել footer։ Ամեն պահի պիտի տեսնես, թե որտեղ ես։

Եթե ինչ-որ պահի ֆոկուսը կորչում է — այնտեղ խնդիր կա։

09Տնային աշխատանք

Մինի-նախագիծ

Այս տնայինի գլխավոր մասը՝ «Նավիգացիա․ dropdown և բուրգեր», քայլ առ քայլ, starter ֆայլերով և պատրաստի օրինակով։ Ներքևի ցուցակի մնացած կետերը առանձին վարժություններ են։

  1. Կառուցիր ամբողջական header՝ լոգո, 5 հղում, կոճակ։
  2. Ավելացրու aria-current="page"։ Ցուցադրիր, ինչպես ես ոճավորում այն առանց լրացուցիչ դասի։
  3. Ավելացրու skip link։ Ցույց տուր, ինչպես է այն հայտնվում Tab-ի ժամանակ։
  4. Կառուցիր dropdown։ Ջնջիր :focus-within-ը և նկարագրիր, ինչ կորավ։
  5. Համեմատիր display: none-ը և visibility: hidden + opacity-ը dropdown-ի համար։ Ո՞րն է անիմացվում։
  6. Կառուցիր բուրգերի պատկերակ, որը վերածվում է ✕-ի։ Ուղարկիր երկու սքրինշոթ։
  7. Իրականացրու checkbox-ի հնարքը։ Ցուցադրիր, որ այն աշխատում է Tab-ով և Space-ով։
  8. Գրիր ցուցակ՝ ի՞նչ 5 բան չի աշխատում CSS-ի տարբերակում։ (Ակնարկ՝ Esc, հղումին սեղմելը, դրսում սեղմելը...)
  9. Կառուցիր footer՝ 3 սյուն, որը հեռախոսում դառնում է 1։ Ստուգիր հղումների կոնտրաստը մուգ ֆոնի վրա։
  10. Անցիր ամբողջ էջով միայն ստեղնաշարով։ Նկարագրիր ամեն խնդիր, որ գտար։

Ստուգաթերթ

  • nav-երն ունեն aria-label
  • Ակտիվ էջը նշված է aria-current-ով
  • Կա skip link
  • Dropdown-ն ունի :focus-within
  • Dropdown-ի ծնող հղումն աշխատող է
  • Բուրգերի կոճակը ≥ 44×44px
  • Բուրգերն ունի տեքստային անուն (aria-label կամ .visually-hidden)
  • Մենյուն հեռախոսում ունի overflow-y: auto
  • Footer-ի հղումների կոնտրաստը ≥ 4.5:1
  • Ամբողջ նավիգացիան անցնելի է Tab-ով

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչու aria-current, ոչ class="active"
  • Գիտե՞մ, ինչու visibility, ոչ display: none
  • Հասկանո՞ւմ եմ ~-ի և +-ի տարբերությունը
  • Կարո՞ղ եմ անվանել CSS-բուրգերի 3 սահմանափակում
  • Գիտե՞մ, ինչու է skip link-ը պետք
Հաջորդ դասին

CSS փոփոխականներ և թեմաներ։ Կխորանանք :root-ի մեջ, կկառուցենք դիզայն-տոկենների համակարգ և կավելացնենք մուգ թեմա՝ առանց մեկ տող JavaScript-ի։
