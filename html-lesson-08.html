Box model

Էջի ամեն էլեմենտ ուղղանկյուն տուփ է։ Հասկանալով, թե ինչից է կազմված այդ տուփը, դու հասկանում ես CSS-ի կեսը։ Եվ վերջապես կիմանաս, ինչ է անում box-sizing: border-box-ը։

DevTools-ում

Ընտրիր ցանկացած էլեմենտ Inspect-ով և ոլորիր Styles վահանակը ներքև։ Այնտեղ կտեսնես գունավոր դիագրամ՝ ճիշտ նույն չորս շերտով, իրական թվերով։ Սա CSS-ի ամենաօգտակար գործիքներից է։

02padding

չորս ուղղություն
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 10px;
    padding-left: 20px;
}

/* Նույնը՝ կարճ */
.box {
    padding: 10px 20px;
}

Կարճ գրառման կանոնները

padding: 20px; բոլոր չորս կողմերը padding: 10px 20px; վեր-վար ձախ-աջ padding: 10px 20px 15px; վեր ձախ-աջ վար padding: 10px 20px 15px 5px; վեր աջ վար ձախ ↑ ժամացույցի սլաքով
Հիշելու ձև

Չորս արժեքի դեպքում՝ սկսում ես վերևից և գնում ժամացույցի սլաքի ուղղությամբ՝ վեր → աջ → վար → ձախ։

padding-ը մեծացնում է տուփը

Առանց box-sizing: border-box-ի width: 200px + padding: 20px = 240px իրական լայնություն։ Դա շփոթեցնող է, և հենց դրա համար ենք global.css-ում գրել այն կանոնը։ Մանրամասն՝ 06-րդ բաժնում։

border-radius

կլորացում
.card   { border-radius: 10px; }
.btn    { border-radius: 6px; }
.pill   { border-radius: 999px; }   /* լրիվ կլոր ծայրեր */
.avatar { border-radius: 50%; }     /* շրջան */

/* Առանձին անկյուններ */
.tab { border-radius: 10px 10px 0 0; }
border-radius: 50% ձգված տուփի վրա

Եթե տուփը քառակուսի չէ, 50%-ը կտա օվալ, ոչ շրջան։ Ավատարի համար պարտադիր դիր նաև հավասար width և height։

outline vs border
/* border — մաս է տուփի, մեծացնում է չափը */
.box { border: 2px solid navy; }

/* outline — նկարվում է վերևից, չափը չի փոխում */
.box:focus-visible { outline: 2px solid navy; outline-offset: 2px; }
Ահա թե ինչու ֆոկուսի համար outline

outline-ը չի ազդում դասավորության վրա։ Եթե ֆոկուսը ցույց տայիր border-ով, ամեն անգամ Tab սեղմելիս էջը «կցատկեր» 2px-ով։

04margin

նույն կանոնները, ինչ padding-ի
.box { margin: 20px; }
.box { margin: 20px 0; }
.box { margin-bottom: 30px; }

/* Բացասական margin — կարելի է, բայց զգույշ */
.box { margin-top: -10px; }

Կենտրոնացում

margin: auto
.container {
    max-width: 1200px;
    margin: 0 auto;      /* վեր-վար 0, ձախ-աջ ինքնաբերաբար */
}
auto-ն աշխատում է միայն երկու պայմանով

1. Էլեմենտն ունի width կամ max-width։
2. Այն բլոկային է (display: block)։

Առանց լայնության էլեմենտն արդեն զբաղեցնում է ամբողջ տողը, և կենտրոնացնելու բան չկա։

Երկու մոտեցում պատերի համար

Ա. .row { padding: 0 60px } — մեր մեթոդաբանությունը։ Բովանդակությունը ձգվում է ամբողջ լայնությամբ, բայց պահում է կողային բացակները։
Բ. .row { max-width: 1200px; margin: 0 auto } — բովանդակությունը կենտրոնանում է և չի ձգվում մեծ էկրաններին։

Երկուսն էլ ճիշտ են։ 13-րդ դասին կհամեմատենք դրանք մանրամասն և կընտրենք գիտակցաբար։

05Margin collapse

Ամենաշփոթեցնող վարքագիծը CSS-ում։ Հասկանանք այն մեկընդմիշտ։

ի՞նչ ես սպասում
.first  { margin-bottom: 30px; }
.second { margin-top: 20px; }

/* Ակնկալում ես՝ 30 + 20 = 50px */
/* Իրականում՝ 30px                */
.first ┌──────────┐ └──────────┘ ↕ 30px ← վերցվում է ՄԵԾԸ, ոչ գումարը ┌──────────┐ .second └──────────┘
Կանոնը

Երբ երկու էլեմենտի ուղղահայաց margin-ները հանդիպում են, դրանք չեն գումարվում — վերցվում է ավելի մեծը։

Կարևոր՝ սա տեղի է ունենում միայն ուղղահայաց ուղղությամբ։ Հորիզոնական margin-ները միշտ գումարվում են։

Երկրորդ դեպքը՝ ծնող և երեխա

margin-ը «դուրս է թռչում»
/* <div class="parent">
       <h2>Վերնագիր</h2>
   </div> */

.parent { background: lightblue; }
h2       { margin-top: 30px; }

/* h2-ի margin-ը դուրս է գալիս ծնողից
   և հրում է ամբողջ .parent-ը ներքև    */
Երեք լուծում

1. Ծնողին տուր padding՝ գոնե 1px։
2. Ծնողին տուր border։
3. Ամենալավը՝ օգտագործիր padding, ոչ margin, երբ բացակը «ներսի» է։

Հենց դրա համար է մեր .col-ը օգտագործում padding, ոչ margin։ Margin collapse-ի հետ խնդիր չի լինում։

Հեռանկար

Flexbox-ում և Grid-ում margin collapse չկա։ Իսկ gap հատկությունը շատ ավելի կանխատեսելի է։ 11-րդ դասից սկսած այս խնդիրը մեծ մասամբ կանհետանա։

06box-sizing

Ահա այն կանոնը, որը Դաս 6-ում գրեցինք global.css-ում առանց բացատրության։

content-box — բրաուզերի լռելյայն
.box {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid;
}

/* Իրական լայնությունը՝
   200 + 20 + 20 + 5 + 5 = 250px   */
border-box — մեր ընտրությունը ✅
.box {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid;
}

/* Իրական լայնությունը՝ 200px
   padding-ը և border-ը սեղմվում են ներս  */
content-box border-box 200px 200px ├────────┤ ├────────┤ │content │ + padding │ p │c│ p│ padding-ը ներսում └────────┘ + border └────────┘ = 250px = 200px ✓
Ինչո՞ւ է border-box-ը շատ ավելի հարմար

Պատկերացրու երեք սյուն՝ width: 33.33%։ content-box-ի դեպքում ամեն padding ավելացնում է լայնություն, և սյուները չեն տեղավորվում — երրորդն ընկնում է ներքև։

border-box-ով 33.33% նշանակում է ուղիղ 33.33%, անկախ ամեն ինչից։ Հենց դրա շնորհիվ է աշխատում մեր .w-25, .w-33 համակարգը։

Դրա համար էլ այն գրում ենք առաջին տողերում

* { box-sizing: border-box } — կիրառվում է ամեն էլեմենտի վրա։ Այս մեկ տողը հանում է հարյուրավոր հետագա գլխացավեր, և այն կա գրեթե ամեն ժամանակակից նախագծում։

07Չափեր

width և ընկերները
.box {
    width: 300px;
    max-width: 100%;      /* չգերազանցի ծնողին */
    min-width: 200px;

    height: 200px;
    min-height: 100px;
}
ՀատկությունԵ՞րբ օգտագործել
width: 100%Ամբողջ ծնողի լայնությամբ
max-widthԱդապտիվության բանալին
min-heightԵրբ բլոկը պիտի ունենա նվազագույն բարձրություն
heightԶգույշ — տեքստը կարող է դուրս գալ
width vs max-width

width: 1200px — 400px էկրանին բլոկը կմնա 1200px, և կհայտնվի հորիզոնական սքրոլ։
max-width: 1200px — «ոչ ավելի, քան 1200px, բայց եթե տեղ չկա՝ սեղմվիր»։

Կանոն՝ ֆիքսված width-ի փոխարեն գրեթե միշտ ավելի լավ է max-width։

Ֆիքսված height-ը վտանգավոր է

height: 200px և ներսում երկար տեքստ → տեքստը դուրս է գալիս տուփից։ Հատկապես վտանգավոր է հայերենի հետ, որտեղ բառերն ավելի երկար են, քան անգլերենում։

Օգտագործիր min-height — բլոկը կունենա նվազագույն բարձրություն, բայց կաճի, եթե պետք լինի։

Նկարները և տուփը

global.css — այսօրվա ավելացումը
picture {
    display: block;
    font-size: 0;
}

img {
    max-width: 100%;
}
ԿանոնԻնչու
img { max-width: 100% }Մեծ նկարը չի ջարդում դասավորությունը փոքր էկրանին
picture { display: block }Դարձնում է բլոկային՝ հեշտ կառավարելի
picture { font-size: 0 }Հանում է նկարի տակի առեղծվածային 4px բացակը
Այդ առեղծվածային բացակը

img-ը տողային էլեմենտ է, ուստի բրաուզերը դրա տակ թողնում է տեղ տառերի «պոչերի» համար (ինչպես ց, ղ)։ Արդյունքում նկարի տակ հայտնվում է 3–5px բացակ, որը շատերին խելագարեցնում է։

font-size: 0-ը ծնողի վրա լուծում է դա։

.card img {
    width: 100%;
    display: block;
}

.card__body {
    padding: 16px;         /* ներսի բացակ — padding, ոչ margin */
}

.card__body .title-4 {
    margin-bottom: 8px;
}

.card__price {
    font-size: 1.25rem;
    font-weight: 700;
    margin: 12px 0;
}

.btn {
    display: inline-block;
    padding: 10px 20px;
    background: var(--secondary);
    color: var(--on-dark);
    border: 1px solid transparent;
    border-radius: 6px;
}

.btn:hover {
    background: var(--on-dark);
    color: var(--secondary);
    border-color: var(--secondary);
}
Երկու կարևոր մանրուք

1. overflow: hidden քարտի վրա — առանց դրա նկարի անկյունները դուրս կգան կլորացումից։
2. border: 1px solid transparent կոճակի վրա — որ hover-ի ժամանակ, երբ եզրագիծը հայտնվի, կոճակը չցատկի 2px-ով։ Փոքր մանրուք, որը տարբերում է ուշադիր աշխատանքը անփույթից։

10Տնային աշխատանք

  1. Ստեղծիր բլոկ և ցուցադրիր չորս շերտն էլ՝ տարբեր գույներով։ Ստուգիր DevTools-ի դիագրամով։
  2. Գրիր padding-ը չորս ձևով՝ 1, 2, 3 և 4 արժեքով։ Նկարագրիր ամեն մեկի արդյունքը։
  3. Ցուցադրիր box-sizing-ի տարբերությունը՝ երկու նույնական բլոկ, տարբեր box-sizing։ Չափիր DevTools-ով։
  4. Ցուցադրիր margin collapse-ը երկու պարբերությամբ։ Ապա ուղղիր՝ padding-ի անցնելով։
  5. Ցուցադրիր երկրորդ դեպքը՝ երեխայի margin-ը դուրս է գալիս ծնողից։ Ուղղիր երեք ձևով։
  6. Կենտրոնացրու բլոկը margin: 0 auto-ով։ Հետո ջնջիր max-width-ը և բացատրիր, ինչու դադարեց աշխատել։
  7. Ստեղծիր չորս ձև՝ քառակուսի, կլորացված, «դեղահատ», շրջան։ Ցույց տուր, ինչ է լինում 50%-ի հետ ոչ քառակուսի տուփի վրա։
  8. Համեմատիր height-ը և min-height-ը երկար տեքստով։
  9. Ավելացրու global.css-ում picture-ի և img-ի կանոնները։ Ցույց տուր՝ ինչ եղավ նկարի տակի բացակի հետ։
  10. Կառուցիր ապրանքի քարտ դասարանական օրինակի պես։ Ավելացրու երկրորդ քարտ և տեղադրիր դրանք կողք կողքի (display: inline-block-ով — Flexbox-ը հաջորդ դասերին է)։

Ի՞նչ ավելացավ global.css-ում այսօր

✓ picture { display: block; font-size: 0 } ✓ img { max-width: 100% }

Ստուգաթերթ

  • box-sizing: border-box-ը կա global.css-ում
  • Ֆիքսված width-ի փոխարեն՝ max-width
  • Ֆիքսված height-ի փոխարեն՝ min-height
  • Ներսի բացակների համար՝ padding, ոչ margin
  • Կոճակներն ունեն border: ... transparent, որ hover-ին չցատկեն
  • Նկարներն ունեն max-width: 100%

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել padding-ի և margin-ի տարբերությունը
  • Գիտե՞մ, ինչու box-sizing: border-box
  • Հասկանո՞ւմ եմ margin collapse-ը
  • Գիտե՞մ, ինչու max-width, ոչ width
  • Կարո՞ղ եմ բացատրել, ինչու ֆոկուսի համար outline
Հաջորդ դասին

display և նորմալ հոսք։ Ինչո՞ւ են div-երը դասավորվում ուղղահայաց, իսկ span-երը՝ հորիզոնական։ Սա վերջին քայլն է մինչև 10-րդ դասը, որտեղ կսկսենք մեր դասավորության համակարգը։
