# ՏեխնոՄարկետ

Տեխնիկայի խանութի 9 էջանոց ստատիկ կայք՝ HTML/CSS բլոկի վերջնական նախագիծ։

**Դեմո՝** https://username.github.io/technomarket/

## Էջեր
| Էջ | Ֆայլ | Ինչ է ցույց տալիս |
|---|---|---|
| Գլխավոր | `index.html` | Hero, հանրաճանաչ ապրանքներ, առավելություններ, բաժանորդագրություն |
| Կատալոգ | `catalog.html` | Ֆիլտրերի ֆորմա, ապրանքների ցանց, դասավորում, էջավորում |
| Ապրանքի էջ | `product.html` | Պատկերասրահ, գին, քանակ, բնութագրերի աղյուսակ, նման ապրանքներ |
| Զամբյուղ | `cart.html` | Աղյուսակ համակարգչում, քարտեր հեռախոսում, ամփոփում |
| Պատվերի ձևակերպում | `checkout.html` | Ֆորմա երեք խմբով՝ կոնտակտներ, առաքում, վճարում |
| Շնորհակալություն | `thanks.html` | Պատվերի հաստատում |
| 404 | `404.html` | Սխալի էջ․ GitHub Pages-ը այն ցույց է տալիս ինքնաշխատ |
| Մուտք | `login.html` | Մուտքի ֆորմա՝ էլ. հասցե, գաղտնաբառ, «Հիշել ինձ» |
| Գրանցում | `register.html` | Գրանցման ֆորմա՝ առավելություններ, երկու գաղտնաբառի դաշտ |

## Տեխնոլոգիաներ
- Սեմանտիկ HTML5, ֆորմաներ, աղյուսակներ
- CSS՝ երկու շերտի տոկեններ, Flexbox, Grid, անիմացիաներ
- Մուգ թեմա՝ `prefers-color-scheme`-ով (փոխվում են միայն իմաստային տոկենները)
- Ադապտիվ՝ 320px–1920px
- Առանց գրադարանների և առանց JavaScript-ի

## Կառուցվածք
- `css/global.css` — վարքագիծ և utility-դասեր, չի փոխվում նախագծից նախագիծ
- `css/main.css` — այս նախագծի արժեքները և կոմպոնենտները, մեկ ֆայլ բոլոր էջերի համար
- `components.html` — ոճերի ուղեցույց
- Դասավորության համակարգ՝ `main > section > .row > .col > .wrapper`

## Հայտնի սահմանափակումներ
- Բուրգեր-մենյուն իրականացված է CSS-ով (checkbox)։ Չի փակվում Esc-ով և հղմանը սեղմելուց հետո։ Կուղղվի JS բլոկում։
- Ֆիլտրերը, դասավորումը և էջավորումը փոխում են միայն հասցեն (`?cat=laptops`), ապրանքները չեն փոխվում։ Կուղղվի JS և PHP բլոկներում։
- Պատկերասրահի փոքր նկարները սեղմելի չեն։ Կուղղվի JS բլոկում։
- Զամբյուղի քանակը և «Հեռացնել» կոճակը չեն փոխում գումարները։ Կուղղվի JS բլոկում։
- Պատվերի ֆորման ուղարկվում է `GET`-ով `thanks.html`, ուստի տվյալները երևում են հասցեում։ Իրական կայքում սա անթույլատրելի է․ կուղղվի PHP բլոկում (`POST` + սերվեր)։
- Մուտքի և գրանցման ֆորմաները ոչինչ չեն անում (`action="#"`)․ գաղտնաբառը ստուգելու համար պետք է սերվեր։ Կաշխատեն PHP Դաս 16-ում, դաշտերի `name`-երն արդեն նույնն են։
- HTML-ը չի կարող ստուգել, որ երկու գաղտնաբառը համընկնում են, իսկ `minlength`-ը հեշտ է ջնջել DevTools-ով։ Բրաուզերի ստուգումը հարմարության համար է, ոչ պաշտպանության։ Կուղղվի JS (հարմարություն) և PHP (պաշտպանություն) բլոկներում։
- Մուգ թեման հետևում է միայն համակարգի կարգավորմանը։ Ձեռքով անջատիչը բոլոր էջերում պահպանելու համար պետք է JavaScript։
- `404.html`-ի հղումները հարաբերական են, ուստի աշխատում են միայն կայքի արմատի մակարդակի հասցեների համար։
