position-ի 16 գործնական օրինակ

Ամեն օրինակ իրական խնդիր է, որին հանդիպելու ես նախագծերում։ Կոդը՝ պատճենելու համար, կենդանի նախադիտումը՝ փորձարկելու։ Ամեն բլոկից հետո կա «փորձիր» առաջադրանք։

Ուղեկցում է Դաս 15-ին 16 օրինակ · 5 խումբ Ախտորոշիչ վարժություններ

00Ինչպես օգտվել

Ամեն խումբ ունի կոդի բլոկներ և մեկ ընդհանուր կենդանի նախադիտում։ Առաջարկվող կարգը՝

  1. Կարդա կոդը և կանխագուշակիր արդյունքը
  2. Նայիր նախադիտումը
  3. Կատարիր «փորձիր» առաջադրանքը — սովորաբար դա ինչ-որ բան ջնջելն է
  4. Վերականգնիր և անցիր հաջորդին
Հիմնական բանաձևը

Գրեթե բոլոր օրինակները հետևում են նույն օրինաչափությանը՝

Ծնող՝ position: relative
Երեխա՝ position: absolute + top/right/bottom/left

Երբ սա մտապահես, մնացածը մանրամասներ են։

01Քարտի վրա

1. Զեղչի պիտակ

ամենատարածվածը
.card  { position: relative; }

.badge {
    position: absolute;
    top: 10px;
    left: 10px;
    z-index: 2;
}

2. Փակելու կոճակ անկյունում

ծանուցում, մոդալ, պիտակ
.notice { position: relative; padding-right: 44px; }

.notice__close {
    position: absolute;
    top: 8px;
    right: 8px;
    width: 28px;
    height: 28px;
}
padding-right-ը կարևոր է

absolute կոճակը դուրս է հոսքից — տեքստը չգիտի, որ այն այնտեղ է, և կանցնի դրա տակով։

Ուստի ծնողին տալիս ենք padding-right՝ կոճակի լայնության չափ։ Նույն տրամաբանությունը՝ վերևի կամ ներքևի կոճակների դեպքում։

3. Գրադիենտ ծածկույթ նկարի ներքևում

տեքստը ընթեռնելի է ցանկացած նկարի վրա
.photo { position: relative; }

.photo__caption {
    position: absolute;
    left: 0;
    right: 0;
    bottom: 0;
    padding: 30px 14px 12px;
    color: #fff;
    background: linear-gradient(
        to top,
        rgba(0,0,0,.85),
        rgba(0,0,0,0)
    );
}
Ինչու գրադիենտ, ոչ պինդ գույն

Պինդ սև շերտը կտրում է նկարը կոպիտ գծով։ Գրադիենտը սահուն անցնում է թափանցիկի, և տեքստը ընթեռնելի է՝ առանց նկարը փչացնելու։

Սա այն մանրուքն է, որ տարբերում է սիրողական աշխատանքը պրոֆեսիոնալից։

4. Անկյունագծային ժապավեն

absolute + transform: rotate
.card { position: relative; overflow: hidden; }

.ribbon {
    position: absolute;
    top: 14px;
    right: -34px;        /* դուրս է գալիս, overflow-ը կտրում է */
    transform: rotate(45deg);
    width: 130px;
    text-align: center;
    background: #c62828;
    color: #fff;
    padding: 4px 0;
}
Չորս օրինակ մեկ նախադիտումում
Փորձիր

1. Ջնջիր .card { position: relative }-ը — ո՞ւր գնացին պիտակն ու ժապավենը։
2. Ջնջիր .notice { padding-right: 48px }-ը և երկարացրու տեքստը։
3. Ջնջիր .card { overflow: hidden }-ը — ի՞նչ եղավ ժապավենի հետ։
4. Գրադիենտը փոխիր պինդ գույնի՝ background: rgba(0,0,0,.85)։

02Պատկերակներ և ավատարներ

5. Ծանուցումների հաշվիչ

զամբյուղի կարմիր շրջանակը
.icon-btn { position: relative; }

.counter {
    position: absolute;
    top: -6px;        /* բացասական՝ դուրս է գալիս */
    right: -6px;
    min-width: 20px;
    height: 20px;
    border-radius: 999px;
    background: #c62828;
    color: #fff;
    font-size: 11px;
    display: flex;
    align-items: center;
    justify-content: center;
}

6. Առցանց կարգավիճակի կետ

ավատարի անկյունում
.avatar { position: relative; width: 48px; }

.avatar__status {
    position: absolute;
    right: 1px;
    bottom: 1px;
    width: 13px;
    height: 13px;
    border-radius: 50%;
    background: #22c55e;
    border: 2px solid #fff;   /* բաժանում է ֆոնից */
}

7. Հուշում (tooltip)

հայտնվում է hover-ի ժամանակ
.tip { position: relative; }

.tip__text {
    position: absolute;
    bottom: calc(100% + 8px);   /* վերևում, 8px բացակով */
    left: 50%;
    transform: translateX(-50%);
    white-space: nowrap;
    opacity: 0;
    pointer-events: none;
    transition: opacity .15s;
}

.tip:hover .tip__text,
.tip:focus-within .tip__text { opacity: 1; }
calc(100% + 8px)

bottom: 100% նշանակում է «ծնողի ամբողջ բարձրության չափ վեր» — այսինքն՝ ուղիղ ծնողից վերև։ + 8px-ը ավելացնում է շնչառություն։

Նույն ձևով՝ top: calc(100% + 8px) — ուղիղ ծնողից ներքև։ Այս հնարքը հիմքն է dropdown-ների։

8. Dropdown մենյու

միայն CSS-ով
.dropdown { position: relative; }

.dropdown__menu {
    position: absolute;
    top: calc(100% + 6px);
    left: 0;
    z-index: 10;
    min-width: 180px;
    background: #fff;
    border-radius: 8px;
    box-shadow: 0 6px 20px rgba(0,0,0,.15);
    display: none;
}

.dropdown:hover .dropdown__menu,
.dropdown:focus-within .dropdown__menu { display: block; }
:focus-within — մի՛ մոռացիր

:hover-ը աշխատում է միայն մկնիկով։ Ստեղնաշարով նավարկողը երբեք չի բացի մենյուն։

:focus-within-ը գործում է, երբ ծնողի ներսում որևէ բան ֆոկուս ունի։ Երկու սելեկտորը միասին ծածկում են երկու դեպքն էլ։

Սավառնիր և սեղմիր Tab
Փորձիր

1. Փոխիր .counter { top: -6px }-ը 0-ի։
2. Ջնջիր .avatar__status { border: 2px solid #fff }-ը։
3. Ջնջիր .tip__text { transform: translateX(-50%) }-ը։
4. Ջնջիր :focus-within սելեկտորը և փորձիր Tab-ով բացել dropdown-ը։

03Կպչուն տարրեր

9. Կպչուն header

չորս պարտադիր հատկություն
header {
    position: sticky;
    top: 0;                 /* առանց սրա չի կպչի */
    z-index: 100;            /* որ լինի վերևում */
    background: #fff;        /* որ տակից չերևա */
}

10. Կպչուն կողքի բլոկ

պատվերի ամփոփում, բովանդակության ցանկ
.sidebar {
    position: sticky;
    top: 80px;              /* header-ի բարձրության չափ */
    align-self: start;      /* ⭐ flex-ում պարտադիր */
}
align-self: start — կրիտիկական

Flex-կոնտեյներում երեխաները լռելյայն stretch են (Դաս 11) — այսինքն ձգվում են ամբողջ բարձրությամբ։ Իսկ sticky-ն կպչում է միայն ծնողի սահմաններում։

Եթե բլոկն արդեն ամբողջ բարձրությամբ է, կպչելու տեղ չկա — և sticky-ն լուռ չի աշխատում։

align-self: start-ը թողնում է բլոկին իր բնական բարձրությունը, և ամեն ինչ սկսում է աշխատել։ Սա այն սխալներից է, որ ժամեր է խլում։

11. Կպչուն աղյուսակի վերնագիր

երկար աղյուսակների համար
.table-wrap {
    max-height: 300px;
    overflow: auto;
}

thead th {
    position: sticky;
    top: 0;
    z-index: 1;
    background: #003459;      /* պարտադիր */
}
Ուշադրություն

position: sticky-ն դրվում է th-ի վրա, ոչ thead-ի։ Աղյուսակի բաժինները չեն աջակցում sticky-ին բոլոր բրաուզերներում։

Նաև՝ այստեղ overflow: auto-ն ծնողի վրա չի կոտրում sticky-ն, որովհետև հենց այդ ոլորվող տարածքի ներսում է կպչում։

Ոլորիր և՛ էջը, և՛ աղյուսակի ներսը
Փորձիր

1. Ջնջիր .sidebar { align-self: start }-ը և .layout { align-items: flex-start }-ը։ Ոլորիր։
2. Ջնջիր thead th { background }-ը և ոլորիր աղյուսակը։
3. Փոխիր .sidebar { top: 60px }-ը 0-ի — բլոկը կմտնի header-ի տակ։
4. Ավելացրու .layout { overflow: hidden } — sticky-ն կկոտրվի։

04Ծածկույթներ և մոդալներ

12. Մոդալ պատուհան

fixed + inset + flex
.backdrop {
    position: fixed;
    inset: 0;
    z-index: 1000;
    background: rgba(0,0,0,.6);

    display: flex;
    justify-content: center;
    align-items: center;
    padding: 20px;              /* որ հեռախոսում չկպչի եզրերին */
}

.modal {
    position: relative;         /* խարիսխ փակելու կոճակի համար */
    background: #fff;
    border-radius: 12px;
    padding: 24px;
    max-width: 440px;
    width: 100%;
    max-height: 90vh;
    overflow-y: auto;          /* երկար բովանդակության համար */
}

13. Ամբողջ էկրանով hero

նկար + մուգ շերտ + կենտրոնացված տեքստ
.hero {
    position: relative;
    min-height: 70vh;
    display: flex;
    align-items: center;
    background-image: url(...);
    background-size: cover;
}

.hero::before {
    content: "";
    position: absolute;
    inset: 0;
    background: rgba(37,50,55,.7);
}

.hero__content {
    position: relative;    /* ⭐ որ լինի ::before-ից վերև */
    z-index: 1;
}
Ինչու է պետք .hero__content { position: relative }

::before-ը absolute է և գծվում է սովորական բովանդակությունից վերև։ Առանց position: relative-ի տեքստը կհայտնվի մուգ շերտի տակ և կդառնա անտեսանելի։

Այս մեկ տողը ամենահաճախ մոռացվողն է hero-ներ սարքելիս։

14. «Վեր» կոճակ

fixed անկյունում
.to-top {
    position: fixed;
    right: 20px;
    bottom: 20px;
    z-index: 50;
}
Մոդալը միշտ բաց է՝ ուսումնական նպատակով
Փորձիր

1. Ջնջիր .hero__content { position: relative }-ը։ Ո՞ւր գնաց տեքստը։
2. Ջնջիր .backdrop { padding: 20px }-ը և նեղացրու նախադիտումը։
3. Փոխիր .modal { position: relative }-ը static-ի — ո՞ւր փախավ ✕-ը։
4. Փոխիր .backdrop { z-index: 1000 }-ը 10-ի և .to-top-ինը՝ 50։ Ո՞րն է վերևում։

05Դեկորատիվ տարրեր

15. Գիծ վերնագրի հետևում

z-index: -1
.divider {
    position: relative;
    text-align: center;
}

.divider::before {
    content: "";
    position: absolute;
    top: 50%;
    left: 0;
    right: 0;
    height: 1px;
    background: #ddd;
    z-index: -1;              /* հետևում */
}

.divider span {
    background: #f5f5f5;      /* էջի ֆոնի գույնը */
    padding: 0 14px;
}

16. Ժամանակագրություն

ուղղահայաց գիծ կետերի հետևում
.timeline { position: relative; padding-left: 28px; }

/* Գիծը՝ ամբողջ բարձրությամբ */
.timeline::before {
    content: "";
    position: absolute;
    left: 7px;
    top: 6px;
    bottom: 6px;
    width: 2px;
    background: #dfe6ea;
}

/* Կետը՝ ամեն տարրի համար */
.timeline li { position: relative; }

.timeline li::before {
    content: "";
    position: absolute;
    left: -28px;
    top: 6px;
    width: 16px;
    height: 16px;
    border-radius: 50%;
    background: #003459;
    border: 3px solid #f5f5f5;
}
::before-ը նույնպես կարող է լինել absolute
Փորձիր

1. Ջնջիր .divider::before { z-index: -1 }-ը։
2. Փոխիր .divider span { background }-ը transparent-ի։
3. Ջնջիր .timeline li { position: relative }-ը — ո՞ւր գնացին կետերը։
4. Փոխիր .timeline::before { bottom: 8px }-ը 0-ի։

06Ախտորոշիչ վարժություններ

Չորս կոտրված օրինակ։ Ամեն մեկում մեկ սխալ կա։ Գտիր և ուղղիր՝ առանց նայելու պատասխանները։

Չորս սխալ · ուղղիր CSS ներդիրում
Պատասխանները — նայիր միայն փորձելուց հետո

1. .card-1 { position: relative } — չկար խարիսխ։
2. .header-2 { top: 0 } — sticky-ն չգիտեր՝ որտեղ կպչի։
3. .header-3 { background: #fff } — թափանցիկ էր։
4. .hero-4__content { position: relative; z-index: 1 } — ::before-ը վերևում էր։

07Ամփոփում

#ՕրինակԲանաձևը
1Զեղչի պիտակrelative + absolute top/left
2Փակելու կոճակ+ ծնողին padding-right
3Գրադիենտ ծածկույթabsolute left/right/bottom: 0

Հինգ ամենահաճախ սխալը

  1. Ծնողը չունի position: relative → երեխան փախչում է էջի անկյուն
  2. sticky-ն առանց top-ի → չի կպչում
  3. sticky-ն առանց background-ի → տակից երևում է տեքստը
  4. sticky flex-ի ներսում առանց align-self: start → կպչելու տեղ չկա
  5. ::before-ը ծածկում է բովանդակությունը → պետք է relative + z-index: 1
