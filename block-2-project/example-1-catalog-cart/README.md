# ՏեխնոՄարկետ · Առաջադրանք 1

Բլոկ 1-ի 9 էջանոց խանութը JavaScript-ով՝ կատալոգ և զամբյուղ (JS Դաս 15–16)։

## Հնարավորություններ
- Կատալոգ՝ ֆիլտր կատեգորիայով, ապրանքանիշով, գնով և առկայությամբ, որոնում debounce-ով, դասավորում, էջավորում
- `catalog.html?cat=laptops`՝ header-ի ենթամենյուից
- «Գնել» ցանկացած էջում, «Ավելացվեց զամբյուղ» մոդալ (խաչիկ, ֆոն, Escape)
- Զամբյուղ localStorage-ում, քանակ 1–10, հեռացում, դատարկում, ամփոփում զեղչով և առաքմամբ
- Header-ի զամբյուղի թիվը բոլոր էջերում

## Կառուցվածք
Սովորական սկրիպտներ `defer`-ով, ուստի կայքը աշխատում է նաև `file://`-ով։
`data.js → storage.js → utils.js → cart.js → էջի սկրիպտը`

## Հայտնի սահմանափակումներ
- Ապրանքի էջը դեռ ստատիկ է (Նոութբուք Pro 14)։ Կդառնա դինամիկ Առաջադրանք 2-ում։
- Պատվերի, մուտքի և գրանցման ֆորմաները դեռ չեն ստուգվում JS-ով։ Առաջադրանք 2։
- Բոլոր ֆայլերի փոփոխականները գլոբալ են։ Մոդուլներ՝ Առաջադրանք 2 (JS Դաս 18)։
- Ֆիլտրերի ընտրությունը չի պահվում թարմացնելիս։
