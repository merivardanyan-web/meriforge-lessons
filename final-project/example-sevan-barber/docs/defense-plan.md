# Պաշտպանության պլան · 10–12 րոպե

> Փորձել եմ ժամացույցով երկու անգամ․ առաջինը՝ 15 րոպե (ցուցադրությունը շատ երկար էր), երկրորդը՝ 11

## 1. Ցուցադրություն · 3 րոպե

Բաց ներդիրներ՝ հյուր, demo, Արամ (Chrome-ի երեք պրոֆիլ, որ սեսիաները չխառնվեն)

1. Հյուր․ գլխավոր → «Սանրվածք + մորուք» → օրը փոխում եմ (առանց վերբեռնման) → «Մուտք գործիր»
2. Demo․ ընտրում եմ ժամ, նշում՝ «կարճ կողքերից» → «Ամրագրված է» → «Իմ ամրագրումները» → չեղարկում եմ մեկը (toast)
3. Արամ․ «Օրվա ցուցակ» → տեսնում է demo-ի նշումը → «Կատարված»

## 2. Սխեմա · 2 րոպե

`docs/schema.md`-ի գծապատկերը։ Մեկ որոշում՝ բոլոր երեք FK-ն `restrict` են, որովհետև ամրագրումը պատմություն է,
և ինչու `services`-ը soft delete է, իսկ `time_slots`-ը՝ ոչ։

## 3. Դժվար ֆունկցիա ⭐ · 3 րոպե

1. Միգրացիա․ `active_slot_id ... ->nullable()->unique()`։ Ինչու `nullable`
2. `BookingService::book()`․ `try { save() } catch (UniqueConstraintViolationException)`
3. Ապացույց․ HeidiSQL-ում `INSERT` նույն `active_slot_id`-ով → `Duplicate entry`
4. 3-ի սահմանը և `lockForUpdate()`․ ինչու այստեղ UNIQUE չի օգնի

## 4. Անվտանգություն · 2 րոպե — ցույց տալ, ոչ պատմել

```bash
# demo-ի cookie-ով, ուրիշի ամրագրում
curl -i -X PATCH https://…/bookings/12/cancel -H "X-CSRF-TOKEN: …" -H "Accept: application/json" -b "…"
# → 403 {"message":"Սա քո ամրագրումը չէ։"}
```

Ապա `BookingPolicy::cancel()`-ը՝ չորս ճյուղը։

## 5. Հարցեր · 2–3 րոպե

Պատրաստված պատասխաններ․

| Հարց | Կարճ պատասխան |
|---|---|
| Ինչ կլինի, եթե երկու հոգի սեղմեն միաժամանակ | Մեկը կանցնի, մյուսը կստանա «զբաղեցրեցին»․ UNIQUE, ոչ PHP-ի ստուգում |
| Քանի SQL հարցում է «Օրվա ցուցակը» | 8՝ անկախ այցերի քանակից (MySQL general log-ով ստուգած)․ `with(['user', 'service', 'slot.staff'])`, իսկ N+1-ի դեպքում `shouldBeStrict()`-ը կգցեր սխալ |
| Ինչու `Gate::inspect`, ոչ `authorize` | Պետք էր նույն պատճառը վերադարձնել JSON-ով (fetch) և flash-ով (առանց JS) |
| Ինչու `Booking`-ը չունի `$fillable` | Ոչ մի դաշտ չի գալիս ֆորմայից անփոփոխ․ գինը՝ ծառայությունից, user_id՝ սեսիայից |
| Ինչ կփոխեիր | 60 րոպեից երկար ծառայություններ՝ «մեկ ամրագրում = մեկ պատուհան»-ը սահմանափակում է։ Կանեի `booking_slot` կապող աղյուսակ |
