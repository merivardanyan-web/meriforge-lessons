# config/app.php — մեկ փոփոխություն

```php
'timezone' => 'Asia/Yerevan',
```

Laravel-ի լռելյայնը `UTC` է։ Վարսավիրանոցի համար դա սխալ է․ «10:00»-ի ժամը բազայում կպահվեր
որպես 10:00 UTC, այսինքն՝ 14:00 Երևանում, իսկ «այսօր»-ը կսկսվեր 04:00-ին։
Ամեն ամսաթվով նախագծում սա առաջին օրը ստուգելու բան է։
