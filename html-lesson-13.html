Դիզայնից դեպի կոդ

Մինչ այժմ սովորում էիր գործիքներ։ Այսօր սովորում ես աշխատել․ բացել դիզայնի մակետը, չափել, հանել արժեքները, կառուցել main.css-ը — և միայն դրանից հետո գրել HTML։

Նախապայման՝ Դաս 06–12 Բլոկ 1 · Աշխատանքային հոսք Ջրբաժան դասընթացում

01Ինչո՞ւ հակառակ հերթականությամբ

Սովորական մոտեցումն է՝ գրել HTML-ը, հետո ոճավորել այն։ Մենք անում ենք հակառակը։ Ահա թե ինչու։

❌ HTML-ը առաջ
/* Գրում ես HTML-ը, հետո սկսում ոճավորել.
   «Այս վերնագիրը մի քիչ մեծ է... 42px? Ոչ, 38... »
   «Այս բացակը... 22px?  Կողքինը 18px արեցի, չեմ հիշում ինչու»
   «Այս գույնը մոտավորապես նույնն է, ինչ վերևինը»

   Արդյունքում՝ 14 տարբեր տառաչափ,
   9 երանգ մոխրագույնի, և ոչ մի համակարգ։  */
Երբ CSS-ն առաջ էԻնչ ես շահում
Չափում ես մեկ անգամԲոլոր արժեքները մեկ տեղում են
Տեսնում ես կրկնությունները3 քարտ նույն ոճով = մեկ դաս
Համակարգ ես կառուցում4 տառաչափ, ոչ 14
HTML-ը դառնում է մաքուրՊարզապես կիրառում ես պատրաստի դասերը
Փոփոխությունը հեշտ էԴիզայներն ասաց «պատերը 80px» → մեկ տող
Համեմատություն

Շինարարը նախ նայում է չերտեզը և պատրաստում նյութերը՝ չափելով ամեն ինչ։ Հետո է սկսում կառուցել։

Ոչ թե դնում է աղյուսը և ասում՝ «հիմա տեսնենք՝ ինչ ցեմենտ է պետք»։

02Ի՞նչ չափել

Վեց կատեգորիա։ Անցիր դրանք հերթականությամբ՝ ամեն նոր մակետի դեպքում։

#ԿատեգորիաԿոնկրետ ի՞նչ
1ԳույներՖոներ, տեքստեր, կոճակներ, եզրագծեր, ստվերներ
2ՏիպոգրաֆիաՏառատեսակ, 3–5 չափ, հաստություններ, line-height
3ՊատերըՀեռավորությունը էկրանի եզրից մինչև բովանդակություն
4Ուղղահայաց ռիթմԲաժինների բարձրություն, վերնագրի և տեքստի միջև
5Սյուների բացակներՔարտերի միջև հեռավորությունը
6ԿոմպոնենտներԿոճակի padding, կլորացումներ, քարտի ներսի բացակներ
Ամենակարևոր հմտությունը՝ նկատել համակարգը

Չափում ես բացակները և ստանում՝ 20, 40, 19, 60, 21, 40, 80։

Սա չի նշանակում, որ պետք է յոթ տարբեր արժեք։ Դիզայներն օգտագործել է սանդղակ՝ 20, 40, 60, 80, իսկ 19-ը և 21-ը շեղումներ են՝ մեկ պիքսելի ճշգրտության պատճառով։

Կլորացրու մոտակա արժեքին։ Համակարգը կարևոր է, ոչ պիքսելային ճշգրտությունը։

Սովորական սանդղակներ

4-ի բազմապատիկ՝ 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80
10-ի բազմապատիկ՝ 10, 20, 30, 40, 50, 60, 80, 100

Եթե չափումներդ մոտ են այս թվերին — ուրեմն գտար սանդղակը։

03Մակետը

Ահա նմուշային մակետ չափումների նշումներով։ Իրական աշխատանքում դու ինքդ ես չափում Figma-ում՝ սեղմելով էլեմենտի վրա և պահելով Alt-ը՝ հեռավորությունները տեսնելու համար։

Figma-ում չափելու ձևը

1. Սեղմիր էլեմենտի վրա — աջ վահանակում կերևա չափը և դիրքը։
2. Պահիր Alt և սավառնիր ուրիշ էլեմենտի վրայով — կերևան հեռավորությունները։
3. Տեքստի համար՝ աջ վահանակի Typography բաժինը՝ չափ, հաստություն, line-height։
4. Գույների համար՝ Fill բաժինը՝ սեղմիր և պատճենիր HEX-ը։

Ոչ ոք չի նկատի 2px տարբերությունը։ Բայց բոլորը կնկատեն, եթե մի տեղ 22 լինի, մյուսում՝ 19, երրորդում՝ 24։

05main.css-ի կառուցում

Հիմա աղյուսակը վերածում ենք կոդի։ Խիստ հերթականությամբ։

css/main.css
/* ============ 1. ԴԻԶԱՅՆԻ ԱՐԺԵՔՆԵՐԸ ============ */
:root {
    /* Գույներ */
    --dark:      #253237;
    --secondary: #003459;
    --light:     #9db4c0;
    --bg:        #f5f5f5;
    --text:      #1a1a1a;
    --muted:     #6b6b6b;
    --on-dark:   #ffffff;

    /* Կմախքի չափերը */
    --wall: 60px;
    --gap:  10px;
}

/* ============ 2. ԲԱԶԱ ============ */
body {
    font-family: "Noto Sans Armenian", system-ui, sans-serif;
    font-size: 0.9375rem;    /* 15px */
    line-height: 1.6;
    color: var(--text);
    background: var(--bg);
}

/* ============ 3. ԿՄԱԽՔԸ ============ */
section { padding: 40px 0; }
.row    { padding: 0 calc(var(--wall) - var(--gap)); }
.col    { padding: var(--gap); }

/* ============ 4. ՏԻՊՈԳՐԱՖԻԱ ============ */
h1, .title-1 { font-size: 2.125rem; font-weight: 700; line-height: 1.2; }
h2, .title-2 { font-size: 1.5rem;   font-weight: 700; line-height: 1.3; }
h3, .title-3 { font-size: 1.125rem; font-weight: 700; }
h4, .title-4 { font-size: 0.875rem; font-weight: 700; }

.text-muted { color: var(--muted); }
.text-small { font-size: 0.75rem; }

/* ============ 5. ՀԵՌԱՎՈՐՈՒԹՅՈՒՆՆԵՐԻ ՍԱՆԴՂԱԿ ============ */
.gap-10 { gap: 10px; }
.gap-20 { gap: 20px; }
.gap-30 { gap: 30px; }

.mb-10 { margin-bottom: 10px; }
.mb-20 { margin-bottom: 20px; }
.mb-30 { margin-bottom: 30px; }

/* ============ 6. ՖՈՆԵՐ ============ */
.bg-dark      { background: var(--dark);      color: var(--on-dark); }
.bg-secondary { background: var(--secondary); color: var(--on-dark); }
.bg-light     { background: var(--light);     color: var(--text); }

/* ============ 7. ԿՈՄՊՈՆԵՆՏՆԵՐ ============ */
.btn {
    padding: 12px 24px;
    border-radius: 6px;
    border: 1px solid transparent;
    font-weight: 700;
    background: var(--secondary);
    color: var(--on-dark);
}

.btn:hover, .btn:focus-visible {
    background: var(--on-dark);
    color: var(--secondary);
    border-color: var(--secondary);
}

/* ============ 8. ԲԱԺԻՆՆԵՐ ============ */
#hero {
    background: var(--dark);
    color: var(--on-dark);
    padding: 50px 0;
}

#products .wrapper {
    background: #ffffff;
    border-radius: 12px;
    overflow: hidden;
}

#products .card__body { padding: 16px; }
#products .price      { color: var(--secondary); font-weight: 700; }
calc(--wall - --gap) — խելացի հնարք

Մակետում պատերը 60px են։ Բայց .col-ն ունի 10px padding, որը գումարվում է պատին։

calc(60px - 10px) = 50px — և բովանդակությունը ստացվում է ուղիղ 60px հեռու եզրից։ Իսկ երբ դիզայներն ասի «պատերը 80px», փոխում ես մեկ փոփոխական։

06Եվ միայն հիմա՝ HTML

Ուշադրություն դարձրու՝ HTML-ը գրվում է արագ և առանց մտածելու։ Բոլոր որոշումներն արդեն ընդունված են։

Քանի՞ նոր CSS կանոն գրեցինք HTML-ի ընթացքում

Զրո։ Բոլոր դասերն արդեն գոյություն ունեին։ Դա նշանակում է, որ համակարգը ճիշտ է կառուցված։

Եթե HTML գրելիս ստիպված ես անընդհատ վերադառնալ CSS-ին և նոր դասեր ավելացնել — ուրեմն մակետը լավ չես չափել։

07Utility-դասեր vs BEM

Մենք օգտագործում ենք utility-դասեր՝ .w-33, .mb-20, .text-muted։ Կա նաև այլ մոտեցում։ Երկուսն էլ արժե իմանալ։

Utility — մեր մոտեցումը
<div class="col w-33">
    <article class="wrapper">
        <h3 class="title-4 mb-10">...</h3>
        <p class="text-small text-muted">...</p>
    </article>
</div>
BEM — կոմպոնենտային մոտեցում
<article class="product-card">
    <h3 class="product-card__title">...</h3>
    <p class="product-card__specs">...</p>
    <p class="product-card__price product-card__price--sale">...</p>
</article>
UtilityBEM
Արագություն✅ Շատ արագԴանդաղ — ամեն բանի անուն
CSS-ի ծավալ✅ Չի աճումԱճում է ամեն կոմպոնենտի հետ
HTML-ի ընթեռնելիությունԵրկար class-եր✅ Մաքուր
Փոփոխություն մեկ տեղումՊիտի ուղղես ամեն HTML✅ Մեկ CSS կանոն
ԱդապտիվությունԴասերը բազմապատկվում են✅ Media query-ն մեկ տեղում
Սովորելու հեշտություն✅ Անմիջապես տեսնում ես արդյունքըՊիտի մտածես անունների մասին
Ինչո՞ւ մենք ընտրում ենք utility-ն

1. Սովորելու փուլում կապը HTML-ի և արդյունքի միջև ուղիղ է․ գրում ես w-33 և տեսնում ես երրորդը։
2. Համակարգը ստիպում է օգտագործել սանդղակը — չկա .mb-17։
3. Tailwind-ը, որն այսօր ամենատարածված գործիքն է, հենց այս գաղափարն է։ Երբ հանդիպես դրան, արդեն կհասկանաս։

Բայց իմացիր սահմանը

Երբ նույն կոմպոնենտը կրկնվում է 20 տեղում և պիտի փոխես դրա տեսքը, utility-ի դեպքում ուղղում ես 20 HTML ֆայլ։ BEM-ի դեպքում՝ մեկ CSS կանոն։

Իրական նախագծերում հաճախ օգտագործում են խառը մոտեցում․ կմախքը և բացակները՝ utility-ով, կրկնվող կոմպոնենտները՝ սեփական դասով։ Մենք հենց այդպես ենք անում՝ .btn-ը և .card__body-ն կոմպոնենտային դասեր են։

08.row-ի երկու տարբերակը

Ա. Ֆիքսված պատեր — մեր տարբերակը
.row {
    display: flex;
    padding: 0 50px;
}
Բ. Կենտրոնացված կոնտեյներ
.row {
    display: flex;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 20px;
}

Օգտագործում ենք Ա տարբերակը, որովհետև այն ուղիղ համապատասխանում է մակետին և ավելի պարզ է սովորելու համար։

Գինը՝ 14-րդ դասին պիտի ավելացնենք media query՝ հեռախոսում պատերը 60px-ից 20px դարձնելու համար։ Մեկ տող, բայց պիտի հիշես այն։

Իրական նախագծերում երկուսն էլ հանդիպում են։ Հիմա գիտես ընտրության պատճառները։

09Խաղահրապարակ

Մակետը՝ կոդում։ Փոխիր :root-ի արժեքները և տես, ինչպես է փոխվում ամեն ինչ միանգամից։

Փոխիր --wall-ը 40px-ից 80px-ի
Փորձիր

1. Փոխիր --wall-ը 80px-ի։ Քանի՞ տեղում պիտի ուղղեիր, եթե փոփոխական չլիներ։
2. Փոխիր --secondary-ն #7b1fa2-ի։
3. Փոխիր --gap-ը 20px-ի — բացակները կմեծանան, պատերը կմնան նույնը։
4. HTML ներդիրում կա մեկ սխալ՝ երրորդ քարտի փակող թեգերը խառնված են։ Գտիր և ուղղիր։

10Տնային աշխատանք

Մինի-նախագիծ

Այս տնայինի գլխավոր մասը՝ «Նախագծերի էջ մակետից», քայլ առ քայլ, starter ֆայլերով և պատրաստի օրինակով։ Ներքևի ցուցակի մնացած կետերը առանձին վարժություններ են։

  1. Վերցրու ցանկացած կայք, որը քեզ դուր է գալիս։ Չափիր DevTools-ով և լրացրու չափումների աղյուսակը՝ վեց կատեգորիայով։
  2. Գտիր դրա հեռավորությունների սանդղակը։ Արդյո՞ք դա 4-ի կամ 10-ի բազմապատիկ է։
  3. Հաշվիր՝ քանի՞ տարբեր տառաչափ է օգտագործվում։ Եթե 6-ից շատ է, առաջարկիր, թե ինչպես կկրճատեիր։
  4. Կառուցիր :root բլոկ այդ կայքի գույներով։
  5. Այս դասի մակետի հիման վրա գրիր ամբողջ main.css-ը՝ ութ բաժնով, ինչպես 05-րդ բաժնում։
  6. Եվ միայն դրանից հետո գրիր HTML-ը։ Հաշվիր՝ քանի՞ նոր CSS կանոն ստիպված եղար ավելացնել։
  7. Փոխիր --wall-ը և --gap-ը։ Համոզվիր, որ ամեն ինչ հարմարվում է ինքնաբերաբար։
  8. Վերաշարադրիր ապրանքի քարտը BEM-ով։ Համեմատիր երկու տարբերակի HTML-ը և CSS-ը։ Ո՞րն է քեզ ավելի հարմար և ինչու։
  9. Փորձիր .row-ի Բ տարբերակը (max-width: 1200px; margin: 0 auto)։ Համեմատիր լայն էկրանին։
  10. Գտիր իրական մակետ (Dribbble, Behance) և կրկնիր այն մեր համակարգով։ Նախ չափումների աղյուսակը, հետո CSS-ը, հետո HTML-ը։

11Հիշելու թերթիկ

Աշխատանքային հոսքը

1. Բացել մակետը 2. Չափել՝ վեց կատեգորիա 3. Գտնել սանդղակը (կլորացնել) 4. Լրացնել չափումների աղյուսակը 5. Գրել main.css-ը՝ ութ բաժնով 6. Գրել HTML-ը 7. Ստուգել՝ քանի՞ նոր կանոն ավելացավ

main.css-ի ութ բաժինը

Ստուգաթերթ

  • Բոլոր գույները :root-ում են
  • Հեռավորությունները սանդղակի վրա են (4-ի կամ 10-ի բազմապատիկ)
  • Տառաչափերը 5-ից քիչ են
  • Պատերը calc()-ով են՝ --gap-ը հաշվի առնված
  • HTML գրելիս նոր CSS կանոն չի պահանջվել
  • Ամեն ֆոն ունի իր տեքստի գույնը
  • Կոնտրաստները ստուգված են

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչու CSS-ը առաջ
  • Գիտե՞մ վեց կատեգորիան
  • Կարո՞ղ եմ գտնել սանդղակը խառը չափումներից
  • Հասկանո՞ւմ եմ calc(--wall - --gap)-ը
  • Կարո՞ղ եմ բացատրել utility-ի և BEM-ի տարբերությունը
Հաջորդ դասին

Ադապտիվություն։ Media queries, mobile-first մոտեցում, և ինչպես մեր .w-* համակարգը դարձնել ճկուն։ Այնտեղ վերջապես կլուծենք այն խնդիրը, որ 60px պատերը հեռախոսում շատ են։
