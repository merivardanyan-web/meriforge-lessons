Կառուցվածք և Flexbox II

Ինչպե՞ս են սյուները բաժանում ազատ տեղը։ Ի՞նչ է gap-ը և ինչո՞ւ մեր համակարգը դրա փոխարեն օգտագործում է .col-ի padding-ը։ Այսօր ավարտում ենք Flexbox-ը։

Նախապայման՝ Դաս 10–11 Բլոկ 1 · Կառուցվածք Դասարանում՝ footer

00Ի՞նչ ենք սովորելու այսօր

  • Կմախքի կրկնում
  • flex-grow — ազատ տեղի բաշխում
  • flex-shrink և flex-basis
  • flex — կարճ գրառումը
  • gap և ինչո՞ւ մենք չենք օգտագործում այն .row-ում
  • flex-wrap — նախապատրաստում ադապտիվությանը
  • align-self և order

01Կրկնում

Երկու րոպե՝ առանց նայելու։ Գրիր հիշողությամբ։

լրացրու բացերը
/* global.css */
.row     { display: ______; }
.wrapper { height: ______; }

/* main.css */
section { padding: ______; }   /* ուղղահայաց */
.row    { padding: ______; }   /* հորիզոնական */
.col    { padding: ______; }   /* բացակներ */
Հարց Դաս 11-իցՊատասխան
Ո՞ր առանցքով է justify-content-ըԳլխավոր
Ի՞նչ է align-items-ի լռելյայնըstretch
Ինչո՞ւ են քարտերը հավասար բարձրությանstretch + .wrapper { height: 100% }
Ինչպե՞ս հրել կոճակը ներքևflex-direction: column + margin-top: auto

02flex-grow

Երբ սյուների լայնությունների գումարը 100%-ից պակաս է, մնում է ազատ տեղ։ flex-grow-ը որոշում է՝ ով և որքան կվերցնի այն։

հիմունքներ
.col       { flex-grow: 0; }   /* լռելյայն — չի աճում */
.col-grow  { flex-grow: 1; }   /* վերցնում է ազատ տեղը */
flex-grow: 0 բոլորին (լռելյայն) ┌────┐┌────┐┌────┐░░░░░░░░░░░░░░░ │ 1 ││ 2 ││ 3 │ ազատ տեղ └────┘└────┘└────┘░░░░░░░░░░░░░░░ flex-grow: 1 բոլորին ┌───────────┐┌───────────┐┌───────────┐ │ 1 ││ 2 ││ 3 │ └───────────┘└───────────┘└───────────┘ ազատ տեղը բաժանվեց հավասար flex-grow: 1 միայն երկրորդին ┌────┐┌───────────────────────┐┌────┐ │ 1 ││ 2 ││ 3 │ └────┘└───────────────────────┘└────┘
համամասնություններ
.a { flex-grow: 1; }
.b { flex-grow: 2; }   /* կրկնակի ավելի շատ ազատ տեղ */
.c { flex-grow: 1; }

/* Ազատ տեղը բաժանվում է 1:2:1 հարաբերությամբ */
Կարևոր նրբություն

flex-grow-ը բաժանում է միայն ազատ տեղը, ոչ ամբողջ լայնությունը։

Եթե .b-ի բովանդակությունն արդեն լայն է, flex-grow: 2-ը չի նշանակի, որ այն կլինի կրկնակի լայն .a-ից։ Այն պարզապես կստանա կրկնակի ավելի շատ ավելացում։

Ամենահաճախ պետք եկող օրինակը

Որոնման դաշտ կոճակով․ դաշտը պիտի ձգվի, կոճակը՝ մնա իր չափին։
input { flex-grow: 1 } և կոճակին ոչինչ։ Ամեն ինչ։

03flex-shrink և flex-basis

երբ տեղը չի հերիքում
.col    { flex-shrink: 1; }   /* լռելյայն — սեղմվում է */
.logo   { flex-shrink: 0; }   /* չսեղմվել ⭐ */
flex-shrink: 0 — շատ օգտակար

Լոգոն, պատկերակը, ավատարը չպիտի սեղմվեն, երբ կողքի տեքստը երկար է։ flex-shrink: 0-ը պաշտպանում է դրանք։

Առանց դրա նկարը կսեղմվի և կդառնա ձվաձև։

flex-basis — ելակետային չափը
.col { flex-basis: 300px; }   /* սկզբնական լայնությունը */
.col { flex-basis: 0; }       /* անտեսել բովանդակությունը */
.col { flex-basis: auto; }    /* լռելյայն — ըստ բովանդակության */

flex — կարճ գրառումը

երեքը մեկում
.col { flex: 1 1 auto; }
/*      ↑ ↑  ↑                    */
/*   grow shrink basis            */

/* Ամենատարածված գրառումները */
.equal  { flex: 1; }        /* = 1 1 0 — բոլորը հավասար ⭐ */
.fixed  { flex: none; }     /* = 0 0 auto — չի փոխվում */
.card   { flex: 1 1 300px; } /* ելակետը 300px, ճկուն */
flex: 1 — ամենակարևոր գրառումը

flex: 1 նշանակում է flex: 1 1 0 — բովանդակությունն անտեսվում է, և բոլոր տարրերը դառնում են ուղիղ հավասար։

Սա այլ բան է, քան flex-grow: 1 առանձին, որտեղ basis-ը մնում է auto, և երկար տեքստով սյունը կլինի ավելի լայն։

04gap

Բացակ flex-տարրերի միջև՝ մեկ հատկությամբ։

շատ պարզ
.menu {
    display: flex;
    gap: 20px;
}

/* Առանձին ուղղություններով */
.grid {
    gap: 20px 10px;    /* տողերի միջև, սյուների միջև */
    row-gap: 20px;
    column-gap: 10px;
}
Առանց gap-ի gap: 20px-ով [1][2][3] [1] [2] [3] ↑ ↑ միայն ՄԻՋԵՎ, եզրերին բացակ չկա

Ինչո՞ւ մեր .row-ը չի օգտագործում gap

Հարցն արդարացի է․ եթե gap-ը այսքան պարզ է, ինչու .col-ի padding-ը։

խնդիրը՝ gap + տոկոսներ
.row { display: flex; gap: 20px; }
.col { width: 33.3333%; }

/* 33.33% + 20px + 33.33% + 20px + 33.33% > 100%
   Երրորդ սյունը ընկնում է ներքև                    */
.col paddinggap
Աշխատում է % լայնությունների հետ✅❌
Բացակ միայն միջև❌ (նաև եզրերին)✅
ՊարզությունՊիտի հիշես շերտըՄեկ տող
Աշխատում է flex: 1-ի հետ✅✅
Ֆոն սյան վրա❌ չի կարելի✅ կարելի է
Երկուսն էլ ճիշտ են՝ տարբեր տեղերում

.col padding — էջի հիմնական ցանցի համար, որտեղ լայնությունները տոկոսներով են (.w-25, .w-33)։

gap — փոքր խմբերի համար՝ մենյու, կոճակների շարք, պիտակներ, քարտի ներսի տարրեր։ Այնտեղ տոկոսներ չկան, և gap-ը շատ ավելի մաքուր է։

Այսինքն՝ մեր համակարգում օգտագործվում են երկուսն էլ՝ ամեն մեկն իր տեղում։

որտեղ gap-ը ճիշտ ընտրություն է
<!-- Մենյու -->
<ul class="flex align-center gap-20">...</ul>

<!-- Կոճակների խումբ -->
<div class="flex gap-10">
    <button class="btn">Պահպանել</button>
    <button class="btn btn-light">Չեղարկել</button>
</div>

<!-- Քարտի ներսում՝ գին և կոճակ -->
<div class="flex justify-between align-center gap-10">
    <span>450 000 ֏</span>
    <a href="#" class="btn">Գնել</a>
</div>

05flex-wrap

Լռելյայն flex-տարրերը չեն տողադարձվում — դրանք սեղմվում են մինչև անհնարինություն։

թույլատրում ենք տողադարձը
.row {
    display: flex;
    flex-wrap: wrap;
}
nowrap (լռելյայն) wrap ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐ ┌────┐┌────┐┌────┐ │1││2││3││4││5││6│ │ 1 ││ 2 ││ 3 │ └─┘└─┘└─┘└─┘└─┘└─┘ └────┘└────┘└────┘ սեղմվում են և ┌────┐┌────┐┌────┐ դառնում անընթեռնելի │ 4 ││ 5 ││ 6 │ └────┘└────┘└────┘
Սա ադապտիվության հիմքն է

flex-wrap: wrap + .w-* դասեր = երբ սյուները չեն տեղավորվում, դրանք բնականորեն անցնում են հաջորդ տող։

14-րդ դասին կավելացնենք media queries, և հեռախոսում w-25-ը կդառնա w-100։ Բայց առանց flex-wrap-ի դա չէր աշխատի — սյուները պարզապես կսեղմվեին։

Առանց wrap-ի հեռախոսում

Չորս սյուն w-25-ով 375px էկրանին՝ ամեն մեկը 94px։ Տեքստն անընթեռնելի է, նկարները՝ մանրիկ։

Ուստի flex-wrap: wrap-ը մեր .row-ի համար գործնականում պարտադիր է։ Ավելացնում ենք global.css-ում որպես առանձին դաս, որ կիրառես գիտակցաբար։

ինքնաբերաբար հարմարվող ցանց
/* Բոնուս՝ առանց media queries */
.auto-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.auto-grid > * {
    flex: 1 1 250px;   /* ելակետը 250px, աճում է, տողադարձվում */
}

/* Լայն էկրանին՝ 4 սյուն, նեղում՝ 2, հեռախոսում՝ 1 */

06align-self և order

բացառություն մեկ տարրի համար
.row { align-items: center; }

.special { align-self: flex-start; }   /* միայն սա՝ վերևից */
order — տեսողական հերթականություն
.a { order: 2; }
.b { order: 1; }   /* կհայտնվի առաջինը */
.c { order: 3; }

/* Լռելյայն բոլորի order-ը 0 է */
order-ը հասանելիության թակարդ է

order-ը փոխում է միայն տեսողական հերթականությունը։ Tab-ի հերթականությունը և էկրանընթերցիչի ընթերցումը մնում են ըստ HTML-ի։

Արդյունքում ստեղնաշարով նավարկողը ֆոկուսը կտեսնի «ցատկելով»՝ երկրորդ, հետո առաջին, հետո երրորդ։ Դա շփոթեցնող է։

Կանոն՝ եթե տեսողական հերթականությունը կարևոր է, փոխիր HTML-ը։ order-ը՝ միայն զուտ դեկորատիվ դեպքերում։

Օրինաչափ կիրառություն

Հեռախոսում նկարը պիտի լինի տեքստից վեր, համակարգչում՝ աջ կողմում։ Այստեղ order-ը արդարացված է, քանի որ իմաստային հերթականությունը չի փոխվում — մենակ դասավորությունն է։

07Խաղահրապարակ

Համեմատիր 3-րդ և 4-րդ օրինակները
Փորձիր

1. Համեմատիր 3-րդ և 4-րդ բլոկները — դա flex-grow: 1-ի և flex: 1-ի ամբողջ տարբերությունն է։
2. Ջնջիր flex-shrink: 0-ը լոգոյից։
3. Փոխիր flex: 1 1 200px-ը 300px-ի։
4. Ջնջիր flex-grow: 1-ը որոնման դաշտից։

    flex-shrink: 0;      /* կոճակը չի սեղմվում ⭐ */
}

/* Ներքևի տողի բաժանարար */
footer .row:last-child .wrapper {
    border-top: 1px solid rgba(255,255,255,.15);
    padding-top: 20px;
}
min-width: 0 — կարևոր մանրուք

Flex-տարրերն ունեն թաքնված min-width: auto, ինչը թույլ չի տալիս դրանց սեղմվել իրենց բովանդակությունից ավելի փոքր։

Երկար placeholder-ով դաշտը կարող է «պայթեցնել» դասավորությունը։ min-width: 0-ը թույլ է տալիս այն սեղմվել նորմալ։

Սա այն սխալներից է, որ շատ դժվար է գտնել, եթե չգիտես դրա մասին։

09Տնային աշխատանք

Մինի-նախագիծ

Այս տնայինի գլխավոր մասը՝ «Flexbox II․ ֆորմաներ և footer», քայլ առ քայլ, starter ֆայլերով և պատրաստի օրինակով։ Ներքևի ցուցակի մնացած կետերը առանձին վարժություններ են։

  1. Ցուցադրիր flex-grow-ի ազդեցությունը՝ երեք բլոկ, grow-ը միայն մեկին։
  2. Ցուցադրիր համամասնությունը 1:2:1 և 1:3:1։
  3. Կողք կողքի համեմատիր flex-grow: 1-ը և flex: 1-ը՝ շատ տարբեր երկարության տեքստերով։ Բացատրիր տարբերությունը։
  4. Կառուցիր որոնման դաշտ կոճակով՝ flex-grow և flex-shrink: 0-ով։
  5. Ցուցադրիր flex-shrink: 0-ի կարևորությունը լոգոյի օրինակով՝ առաջ և հետո։
  6. Ցուցադրիր gap-ի և տոկոսային լայնությունների կոնֆլիկտը։ Ապա լուծիր՝ flex: 1-ի անցնելով։
  7. Կառուցիր ինքնահարմարվող ցանց՝ flex: 1 1 250px-ով, 6 տարրով։ Ստուգիր տարբեր լայնություններով։
  8. Ավելացրու flex-wrap: wrap Դաս 10-ի «Մեր թիմը» բաժնին։ Նեղացրու պատուհանը և նկարագրիր վարքագիծը։
  9. Կառուցիր footer դասարանական օրինակի պես։ Ստուգիր Tab-ով և նեղ էկրանով։
  10. Ցուցադրիր order-ի հասանելիության խնդիրը․ երեք հղում, order-ով փոխված հերթականությամբ։ Անցիր Tab-ով և նկարագրիր, ինչ ես տեսնում։

gap-ի արժեքները դիզայնի մաս են — ամեն նախագծում իր սանդղակն է։ Իսկ .flex-wrap-ը վարքագիծ է, որը չի փոխվում։

Նույն տրամաբանությամբ են բաժանված .row { display: flex }-ը և .row { padding: 0 50px }-ը։

Ստուգաթերթ

  • Լոգոները և պատկերակներն ունեն flex-shrink: 0
  • Ձգվող դաշտերն ունեն min-width: 0
  • .row-երն ունեն flex-wrap, եթե սյուները շատ են
  • gap-ը չի օգտագործվում տոկոսային լայնությունների հետ
  • order-ը չի կոտրում Tab-ի հերթականությունը

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել flex: 1-ի և flex-grow: 1-ի տարբերությունը
  • Գիտե՞մ, ինչու gap-ը կոնֆլիկտում է տոկոսների հետ
  • Հասկանո՞ւմ եմ, ինչու է պետք min-width: 0
  • Գիտե՞մ, ինչու է order-ը վտանգավոր
Հաջորդ դասին — ջրբաժան

Կառուցվածքի երեք դասն ավարտված է։ Դաս 13-ը լինելու է շրջադարձային․ կսովորենք դիզայնի մակետը կարդալ — չափել հեռավորությունները, հանել գույներն ու տառաչափերը, կառուցել main.css-ը, և միայն դրանից հետո գրել HTML։

Այնտեղ նաև կհամեմատենք երկու մոտեցում՝ utility-դասեր vs BEM, և կհասկանանք, թե ինչու ենք ընտրում այս ձևը։
