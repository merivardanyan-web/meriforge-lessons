Տնային աշխատանք · HTML Դաս 06 · մինի-նախագիծ

Առաջին ոճերը

Կայքը ստանում է global.css և main.css։ Գործնականում ես կիրառում սելեկտորները, համակցությունները, վիճակները, կասկադը և ժառանգումը։

Ժամանակ՝ ~1.5 ժամ Սկսիր Դաս 05-ի արդյունքից Արդյունք՝ css/global.css + css/main.css
Միայն անցածը

Օգտագործիր միայն Դաս 01–06-ը։ Գույները HEX-ով, տառաչափերը px-ով․ :root-ի փոփոխականները, Google Fonts-ը և rem-ը Դաս 07-ում են։ Box model-ը (Դաս 08) և display-ը (Դաս 09) դեռ չենք անցել, ուստի մենյուն մնում է ուղղահայաց։

00Ինչ պետք է ստացվի

Կայքը ստանում է առաջին ոճերը՝ գույներ, տառաչափեր, աղյուսակների եզրագծեր և hover/focus վիճակներ։ Reset-ից հետո բրաուզերի բացակները անհետանում են․ մենք մի քանի ժամանակավոր margin-bottom ենք դնում, իսկ իսկական բացակները՝ Դաս 08-ում։ Մենյուն դեռ ուղղահայաց է․ հորիզոնականը՝ Դաս 09-ում։

01Ինչ ես ստանում

starter/ └── content.md ← որ class-ը որտեղ դնել, գույներ և տառաչափեր

Սկսիր Դաս 05-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 05-ի օրինակը։

02Քայլեր

Քայլ 1 · Երկու ֆայլ, ճիշտ հերթականությամբ

Դաս 05-ում head-ում արդեն միացրել ենք css/global.css-ը և css/main.css-ը։ Հերթականությունը կարևոր է․ նախ global, հետո main։ Երբ երկու կանոն նույն սպեցիֆիկությունն ունեն, հաղթում է ավելի ուշ գրվածը, ուստի main.css-ը կարող է վերագրել global.css-ը։

Քայլ 2 · global.css

Պատճենիր Դաս 06-ի «global.css-ի ծնունդը» բաժնի ամբողջ կոդը՝ reset, հղումներ, ցուցակներ, տեքստի դասեր, .skip-link և .visually-hidden։

Ստուգում

Թարմացրու էջը։ Skip link-ը անհետացավ, իսկ առաջին Tab-ով հայտնվում է վերևի ձախ անկյունում։ Ցուցակների կետերը նույնպես անհետացան․ դա list-style: none-ն է։

Քայլ 3 · Թեգային սելեկտորներ

main.css — թեգեր
body {
    font-family: Arial, sans-serif;
    color: #1a1a1a;
    background: #ffffff;
}

h1 { font-size: 32px; color: #003459; }
h2 { font-size: 24px; color: #003459; }
h3 { font-size: 18px; }

table { border-collapse: collapse; }
Ժառանգում

body-ին տվել ենք color և font-family, և դրանք հասել են բոլոր պարբերություններին և ցուցակներին։ Հիմա տուր body-ին border: 2px solid red։ Եզրագիծը կհայտնվի միայն body-ի շուրջը, ոչ ներսի տարրերի․ border-ը չի ժառանգվում։ Ստուգելուց հետո ջնջիր։

Քայլ 4 · Դասեր և id-ներ

Ավելացրու HTML-ում content.md-ի աղյուսակի class-երը։ Հետո գրիր հինգ կանոն դասերով (.site-name, .lead, .meta, .copyright, .btn) և երկուսը id-ով (#intro, #conclusion)։

Քայլ 5 · Հինգ համակցություն

ՀամակցությունՕրինակ կայքում
1. Ներսումheader a, main a
2. Ուղիղ երեխաfooter > p
3. Երկու դաս միաժամանակ.btn.btn-light
4. Խմբավորումth, td
5. Թեգ + դասbutton.btn

Reset-ը հանել էր ցուցակների կետերը։ Հոդվածի ցուցակներին վերադարձրու դրանք՝ main ul { list-style: disc; padding-left: 24px; }։

Քայլ 6 · Վիճակներ

main.css — վիճակներ
header a:hover,
header a:focus-visible { color: #9db4c0; }

main a:hover,
main a:focus-visible   { background: #fff3a0; }

.btn:hover,
.btn:focus-visible {
    background: #ffffff;
    color: #003459;
}

tr:nth-child(even) td { background: #f5f5f5; }
Ստուգում

Անցիր էջը Tab-ով։ Ամեն հղում և կոճակ պետք է փոխի տեսքը ֆոկուսի ժամանակ, ոչ միայն մկնիկով։ Եթե :focus-visible-ը մոռացել ես, ստեղնաշարով նավարկողը չի տեսնի, թե որտեղ է։

Քայլ 7 · Ով է հաղթում

«Կարդալ ավելին» կոճակը գտնվում է main-ի ներսում, ուստի նրա վրա գործում են և՛ main a-ն, և՛ .btn-ը։ Բացիր DevTools → Styles և գտիր, որ կանոններն են ջնջված։ Ինչու՞ է գույնը .btn-ից, իսկ ընդգծումը՝ main a-ից։ Ուղղիր .btn-ին ավելացնելով text-decoration: none։

03Ընդունման ստուգաթերթ

Ֆայլեր

  • global.css-ը միացված է main.css-ից առաջ բոլոր յոթ էջում
  • Skip link-ը թաքնված է և հայտնվում է առաջին Tab-ով

Սելեկտորներ

  • Առնվազն հինգ կանոն թեգով, հինգը՝ դասով, երկուսը՝ id-ով
  • Օգտագործված են բոլոր հինգ համակցությունները
  • Կա :hover և :focus-visible հղումների և կոճակների համար
  • Աղյուսակների զույգ տողերը՝ :nth-child(even)

Կոդ

  • Ոչ մի !important
  • Ոչ մի style ատրիբուտ HTML-ում
  • Մուգ ֆոնի վրա տեքստը բաց է, բաց ֆոնի վրա՝ մուգ

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
main.css-ի կանոնը չի աշխատումՖայլերի հերթականությունը սխալ է, կամ global.css-ում ավելի սպեցիֆիկ սելեկտոր կա։ DevTools → Styles-ում ջնջված կանոնը ցույց է տալիս, թե ով է հաղթել
Ոճերը չեն երևում pages/-ի էջերումՈւղին՝ ../css/main.css
Ամբողջ էջը «սեղմված» էReset-ը հանել է բրաուզերի բացակները։ Առայժմ՝ մի քանի margin-bottom, իսկական լուծումը՝ Դաս 08-ում

04Դասի մյուս վարժությունները

Սրանք Դաս 06-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Ստեղծիր global.css և main.css։ Միացրու ճիշտ հերթականությամբ։ մինի-նախագծում
  2. Փորձիր փոխել հերթականությունը՝ main.css-ը առաջինը։ Նկարագրիր՝ ինչ կոտրվեց։ Վերականգնիր։
  3. Գրիր հինգ կանոն թեգային սելեկտորով, հինգը՝ դասով, երկուսը՝ id-ով։ մինի-նախագծում
  4. Օգտագործիր բոլոր հինգ համակցությունները 04-րդ բաժնից։ մինի-նախագծում
  5. Ստեղծիր երկու կանոն, որոնք հակասում են իրար։ Կանխագուշակիր՝ որը կհաղթի, հետո ստուգիր DevTools-ով։
  6. Հաշվիր սպեցիֆիկությունը՝ .card p, #hero .btn, ul li a.link, input[type="text"]:focus։ Ստուգիր DevTools-ով։
  7. Ցուցադրիր ժառանգումը․ body-ին տուր color և font-family, և ցույց տուր, որ դրանք հասնում են ներսի էլեմենտներին։ Հետո ցույց տուր, որ border-ը չի ժառանգվում։ մինի-նախագծում
  8. Ավելացրու :hover և :focus-visible վիճակներ կոճակներին ու հղումներին։ Ստուգիր Tab-ով։ մինի-նախագծում
  9. Օգտագործիր :nth-child(even) աղյուսակի տողերի համար (Դաս 3-ի աղյուսակը)։ մինի-նախագծում
  10. Վերցրու Դաս 5-ի սեմանտիկ էջը և ոճավորիր այն՝ գույներ, տառաչափեր, hover վիճակներ։ Ոչ մի !important։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
