Grid․ պատկերասրահ, բլոգ, ֆորմա

Grid-ը վերցնում է այն գործերը, որոնց համար նախատեսված է․ ցանցեր, 2 × 2 նկար, անվանված տարածքներ և ֆորմա պիտակներով ձախում։

Ժամանակ՝ ~2 ժամ Սկսիր Դաս 19-ի արդյունքից Արդյունք՝ նոր ցանցեր 4 էջում
Միայն անցածը

Օգտագործիր միայն Դաս 01–20-ը։ Էջի կմախքը (section > .row > .col) մնում է նույնը․ Grid-ը օգտագործում ենք .col-ի ներսում։

00Ինչ պետք է ստացվի

Պատկերասրահում առաջին նկարը զբաղեցնում է չորս վանդակ, բլոգը կառուցված է անվանված տարածքներով, իսկ քարտերի ցանցերը կորցրել են սյուների բոլոր դասերը։

01Ինչ ես ստանում

starter/ └── content.md ← որտեղ և ինչպես կիրառել Grid

Սկսիր Դաս 19-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 19-ի օրինակը։

02Քայլեր

Քայլ 1 · Grid օգնականներ

global.css — Դաս 20
.grid { display: grid; }

.grid-auto {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(min(260px, 100%), 1fr));
}

.col-full { grid-column: 1 / -1; }
Ինչու min()

minmax(260px, 1fr)-ը 240px լայն էկրանին ստիպում է ցանցին լինել 260px և դուրս գալ։ min(260px, 100%)-ը ասում է․ «260px, բայց ոչ ավելի, քան տեղը»։

Քայլ 2 · Քարտերի ցանցեր

index.html — առաջ և հետո
<!-- Առաջ՝ երեք սյուն, ամեն մեկը իր դասերով -->
<div class="row flex-wrap">
    <div class="col w-33 w-md-50 w-sm-100"> <article class="wrapper card">...</article> </div>
    ...
</div>

<!-- Հետո -->
<div class="row">
    <div class="col w-100">
        <div class="wrapper">
            <div class="grid-auto gap-20">
                <article class="card">...</article>
                <article class="card">...</article>
                <article class="card">...</article>
            </div>
        </div>
    </div>
</div>

Հաշվիր, թե քանի դաս կրճատվեց HTML-ից։ Նախագծերի էջում «Այս կայքը» քարտը (.card--featured) զբաղեցնում է երկու սյուն՝ grid-column: span 2, իսկ հեռախոսում՝ մեկ։

Քայլ 3 · Պատկերասրահ 2 × 2-ով

main.css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.gallery__item:first-child {
    grid-column: span 2;
    grid-row: span 2;
}

Մեծ նկարի sizes-ը փոխիր․ համակարգչում այն հիմա էջի երկու երրորդն է (66vw)։

Քայլ 4 · Բլոգը grid-template-areas-ով

main.css
.blog-layout {
    display: grid;
    grid-template-columns: 1fr 300px;
    grid-template-areas: "posts aside";
}

.blog-layout > .posts { grid-area: posts; }
.blog-layout > aside  { grid-area: aside; }

@media (max-width: 768px) {
    .blog-layout {
        grid-template-columns: 1fr;
        grid-template-areas:
            "posts"
            "aside";
    }
}
Ստուգիր Tab-ով

Grid-ը կարող է տարածքները դասավորել ցանկացած հերթականությամբ, բայց Tab-ը միշտ գնում է HTML-ի հերթականությամբ։ Այստեղ HTML-ում գրառումները aside-ից առաջ են, ուստի տեսողական և ստեղնաշարի հերթականությունները համընկնում են։

Քայլ 5 · Ֆորմա Grid-ով

«Հաշիվ» և «Անձնական տվյալներ» խմբերում p > label + br + input-ը փոխարինիր <div class="form-grid">-ով, որի ներսում label-ը և դաշտը հաջորդում են իրար։ Սյուները՝ 140px minmax(0, 1fr)։ minmax(0, …)-ը պետք է, որ լայն դաշտը (օրինակ՝ ֆայլի) չընդարձակի սյունը նեղ էկրանին։

03Ընդունման ստուգաթերթ

Ցանցեր

  • Քարտերի ցանցերը՝ .grid-auto, առանց սյուների դասերի
  • Առանձնահատուկ քարտը՝ երկու սյուն համակարգչում
  • 320px-ում ոչինչ դուրս չի գալիս

Պատկերասրահ և բլոգ

  • Առաջին նկարը՝ 2 × 2
  • Բլոգը՝ անվանված տարածքներով, հեռախոսում՝ մեկ սյուն
  • Tab-ի հերթականությունը տրամաբանական է

Ֆորմա

  • Պիտակները ձախում, դաշտերը աջում
  • Հեռախոսում՝ մեկը մյուսի տակ

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Ցանցը տոկոսներով և gap-ով դուրս է գալիս33% × 3 + 2 × gap > 100%։ Օգտագործիր 1fr
Երկու տարրով auto-fit-ը ձգում է դրանք ամբողջ լայնությամբԱյդպես է աշխատում auto-fit-ը։ auto-fill-ը պահում է դատարկ սյուները
grid-area-ն չի աշխատումՏարածքի անունը չակերտներով է գրված, կամ grid-template-areas-ի տողերում տարբեր քանակի սյուներ կան

04Դասի մյուս վարժությունները

Սրանք Դաս 20-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Կառուցիր ցանց 1fr-ով և ցանց տոկոսներով՝ երկուսն էլ gap: 20px-ով։ Ցույց տուր, ինչու տոկոսներով տարբերակը դուրս է գալիս։
  2. Ցուցադրիր auto-fit-ի և auto-fill-ի տարբերությունը՝ 2 տարրով լայն էկրանին։
  3. Կառուցիր ապրանքների ցանց auto-fit-ով։ Համեմատիր Դաս 14-ի flex տարբերակի հետ՝ քանի՞ տող կոդ և քանի՞ դաս կրճատվեց։ մինի-նախագծում
  4. Ցուցադրիր minmax(400px, 1fr)-ի խնդիրը 320px էկրանին։ Ուղղիր min()-ով։ մինի-նախագծում
  5. Կառուցիր գալերեա, որտեղ առաջին նկարը զբաղեցնում է 2×2 վանդակ։ մինի-նախագծում
  6. Օգտագործիր grid-column: 1 / -1 բաժնի վերնագրի համար ցանցի ներսում։ մինի-նախագծում
  7. Կառուցիր էջի կմախք grid-template-areas-ով՝ header, sidebar, main, footer։ մինի-նախագծում
  8. Ավելացրու հեռախոսի տարբերակը, որտեղ sidebar-ը գնում է main-ից հետո։ Ստուգիր Tab-ի հերթականությունը։ մինի-նախագծում
  9. Կառուցիր ֆորմա Grid-ով՝ պիտակները ձախում, դաշտերը աջում (grid-template-columns: 140px 1fr)։ մինի-նախագծում
  10. Գրիր ցուցակ՝ քո նախագծի որ բաժիններում կօգտագործեիր Grid, որտեղ՝ Flex, և ինչու։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
