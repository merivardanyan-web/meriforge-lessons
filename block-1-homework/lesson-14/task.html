Ամբողջ կայքը ադապտիվ

Կայքը դառնում է ադապտիվ 320px-ից մինչև 1920px․ ադապտիվ սյուներ, media query-ներ, clamp() և ստուգում իրական հեռախոսում։

Ժամանակ՝ ~2.5 ժամ Սկսիր Դաս 13-ի արդյունքից Արդյունք՝ բոլոր էջերը՝ ադապտիվ
Միայն անցածը

Օգտագործիր միայն Դաս 01–14-ը։ Հեռախոսում մենյուն պարզապես փաթաթվում է․ բուրգեր-մենյուն Դաս 18-ում է։

00Ինչ պետք է ստացվի

Ամբողջ կայքը աշխատում է 320px-ից մինչև 1920px․ սյուները դառնում են երկու, ապա մեկ, վերնագրերը սահուն փոքրանում են, իսկ մենյուն փաթաթվում է կենտրոնում։

01Ինչ ես ստանում

starter/ └── content.md ← breakpoint-ներ և ամեն բաժնի սյուները

Սկսիր Դաս 13-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 13-ի օրինակը։

02Քայլեր

Քայլ 1 · viewport

Ստուգիր, որ բոլոր էջերում կա <meta name="viewport" content="width=device-width, initial-scale=1.0">։ Ջնջիր այն մեկ էջից և բացիր DevTools-ի սարքի ռեժիմում․ էջը կփոքրանա ամբողջությամբ։ Վերադարձրու։

Քայլ 2 · Ադապտիվ .w-* դասեր

global.css — Դաս 14
@media (max-width: 992px) {
    .w-md-25  { width: 25%; }
    .w-md-33  { width: 33.3333%; }
    .w-md-50  { width: 50%; }
    .w-md-100 { width: 100%; }
}

@media (max-width: 576px) {
    .w-sm-50  { width: 50%; }
    .w-sm-100 { width: 100%; }
}
HTML — մեծ էկրանի դասից ՀԵՏՈ
<div class="col w-33 w-md-50 w-sm-100">

Քայլ 3 · Ամեն բաժին

Անցիր բոլոր էջերով և ավելացրու w-md-* և w-sm-* դասերը՝ content.md-ի աղյուսակով։ Համոզվիր, որ ամեն այդպիսի .row ունի flex-wrap։ Ջնջիր այն մեկ տեղից և նկարագրիր, ինչ եղավ։

Քայլ 4 · Ադապտիվ բլոկ main.css-ի վերջում

main.css — բաժին 9
@media (max-width: 768px) {
    :root { --wall: 20px; }      /* բոլոր պատերը՝ մեկ տողով */

    section { padding: 30px 0; }

    header .row { flex-wrap: wrap; justify-content: center; }
    .menu       { flex-wrap: wrap; justify-content: center; }
}

Քայլ 5 · clamp()

main.css
h1 { font-size: clamp(1.75rem, 4vw, 2.5rem); }
h2 { font-size: clamp(1.375rem, 3vw, 1.75rem); }

Նեղացրու պատուհանը դանդաղ․ վերնագրերը փոքրանում են սահուն, առանց թռիչքների։ Փորձիր նաև պատերը clamp()-ով՝ --wall: clamp(20px, 5vw, 60px), և համեմատիր media query-ի տարբերակի հետ։

Քայլ 6 · Նեղ էկրանի երկու թակարդ

  • Երկար հղումները չեն կոտրվում, որովհետև global.css-ում a { white-space: nowrap; }։ Տեքստի մեջ հղումներին՝ white-space: normal
  • Ֆորմայի fieldset-ը լռելյայն չի նեղանում իր բովանդակությունից փոքր։ Տուր նրան min-width: 0՝ նույնը, ինչ Դաս 12-ի input-ին

Քայլ 7 · Ստուգում

Console — ով է ստեղծում հորիզոնական սքրոլը
document.querySelectorAll('*').forEach(e => {
    if (e.offsetWidth > document.body.offsetWidth) console.log(e);
});

Ստուգիր հինգ լայնությամբ՝ 375, 576, 768, 992, 1440։ Հետո բացիր կայքը իրական հեռախոսում Live Server-ի ցանցային հասցեով։

03Ընդունման ստուգաթերթ

Սյուներ

  • Բոլոր սյուներն ունեն ադապտիվ դասեր
  • Սյուներով բոլոր տողերն ունեն flex-wrap
  • Footer-ը՝ 40/20/40 → 100/50/50 → 100/100/100

Չափեր

  • --wall-ը փոքրանում է հեռախոսում
  • h1-ը և h2-ը՝ clamp()-ով

Ստուգում

  • Հինգ լայնություն, հինգ սքրինշոթ
  • 320px-ում հորիզոնական սքրոլ չկա ոչ մի էջում
  • Ստուգված է իրական հեռախոսում

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
.w-md-100-ը չի աշխատումԱդապտիվ դասը գրված է HTML-ում մեծ էկրանի դասից առաջ, կամ global.css-ում media query-ն վերևում է, իսկ .w-*-ը՝ ներքևում
Սյուները չեն անցնում նոր տող.row-ը չունի flex-wrap
Ֆորման դուրս է գալիս հեռախոսումfieldset-ին՝ min-width: 0
Հեռախոսում ամեն ինչ փոքր էԲացակայում է viewport meta-ն

04Դասի մյուս վարժությունները

Սրանք Դաս 14-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Ջնջիր viewport meta-ն և բացիր հեռախոսում (կամ DevTools-ի սարքի ռեժիմում)։ Ուղարկիր սքրինշոթ։ Վերականգնիր։ մինի-նախագծում
  2. Ավելացրու global.css-ում ադապտիվ .w-* դասերը։ մինի-նախագծում
  3. Կառուցիր 4-սյունանոց ցանց, որը դառնում է 2, ապա 1։ Ստուգիր երեք լայնությամբ։ մինի-նախագծում
  4. Ջնջիր flex-wrap-ը և նկարագրիր, ինչ եղավ։ մինի-նախագծում
  5. Դարձրու պատերը ադապտիվ երկու ձևով՝ media query-ով և clamp()-ով։ Համեմատիր։ մինի-նախագծում
  6. Կիրառիր clamp() բոլոր վերնագրերին։ Նեղացրու պատուհանը դանդաղ և նկարագրիր վարքագիծը։ մինի-նախագծում
  7. Դիտավորյալ ստեղծիր հորիզոնական սքրոլ (օրինակ՝ width: 120% ինչ-որ բլոկի վրա)։ Գտիր այն Console-ի կոդով։ մինի-նախագծում
  8. Բացիր քո էջը իրական հեռախոսում Live Server-ի ցանցային հասցեով։ Նկարագրիր, ինչ նկատեցիր, որ DevTools-ում չէիր տեսնում։ մինի-նախագծում
  9. Դարձրու Դաս 12-ի footer-ը ադապտիվ՝ 40/20/40-ից 100/50/50, ապա 100/100/100։ մինի-նախագծում
  10. Վերցրու Դաս 13-ի ամբողջ էջը և դարձրու ամբողջովին ադապտիվ։ Ստուգիր՝ 375, 576, 768, 992, 1440։ Ուղարկիր հինգ սքրինշոթ։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
