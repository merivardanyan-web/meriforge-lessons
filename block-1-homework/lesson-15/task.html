Կպչուն header, պիտակ, մոդալ

Գործնականում ես կիրառում position-ի բոլոր արժեքները․ sticky header, absolute պիտակ, fixed «վեր» կոճակ և մոդալ պատուհան inset: 0-ով։

Ժամանակ՝ ~2 ժամ Սկսիր Դաս 14-ի արդյունքից Արդյունք՝ +1 էջ (thanks.html)
Միայն անցածը

Օգտագործիր միայն Դաս 01–15-ը։ Մոդալը չի բացվում և չի փակվում կոճակով․ դա JavaScript է։ Բուրգեր-մենյուն Դաս 18-ում է։

00Ինչ պետք է ստացվի

Header-ը մնում է վերևում ոլորելիս, քարտի անկյունում պիտակ է, էջի անկյունում՝ «վեր» կոճակ։ Գրանցման ֆորման ուղարկելուց հետո բացվում է էջ մոդալ պատուհանով։

01Ինչ ես ստանում

starter/ └── content.md ← header, պիտակ, «վեր» կոճակ, մոդալ

Սկսիր Դաս 14-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 14-ի օրինակը։

02Քայլեր

Քայլ 1 · Կպչուն header

main.css
header {
    position: sticky;
    top: 0;              /* առանց սրա sticky-ն չի աշխատում */
    z-index: 100;
    background-color: var(--secondary);   /* առանց ֆոնի բովանդակությունը կերևա տակից */
}

html {
    scroll-behavior: smooth;
    scroll-padding-top: 90px;   /* խարիսխները չեն մտնում header-ի տակ */
}
Փորձիր

Ջնջիր top: 0-ն և ոլորիր։ Հետո ջնջիր ֆոնը և ոլորիր։ Հետո ջնջիր scroll-padding-top-ը և սեղմիր գլխավոր էջի «Ինչ եմ սովորում» հղմանը։ Ամեն անգամ նկարագրիր արդյունքը և վերադարձրու։

Հեռախոսում մեր header-ը մենյուի պատճառով բարձր է (մոտ 250px)։ Կպչուն լինելով այն կզբաղեցներ էկրանի երրորդ մասը։ Մինչև բուրգեր-մենյուն (Դաս 18) 768px-ից ներքև տուր նրան position: static։

Քայլ 2 · Պիտակ քարտի անկյունում

main.css
.card { position: relative; }   /* խարիսխ */

.card__badge {
    position: absolute;
    top: 10px;
    left: 10px;
    z-index: 2;
}

Ջնջիր .card-ի position: relative-ը։ Ո՞ւր գնաց պիտակը, և ինչու։

Քայլ 3 · «Վեր» կոճակ

position: fixed, right և bottom 20px, z-index: 50։ Կոճակի բովանդակությունը կենտրոնացրու flex-ով։ aria-label-ը պարտադիր է, որովհետև «↑» նշանը էկրանընթերցիչի համար ոչինչ չի ասում։

Քայլ 4 · Մոդալ պատուհան

pages/thanks.html
<div class="modal" aria-label="Գրանցումն ընդունված է">
    <div class="modal__window">
        <a href="register.html" class="modal__close" aria-label="Փակել">×</a>
        <h2>Շնորհակալություն</h2>
        <p>Գրանցումն ընդունված է։ ...</p>
        <a href="../index.html" class="btn">Գլխավոր էջ</a>
    </div>
</div>
main.css
.modal {
    position: fixed;
    inset: 0;                  /* ծածկում է ամբողջ էկրանը */
    z-index: 200;
    display: flex;             /* պատուհանը՝ կենտրոնում */
    align-items: center;
    justify-content: center;
    background: rgba(0, 37, 63, .6);
}

.modal__window { position: relative; }

.modal__close {
    position: absolute;
    top: 8px;
    right: 8px;
}

Գրանցման ֆորմայի action-ը փոխիր thanks.html։ Իսկական բացել-փակելը JavaScript-ով է․ այսօր կառուցում ենք միայն տեսքը։

03Ընդունման ստուգաթերթ

Header

  • Կպչուն է համակարգչում, հեռախոսում՝ ոչ
  • Խարիսխները չեն մտնում header-ի տակ

Դիրքավորում

  • Պիտակը քարտի անկյունում է
  • «Վեր» կոճակը բոլոր էջերում է և ունի aria-label
  • Մոդալը ծածկում է ամբողջ էկրանը, պատուհանը՝ կենտրոնում, «×»-ը՝ անկյունում

z-index

  • Մոդալը header-ից վերև է
  • Header-ը քարտերից և «վեր» կոճակից վերև է ոլորելիս

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Sticky-ն չի աշխատումՉկա top, կամ ծնողներից մեկը ունի overflow: hidden
Պիտակը թռավ էջի վերևի անկյունԾնողը չունի position: relative
z-index: 9999-ը չի օգնումՏարրը գտնվում է այլ stacking context-ում։ Ծնողի z-index-ն է որոշում

04Դասի մյուս վարժությունները

Սրանք Դաս 15-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Ցուցադրիր relative-ի և absolute-ի տարբերությունը՝ երեք բլոկ, միջինը տեղաշարժված։ Նկարագրիր, ինչ եղավ հարևանների հետ։
  2. Ավելացրու պիտակ քարտի անկյունում։ Ապա ջնջիր ծնողի relative-ը և գրիր՝ ուր գնաց այն։ մինի-նախագծում
  3. Կառուցիր ծածկույթ նկարի վրա՝ inset: 0-ով և կենտրոնացված տեքստով։
  4. Կենտրոնացրու բլոկ երկու ձևով՝ transform-ով և flex-ով։ Համեմատիր կոդի ծավալը։
  5. Դարձրու header-ը կպչուն։ Ջնջիր top: 0-ը և նկարագրիր արդյունքը։ մինի-նախագծում
  6. Ջնջիր header-ի background-ը և ոլորիր։ Ուղարկիր սքրինշոթ։ մինի-նախագծում
  7. Ավելացրու scroll-padding-top և ստուգիր խարիսխներով նավիգացիան։ Ջնջիր և համեմատիր։ մինի-նախագծում
  8. Կառուցիր «վեր» կոճակ՝ position: fixed-ով։ մինի-նախագծում
  9. Վերարտադրիր stacking context-ի խնդիրը՝ երկու բլոկ z-index: 1 և 2, առաջինի ներսում՝ z-index: 9999։ Բացատրիր, ինչու չաշխատեց։
  10. Կառուցիր մոդալ պատուհան՝ ֆոնով (fixed + inset: 0), կենտրոնացված պատուհանով և փակելու կոճակով անկյունում (absolute)։ JavaScript պետք չէ — պարզապես ցույց տուր տեսքը։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
