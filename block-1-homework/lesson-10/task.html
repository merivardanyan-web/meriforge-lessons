Տնային աշխատանք · HTML Դաս 10 · մինի-նախագիծ

Ամբողջ կայքը կառուցվածքի համակարգով

Կայքը վերակառուցում ենք section > .row > .col > .wrapper համակարգով, որը կօգտագործես մինչև դասընթացի վերջ։

Ժամանակ՝ ~2.5 ժամ Սկսիր Դաս 09-ի արդյունքից Արդյունք՝ բոլոր 7 էջը սյուներով
Միայն անցածը

Օգտագործիր միայն Դաս 01–10-ը։ .row-ի display: flex-ը այս դասից է, բայց Flexbox-ի հատկությունները (justify-content, align-items, gap) Դաս 11–12-ում են։ Էջը նախատեսված է համակարգչի համար․ ադապտիվությունը Դաս 14-ում է։

00Ինչ պետք է ստացվի

Կայքն առաջին անգամ ունի իսկական դասավորություն՝ սյուներ, հավասար բացակներ և ամբողջ լայնությամբ ֆոներ։ Ամեն էջ կառուցված է նույն հինգ շերտով։

01Ինչ ես ստանում

starter/ └── content.md ← չափեր և ամեն էջի սյուները

Սկսիր Դաս 09-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 09-ի օրինակը։

02Քայլեր

    display: flex;

    height: 100%;

.w-25  { width: 25%; }
.w-30  { width: 30%; }
.w-40  { width: 40%; }

.w-60  { width: 60%; }

/* + w-10, w-20, w-33, w-75, w-80 */

Քայլ 2 · main.css-ի չափերը

main.css
section { padding: 40px 0; }
.row    { padding: 0 50px; }
.col    { padding: 10px; }

Ջնջիր Դաս 08-ի main { max-width: 960px; margin: 0 auto; }-ը։ Պատերը հիմա .row-ի գործն են, իսկ ֆոնը կարող է զբաղեցնել ամբողջ լայնությունը։

Քայլ 3 · Մեկ էջ ամբողջությամբ

Ստուգում

Ժամանակավորապես ավելացրու .row { outline: 2px solid red; }, .col { outline: 2px solid blue; }, .wrapper { outline: 2px solid green; }։ Կարմիրի և կապույտի միջև՝ 50px պատ, կապույտի և կանաչի միջև՝ 10px բացակ։ Սքրինշոթ արա և ջնջիր outline-ները։

Քայլ 4 · Header և footer

Header-ում երկու սյուն․ w-30 անվան և w-70 մենյուի համար։ Մենյուն աջ տանելու համար՝ text-align: right մենյուի սյան վրա, որովհետև մենյուի կետերը inline-block են։ Footer-ում երեք սյուն։

Քայլ 5 · Մնացած էջերը

Վերակառուցիր բոլոր էջերը content.md-ի աղյուսակով։ Ամեն section-ում՝ մեկ կամ մի քանի .row, ամեն սյան մեջ՝ .wrapper։

Քայլ 6 · Քարտերը սյուներում

Գլխավոր էջի քարտը դիր անմիջապես .col-ի մեջ և տուր նրան նաև wrapper դասը՝ <article class="wrapper card">։ Դաս 08-ի display: inline-block, width և margin-ը ջնջիր․ լայնությունը հիմա սյունն է որոշում։

height: 100%

Մի քարտի տեքստը դարձրու երեք անգամ ավելի երկար։ Երկու քարտն էլ կմնան նույն բարձրության, որովհետև .row-ը flex է, իսկ .wrapper-ը՝ height: 100%։ Հանիր wrapper դասը մեկ քարտից և համեմատիր։

03Ընդունման ստուգաթերթ

Կառուցվածք

  • Ամեն էջ՝ main > section > .row > .col > .wrapper
  • Ամեն section ունի id
  • Ամեն .col ունի ուղիղ մեկ .wrapper

Չափեր

  • Սյուների լայնությունների գումարը ամեն .row-ում 100% է
  • Պատերը և բացակները հավասար են բոլոր էջերում
  • Կողք կողքի բլոկները նույն բարձրության են

Շերտերի դերերը

  • Ֆոնը՝ section-ի կամ .wrapper-ի վրա, երբեք .col-ի
  • .row-ը և .col-ը միայն չափեր ունեն

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Ֆոնով բլոկները կպած են իրար, բացակ չկաՖոնը դրված է .col-ի վրա։ .col-ի padding-ը ֆոնի ներսում է, ուստի բացակը անհետանում է։ Ֆոնը տեղափոխիր .wrapper-ի վրա
Մեկ բլոկ ավելի կարճ է հարևաններիցԱյդ սյան մեջ .wrapper-ը բացակայում է
Վերջին սյունը տեղափոխվել է նոր տող կամ դուրս է եկելԼայնությունների գումարը 100%-ից ավելի է
Հեռախոսում ամեն ինչ շատ նեղ էՍպասելի է․ ադապտիվ լայնությունները (w-md-*) Դաս 14-ում են

04Դասի մյուս վարժությունները

Սրանք Դաս 10-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Ավելացրու global.css-ում .row, .wrapper և բոլոր .w-* դասերը։ մինի-նախագծում
  2. Ավելացրու main.css-ում section-ի, .row-ի և .col-ի չափերը։ մինի-նախագծում
  3. Կառուցիր բաժին չորս սյունով (w-25)։ Ստուգիր, որ բացակները հավասար են։ մինի-նախագծում
  4. Կառուցիր բաժին երկու անհամաչափ սյունով՝ w-70 և w-30։ մինի-նախագծում
  5. Կառուցիր section, որի ներսում կան երեք տարբեր .row՝ վերնագիր, բովանդակություն, կոճակ։
  6. Ցուցադրիր height: 100%-ի ազդեցությունը՝ երեք քարտ շատ տարբեր երկարության տեքստերով, առաջ և հետո։ մինի-նախագծում
  7. Դիտավորյալ դիր ֆոն .col-ի վրա։ Նկարագրիր՝ ինչ կոտրվեց և ինչու։
  8. Դիտավորյալ բաց թող .wrapper-ը մեկ սյան մեջ։ Համեմատիր հարևանների հետ։
  9. Ժամանակավորապես ավելացրու outline-ներ բոլոր երեք շերտին տարբեր գույներով։ Ուղարկիր սքրինշոթ։ մինի-նախագծում
  10. Վերցրու Դաս 5-ի սեմանտիկ էջը և վերակառուցիր այն ամբողջովին այս համակարգով։ Ամեն բաժին պիտի ունենա id, ամեն սյուն՝ .wrapper։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
