Flexbox II․ ֆորմաներ և footer

Գործնականում ես կիրառում flex-grow-ը, flex-shrink-ը, gap-ը և flex-wrap-ը․ բաժանորդագրման ֆորմա footer-ում և որոնում բլոգում։

Ժամանակ՝ ~1.5 ժամ Սկսիր Դաս 11-ի արդյունքից Արդյունք՝ footer + որոնում
Միայն անցածը

Օգտագործիր միայն Դաս 01–12-ը։ Media query-ներ դեռ չենք օգտագործում (Դաս 14), իսկ դիզայնի տոկենները (--wall, --gap) Դաս 13-ում են։

00Ինչ պետք է ստացվի

Footer-ը ստանում է բաժանորդագրման ֆորմա, իսկ բլոգը՝ որոնման դաշտ։ Երկու դեպքում էլ դաշտը ձգվում է, իսկ կոճակը երբեք չի սեղմվում։ Սյուներով տողերը փաթաթվում են նեղ էկրանին։

01Ինչ ես ստանում

starter/ └── content.md ← footer, որոնում, spacing դասեր

Սկսիր Դաս 11-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 11-ի օրինակը։

02Քայլեր

Քայլ 1 · Օգնականներ

global.css-ում՝ .flex-wrap { flex-wrap: wrap; }։ main.css-ում՝ .gap-* և .mb-* դասերը (բաժին 5)։

Քայլ 2 · Դաշտ + կոճակ մեկ տողում

footer-ի ֆորմա
<form class="inline-form flex gap-10" action="index.html" method="get">
    <label for="mail" class="visually-hidden">Էլ. հասցե</label>
    <input type="email" id="mail" name="mail" placeholder="ani@example.com" required>
    <button type="submit" class="btn">Բաժանորդագրվել</button>
</form>
main.css
.inline-form input {
    flex-grow: 1;      /* ձգվում է ազատ տեղի վրա */
    min-width: 0;      /* թույլ է տալիս սեղմվել իր բովանդակությունից փոքր */
}

.inline-form .btn {
    flex-shrink: 0;    /* կոճակը չի սեղմվում */
}
Փորձիր

Ջնջիր flex-shrink: 0-ն և նեղացրու պատուհանը․ կոճակի տեքստը կսկսի կոտրվել երկու տողի։ Ջնջիր min-width: 0-ն․ երկար placeholder-ով դաշտը դուրս կգա սյունից։

Քայլ 3 · Footer ըստ դասարանականի

Երեք սյուն՝ 40/20/40, ներքևի տողը՝ flex justify-between align-center flex-wrap gap-10, իսկ բաժանարար գիծը՝ .footer__bottom-ի border-top-ով։

Քայլ 4 · Որոնում բլոգում

Նույն .inline-form կոմպոնենտը, ուրիշ տեղում։ Նոր CSS պետք չէ․ եթե պետք եղավ, ուրեմն կոմպոնենտը կախված է իր տեղից։

Քայլ 5 · flex-wrap

Բոլոր այն .row-երին, որոնցում մեկից ավելի սյուն կա, ավելացրու flex-wrap։ Մենյուի ul-ին՝ նույնպես։ Նեղացրու պատուհանը և նկարագրիր, թե ինչ է կատարվում։ Լիարժեք ադապտիվությունը Դաս 14-ում է․ այսօր միայն համոզվում ենք, որ ոչինչ դուրս չի գալիս։

gap և տոկոսներ

Մեր սյուներն ունեն .w-* տոկոսներով և padding՝ բացակի համար։ Եթե .row-ին տաս gap, 33% + 33% + 33% + 2 × gap > 100%, և վերջին սյունը կանցնի նոր տող։ Ուստի սյուների համար gap չենք օգտագործում, իսկ ներսի flex բլոկների համար՝ այո։

03Ընդունման ստուգաթերթ

Ֆորմաներ

  • Երկու ֆորմայում էլ դաշտը ձգվում է, կոճակը չի սեղմվում
  • Ամեն դաշտ ունի label (թեկուզ թաքնված)
  • Մեկ .inline-form կոմպոնենտ՝ երկու տեղում

Footer

  • 40/20/40 սյուներ, ներքևի տող բաժանարարով
  • Ստուգված է Tab-ով

Փաթաթում

  • Սյուներով բոլոր տողերն ունեն flex-wrap
  • Նեղ էկրանին ոչինչ դուրս չի գալիս

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Դաշտը դուրս է գալիս սյունիցԲացակայում է min-width: 0
Կոճակի տեքստը կոտրվում էԲացակայում է flex-shrink: 0
Վերջին սյունը միշտ նոր տողում է.row-ին տրված է gap, և տոկոսների գումարը 100%-ից անցավ

04Դասի մյուս վարժությունները

Սրանք Դաս 12-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Ցուցադրիր flex-grow-ի ազդեցությունը՝ երեք բլոկ, grow-ը միայն մեկին։
  2. Ցուցադրիր համամասնությունը 1:2:1 և 1:3:1։
  3. Կողք կողքի համեմատիր flex-grow: 1-ը և flex: 1-ը՝ շատ տարբեր երկարության տեքստերով։ Բացատրիր տարբերությունը։
  4. Կառուցիր որոնման դաշտ կոճակով՝ flex-grow և flex-shrink: 0-ով։ մինի-նախագծում
  5. Ցուցադրիր flex-shrink: 0-ի կարևորությունը լոգոյի օրինակով՝ առաջ և հետո։ մինի-նախագծում
  6. Ցուցադրիր gap-ի և տոկոսային լայնությունների կոնֆլիկտը։ Ապա լուծիր՝ flex: 1-ի անցնելով։
  7. Կառուցիր ինքնահարմարվող ցանց՝ flex: 1 1 250px-ով, 6 տարրով։ Ստուգիր տարբեր լայնություններով։
  8. Ավելացրու flex-wrap: wrap Դաս 10-ի «Մեր թիմը» բաժնին։ Նեղացրու պատուհանը և նկարագրիր վարքագիծը։ մինի-նախագծում
  9. Կառուցիր footer դասարանական օրինակի պես։ Ստուգիր Tab-ով և նեղ էկրանով։ մինի-նախագծում
  10. Ցուցադրիր order-ի հասանելիության խնդիրը․ երեք հղում, order-ով փոխված հերթականությամբ։ Անցիր Tab-ով և նկարագրիր, ինչ ես տեսնում։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
