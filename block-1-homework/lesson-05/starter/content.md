# Դաս 05 · սեմանտիկ կառուցվածք և բլոգ

Սկսիր Դաս 04-ի քո կայքից։ Եթե այն չունես, վերցրու ../lesson-04/example/-ը։

## Ամեն էջում
- body-ի առաջին տարրը՝ <a href="#main" class="skip-link">Անցնել բովանդակությանը</a>
- header՝ կայքի անունը (հղում գլխավոր էջին) և nav aria-label="Գլխավոր մենյու"
- main id="main"՝ էջի բովանդակությունը section-ներով, ամեն section՝ id-ով
- footer՝ nav aria-label="Footer-ի հղումներ" (Գլխավոր · Բլոգ · Կապ), address, © տող

Նավիգացիա: Գլխավոր · Իմ մասին · Բլոգ · Դասացուցակ · Համեմատություն · Ակումբ · Կապ
