Անի Սարգսյան

Սովորում եմ վեբ ծրագրավորում։ Այստեղ գրում եմ այն, ինչ սովորում եմ ամեն շաբաթ։

Այս էջում՝ Ինչ եմ սովորում · Իմ նախագծերը · Օգտակար նյութեր

Ինչ եմ սովորում

HTML

HTML-ը էջի կմախքն է։ Այսօր սովորեցի, որ div-ների ապուրը վատ է, և ամեն բլոկ պետք է ունենա իմաստ՝ <header>, <main>, <footer>։

CSS

CSS-ը էջի տեսքն է։ Սկսում ենք հաջորդ դասին․ css/ թղթապանակում արդեն կան երկու դատարկ ֆայլ։

Այս կայքը

Հինգ դասում կայքս աճեց մեկ էջից մինչև յոթը․

  1. Դաս 1՝ առաջին էջը
  2. Դաս 2՝ երեք էջ, նկարներ և հղումներ
  3. Դաս 3՝ դասացուցակ և համեմատական աղյուսակ
  4. Դաս 4՝ գրանցման ֆորմա
  5. Դաս 5՝ սեմանտիկ կառուցվածք և բլոգ
