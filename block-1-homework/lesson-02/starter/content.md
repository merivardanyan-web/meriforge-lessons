### Ներդրված ցուցակ
- Խմբագրիչ: VS Code · Live Server · Auto Rename Tag
- Բրաուզեր: Chrome · DevTools · Firefox՝ ստուգելու համար
- Նկարներ: Լուսանկարներ՝ ինքս եմ անում · Պատկերակներ · Ձևաչափեր՝ JPG և PNG
