Պատկերասրահ և hero

Կայքը ստանում է պատկերասրահ տարբեր չափերի նկարներով, hero ֆոնային նկարով, WebP, srcset և inline SVG պատկերակներ։

Ժամանակ՝ ~2.5 ժամ Սկսիր Դաս 15-ի արդյունքից Արդյունք՝ +1 էջ (gallery.html)
Միայն անցածը

Օգտագործիր միայն Դաս 01–16-ը։ Պատկերասրահը կառուցում ենք մեր սյուներով․ Grid-ը, որով առաջին նկարը կզբաղեցնի 2 × 2 վանդակ, Դաս 20-ում է։

00Ինչ պետք է ստացվի

Գլխավոր էջը ստանում է hero ֆոնային նկարով, իսկ կայքը՝ պատկերասրահ, որտեղ բոլորովին տարբեր չափերի վեց նկար ցուցադրվում են նույն վանդակներում՝ առանց ձգվելու։

01Ինչ ես ստանում

starter/ ├── content.md ← նկարների աղյուսակ, alt-եր, տեքստեր └── images/ ├── g-*.jpg g-*.webp ← վեց ջրաներկ, տարբեր չափերի ├── g-lake-400/800/1600.jpg ← srcset-ի համար ├── hero.jpg └── *.webp ← քարտերի նկարների WebP տարբերակները

Սկսիր Դաս 15-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 15-ի օրինակը։

02Քայլեր

Քայլ 1 · Նկարների օգնականներ

global.css — Դաս 16
.img-cover   { width: 100%; height: 100%; object-fit: cover; }
.img-contain { width: 100%; height: 100%; object-fit: contain; }

.ratio-1-1  { aspect-ratio: 1 / 1; }
.ratio-4-3  { aspect-ratio: 4 / 3; }
.ratio-3-2  { aspect-ratio: 3 / 2; }
.ratio-16-9 { aspect-ratio: 16 / 9; }

Քայլ 2 · Քարտերի նկարները

քարտի նկար
<picture class="card__media ratio-3-2">
    <source srcset="images/project-site.webp" type="image/webp">
    <img class="img-cover" src="images/project-site.jpg" alt="..." width="600" height="400" loading="lazy">
</picture>

aspect-ratio-ը picture-ի վրա է, որովհետև Դաս 08-ից global.css-ում picture-ը block է։ Համեմատիր height: 200px-ի հետ՝ նեղացնելով պատուհանը։

Քայլ 3 · Պատկերասրահ

  • Վեց նկար՝ col w-33 w-md-50 w-sm-100 սյուներում, ամեն մեկը figure + figcaption
  • Բոլորը՝ ratio-4-3 և img-cover։ Ստուգիր, որ ոչ մեկը ձգված չէ
  • Դիմանկարում cover-ը կտրում է գլուխը։ Ուղղիր object-position: top-ով
  • Էկրանից ներքև գտնվող նկարներին՝ loading="lazy", վերևի երեքին՝ ոչ

Քայլ 4 · srcset և sizes

առաջին նկարը
<img class="img-cover"
     src="../images/g-lake-800.jpg"
     srcset="../images/g-lake-400.jpg   400w,
             ../images/g-lake-800.jpg   800w,
             ../images/g-lake-1600.jpg 1600w"
     sizes="(max-width: 576px) 100vw, (max-width: 992px) 50vw, 33vw"
     alt="Սևանա լիճը ջրաներկով, հեռվում՝ սարեր" width="800" height="533">
Ստուգում

DevTools → Network → Img։ Թարմացրու էջը 375px, 768px և 1280px լայնություններով և նայիր, թե որ ֆայլն է բեռնվում։ Եթե միշտ նույնն է, մաքրիր cache-ը (Ctrl+Shift+R)։

Քայլ 5 · Hero

main.css
.hero {
    background-image:
        linear-gradient(90deg, rgba(0, 37, 63, .85), rgba(0, 37, 63, .45)),
        url("../images/hero.jpg");
    background-size: cover;
    background-position: center;
    color: #ffffff;
}

Գրադիենտը և նկարը՝ մեկ background-image-ում, գրադիենտը՝ առաջինը, որ լինի վերևում։ Ուղին՝ ../images/, որովհետև CSS ֆայլը css/-ում է։ Ստուգիր տեքստի կոնտրաստը նկարի ամենաբաց մասում։

Քայլ 6 · Inline SVG պատկերակներ

main.css
.icon {
    width: 24px;
    height: 24px;
    fill: none;
    stroke: currentColor;   /* գույնը՝ տեքստից */
    stroke-width: 2;
}

«Պատվիրել նկար» կոճակում պատկերակը տեքստի կողքին է։ Hover-ի ժամանակ կոճակի տեքստի գույնը փոխվում է, և պատկերակը փոխվում է նրա հետ, որովհետև currentColor է։

03Ընդունման ստուգաթերթ

Նկարներ

  • Ոչ մի նկար ձգված կամ սեղմված չէ
  • Դիմանկարի գլուխը չի կտրվում
  • Բոլոր նկարներն ունեն alt, width, height
  • Ներքևի նկարները՝ loading="lazy"

Ձևաչափեր

  • WebP + JPG picture-ով
  • Մեկ նկար՝ srcset + sizes, ստուգված Network-ում

Hero և SVG

  • Hero-ն ունի նկար և գրադիենտ մեկ հատկությամբ
  • Տեքստը կարդացվում է ամբողջ hero-ում
  • Երեք inline SVG, գույնը՝ currentColor

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
aspect-ratio-ը չի աշխատումimg-ին տրված է height, կամ picture-ը inline է
Ֆոնային նկարը չի երևումՈւղին images/hero.jpg է՝ առանց ../։ Ուղին հաշվվում է CSS ֆայլից
SVG-ի գույնը չի փոխվումSVG-ն միացված է img-ով։ CSS-ով կարելի է գունավորել միայն inline SVG-ն

04Դասի մյուս վարժությունները

Սրանք Դաս 16-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Վերցրու 6 նկար բոլորովին տարբեր չափերի։ Ցուցադրիր դրանք նույն ցանցում՝ aspect-ratio + object-fit: cover-ով։ մինի-նախագծում
  2. Ցուցադրիր object-fit-ի հինգ արժեքը՝ նույն նկարով։ Նկարագրիր ամեն մեկը։
  3. Գտիր դիմանկար, որտեղ cover-ը կտրում է գլուխը։ Ուղղիր object-position-ով։ մինի-նախագծում
  4. Համեմատիր height: 200px-ը և aspect-ratio: 4/3-ը՝ նեղացնելով պատուհանը։ Ուղարկիր երկու սքրինշոթ։
  5. Կառուցիր hero՝ ֆոնային նկարով և գրադիենտ շերտով՝ մեկ background-image հատկությամբ։ մինի-նախագծում
  6. Գտիր անվճար SVG պատկերակներ (օր.՝ Feather Icons)։ Ներդրիր երեքը inline և գունավորիր fill: currentColor-ով։ մինի-նախագծում
  7. Ստեղծիր կոճակ պատկերակով, որի գույնը փոխվում է :hover-ի ժամանակ։ մինի-նախագծում
  8. Պատրաստիր մեկ նկարի երեք չափ (400/800/1600) և գրիր srcset + sizes։ Ստուգիր DevTools-ով՝ որ ֆայլն է բեռնվում տարբեր լայնություններում։ մինի-նախագծում
  9. Փոխարկիր 5 նկար WebP-ի (squoosh.app)։ Համեմատիր քաշերը և գրիր տոկոսային տարբերությունը։
  10. Ամբողջ էջում ավելացրու loading="lazy" ներքևի նկարներին։ Չափիր բեռնման ժամանակը DevTools → Network-ում՝ առաջ և հետո։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
