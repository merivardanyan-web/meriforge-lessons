Անցումներ և անիմացիաներ

Կայքը ստանում է սահուն անցումներ, հերթով հայտնվող hero, ընդգծում կենտրոնից, բեռնման կմախք և prefers-reduced-motion։ Սա վերջին տնայինն է Դաս 22-ի նախագծից առաջ։

Ժամանակ՝ ~2 ժամ Սկսիր Դաս 20-ի արդյունքից Հաջորդը՝ ՏեխնոՄարկետ նախագիծ
Միայն անցածը

Օգտագործիր միայն Դաս 01–21-ը։ Անիմացիաները գործարկվում են էջի բեռնման և hover-ի ժամանակ․ ոլորումով կամ կտտոցով գործարկվողները JavaScript են։

00Ինչ պետք է ստացվի

Կայքը «կենդանանում» է․ կոճակները և քարտերը սահուն են փոխվում, hero-ի տարրերը հայտնվում են հերթով, իսկ բլոգում կա բեռնման կմախք։ Ամեն շարժում անջատվում է, եթե օգտագործողը համակարգում խնդրել է նվազեցնել շարժումը։

01Ինչ ես ստանում

starter/ └── content.md ← անցումներ, անիմացիաներ, կմախք

Սկսիր Դաս 20-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 20-ի օրինակը։

02Քայլեր

Քայլ 1 · Շարժման հարգանք՝ առաջինը

global.css — Դաս 21
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: .01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: .01ms !important;
        scroll-behavior: auto !important;
    }
}

Սա միակ տեղն է, որտեղ !important-ը արդարացված է․ օգտագործողի ընտրությունը ավելի կարևոր է, քան ցանկացած մեր կանոն։

Քայլ 2 · transition բազայում, ոչ :hover-ում

main.css
.card {
    transition: box-shadow var(--transition), transform var(--transition);
}

.card:hover {
    box-shadow: var(--shadow-md);
    transform: translateY(-4px);   /* ոչ margin-top — Դաս 21, «էժան» անիմացիա */
}
Փորձիր

Տեղափոխիր transition-ը .card:hover-ի մեջ։ Քարտը սահուն կբարձրանա, բայց կթռչի վար առանց անցման։ Վերադարձրու։

Կոճակների transition-ին ավելացրու transform, որ :active-ի 1px-ը նույնպես սահուն լինի։

Քայլ 3 · Ընդգծում կենտրոնից

main.css
.menu a:not(.btn) { position: relative; }

.menu a:not(.btn)::after {
    content: "";
    position: absolute;
    left: 14px;
    right: 14px;
    bottom: 6px;
    height: 2px;
    background: var(--accent);
    transform: scaleX(0);
    transform-origin: center;      /* փորձիր left և right */
    transition: transform var(--transition);
}

.menu a:not(.btn):hover::after,
.menu a[aria-current="page"]::after { transform: scaleX(1); }

Քայլ 4 · @keyframes

main.css
@keyframes fade-up {
    from { opacity: 0; transform: translateY(16px); }
    to   { opacity: 1; transform: translateY(0); }
}

.fade-up { animation: fade-up .5s ease-out both; }
.delay-1 { animation-delay: .1s; }
.delay-2 { animation-delay: .2s; }

Hero-ի h1-ին՝ fade-up, .lead-ին՝ fade-up delay-1, կոճակներին՝ fade-up delay-2։ Ջնջիր both-ը և նայիր, թե ինչ է կատարվում հետաձգման ընթացքում․ տարրը երևում է, անհետանում և նոր հայտնվում։

Ավելացրու նաև «Նոր» պիտակին pulse՝ 3 անգամ, ոչ անվերջ, և մոդալին՝ pop։

Քայլ 5 · Բեռնման կմախք

main.css
@keyframes shimmer {
    to { background-position: -200% 0; }
}

.skeleton {
    background: linear-gradient(90deg, var(--border) 25%, var(--bg) 50%, var(--border) 75%);
    background-size: 200% 100%;
    animation: shimmer 1.4s linear infinite;
}

Կմախքը դեկորատիվ է․ ամբողջ բլոկին՝ aria-hidden="true"։ JS բլոկում այն կերևա, մինչ գրառումները բեռնվում են սերվերից։

Քայլ 6 · Ստուգում

DevTools → Rendering → Emulate CSS prefers-reduced-motion: reduce։ Անցիր ամբողջ կայքով և գրիր, թե ինչ կոտրվեց (օրինակ՝ տարր, որը մնաց opacity: 0), և ինչպես ուղղեցիր։ Performance ներդիրով համեմատիր margin-top-ով և transform-ով hover-ը։

03Ընդունման ստուգաթերթ

Անցումներ

  • transition-ը բազային կանոնում է
  • Անիմացվում են միայն transform և opacity (և գույները)
  • Ժամանակը՝ --transition տոկենից

Անիմացիաներ

  • Hero-ի տարրերը հայտնվում են հերթով, առանց թարթելու
  • Պիտակը շարժվում է 3 անգամ, ոչ անվերջ
  • Կմախքը՝ aria-hidden

Հասանելիություն

  • prefers-reduced-motion-ը global.css-ում է
  • Շարժման անջատումով ոչինչ չի կորչում

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Տարրը մնում է անտեսանելիfrom {{ opacity: 0 }} և չկա animation-fill-mode: both, կամ անիմացիան չի սկսվում
Hover-ի ժամանակ մոտակա տարրերը շարժվում ենԱնիմացնում ես margin կամ width։ Օգտագործիր transform
Երկրորդ transform-ը ջնջեց առաջինըtransform-ը մեկ հատկություն է։ Գրիր երկուսը միասին՝ translateY(-4px) scale(1.02)

04Դասի մյուս վարժությունները

Սրանք Դաս 21-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Կառուցիր երկու նույնական քարտ՝ մեկում transition-ը բազայում, մյուսում՝ :hover-ում։ Նկարագրիր տարբերությունը։ մինի-նախագծում
  2. Համեմատիր margin-top: -4px-ը և transform: translateY(-4px)-ը։ Չափիր FPS-ը DevTools-ով։ մինի-նախագծում
  3. Ցուցադրիր, որ երկրորդ transform-ը ջնջում է առաջինը։ Ուղղիր։
  4. Ցուցադրիր հերթականության կարևորությունը՝ rotate + translateX երկու կարգով։
  5. Կառուցիր ընդգծում, որը աճում է ձախից, կենտրոնից և աջից (transform-origin)։ մինի-նախագծում
  6. Կառուցիր fade-up անիմացիա 5 քարտի համար՝ animation-delay-ի հերթականությամբ։ մինի-նախագծում
  7. Ջնջիր animation-fill-mode: both-ը և նկարագրիր, ինչ եղավ delay-ի ընթացքում։ մինի-նախագծում
  8. Կառուցիր skeleton-ցուցիչ բեռնման համար։ մինի-նախագծում
  9. Համեմատիր box-shadow-ը և drop-shadow-ը ոչ ուղղանկյուն SVG-ի վրա։
  10. Ավելացրու prefers-reduced-motion, միացրու այն DevTools-ում և անցիր ամբողջ նախագծով։ Գրիր ցուցակ՝ ի՞նչ կոտրվեց և ինչպես ուղղեցիր։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
