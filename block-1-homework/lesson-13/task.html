Նախագծերի էջ մակետից

Կառուցում ենք նոր էջ ճիշտ հերթականությամբ․ չափումներ → main.css ութ բաժնով և տոկեններով → HTML։

Ժամանակ՝ ~2 ժամ Սկսիր Դաս 12-ի արդյունքից Արդյունք՝ pages/projects.html + նոր main.css
Միայն անցածը

Օգտագործիր միայն Դաս 01–13-ը։ Մակետը համակարգչի համար է․ ադապտիվությունը Դաս 14-ում է։

00Ինչ պետք է ստացվի

Նոր էջ՝ «Նախագծեր», որը կառուցում ես մակետից։ Ամբողջ էջի տեսքը որոշվում է main.css-ի տոկեններով, իսկ HTML-ը գրվում է վերջում։

01Ինչ ես ստանում

starter/ ├── mockup.jpg ← մակետը ├── content.md ← չափումների աղյուսակ և տեքստեր └── images/ └── project-compare.jpg

Սկսիր Դաս 12-ի քո կայքից։ Եթե այն չունես, վերցրու Դաս 12-ի օրինակը։

02Քայլեր

Քայլ 1 · Չափումների աղյուսակ

Բացիր mockup.jpg-ը և համեմատիր content.md-ի աղյուսակի հետ։ Իրական աշխատանքում աղյուսակը դու ես լրացնում Figma-ում կամ DevTools-ով (Դաս 13, բաժին 04)։ Ուշադրություն դարձրու․ բոլոր հեռավորությունները 10-ի բազմապատիկ են, տառաչափերը՝ չորսը։

Քայլ 2 · main.css-ը ութ բաժնով

1. Դիզայնի արժեքներ :root — գույներ + --wall, --gap 2. Բազա body 3. Կմախք section, .row, .col — միայն տոկեններով 4. Տիպոգրաֆիա h1–h4, .text-muted 5. Հեռավորություններ .gap-*, .mb-* 6. Ֆոներ .bg-* 7. Կոմպոնենտներ .btn, .pill, .box, .card, ֆորմա, աղյուսակ 8. Բաժիններ header, footer, #intro
main.css — բաժին 3
section { padding: 40px 0; }
.row    { padding: 0 calc(var(--wall) - var(--gap)); }
.col    { padding: var(--gap); }
Ստուգում

Փոխիր --wall-ը 100px և --gap-ը 20px։ Բոլոր էջերի պատերը և սյուների միջև բացակները պետք է փոխվեն միանգամից։ Վերադարձրու 60px և 10px։

Քայլ 3 · Եվ միայն հիմա՝ HTML

Ստեղծիր pages/projects.html․ վերնագրի բաժին (bg-surface) և չորս քարտ w-33 սյուներում։ Հաշվիր, թե քանի նոր CSS կանոն ստիպված եղար ավելացնել։ Եթե main.css-ը ճիշտ է, պատասխանը մոտ զրո է։

Քայլ 4 · Քարտը BEM-ով

BEM անուններ
<article class="wrapper card">
    <img>
    <div class="card__body">
        <h3 class="card__title">Այս կայքը</h3>
        <p class="card__text">...</p>
    </div>
    <div class="card__footer">...</div>
</article>

Համեմատիր նախորդ տարբերակի հետ (title-4, text-muted)։ Ո՞րն է ավելի հեշտ կարդալ HTML-ում, և որն է ավելի հեշտ փոխել CSS-ում։

Քայլ 5 · Մենյու

Մենյուում «Դասացուցակ»-ը և «Համեմատություն»-ը փոխարինիր մեկ «Նախագծեր» կետով, իսկ գլխավոր էջի «Բոլոր նախագծերը» հղումը տար projects.html։

03Ընդունման ստուգաթերթ

Հերթականություն

  • Չափումների աղյուսակը կարդացված է մինչև կոդը
  • main.css-ը ութ բաժնով է
  • HTML-ը գրված է CSS-ից հետո

Տոկեններ

  • --wall-ը և --gap-ը :root-ում են
  • .row-ը և .col-ը օգտագործում են միայն դրանք
  • Փոփոխելիս ամբողջ կայքը հարմարվում է

Էջ

  • Համապատասխանում է մակետին
  • Քարտը BEM անուններով է
  • Մենյուն թարմացված է բոլոր էջերում

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Պատը 60px չէ, այլ 70px.row-ի padding-ին գումարվում է .col-ի padding-ը։ Դրա համար՝ calc(var(--wall) - var(--gap))
Էջի համար շատ նոր կանոններ պետք եղանԻնչ-որ արժեք գրված է ուղիղ էջի համար, ոչ կոմպոնենտում։ Տեղափոխիր այն բաժին 7

04Դասի մյուս վարժությունները

Սրանք Դաս 13-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Վերցրու ցանկացած կայք, որը քեզ դուր է գալիս։ Չափիր DevTools-ով և լրացրու չափումների աղյուսակը՝ վեց կատեգորիայով։
  2. Գտիր դրա հեռավորությունների սանդղակը։ Արդյո՞ք դա 4-ի կամ 10-ի բազմապատիկ է։
  3. Հաշվիր՝ քանի՞ տարբեր տառաչափ է օգտագործվում։ Եթե 6-ից շատ է, առաջարկիր, թե ինչպես կկրճատեիր։
  4. Կառուցիր :root բլոկ այդ կայքի գույներով։ մինի-նախագծում
  5. Այս դասի մակետի հիման վրա գրիր ամբողջ main.css-ը՝ ութ բաժնով, ինչպես 05-րդ բաժնում։ մինի-նախագծում
  6. Եվ միայն դրանից հետո գրիր HTML-ը։ Հաշվիր՝ քանի՞ նոր CSS կանոն ստիպված եղար ավելացնել։ մինի-նախագծում
  7. Փոխիր --wall-ը և --gap-ը։ Համոզվիր, որ ամեն ինչ հարմարվում է ինքնաբերաբար։ մինի-նախագծում
  8. Վերաշարադրիր ապրանքի քարտը BEM-ով։ Համեմատիր երկու տարբերակի HTML-ը և CSS-ը։ Ո՞րն է քեզ ավելի հարմար և ինչու։ մինի-նախագծում
  9. Փորձիր .row-ի Բ տարբերակը (max-width: 1200px; margin: 0 auto)։ Համեմատիր լայն էկրանին։
  10. Գտիր իրական մակետ (Dribbble, Behance) և կրկնիր այն մեր համակարգով։ Նախ չափումների աղյուսակը, հետո CSS-ը, հետո HTML-ը։

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
