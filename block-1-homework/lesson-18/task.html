Նավիգացիա․ dropdown և բուրգեր

Header-ը դառնում է ամբողջական նավիգացիա՝ aria-current, dropdown :focus-within-ով և բուրգեր-մենյու առանց JavaScript-ի։

Քայլ 2 · aria-current

Ջնջիր բոլոր class="is-active"-երը և դրանց փոխարեն գրիր aria-current="page"։ Ոճը՝ ատրիբուտով սելեկտորով (Դաս 06)․ .menu a[aria-current="page"]։ Մեկ ատրիբուտ, երկու օգուտ․ էկրանընթերցիչը ասում է «ընթացիկ էջ», իսկ CSS-ը ոճավորում է առանց լրացուցիչ դասի։

Քայլ 3 · Dropdown

main.css
.has-sub { position: relative; }

.submenu {
    position: absolute;
    top: calc(100% + 4px);
    left: 0;
    opacity: 0;
    visibility: hidden;          /* display: none-ը չի անիմացվում */
    transform: translateY(-6px);
    transition: opacity .15s, transform .15s, visibility .15s;
}

.has-sub:hover .submenu,
.has-sub:focus-within .submenu {  /* ստեղնաշարի համար */
    opacity: 1;
    visibility: visible;
    transform: translateY(0);
}
Փորձիր

Ջնջիր :focus-within-ը և անցիր մենյուն Tab-ով։ Ենթամենյուի հղումները ստանում են ֆոկուս, բայց չեն երևում։ Վերադարձրու։

Քայլ 4 · Բուրգեր checkbox-ով

main.css
/* Համակարգչում */
.nav-toggle { display: none; position: absolute; opacity: 0; }

@media (max-width: 768px) {
    .burger     { display: flex; }

    }

    .nav-toggle:checked ~ .row .menu {

        visibility: visible;
    }

    .nav-toggle:checked ~ .row .burger span:nth-child(1) { transform: translateY(7px) rotate(45deg); }
    .nav-toggle:checked ~ .row .burger span:nth-child(2) { opacity: 0; }
    .nav-toggle:checked ~ .row .burger span:nth-child(3) { transform: translateY(-7px) rotate(-45deg); }
}
Ինչու checkbox-ը .row-ից առաջ

~ սելեկտորը գտնում է միայն հետագա եղբայրներին։ Checkbox-ը և .row-ը header-ի երեխաներ են, ուստի .nav-toggle:checked ~ .row .menu-ը հասնում է մենյուին, որքան էլ այն խորը լինի .row-ի ներսում։

Ուշադրություն․ ul-երն ունեն margin-bottom: 16px, և fixed մենյուն կկարճանա 16px-ով։ Տուր .menu-ին margin-bottom: 0։

Քայլ 5 · Ստուգում ստեղնաշարով

Անցիր ամբողջ էջը միայն ստեղնաշարով 1280px-ում և 375px-ում։ Հեռախոսում բուրգերը բացվում է Space-ով։ Գրիր հինգ բան, որ CSS-ի տարբերակը չի կարող անել (Esc, դրսում սեղմել, հղմանը սեղմելուց հետո փակվել, ...)։ Դրանք JS բլոկում են։

03Ընդունման ստուգաթերթ

Header

  • Լոգո, 5 հղում, կոճակ
  • Ընթացիկ էջը՝ aria-current, ոչ դաս
  • Skip link-ը առաջինն է ստանում ֆոկուս

Dropdown

  • Բացվում է մկնիկով և Tab-ով
  • Թաքնված է visibility-ով և անիմացվում է

Բուրգեր

  • × դառնում է բացված վիճակում
  • Աշխատում է Tab + Space-ով
  • Փակ մենյուի հղումները ֆոկուս չեն ստանում
  • Պանելը հասնում է էկրանի ներքև

Հաճախ հանդիպող սխալներ

ՍխալԻնչպես ուղղել
Բուրգերը սեղմվում է, բայց մենյուն չի բացվումCheckbox-ը .row-ից առաջ չէ, կամ for-ը և id-ն տարբեր են
Dropdown-ը փակվում է, երբ մկնիկը տանում ես դեպի ենթամենյուԵնթամենյուի և հղման միջև մեծ բացակ կա
Համակարգչում Tab-ը կանգ է առնում անտեսանելի տարրի վրաCheckbox-ը տեսանելի չէ, բայց ֆոկուս է ստանում։ Համակարգչում՝ display: none
Մենյուի պանելը չի հասնում ներքևul-ի margin-bottom-ը

04Դասի մյուս վարժությունները

Սրանք Դաս 18-ի տնային աշխատանքի կետերն են։ «մինի-նախագծում» նշվածները արդեն կատարել ես վերևի քայլերում, մնացածը կատարիր առանձին ֆայլերում կամ նույն թղթապանակում։

  1. Կառուցիր ամբողջական header՝ լոգո, 5 հղում, կոճակ։ մինի-նախագծում
  2. Ավելացրու aria-current="page"։ Ցուցադրիր, ինչպես ես ոճավորում այն առանց լրացուցիչ դասի։ մինի-նախագծում
  3. Ավելացրու skip link։ Ցույց տուր, ինչպես է այն հայտնվում Tab-ի ժամանակ։ մինի-նախագծում
  4. Կառուցիր dropdown։ Ջնջիր :focus-within-ը և նկարագրիր, ինչ կորավ։ մինի-նախագծում
  5. Համեմատիր display: none-ը և visibility: hidden + opacity-ը dropdown-ի համար։ Ո՞րն է անիմացվում։ մինի-նախագծում
  6. Կառուցիր բուրգերի պատկերակ, որը վերածվում է ✕-ի։ Ուղարկիր երկու սքրինշոթ։ մինի-նախագծում
  7. Իրականացրու checkbox-ի հնարքը։ Ցուցադրիր, որ այն աշխատում է Tab-ով և Space-ով։ մինի-նախագծում
  8. Գրիր ցուցակ՝ ի՞նչ 5 բան չի աշխատում CSS-ի տարբերակում։ (Ակնարկ՝ Esc, հղումին սեղմելը, դրսում սեղմելը...) մինի-նախագծում
  9. Կառուցիր footer՝ 3 սյուն, որը հեռախոսում դառնում է 1։ Ստուգիր հղումների կոնտրաստը մուգ ֆոնի վրա։ մինի-նախագծում
  10. Անցիր ամբողջ էջով միայն ստեղնաշարով։ Նկարագրիր ամեն խնդիր, որ գտար։ մինի-նախագծում

05Համեմատիր օրինակի հետ

Նախ ստուգաթերթը, հետո օրինակը

Երբ բաժին 03-ի բոլոր կետերը նշված են, բացիր օրինակը և քո էջը կողք կողքի։ Բացիր երկուսի կոդն էլ խմբագրիչում։ Գտիր մեկ բան, որ դու արել ես այլ կերպ, և մտածիր՝ որն է ավելի հասկանալի և ինչու։ Քո լուծումը կարող է տարբերվել և լինել ճիշտ։
