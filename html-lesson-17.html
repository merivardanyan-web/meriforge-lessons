01Ե՞րբ ստեղծել կոմպոնենտ

ԻրավիճակԻ՞նչ անել
Հանդիպում է 1 անգամUtility-դասեր՝ flex gap-10 mb-20
Հանդիպում է 2–3 անգամԴեռ utility, բայց ուշադիր հետևիր
4+ անգամԿոմպոնենտ՝ սեփական դասով
Ունի վիճակներ (hover, active)Կոմպոնենտ
Ունի տարբերակներ (մեծ/փոքր, կարմիր/կապույտ)Կոմպոնենտ + մոդիֆիկատորներ
Հիշեցում Դաս 13-ից

Մենք չենք ընտրում «utility կամ BEM»։ Օգտագործում ենք երկուսն էլ՝

.row, .col, .w-33, .mb-20 — կմախք և բացակներ
.btn, .card, .badge — կրկնվող կոմպոնենտներ

Այսօր կենտրոնանում ենք երկրորդի վրա։

Հակառակ ծայրահեղությունը

Կոմպոնենտ ամեն բանի համար նույնպես սխալ է։ Եթե ունես .hero-title, .about-title, .contact-title և բոլորը նույնն են՝ դա ուղղակի h2 է։

Կոմպոնենտն արժեք ունի, երբ այն իսկապես կրկնվում է և ունի սեփական տրամաբանություն։

02BEM անվանակարգում

.card ← Բլոկ (ինքնուրույն կոմպոնենտ) .card__title ← Էլեմենտ (մաս է, առանձին չի ապրում) .card--featured ← Մոդիֆիկատոր (տարբերակ) __ երկու ընդգծում → «-ի մասն է» -- երկու գծիկ → «այսպիսի տարբերակ»
գործնականում
<article class="card card--featured">
    <span class="card__badge">Հիթ</span>
    <picture class="card__media ratio-4-3">...</picture>
    <div class="card__body">
        <h3 class="card__title">Նոութբուք Pro</h3>
        <p class="card__price">450 000 ֏</p>
    </div>
</article>
Երկու տարածված սխալ

1. Ներդրվածությունն արտացոլել անվան մեջ
.card__body__title ❌ → .card__title ✅
BEM-ում կա միայն մեկ մակարդակի էլեմենտ, որքան էլ խորն է HTML-ը։

2. Մոդիֆիկատորը առանց բլոկի
class="card--featured" ❌ → class="card card--featured" ✅
Մոդիֆիկատորը միայն փոփոխում է, չի փոխարինում։

Ինչո՞ւ ոչ պարզապես ներդրված սելեկտորներ

.card h3 { ... } — կաշխատի։ Բայց՝

1. Եթե քարտի ներսում հայտնվի ուրիշ h3, այն էլ կստանա ոճերը։
2. Սպեցիֆիկությունն աճում է, և հետո դժվար է վերագրել (Դաս 6)։
3. Կարդալով class="card__title"՝ անմիջապես գիտես, որտեղ փնտրել CSS-ը։

BEM-ի բոլոր սելեկտորները մեկ դասի են՝ սպեցիֆիկությունը 0-1-0։ Հարթ և կանխատեսելի։

03Կոճակների համակարգ

1. Բազա
.btn {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    gap: 8px;

    padding: 12px 24px;
    min-height: 44px;              /* սեղմելի տարածք ⭐ */

    border: 1px solid transparent;  /* որ hover-ին չցատկի */
    border-radius: 6px;

    font-weight: 700;
    white-space: nowrap;
    cursor: pointer;
    transition: background-color .15s, color .15s, border-color .15s;
}
2. Տեսակներ
/* Հիմնական գործողություն — էջում սովորաբար մեկ հատ */
.btn--primary {
    background: var(--secondary);
    color: var(--on-dark);
}
.btn--primary:hover { background: #00253f; }

/* Երկրորդական */
.btn--outline {
    background: transparent;
    color: var(--secondary);
    border-color: var(--secondary);
}
.btn--outline:hover {
    background: var(--secondary);
    color: var(--on-dark);
}

/* Երրորդական — գրեթե հղում */
.btn--ghost {
    background: transparent;
    color: var(--secondary);
}
.btn--ghost:hover { background: var(--bg); }

/* Վտանգավոր գործողություն */
.btn--danger {
    background: #c62828;
    color: #ffffff;
}
3. Չափեր և ձևեր
.btn--sm { padding: 8px 16px;  min-height: 36px; font-size: 0.875rem; }
.btn--lg { padding: 16px 32px; min-height: 54px; font-size: 1.125rem; }

.btn--block { width: 100%; }
.btn--icon  { padding: 0; width: 44px; }   /* քառակուսի */
4. Վիճակներ
/* Ֆոկուս — ստեղնաշարի համար ⭐ */
.btn:focus-visible {
    outline: 2px solid var(--secondary);
    outline-offset: 2px;
}

/* Սեղմված */
.btn:active { transform: translateY(1px); }

/* Անջատված */
.btn:disabled,
.btn.is-disabled {
    opacity: .5;
    cursor: not-allowed;
    pointer-events: none;
}
Չորս վիճակի կանոն

Ամեն ինտերակտիվ էլեմենտ պիտի ունենա՝
1. Սովորական — հասկանալի է, որ սեղմելի է
2. :hover — մկնիկի համար
3. :focus-visible — ստեղնաշարի համար
4. :active — սեղմման պահին

Ամենահաճախ մոռացվողը երրորդն է։ Առանց դրա ստեղնաշարով նավարկողը չգիտի՝ որտեղ է գտնվում։

button թե՞ a

<button> — երբ ինչ-որ բան կատարվում է․ բացվում է մոդալ, ուղարկվում է ֆորմա, ապրանքն ավելանում է զամբյուղ։

<a href> — երբ անցնում ես ուրիշ տեղ․ ուրիշ էջ, ուրիշ բաժին։

Երկուսն էլ կարող են ունենալ .btn դասը և նույն տեսքը։ Բայց էկրանընթերցիչը հայտարարում է «կոճակ» կամ «հղում», և օգտագործողը գիտի՝ ինչ սպասել։

04Ստվերներ

սանդղակ, ոչ պատահական արժեքներ
:root {
    --shadow-sm: 0 1px 3px  rgba(0,0,0,.08);
    --shadow-md: 0 4px 12px rgba(0,0,0,.10);
    --shadow-lg: 0 10px 28px rgba(0,0,0,.14);
}

.card       { box-shadow: var(--shadow-sm); }
.card:hover { box-shadow: var(--shadow-md); }
.dropdown   { box-shadow: var(--shadow-lg); }
box-shadow: 0 4px 12px rgba(0,0,0,.1) │ │ │ │ │ │ │ └─ գույն և թափանցիկություն │ │ └─ լղոզում (blur) │ └─ ուղղահայաց տեղաշարժ └─ հորիզոնական տեղաշարժ
Երկու կանոն բնական ստվերի համար

1. Հորիզոնական տեղաշարժը գրեթե միշտ 0 է — լույսը գալիս է վերևից։
2. Որքան մեծ է ուղղահայաց տեղաշարժը, այնքան մեծ պիտի լինի լղոզումը։ Մոտավոր հարաբերությունը՝ լղոզումը ≈ տեղաշարժը × 3։

0 2px 30px — տարօրինակ է երևում, կարծես օբյեկտը լողում է։

05::before և ::after

Կեղծ էլեմենտներ՝ CSS-ով ստեղծված «երեխաներ»։ HTML-ում դրանք չկան։

content-ը պարտադիր է
.el::before {
    content: "";      /* առանց սրա ոչինչ չի երևա ⭐ */
}
չորս գործնական օրինակ
/* 1. Ցուցակ ✓ նշաններով */
.check-list li {
    position: relative;
    padding-left: 28px;
}
.check-list li::before {
    content: "✓";
    position: absolute;
    left: 0;
    color: #0f7b4f;
    font-weight: 700;
}

/* 2. Գիծ վերնագրի տակ */
.section-title { position: relative; padding-bottom: 12px; }
.section-title::after {
    content: "";
    position: absolute;
    left: 0;
    bottom: 0;
    width: 48px;
    height: 3px;
    background: var(--secondary);
}

/* 3. Պարտադիր դաշտ */
.required::after {
    content: " *";
    color: #c62828;
}

/* 4. Bread crumbs — բաժանարար ամեն երկրորդից սկսած */
.crumbs li + li::before {
    content: "/";
    margin: 0 8px;
    color: var(--muted);
}
Երկու սահմանափակում

1. ::before/::after չեն աշխատում փոխարինվող էլեմենտների վրա՝ img, input, br, hr։ Դրանք սեփական բովանդակություն չունեն։ Լուծում՝ փաթեթավորիր span-ի կամ picture-ի մեջ։

2. content-ի տեքստը անհասանելի է ընտրելու և պատճենելու համար, և էկրանընթերցիչները այն կարդում են անհետևողականորեն։ Կարևոր տեղեկություն երբեք մի՛ դիր content-ի մեջ։

06Ապրանքի քարտ · ամբողջական

Հավաքում ենք ամեն ինչ՝ Դաս 11-ի margin-top: auto, Դաս 15-ի պիտակը, Դաս 16-ի aspect-ratio-ն։

HTML
<div class="col w-33 w-md-50 w-sm-100">
    <article class="card">

        <span class="card__badge">-30%</span>

        <picture class="card__media ratio-4-3">
            <img class="img-cover" src="images/laptop.jpg"
                 alt="Նոութբուք Pro 14"
                 width="800" height="600" loading="lazy">
        </picture>

        <div class="card__body">
            <h3 class="card__title">Նոութբուք Pro 14</h3>
            <p class="card__meta">16 ԳԲ / 512 ԳԲ SSD</p>

            <div class="card__footer">
                <p class="card__price">450&nbsp;000 ֏</p>
                <button class="btn btn--primary btn--sm">Գնել</button>
            </div>
        </div>

    </article>
</div>
CSS
.card {
    position: relative;         /* խարիսխ պիտակի համար — Դաս 15 */
    display: flex;

    height: 100%;

Չորս դասի արդյունքը մեկ կոմպոնենտում

position: relative → Դաս 15
flex-direction: column + margin-top: auto → Դաս 11
flex-grow: 1 → Դաս 12
aspect-ratio + object-fit → Դաս 16

Ոչ մի նոր հատկություն։ Պարզապես ճիշտ հավաքված։

07Խաղահրապարակ

Սեղմիր Tab՝ ֆոկուսի վիճակը տեսնելու համար
Փորձիր

1. Ջնջիր .btn { border: 1px solid transparent }-ը և սավառնիր .btn--outline-ի վրայով։
2. Ջնջիր .card__footer { margin-top: auto }-ը։
3. Ջնջիր .check-list li::before { content: "✓" }-ի content-ը։
4. Փոխիր --shadow-md-ը 0 2px 30px-ի։

08Դասարանական

Կառուցում ենք կոմպոնենտների գրադարան՝ առանձին էջ, որտեղ հավաքված են բոլոր տարրերը։

  1. Ստեղծիր components.html ֆայլ
  2. Ավելացրու main.css-ում ստվերների փոփոխականները
  3. Կառուցիր .btn բազան և չորս տեսակ
  4. Ավելացրու երեք չափ և չորս վիճակ
  5. Կառուցիր .card-ը BEM-ով
  6. Ավելացրու .card--featured մոդիֆիկատոր
  7. Կառուցիր .badge երեք տարբերակով
  8. Ավելացրու .section-title՝ ::after գծով
  9. Ստուգիր ամեն կոճակը Tab-ով
Ինչո՞ւ առանձին էջ

components.html-ը քո ոճերի ուղեցույցն է։ Այնտեղ բոլոր կոմպոնենտները երևում են կողք կողքի, և անմիջապես նկատում ես անհամապատասխանությունները՝ մեկը 6px կլորացում ունի, մյուսը՝ 8px։

Իրական թիմերում այս էջը կոչվում է style guide կամ design system, և այն ամենակարևոր փաստաթղթերից է։ Դաս 22–23-ի նախագծում այն շատ կօգնի։

09Տնային աշխատանք

  1. Կառուցիր components.html՝ բոլոր կոճակների տեսակներով, չափերով և վիճակներով։
  2. Ցուցադրիր չորս վիճակը մեկ կոճակի վրա։ Ուղարկիր չորս սքրինշոթ։
  3. Ջնջիր :focus-visible-ը և փորձիր նավարկել Tab-ով։ Նկարագրիր զգացողությունը։
  4. Վերաշարադրիր Դաս 16-ի քարտը ամբողջովին BEM-ով։ Համեմատիր utility տարբերակի հետ։
  5. Ստեղծիր .card--horizontal մոդիֆիկատոր՝ նկարը ձախում, տեքստը աջում։
  6. Կառուցիր ստվերների սանդղակ՝ երեք մակարդակ։ Ցուցադրիր դրանք երեք քարտի վրա։
  7. Ցուցադրիր, ինչ է լինում, երբ լղոզումը փոքր է տեղաշարժից՝ 0 10px 3px։
  8. Կառուցիր ✓ ցուցակ և bread crumbs՝ միայն ::before-ով, առանց լրացուցիչ HTML-ի։
  9. Ավելացրու ::after գիծ բոլոր բաժինների վերնագրերին։
  10. Անցիր ամբողջ նախագծով և գտիր բոլոր կրկնվող տարրերը։ Կազմիր ցուցակ՝ ի՞նչը պիտի դառնա կոմպոնենտ և ինչու։

Կոմպոնենտի ստուգաթերթ

  • Ունի չորս վիճակ՝ սովորական, hover, focus-visible, active
  • Սեղմելի տարածքը ≥ 44×44px
  • Չի ցատկում hover-ի ժամանակ
  • Կոնտրաստը ≥ 4.5:1 բոլոր վիճակներում
  • Անունները BEM-ով են
  • Մոդիֆիկատորը գրված է բլոկի հետ
  • Չի կախված իր տեղից էջում
  • Աշխատում է ցանկացած լայնության .col-ում
  • Երկար և կարճ տեքստի դեպքում էլ ճիշտ է երևում
