# ՏեխնոՄարկետ · նոր տեքստեր (Առաջադրանք 2)

## Մուտք և գրանցում — PHP Դաս 16
- Սխալ էլ. հասցե կամ գաղտնաբառ   ← ⭐ նույնը երկու դեպքում
- Չափազանց շատ փորձեր։ Փորձեք 15 րոպեից։
- Բարի գալուստ, {անուն}
- Այս էլ. հասցեով արդեն կա հաշիվ
- Անունը՝ 2-ից 100 նիշ · Ստուգիր էլ. հասցեն · Գաղտնաբառը՝ առնվազն 8 նիշ · Գաղտնաբառերը չեն համընկնում
- Չափազանց շատ գրանցումներ։ Փորձեք մեկ ժամից։
- Հաշիվը պետք է պատվերների պատմության համար։ Գնել կարելի է նաև առանց դրա։

## Դերեր
- Այս էջը հասանելի է միայն աշխատակիցներին (403)
- Արխիվացնել կարող է միայն ադմինը (403)
- Դու մենեջեր ես․ կարող ես ավելացնել և խմբագրել, իսկ արխիվացնել կարող է միայն ադմինը։

## CSRF և սխալներ — PHP Դաս 15–17
- Ձևաթուղթը ժամկետանց է։ Թարմացրեք էջը և փորձեք կրկին։ (419)
- Մեթոդը չի թույլատրվում (405)
- Սխալ JSON (400)
- Տվյալները վավեր չեն (422)
- Տեխնիկական խնդիր։ Փորձեք ավելի ուշ։ (500, APP_DEBUG=false)
