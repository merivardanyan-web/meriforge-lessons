# ՏեխնոՄարկետ · PHP + MySQL (Բլոկ 3 · Առաջադրանք 1)

Բլոկ 1–2-ի խանութը, որի տվյալները հիմա բազայում են, իսկ էջերը կառուցում է PHP-ն։
Կոդը օգտագործում է միայն PHP Դաս 1–11-ը․ ֆունկցիաներ, շաբլոններ, ֆորմաներ, սեսիաներ, PDO։

## Գործարկում

**Laragon** (PHP Դաս 1)

1. Պատճենիր թղթապանակը `C:\laragon\www\technomarket\`
2. HeidiSQL → File → Run SQL file → `sql/schema.sql`, հետո `sql/seed.sql`
3. Պատճենիր `config.example.php` → `config.php` և լրացրու բազայի տվյալները
4. Բաց արա http://technomarket.test

**Առանց Laragon-ի**

```bash
mysql -u root < sql/schema.sql
mysql -u root < sql/seed.sql
cp config.example.php config.php
php -S localhost:8000
```

## Անվտանգության որոշումներ

- Ամեն ելք՝ `e()`-ով, արտաքին հղումներ՝ `safeUrl()`-ով (Դաս 5)
- Ամեն SQL՝ prepared statement, դասավորումը՝ սպիտակ ցուցակով (Դաս 10)
- Ամեն վիճակ փոխող գործողություն՝ POST, ապա 303 վերահղում (Դաս 6, 7)
- `back` պարամետրը ընդունում է միայն ներքին ուղի (Դաս 7)
- Նկարի տիպը՝ `finfo`-ով, անունը՝ պատահական (Դաս 7)
- Պատվերը և պահեստը՝ մեկ տրանզակցիայում, `stock >= :qty` պայմանով (Դաս 11)
- `config.php`-ն `.gitignore`-ում է (Դաս 10)
