Ինչպես է աշխատում վեբը

Առաջին դասը։ Հասկանում ենք, թե ինչ է կատարվում, երբ բացում ես կայք, տեղադրում ենք գործիքները և գրում ենք առաջին էջը, որը կաշխատի իսկական բրաուզերում։

Նախապայման՝ չկա Բլոկ 1 · HTML հիմունքներ Արդյունք՝ առաջին էջը

00Ի՞նչ ենք սովորելու այսօր

  • Ի՞նչ է կատարվում, երբ մուտքագրում ես կայքի հասցեն
  • HTML, CSS և JavaScript — երեք տարբեր դեր
  • VS Code և Live Server
  • Նախագծի ճիշտ կառուցվածքը
  • Էջի կմախքը՝ <html>, <head>, <body>
  • Թեգեր, ատրիբուտներ, ներդրվածություն
  • DevTools — բրաուզերի ռենտգենը

01Ի՞նչ է կատարվում, երբ բացում ես կայք

Մուտքագրում ես example.am և սեղմում Enter։ Հաջորդ մեկ վայրկյանում տեղի է ունենում հետևյալը։

Քո համակարգիչը Սերվերը (բրաուզեր) (ուրիշի համակարգիչ) │ │ │ «Տո՛ւր example.am էջը» │ │ ────────────────────────────────────► │ │ │ │ index.html + style.css │ │ ◄──────────────────────────────────── │ │ │ Բրաուզերը կարդում է ֆայլերը և նկարում է էջը էկրանին
Կարևոր հասկացողություն

Սերվերը հատուկ կախարդական սարք չէ։ Դա սովորական համակարգիչ է, որը միշտ միացած է և ֆայլեր է տալիս, երբ նրանից խնդրում են։ Քո համակարգիչն էլ կարող է սերվեր դառնալ — հենց դա կանենք Live Server-ով։

Այսինքն՝ կայքը ֆայլերի հավաքածու է։ Դու գրում ես այդ ֆայլերը, բրաուզերը կարդում է դրանք։ Ամբողջ դասընթացը հենց այդ ֆայլերը գրելու մասին է։

02Երեք լեզու, երեք դեր

ԼեզուԴերըՀամեմատություն
HTMLԻ՞նչ կա էջումԿմախք
CSSԻնչպիսի՞ն է այնՀագուստ
JavaScriptԻ՞նչ է անումՈւղեղ

Առաջին 5 դասին զբաղվում ենք միայն կմախքով։ Հագուստը կսկսվի 6-րդ դասից, ուղեղը՝ երկրորդ բլոկում։

Հաճախ շփոթում են

HTML-ը ծրագրավորման լեզու չէ։ Այնտեղ չկան պայմաններ, ցիկլեր, հաշվարկներ։ Դա նշագրման լեզու է․ դու պարզապես ասում ես՝ «սա վերնագիր է, սա պարբերություն է, սա նկար է»։ Դրա համար այն արագ է սովորվում։

03Գործիքները

VS Code

Անվճար խմբագրիչ Microsoft-ից։ Ներբեռնիր code.visualstudio.com-ից։ Դա այն ծրագիրն է, որտեղ կանցկացնես հաջորդ 72 դասը։

Երկու պարտադիր ընդլայնում

VS Code → ձախից քառակուսիների պատկերակը (Extensions) → որոնիր և տեղադրիր․

ԸնդլայնումԻնչի համար
Live ServerԲացում է էջը և ինքնաբերաբար թարմացնում պահպանելիս
Auto Rename TagԹեգի անունը փոխելիս ուղղում է նաև զույգը
Ինչպես գործարկել Live Server-ը

Աջ սեղմում index.html-ի վրա → Open with Live Server։ Կբացվի բրաուզերը http://127.0.0.1:5500 հասցեով։

Հիմա ամեն անգամ, երբ պահպանում ես ֆայլը (Ctrl + S), էջն ինքնաբերաբար թարմանում է։ Ձեռքով F5 սեղմել պետք չէ։

Բրաուզեր

Chrome կամ Firefox։ Կարևորը՝ ունենան DevTools, որին կանդրադառնանք 08-րդ բաժնում։

04Նախագծի կառուցվածքը

Ամեն նոր նախագիծ սկսվում է նույն կառուցվածքով։ Այս ձևը կպահենք բոլոր 72 դասերի ընթացքում։

my-project/ ├── index.html ← գլխավոր էջը ├── css/ │ ├── global.css ← կհայտնվի 6-րդ դասին │ └── main.css ← կհայտնվի 6-րդ դասին └── images/ ← բոլոր նկարները
Երեք խիստ կանոն անվանման համար

1. Միայն լատինատառ։ Ոչ մի հայերեն կամ ռուսերեն տառ ֆայլի անվան մեջ։
2. Ոչ մի բացատ։ Բացատի փոխարեն՝ գծիկ․ about-us.html, ոչ about us.html։
3. Միայն փոքրատառ։ Սերվերի համար Logo.png և logo.png երկու տարբեր ֆայլ են։

Ինչո՞ւ հենց index.html

Դա պայմանավորվածություն է․ երբ բացում ես կայքի հասցեն առանց ֆայլի անվան, սերվերն ինքնաբերաբար տալիս է index.html-ը։ Այդ պատճառով գլխավոր էջը միշտ այդպես է կոչվում։

05Էջի կմախքը

Ամեն HTML ֆայլ սկսվում է նույն կառուցվածքով։ Այն կգրես հարյուրավոր անգամ, ուստի հասկանանք ամեն տողը։

index.html
<!DOCTYPE html>
<html lang="hy">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Իմ առաջին էջը</title>
</head>

<body>
    <h1>Բարև, աշխարհ</h1>
</body>

</html>
ՏողԻնչ է անում
<!DOCTYPE html>«Սա ժամանակակից HTML է»։ Առանց սրա բրաուզերն անցնում է հին ռեժիմի
<html lang="hy">Ամբողջ էջի պատյանը։ lang-ը ասում է՝ ի՞նչ լեզվով է բովանդակությունը
<head>Տեղեկություն էջի մասին։ Էկրանին չի երևում
<meta charset="UTF-8">Հայերեն տառերի աջակցություն
<meta name="viewport">Հեռախոսում ճիշտ ցուցադրում
<title>Ներդիրի վրայի տեքստը
<body>Այն ամենը, ինչ երևում է էկրանին
Առանց charset-ի

Հայերեն տեքստը կվերածվի անհասկանալի նշանների՝ Ô²Õ¡Ö€Ö‡։ Սա ամենահաճախ հանդիպող սկսնակի խնդիրն է։ <meta charset="UTF-8">-ը պիտի լինի <head>-ի ամենասկզբում։

Արագ ձև

VS Code-ում դատարկ .html ֆայլում գրիր ! և սեղմիր Tab։ Ամբողջ կմախքը կհայտնվի ինքնաբերաբար։ Բայց նախ մի քանի անգամ գրիր ձեռքով — որ հասկանաս, ոչ միայն օգտվես։

06Թեգեր և ատրիբուտներ

բացվող թեգ բովանդակություն փակվող թեգ │ │ │ ▼ ▼ ▼ <h1> Բարև, աշխարհ </h1> └──┬──┘ └──┬──┘ անունը՝ h1 նույն անունը + /

Թեգերի մեծ մասն ունի զույգ՝ բացվող և փակվող։ Բայց կան նաև ինքնափակվող թեգեր, որոնք բովանդակություն չունեն։

երկու տեսակ
<!-- Զույգ թեգեր -->
<h1>Վերնագիր</h1>
<p>Պարբերություն</p>

<!-- Ինքնափակվող -->
<br>
<hr>
<img src="images/cat.jpg" alt="Կատու պատուհանին">

Ատրիբուտներ

Ատրիբուտը լրացուցիչ տեղեկություն է թեգի մասին։ Գրվում է բացվող թեգի ներսում։

<img src="images/cat.jpg" alt="Կատու պատուհանին"> └┬┘ └──────┬──────┘ └┬┘ └────────┬───────┘ անունը արժեքը անունը արժեքը
Կանոններ

Արժեքը միշտ չակերտների մեջ։ Ատրիբուտները բաժանվում են բացատով։ Հերթականությունը նշանակություն չունի։

Մեկնաբանություններ

բրաուզերը դրանք անտեսում է
<!-- Այս տեքստը էջում չի երևա -->

<!-- Հարմար է բաժինները նշելու համար -->
<header> ... </header>
<!-- header-ի վերջ -->

07Ներդրվածություն և ինդենտացիա

Թեգերը կարող են լինել իրար ներսում։ Դա կոչվում է ներդրվածություն, և դա HTML-ի ամենակարևոր գաղափարն է։

✅ ճիշտ — ինչպես տուփերը իրար մեջ
<body>
    <div>
        <h1>Վերնագիր</h1>
        <p>Տեքստ</p>
    </div>
</body>
❌ սխալ — թեգերը խաչվում են
<div>
    <h1>Վերնագիր
</div>
    </h1>
Կանոն

Ինչ վերջինն է բացվել, առաջինը պիտի փակվի։ Ինչպես փակագծերը մաթեմատիկայում։ Եթե բացել ես <div>, հետո <h1>, ապա նախ պիտի փակես </h1>, հետո՝ </div>։

Ինդենտացիա

Ամեն ներդրված մակարդակ շեղվում է աջ՝ 4 բացատով (կամ Tab-ով)։ Բրաուզերի համար դա նշանակություն չունի — մարդու համար՝ ամեն ինչ։

Ինքնաբերաբար

VS Code-ում Shift + Alt + F — ինքնաբերաբար դասավորում է ամբողջ ֆայլը։ Օգտագործիր հաճախ։ Իսկ եթե ինդենտացիան կոտրվում է — ուրեմն ինչ-որ թեգ չի փակվել։ Դա անվճար սխալի ցուցիչ է։

Փորձիր ինքդ

Փոխիր տեքստը, ավելացրու նոր թեգեր։ Արդյունքը թարմանում է ինքնաբերաբար։

Արդյունքը թարմանում է գրելիս

08DevTools

Բրաուզերի ներկառուցված գործիքը, որով կարող ես տեսնել ցանկացած կայքի HTML-ը։

Ինչպես բացելՍտեղներ
ԱմենուրF12
WindowsCtrl + Shift + I
MacCmd + Option + I
Կոնկրետ էլեմենտի վրաԱջ սեղմում → Inspect

Elements ներդիրում երևում է էջի ամբողջ HTML-ը։ Կարող ես․

  • Սավառնել թեգի վրայով — էջում այն կլուսավորվի
  • Կրկնակի սեղմել տեքստի վրա և փոխել այն
  • Ջնջել ցանկացած էլեմենտ Delete-ով
Հանգիստ, ոչինչ չես կոտրի

DevTools-ի փոփոխությունները տեղի են ունենում միայն քո էկրանին և անհետանում են էջը թարմացնելիս։ Իսկական կայքին ոչինչ չի պատահում։ Ուստի փորձարկիր ազատ։

Առաջադրանք հենց հիմա

Բացիր ցանկացած ճանաչված կայք, սեղմիր F12 և նայիր Elements-ը։ Կտեսնես նույն <html>, <head>, <body> կառուցվածքը, ինչ հենց նոր գրեցինք։ Ամեն կայք այդպես է կառուցված։

09Դասարանական · իմ առաջին էջը

Քայլ առ քայլ։ Ամեն կետից հետո պահպանիր և նայիր բրաուզերում։

  1. Ստեղծիր թղթապանակ՝ lesson-01
  2. Բացիր այն VS Code-ով՝ File → Open Folder
  3. Ստեղծիր index.html
  4. Գրիր կմախքը ձեռքով (առանց ! + Tab)
  5. Գործարկիր Live Server-ը
  6. Լրացրու <body>-ն ներքևի օրինակի պես
  7. Ամեն փոփոխությունից հետո՝ Ctrl + S և նայիր բրաուզերին

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Կենդանի փորձարկում

Նույն էջը՝ խմբագրելի։ Փոխիր անունը, ավելացրու նոր բաժին։

Փոխիր և տես արդյունքը
Նկատեցի՞ր

h1-ը մեծ է, h2-ը փոքր, պարբերությունների միջև բացակ կա։ Դա բրաուզերի լռելյայն ոճն է — մենք դեռ ոչ մի CSS չենք գրել։ 6-րդ դասին կսկսենք այդ ամենը վերահսկել ինքներս։

10Տնային աշխատանք

  1. Տեղադրիր VS Code-ը, Live Server-ը և Auto Rename Tag-ը։ Ուղարկիր սքրինշոթ։
  2. Ստեղծիր lesson-01 թղթապանակը ճիշտ կառուցվածքով՝ index.html, css/, images/։
  3. Գրիր HTML կմախքը ձեռքով, առանց ! + Tab։ Առնվազն երեք անգամ՝ երեք տարբեր ֆայլում։
  4. Կառուցիր էջ քո մասին՝ առնվազն մեկ h1, երկու h2, չորս p և մեկ hr։
  5. Ավելացրու առնվազն երեք մեկնաբանություն, որոնք նշում են բաժինները։
  6. Դիտավորյալ մի՛ փակիր որևէ թեգ։ Պահպանիր, նայիր բրաուզերում և գրիր՝ ի՞նչ կոտրվեց։ Հետո ուղղիր։
  7. Ջնջիր <meta charset="UTF-8"> տողը։ Ի՞նչ եղավ հայերեն տեքստի հետ։ Վերականգնիր։
  8. Փոխիր <title>-ը և ցույց տուր, թե որտեղ է այն երևում բրաուզերում։
  9. Բացիր որևէ ճանաչված կայք DevTools-ով։ Գտիր այնտեղ <h1>-ը և փոխիր տեքստը։ Ուղարկիր սքրինշոթ։
  10. Գրիր 3–4 նախադասությամբ՝ ի՞նչ է կատարվում, երբ մուտքագրում ես կայքի հասցեն։ Սեփական բառերով։

Ստուգաթերթ

  • Ֆայլը կոչվում է index.html
  • Կա <!DOCTYPE html>
  • Կա <meta charset="UTF-8"> և հայերենը ճիշտ է երևում
  • <title>-ը իմաստալից է, ոչ «Document»
  • Բոլոր թեգերը փակված են
  • Ինդենտացիան ճիշտ է
  • Ֆայլերի անունները՝ լատինատառ, փոքրատառ, առանց բացատի

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել, ինչ է սերվերը
  • Գիտե՞մ տարբերությունը <head>-ի և <body>-ի միջև
  • Կարո՞ղ եմ գրել կմախքը առանց նայելու
  • Հասկանո՞ւմ եմ, ինչու է charset-ը պարտադիր
  • Գիտե՞մ, ինչ է ատրիբուտը
Հաջորդ դասին

Տեքստ և բովանդակություն՝ վերնագրերի հիերարխիա, ցուցակներ, հղումներ, նկարներ և ֆայլերի ուղիներ։ Էջը կսկսի իսկապես բովանդակալից դառնալ։
