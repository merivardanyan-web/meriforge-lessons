position և z-index

Մինչ այժմ ամեն էլեմենտ ապրում էր նորմալ հոսքում։ Այսօր սովորում ենք հանել այն այդտեղից՝ պիտակ նկարի անկյունում, կպչուն header, մոդալ պատուհան։ Եվ կհասկանանք, ինչու է z-index-ը երբեմն «չաշխատում»։

Նախապայման՝ Դաս 08–14 Բլոկ 1 · Դասավորություն Նախապատրաստում Դաս 18-ին

00Ի՞նչ ենք սովորելու այսօր

  • static — լռելյայնը
  • relative — տեղաշարժ և խարիսխ
  • absolute — դուրս հոսքից
  • fixed — կպած էկրանին
  • sticky — հիբրիդը
  • Կենտրոնացման երկու ձև
  • z-index և stacking context
  • Կպչուն header գործնականում

01Հինգ արժեք

ԱրժեքՄնո՞ւմ է հոսքումԻնչի՞ նկատմամբ է տեղաշարժվում
staticԱյոՉի տեղաշարժվում
relativeԱյո — տեղը մնում էԻր սկզբնական դիրքի
absoluteՈչ — տեղը անհետանում էՄոտակա relative ծնողի
fixedՈչԷկրանի (viewport-ի)
stickyԱյոՍկզբում հոսքում, հետո՝ էկրանի
ուղեկցող հատկություններ
.box {
    position: absolute;
    top: 10px;
    right: 10px;
    bottom: auto;
    left: auto;
    z-index: 10;
}
Կարևոր

top, right, bottom, left և z-index հատկությունները չեն աշխատում position: static-ի դեպքում — այսինքն՝ լռելյայն։

Եթե գրել ես top: 20px և ոչինչ չի փոխվել — առաջին բանը, որ պիտի ստուգես, position-ն է։

02relative

տեղաշարժ իր դիրքից
.box {
    position: relative;
    top: 20px;
    left: 30px;
}
Առաջ Հետո ┌────┐┌────┐┌────┐ ┌────┐ ┌────┐ │ 1 ││ 2 ││ 3 │ │ 1 │░░░░░░│ 3 │ └────┘└────┘└────┘ └────┘░ 2 ░ └────┘ └────┘ ↑ տեղը մնում է դատարկ, հարևանները չեն շարժվում
Երկու գործածություն

1. Փոքր ճշգրտում՝ պատկերակը 2px վեր բարձրացնել։ Հազվադեպ։

2. Խարիսխ դառնալ absolute երեխայի համար։ Սա իրական պատճառն է, որի համար relative-ը գրվում է 95% դեպքերում։

03absolute

Էլեմենտը դուրս է գալիս նորմալ հոսքից։ Հարևանները վարվում են այնպես, կարծես այն գոյություն չունի։

դասական զույգ՝ relative + absolute
/* Ծնողը՝ խարիսխ */
.card {
    position: relative;
}

/* Երեխան՝ ազատ տեղաշարժվող */
.card__badge {
    position: absolute;
    top: 10px;
    right: 10px;
}
┌─────────────────────┐ │ .card (relative) ┌──┴──┐ │ │ -30%│ ← .card__badge (absolute) │ ┌──────────┐ └──┬──┘ top: 10px; right: 10px │ │ նկար │ │ │ └──────────┘ │ │ Նոութբուք Pro │ └─────────────────────┘
Եթե relative ծնող չկա

absolute-ը փնտրում է մոտակա ծնողը, որի position-ը static չէ։ Եթե չգտնի — կապվում է <html>-ին և կհայտնվի էջի անկյունում։

Սա ամենահաճախ հանդիպող սխալն է․ պիտակը հայտնվում է էջի վերևում, ոչ քարտի վրա։ Առաջին բանը, որ պիտի ստուգես՝ ծնողն ունի՞ position: relative։

Ձգում չորս կողմից

ծածկույթ նկարի վրա
.overlay {
    position: absolute;
    top: 0;
    right: 0;
    bottom: 0;
    left: 0;
    background: rgba(0, 0, 0, .5);
}

/* Կարճ ձև */
.overlay { position: absolute; inset: 0; }
inset

inset: 0 = top: 0; right: 0; bottom: 0; left: 0։ Աշխատում է ինչպես padding-ի կարճ գրառումը՝ inset: 10px 20px։

04Կենտրոնացում

ձև 1՝ transform
.modal {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
Միայն top/left: 50% + transform: translate(-50%, -50%) ┌──────────────────┐ ┌──────────────────┐ │ │ │ │ │ ┌────────┤ │ ┌─────┐ │ │ │ բլոկ │ │ │բլոկ │ │ │ │ │ │ └─────┘ │ └─────────┴────────┘ └──────────────────┘ ձախ վերին անկյունն է իսկական կենտրոնում կենտրոնում, ոչ բլոկը
Ինչու է պետք transform-ը

top: 50%-ը տեղափոխում է էլեմենտի վերին ձախ անկյունը կենտրոն։ Ինքը բլոկը մնում է աջ-ներքև։

translate(-50%, -50%)-ը հետ է քաշում այն իր սեփական չափի կեսով։ Դրա գեղեցկությունն այն է, որ բլոկի չափը իմանալ պետք չէ։

ձև 2՝ flex — ավելի պարզ
.modal-backdrop {
    position: fixed;
    inset: 0;
    background: rgba(0,0,0,.6);

    display: flex;
    justify-content: center;
    align-items: center;
}

.modal {
    background: white;
    border-radius: 12px;
    padding: 24px;
    max-width: 500px;
}
Ո՞րն ընտրել

Flex — երբ կարող ես ծնողին տալ display: flex։ Ավելի պարզ և ավելի կանխատեսելի։

Transform — երբ ծնողն արդեն ուրիշ դեր ունի, կամ պիտի կենտրոնացնես միայն մեկ առանցքով։

05fixed և sticky

fixed — կպած էկրանին
.to-top {
    position: fixed;
    right: 20px;
    bottom: 20px;
    z-index: 50;
}

Չի շարժվում ոլորելիս։ Օգտագործվում է «վեր» կոճակի, cookie-ի ծանուցման, մոդալի ֆոնի համար։

sticky — կպչուն header
header {
    position: sticky;
    top: 0;              /* ՊԱՐՏԱԴԻՐ */
    z-index: 100;
    background: white;   /* ՊԱՐՏԱԴԻՐ */
}
Ոլորելուց առաջ Ոլորելուց հետո ┌──────────────┐ ┌──────────────┐ │ header │ │ header │ ← կպել է վերևին ├──────────────┤ ├──────────────┤ │ բովանդակ. │ │ բովանդակ. │ │ │ │ (ոլորվում) │ └──────────────┘ └──────────────┘
Երեք պատճառ, ինչու sticky-ն չի աշխատում

1. Չկա top (կամ bottom)։ Առանց դրա բրաուզերը չգիտի՝ որտեղ կպչի։
2. Ծնողն ունի overflow: hidden կամ auto։ Դա կոտրում է sticky-ն։
3. Ծնողի բարձրությունը հավասար է էլեմենտի բարձրությանը — կպչելու տեղ չկա։

Չկա background՝ չորրորդ խնդիր է — բովանդակությունը կերևա header-ի տակից։

fixedsticky
Տեղը հոսքումԱնհետանում էՄնում է
Հաջորդ բլոկըԲարձրանում է վերև ⚠️Մնում է տեղում
Ե՞րբ«Վեր» կոճակ, մոդալHeader, կողքի մենյու
fixed header-ի թակարդը

position: fixed header-ը դուրս է գալիս հոսքից, և առաջին բաժինը մտնում է դրա տակ։ Պիտի ավելացնես body { padding-top: 70px }՝ header-ի բարձրության չափ։

sticky-ի դեպքում այդ խնդիրը չկա — հենց դրա համար է այն ավելի լավ ընտրություն header-ի համար։

06z-index

Որոշում է՝ ո՞ր էլեմենտն է վերևում, երբ դրանք ծածկում են իրար։

շերտերի սանդղակ
.dropdown       { z-index: 10; }
header          { z-index: 100; }
.modal-backdrop { z-index: 1000; }
.toast          { z-index: 2000; }
z-index-ը չի աշխատում առանց position-ի

z-index-ը գործում է միայն, եթե էլեմենտն ունի position՝ relative, absolute, fixed կամ sticky։

Բացառություն՝ flex-տարրերի և grid-տարրերի վրա z-index-ը աշխատում է նաև առանց position-ի։

Stacking context — ամենաշփոթեցնողը

ինչու z-index: 9999-ը չօգնեց
.header  { position: relative; z-index: 1; }
.content { position: relative; z-index: 2; }

.header .dropdown { z-index: 9999; }

/* Dropdown-ը ՄԻԵՎՆՈՒՅՆ Է կմնա .content-ի տակ։
   Որովհետև ամբողջ .header-ը (z-index: 1) գտնվում է
   .content-ից (z-index: 2) ցածր, և ներսի 9999-ը
   համեմատվում է միայն .header-ի ՆԵՐՍՈՒՄ։            */
Համեմատություն միայն ՆՈՒՅՆ մակարդակում .header (z-index: 1) .content (z-index: 2) │ │ └── .dropdown (9999) └── .card (5) 1 < 2 → ամբողջ .header-ը ցածր է անկախ ներսի թվերից
Ի՞նչ է ստեղծում stacking context

position + z-index (ոչ auto), opacity 1-ից պակաս, transform, filter, will-change։

Այսինքն՝ opacity: 0.99-ը կարող է անսպասելիորեն կոտրել z-index-ի տրամաբանությունը։ Երբ ինչ-որ բան չի աշխատում, փնտրիր հենց այս հատկությունները ծնողների վրա։

Կանոն

Օգտագործիր ընդամենը 4–5 արժեք՝ 10, 100, 1000, 2000։ Եթե սկսում ես գրել 9999, 99999 — խնդիրը z-index-ը չէ, այլ stacking context-ը։

07Խաղահրապարակ

Ոլորիր նախադիտման ներսում
Փորձիր

1. Ջնջիր .card { position: relative }-ը — ո՞ւր փախավ պիտակը։
2. Ջնջիր header { top: 0 }-ը։
3. Ջնջիր header { background }-ը և ոլորիր։
4. Փոխիր header { z-index: 100 }-ը 0-ի։

08Դասարանական · կպչուն header

Վերցնում ենք Դաս 11-ի header-ը և դարձնում ենք կպչուն։ Ապա ավելացնում ենք պիտակ ապրանքի քարտին։

css/main.css
/* ---------- Կպչուն header ---------- */
header {
    position: sticky;
    top: 0;
    z-index: 100;
    background: #ffffff;
    box-shadow: 0 1px 4px rgba(0,0,0,.08);
}

/* ---------- Խարիսխներով նավիգացիա ---------- */
html {
    scroll-behavior: smooth;
    scroll-padding-top: 80px;   /* header-ի բարձրությունը ⭐ */
}

/* ---------- Պիտակ քարտի վրա ---------- */
#products .wrapper {
    position: relative;      /* խարիսխ */
}

.badge {
    position: absolute;
    top: 10px;
    left: 10px;
    z-index: 2;
    background: #c62828;
    color: #ffffff;
    padding: 4px 10px;
    border-radius: 999px;
    font-size: 0.75rem;
    font-weight: 700;
}
scroll-padding-top — շատ օգտակար

Խարիսխով հղումը (Դաս 2՝ href="#contacts") ոլորում է այնպես, որ բաժինը հայտնվի էկրանի հենց վերևում։ Բայց այնտեղ արդեն կպչուն header-ն է — և վերնագիրը ծածկվում է։

scroll-padding-top: 80px-ը ասում է․ «կանգնիր 80px շուտ»։ Մեկ տող, և բոլոր խարիսխները ճիշտ են աշխատում։

HTML
<div class="col w-33 w-md-50 w-sm-100">
    <article class="wrapper">

        <span class="badge">-30%</span>

        <picture>
            <img src="images/laptop.jpg" alt="Նոութբուք Pro">
        </picture>

        <div class="card__body">
            <h3 class="title-4 mb-10">Նոութբուք Pro</h3>
            <p class="price">450&nbsp;000 ֏</p>
        </div>

    </article>
</div>
Ուշադրություն՝ overflow: hidden

Դաս 8-ում .wrapper-ին տվեցինք overflow: hidden՝ որ նկարի անկյունները կտրվեն։ Դա նշանակում է, որ պիտակը չի կարող դուրս գալ քարտից։

Եթե դիզայնում պիտակը մասամբ դուրս է քարտից — պիտի հանես overflow: hidden-ը և կլորացնես նկարը առանձին՝ picture img { border-radius: 12px 12px 0 0 }։

09Տնային աշխատանք

  1. Ցուցադրիր relative-ի և absolute-ի տարբերությունը՝ երեք բլոկ, միջինը տեղաշարժված։ Նկարագրիր, ինչ եղավ հարևանների հետ։
  2. Ավելացրու պիտակ քարտի անկյունում։ Ապա ջնջիր ծնողի relative-ը և գրիր՝ ուր գնաց այն։
  3. Կառուցիր ծածկույթ նկարի վրա՝ inset: 0-ով և կենտրոնացված տեքստով։
  4. Կենտրոնացրու բլոկ երկու ձևով՝ transform-ով և flex-ով։ Համեմատիր կոդի ծավալը։
  5. Դարձրու header-ը կպչուն։ Ջնջիր top: 0-ը և նկարագրիր արդյունքը։
  6. Ջնջիր header-ի background-ը և ոլորիր։ Ուղարկիր սքրինշոթ։
  7. Ավելացրու scroll-padding-top և ստուգիր խարիսխներով նավիգացիան։ Ջնջիր և համեմատիր։
  8. Կառուցիր «վեր» կոճակ՝ position: fixed-ով։
  9. Վերարտադրիր stacking context-ի խնդիրը՝ երկու բլոկ z-index: 1 և 2, առաջինի ներսում՝ z-index: 9999։ Բացատրիր, ինչու չաշխատեց։
  10. Կառուցիր մոդալ պատուհան՝ ֆոնով (fixed + inset: 0), կենտրոնացված պատուհանով և փակելու կոճակով անկյունում (absolute)։ JavaScript պետք չէ — պարզապես ցույց տուր տեսքը։

Ստուգաթերթ

  • Ամեն absolute-ի ծնողն ունի relative
  • sticky header-ն ունի top, z-index և background
  • Կա scroll-padding-top՝ header-ի բարձրության չափ
  • z-index-ի արժեքները սանդղակի վրա են (10/100/1000)
  • Չկա z-index: 9999
  • Fixed տարրերը չեն ծածկում կարևոր բովանդակությունը հեռախոսում

Ինքնաստուգում

  • Կարո՞ղ եմ բացատրել relative-ի և absolute-ի տարբերությունը
  • Գիտե՞մ, ինչու է պետք translate(-50%, -50%)
  • Հասկանո՞ւմ եմ, ինչու sticky-ն երբեմն չի աշխատում
  • Կարո՞ղ եմ բացատրել stacking context-ը
  • Գիտե՞մ տարբերությունը fixed-ի և sticky-ի միջև
