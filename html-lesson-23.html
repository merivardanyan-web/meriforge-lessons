Ադապտիվություն, հղկում, հրապարակում

Երեկ էջն աշխատում էր համակարգչում։ Այսօր այն պիտի աշխատի ամենուր՝ 320px-ից մինչև 1920px, մկնիկով և ստեղնաշարով։ Եվ վերջում՝ հրապարակում ինտերնետում։

Նախապայման՝ Դաս 22 Բլոկ 1 · Նախագիծ Աուդիտ և deploy
Գործնական մասը

Այս դասի տեսությունից հետո բացիր Առաջադրանք 2-ը․ այնտեղ քայլ առ քայլ առաջադրանքն է, starter ֆայլերը և ստուգաթերթը։ Դասից հետո՝ Առաջադրանք 3-ը (մնացած հինգ էջը, մեկ շաբաթ)։ Պատրաստի օրինակը նույն թղթապանակում է, բայց բացիր այն միայն ավարտելուց հետո։

Վերնագրերը չկան, որովհետև դրանք clamp()-ով են (Դաս 22)։

Երբ հիմքը ճիշտ է կառուցված, ադապտիվության բլոկը կարճ է։ Եթե այն 200 տող է — ինչ-որ բան սխալ է հիմքում։

400px breakpoint — ինչու

Քարտի ներսում գինը և կոճակը space-between-ով են։ Շատ նեղ էկրանին կոճակի տեքստը կսեղմվի երկու տողի։

Սա breakpoint-ի ընտրության ճիշտ ձևն է (Դաս 14)՝ ոչ թե «այս սարքի համար», այլ «այստեղ է կոտրվում»։ Նեղացրու դանդաղ և գտիր այդ կետը։

Այս մենյուն թերի է — և դա գիտենք

Դաս 18-ից՝ CSS-տարբերակը չի փակվում հղումին սեղմելուց հետո, Esc-ով կամ դրսում սեղմելիս։ Նաև aria-expanded-ը չի թարմացվում։

Այսօր դա ընդունելի է — մենք CSS բլոկում ենք։ JS բլոկի Դաս 11-ում այս ֆայլը կվերցնենք և կվերաշարադրենք մենյուն ճիշտ։

Գրիր դա README-ում որպես հայտնի սահմանափակում։ Իրական աշխատանքում հայտնի թերությունը փաստագրելը պրոֆեսիոնալիզմի նշան է, ոչ թույլության։

03Ստուգում բոլոր չափերով

ԼայնությունԻ՞նչ ստուգել
320pxԱմենափոքրը։ Հորիզոնական սքրոլ չկա՞
375pxԲուրգերն աշխատո՞ւմ է, կոճակները սեղմելի՞ են
576pxՑանցը 1 սյուն է դառնում
768pxԱնցում բուրգերի ↔ մենյուի
992pxՊատերը փոխվում են
1440pxՍովորական նոութբուք
1920pxՏեքստը շատ չի՞ ձգվում
Դանդաղ քաշելու մեթոդը

DevTools → Responsive ռեժիմ → բռնիր աջ եզրը և քաշիր դանդաղ 1920-ից 320։

Նայիր ոչ թե breakpoint-ներին, այլ դրանց միջև։ Հենց այնտեղ են թաքնվում խնդիրները՝ 700px-ում վերնագիրը կոտրվում է տարօրինակ, 850px-ում քարտերի միջև բացակը շատ մեծ է թվում։

04Հղկում

Այն մանրուքները, որոնք տարբերում են «աշխատում է»-ը «պատրաստ է»-ից։

վեց ուղղում
/* 1. Խարիսխները չեն մտնում header-ի տակ — Դաս 15 */
html {
    scroll-behavior: smooth;
    scroll-padding-top: 80px;
}

/* 2. Երկար հայերեն բառերը չեն դուրս գալիս — Դաս 9 */
body { overflow-wrap: break-word; }

/* 3. Ընտրված տեքստի գույնը */
::selection {
    background: var(--accent);
    color: var(--on-dark);
}

/* 4. Տեքստի օպտիմալ լայնություն hero-ում — Դաս 7 */
#hero h1 { max-width: 18ch; }
#hero .hero__lead { max-width: 50ch; }

/* 5. Քարտի ամբողջ մակերեսը՝ սեղմելի */
.card__title a::after {
    content: "";
    position: absolute;
    inset: 0;
    z-index: 1;
}

/* 6. Անիմացիաների հարգանք — Դաս 21 */
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: .01ms !important;
        transition-duration: .01ms !important;
        scroll-behavior: auto !important;
    }
}
Հինգերորդի մասին առանձին

::after-ը inset: 0-ով քարտի հղումի վրա դարձնում է ամբողջ քարտը սեղմելի՝ առանց ամեն ինչը <a>-ի մեջ փաթեթավորելու։

Առավելությունը՝ էկրանընթերցիչը կարդում է միայն վերնագիրը որպես հղում, ոչ ամբողջ քարտի բովանդակությունը։ Իսկ մկնիկով սեղմելի է ամենուր։

Պայման՝ .card-ը պիտի ունենա position: relative (արդեն ունի), իսկ «Գնել» կոճակին պիտի տաս position: relative; z-index: 2, որ այն մնա սեղմելի։

05Հասանելիության աուդիտ

Ձեռքով ստուգում — 10 րոպե

  1. Ձեռքդ վերցրու մկնիկից
  2. Tab — առաջինը պիտի հայտնվի skip link-ը
  3. Անցիր ամբողջ էջով միայն Tab-ով
  4. Ամեն պահի պիտի տեսնես, թե որտեղ ես
  5. Հերթականությունը պիտի համընկնի տեսողականին
  6. Enter-ով բացիր բուրգերը
  7. Հասիր footer և վերադարձիր Shift+Tab-ով
Ֆոկուսի թակարդ բուրգերում

Երբ մենյուն փակ է, դրա հղումները translateX(100%)-ով դուրս են էկրանից — բայց դեռ ֆոկուսվում են։

Արդյունքում Tab-ով նավարկողը «կորչում է» անտեսանելի հղումների մեջ։

Ժամանակավոր լուծում CSS-ով՝
@media (max-width: 768px) {
  .menu { visibility: hidden; }
  .nav-toggle:checked ~ .row .menu { visibility: visible; }
}

visibility: hidden-ը հանում է էլեմենտները Tab-ի հերթից և միևնույն ժամանակ անիմացվում է (Դաս 18)։

Ամբողջական ստուգաթերթ

  • Կա lang="hy"
  • Կա մեկ h1
  • Վերնագրերը չեն ցատկում (h2 → h4 ❌)
  • Բոլոր նկարներն ունեն alt
  • Դեկորատիվ նկարներն ունեն alt=""
  • Ֆորմայի բոլոր դաշտերն ունեն label
  • Պատկերակ-կոճակներն ունեն aria-label
  • Բոլոր nav-երն ունեն aria-label
  • Ֆոկուսը տեսանելի է ամենուր
  • Կոնտրաստը ≥ 4.5:1
  • Սեղմելի տարածքները ≥ 44×44px
  • Կա prefers-reduced-motion
  • Կա skip link

1. Ֆայլի անունը — գլխավոր էջը պիտի լինի ուղիղ index.html, փոքրատառ։ Index.html-ը չի աշխատի։

3. Բացարձակ ուղիներ — /images/laptop.jpg-ը (առաջին շեղագծով) կփնտրի կայքի արմատում, ոչ քո թղթապանակում։ Օգտագործիր images/laptop.jpg։ Դա Դաս 2-ի կանոնն է, և հենց այստեղ է այն վրեժ լուծում։

README.md
# ՏեխնոՄարկետ

Landing page — HTML/CSS բլոկի վերջնական նախագիծ։

**Դեմո՝** https://username.github.io/technomarket/

## Տեխնոլոգիաներ
- Սեմանտիկ HTML5
- CSS՝ փոփոխականներ, Flexbox, Grid
- Ադապտիվ՝ 320px–1920px
- Առանց գրադարանների

## Կառուցվածք
- `css/global.css` — վարքագիծ և utility-դասեր
- `css/main.css` — այս նախագծի արժեքները
- Դասավորության համակարգ՝ `main > section > .row > .col > .wrapper`

## Հայտնի սահմանափակումներ
- Բուրգեր-մենյուն իրականացված է CSS-ով (checkbox)։
  Չի փակվում Esc-ով և հղումին սեղմելուց հետո։
  Կուղղվի JS բլոկում։

08Վերջնական ընդունում

Անցիր ամբողջ ցուցակով։ Ամեն «ոչ»-ը՝ առաջադրանք։

Տեսք

  • Համապատասխանում է մակետին
  • Բոլոր հեռավորությունները սանդղակի վրա են
  • Տառաչափերը 5-ից քիչ են
  • Կլորացումները հետևողական են
  • Ստվերները մեկ սանդղակից են

Ադապտիվություն

  • Աշխատում է 320px-ից 1920px
  • Չկա հորիզոնական սքրոլ
  • Բուրգերն աշխատում է
  • Ցանցերը ճիշտ են վերակառուցվում
  • Կոճակները հեռախոսում հարմար են

Կոդ

  • :root-ից դուրս HEX չկա
  • Կմախքը հետևողական է
  • Չկա !important (բացի reduced-motion-ից)
  • Չկա inline style (բացի փոփոխականների)
  • HTML-ը վալիդ է
  • Դասերի անունները հասկանալի են

Հասանելիություն

  • Ամբողջ էջն անցնելի է Tab-ով
  • Ֆոկուսը տեսանելի է
  • Կոնտրաստները ≥ 4.5:1
  • Lighthouse Accessibility = 100

Հրապարակում

  • Կոդը GitHub-ում է
  • Էջը հասանելի է հղումով
  • Բոլոր նկարները բեռնվում են
  • Ստուգված է իրական հեռախոսում

09Տնային աշխատանք

  1. Ավելացրու ադապտիվության բլոկը main.css-ի վերջում։
  2. Իրականացրու բուրգեր-մենյուն։ Ստուգիր Tab-ով և Space-ով։
  3. Ուղղիր ֆոկուսի թակարդը՝ visibility-ով։ Ցույց տուր՝ առաջ և հետո։
  4. Անցիր 7 լայնությամբ և ուղարկիր 7 սքրինշոթ։
  5. Քաշիր պատուհանը դանդաղ 1920-ից 320 և գրիր ամեն խնդիր, որ գտար breakpoint-ների միջև։
  6. Ավելացրու վեց հղկման ուղղումը։
  7. Կարդա ամբողջ էջը բարձրաձայն։ Ուղղիր բոլոր տառասխալները։
  8. Գործարկիր Lighthouse-ը Incognito-ում։ Ուղարկիր սքրինշոթ։ Ուղղիր ամեն ինչ, ինչ 90-ից ցածր է։
  9. Հրապարակիր GitHub Pages-ում։ Բացիր հեռախոսում։
  10. Գրիր README՝ ներառյալ «Հայտնի սահմանափակումներ» բաժինը։ Ուղարկիր հղումը։

Ի՞նչ ես իսկապես սովորել

Ոչ թե «CSS հատկություններ»։ Դու սովորել ես․

· Կարդալ մակետ և հանել դրանից համակարգ
· Կառուցել CSS ճարտարապետություն, որը չի փլվում
· Մտածել ոչ միայն մկնիկով նավարկողի մասին
· Ստուգել սեփական աշխատանքը
· Ազնվորեն փաստագրել սահմանափակումները

Հատկությունները կմոռացվեն և կփոխվեն։ Այս հմտությունները՝ ոչ։
